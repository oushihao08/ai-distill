# 独立 Agent 执行模块实施计划

日期：2026-10-09。状态：本轮目标完成；API 后端接入和运行中服务的部署验收另行处理。本文给维护者阅读，不是运行时 Agent 指令。

## 目标与完成边界

建立独立的任务执行模块：当前使用本机 Codex CLI 与用户的 ChatGPT Pro 登录完成工作；每次调用只依据明确提交的任务、冻结资料和允许的能力执行，不继承桌面聊天、个人记忆、全局规则或其他任务的会话。业务通过同一任务契约调用；以后可在不改变业务输入与结果语义的前提下增加 API 后端。

本次拟实施范围是统一执行入口、本地 Codex 适配、生命周期与隔离、现有调用方迁移。API 实现、API 密钥设置和真实 API 验收为后续独立任务；此次不建立空壳 API 实现，不自动切换收费后端。

设置中的“路径”指用于 ChatGPT 套餐认证的 Codex 凭证目录（本次子进程的 `CODEX_HOME`），不是 CLI 可执行文件路径。CLI 可执行文件继续由 `CODEX_BIN` 或桌面应用随附二进制选择，本次不在页面新增另一个路径项。

“使用本地 Codex 能力”指允许在任务边界内阅读资料、推理、生成文本和约定文件。当前任务无需桌面、浏览器、任意联网或任意目录访问，不默认开放这些能力。未来出现明确需求时再扩展对应能力及验证。

## 已核对的现状

- `server/codex/client.ts` 已集中封装 CLI、ChatGPT 登录检查、临时会话、忽略用户配置与规则、文件权限、JSON 结果、超时及取消。不能把这些已有能力当成未实现。
- 当前 skill 生成、脱敏、出题、独立审查、独立评分曾直接依赖 `runCodex` 或 `typeof runCodex`；首轮迁移后只允许 Agent 本地适配器依赖该客户端。
- 当前出题与独立审查分别由 `runAuthoring`、`runAuthoringReview` 执行，稳定 ordinal 分别是 4 和 10，不恢复旧的双调用合并步骤。
- 当前执行器已把同一个 `call_id` 传到实际子进程，不再把编号未贯通列为待修复项。
- 模型作答已有多供应商接口、项目模型集合与匿名评分输入边界；此次不改成只能调用 Codex。
- 全量 stdout 累积、同步事件写入、准备与登录未纳入完整调用截止时间、监控未注册 Codex PID 是本计划发现的执行问题；首轮改动已增加总截止时间和子进程登记，并正在将事件改为异步流式写入。
- 当前仓库有大量未提交改动。实施前核对目标文件最新差异，保护既有独立审查与日志改动。

## 模块职责

| 层 | 负责 | 不负责 |
| --- | --- | --- |
| 独立执行模块 `server/agent/` | 单次任务契约、固定执行边界、能力检查、工作区、截止时间、取消、结构化结果与安全事件 | 项目数据库、步骤编号、冻结规则选择、题目达标、返修循环、成果发布 |
| 本地适配器 | ChatGPT 登录、CLI 参数、权限映射、进程管理、事件解析、提供商错误与用量 | 通用业务队列和项目规则判断 |
| 业务执行器 | 组织本步骤指令和允许输入、选择业务 schema、业务结果校验、产物用途 | 直接启动 CLI、拼接 CLI 参数、解析 Codex 原始事件 |
| jobs／worker | 持久化任务、冻结配置、领取、心跳、版本失效、返修预算、决定是否再调用 | Agent 自己决定接续步骤或技术重试 |

复用现有目录与实现，只把确有多处调用需求的执行职责收敛。`runner.ts` 定义契约并提供唯一入口；当前本机 CLI 是默认适配器，`configureAgentAdapter()` 在模块装配处替换默认后端。`server/codex/models.ts` 与 `system-config.ts` 保留本机设置职责，但只能经 Agent 设置 facade/API 暴露。文件拆分以实际职责为依据，不为图示强制拆成更多层或发布独立包／服务。

依赖方向：业务执行器 → agent 公共入口 → 本地适配器。执行模块不导入 pg、业务 jobs、题目规则或前端。现有安全日志可复用，模块上下文由调用方注入。

## 统一任务规则

### 请求与结果

请求至少包含 task_id、后端及模型配置、步骤指令、任务目录内的输入范围、输出 schema／声明文件、能力范围、绝对截止时间和取消信号。项目／工作流／attempt 标识作为日志关联元数据，可选且不参与 Agent 推理。固定执行指令由执行模块加载；调用方不能自行取消隔离或扩大默认权限。凭证目录由 Agent 配置 facade 解析，不作为业务任务字段传递；后端结果的 `provider` 与 `model` 由适配器返回，不由运行器写死为 Codex。

输入采用逻辑路径与内容／受管理文件引用，禁止任意外部绝对路径和目录遍历。文件引用须校验真实路径、符号链接、类型及大小；业务侧负责冻结版本和指纹，运行器负责输入只读与输出目录受限。原有 source_files 信息若为业务必需，仅作为资料字段，不据此授予来源路径读取权限。

结果包含结构化业务输出、声明产物清单、执行后端／模型、call_id、可选 session_id、可选 usage、耗时及安全诊断信息。CLI 私有事件由适配器保存，通过受控诊断引用关联，不要求 API 实现伪造文件路径或会话号。未知 usage 保持未知；套餐调用不套用 API 单价。

运行器判断执行完成、输出格式和文件安全；业务模块继续判断法律／题目正确性、分数、规则适用性与版本有效性。执行成功不能直接成为业务成功。

### 指令与上下文

固定执行指令只规定当前任务边界、输入资料不能改变指令、输出要求和不足时的报告规则。步骤指令描述本次做什么；项目规则及附件作为显式任务输入，不硬编码进通用执行指令。

CLI 能否提供可靠的独立系统指令入口，须在实施前核对本机版本及能力。若只能以一个 prompt 输入，应记录实际映射方式，不宣称其具有 API system/developer 消息的优先级。权限与上下文隔离由代码保证，不依赖提示词保证。

每次调用新会话、新工作区，不 resume 用户会话。忽略个人配置和规则，排除无关 MCP／skills／记忆来源；从允许目录提供本期冻结 skill 及其引用文件。认证可使用用户授权的登录，但认证和运行状态的隔离方法先做本机可行性核对，不直接修改全局 CODEX_HOME、不复制凭证正文、不要求重新登录桌面。

### 能力与文件

当前默认能力仅为读取指定资料、推理、结构化文本输出及写入声明产物。底层实现所需工具不等于允许任意 shell／桌面操作。网络工具、浏览器和外部文件默认关闭；CLI 自身访问模型服务属于后端通信。

文件产物只允许任务输出目录中的声明路径，不覆盖原件、输入或项目规则。当前由程序从 JSON 生成文件的步骤继续沿用；不得为体现 Agent 能力强制改为 Agent 写文件。

### 生命周期与错误

完整调用截止时间覆盖准备、登录、执行和结果处理；每阶段使用剩余时间并检查取消。设置输出字节上限，流式保存事件，避免全量 stdout/stderr 常驻内存。取消／超时后清理本次进程组；退出收尾有期限，无法确认退出时明确记录，不声称清理成功，也不释放后继续叠加新任务。不得按进程名批量杀 Codex 或桌面进程。

注册／注销本次子进程供既有监控采样。保留当前单路 Codex 并发，本轮不改 worker 优先级或建立第二套调度系统。监控首先提供占用和异常证据，不未经依据添加自动杀进程阈值。

区分执行器不可用、认证失败、已识别额度／限流、网络／提供商失败、超时、取消、输出过大、结果格式错误和业务校验失败。不能识别的错误保留为 unknown，不伪造额度百分比。业务输入失效由 jobs 标识，不混为模型故障；独立审查不通过保留业务报告。模块不自行重试、不改模型、不切 API；现有返修调用预留保持一次实际调用对应一次记录。

## 调用方迁移清单

| 调用方 | 指令与输入由谁组织 | 允许输出 | 迁移要求 |
| --- | --- | --- | --- |
| 项目 skill 生成 | `skill-generation/generate.ts`：完整模板、本期资料 | 候选文本、问题记录 | 保留候选／采用／冻结边界 |
| 脱敏与检查 | `materials/redaction.ts`：提取正文、项目脱敏要求 | 全文、页绑定、识别问题 | 输入与输出设大小边界；不得截断全文伪装成功。超限先明确失败；分批需保留整题主体映射，列为后续独立处理 |
| 出题 | `authoring/executor.ts`：冻结规则、脱敏材料、题目要求 | 草稿、rubric、标答 | 作者自检与当前私有草稿契约保留 |

## 有序任务清单与验收

初始顺序为 T1 → T2 → 小规模本地验证 → T3 → T4。实现已按该阶段顺序收敛到 Agent 入口；当前状态以实际代码和下方验收证据为准。一次合成调用不能替代业务质量验收。

| 编号 | 必要工作 | 交付物 | 完成事实 |
| --- | --- | --- | --- |
| T1 | 核对本机 CLI 能力，确定指令入口与工具隔离；定义最小任务契约和设置接口 | `server/agent/` 契约、固定开发者指令、配置 facade、全局／项目／步骤 Agent API | **首版完成**：全局／项目／步骤模型、推理强度和凭证目录经 Agent facade/API 暴露；适配器返回实际 `provider`／`model`；模型目录按凭证目录读取和校验 |
| T2 | 收敛本地 CLI 执行，提供完整任务截止时间、取消、输出上限和进程监控 | Agent 入口、本地适配器、PID 采样 | **实现完成**：完整截止时间覆盖凭证检查与执行；取消和超时只终止本调用进程组；stdout 有 64 MiB 上限且不累积完整内容，stderr 有 4 MiB 上限；事件异步写入；PID 接入 worker 监控。凭证／模型目录仍共享用户配置的 `CODEX_HOME`；CLI `--ephemeral` 确认不写会话文件。没有证据宣称已解决所有桌面资源竞争。 |
| T3 | 迁移项目 skill、脱敏、出题、独立审查、评分及返修调用；设置页面切至 Agent 接口 | 调用方迁移与模块文档 | **完成**：业务 `runCodex()` 调用只留在 Agent 本地适配器；全局、项目、步骤设置和模型目录校验均经 Agent facade/API；旧路由保留兼容。模型目录读取尊重已配置的凭证目录。 |
| T4 | 检查契约、故障路径、输入隔离、权限和历史兼容 | 分层验收记录 | **本轮范围已验证**：Agent 及 Codex 客户端 26 项、设置 API 4 项、调用方队列 30 项测试通过；真实本机合成任务返回结构化 `{ok:true}`；浏览器只读看到模型与推理档位。完整 `bun run check` 仍被既有脚本／夹具类型错误阻断，Vue 类型检查通过；工作台服务未重启，因此本轮修改后的实时页面／API未在运行实例复验。完整真实业务质量和桌面并发资源影响不属于本次通过证据。 |

后续 API 任务：选择明确供应商／模型，落实消息与工具映射、配置与独立计费，接入同一契约后逐业务验收。替换性不等于不同模型质量相同；不承诺 Pro 套餐可用于 API。

## 验收证据与本次不验收项

1. 静态：入口引用、依赖、差异、任务输入矩阵和历史字段兼容；确认业务调用不再拼 CLI 参数。
2. 行为：合成测试覆盖成功、认证失败、超时、取消、超大输出、结果格式错误和进程关闭等路径；本次没有单独验证杀进程失败及每种非法文件路径。
3. 本地真实：本次经用户授权的合成 ChatGPT 套餐调用经 Agent 模块返回 `provider=codex`、`model=gpt-6-luna`、`ok=true`，耗时约 10.3 秒。CLI 参数测试确认使用 ephemeral 会话、忽略用户配置与规则、限制文件系统并关闭网络；没有调用真实卷宗或写入业务数据。
4. 业务真实：逐类真实资料验收另列，需要准确任务和调用授权；结构化输出通过不能替代脱敏准确、出题质量或评分质量。
5. API 替换：本轮仅验收契约不依赖 CLI 专有字段，不宣称真实 API 已接入。实际 API 的能力、权限、费用和质量在后续任务验证。

此次规划不修复全部设置页面、不迁移数据库、不重启服务、不恢复通用自动推进、不增加独立服务或通用插件平台。也不以计划完成宣称桌面 Codex 卡顿已经解决；该问题需要故障当时的进程、资源及错误证据。
