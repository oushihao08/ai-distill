# 可选脱敏 DOCX 导出计划

状态：代码与本机合成 DOCX 验收完成；本轮未运行真实业务工作流或浏览器服务。LibreOffice 能打开并转换 DOCX 为两页，文本及分页正确；macOS Quick Look 预览确认中文、表格和附件边界可读。

## 当前事实

- PDF 入库后由 MinerU 提取逐页文本；独立脱敏步骤读取该结果。
- 脱敏当前保存 `redacted_markdown` 和 `redacted_index`，没有 DOCX 文件生成器。
- 工作流页面在现有步骤全部完成后显示“全部完成”；发布为 ordinal 8。独立审查为历史步骤，不参与当前工作流完成状态。
- `projects/<项目>/questions/` 是输入目录，扫描器会把其中 PDF、DOCX、TXT、MD 识别为材料。项目已经预留 `outputs/` 作为成果目录，但实际产物当前主要写入 `.storage/`。
- DOCX 生成必须使用当前有效的脱敏产物，不能读取原始提取正文来生成文件。

## 不改变的边界

- DOCX 是用户手动触发的可选导出，不新增工作流步骤、不自动运行，也不是完成或发布的门槛。
- 导出使用独立 HTTP 请求，不进入 worker／步骤队列，不复用或改写任何既有步骤任务；除新增的导出产物索引外，不写 `steps`、`step_attempts`、发布或返修状态。
- 生成失败只返回导出错误；不得回滚、重试、重置或改动入库、脱敏、出题、审查、作答、评分、发布及返修状态，也不触发这些流程重新执行。
- 不修改原始 PDF，不把 DOCX 写进 `questions/题目/`，不代替用户向第三方网站上传。
- 第一版只做重新排版的 DOCX，不承诺复刻扫描 PDF 的原页面布局；不生成 PDF。

## 隔离实施顺序

1. 先复用现有脱敏结果和成果文件能力，确认只读输入及导出索引所需字段；不改步骤注册表、工作流状态机、worker 调度和现有任务输入契约。
2. 独立实现 DOCX 转换和文件落盘；导出接口只读取已完成工作流的当前脱敏产物，并只创建／更新导出产物索引。
3. 最后增加详情页手动按钮和下载入口。按钮仅在工作流已完成时出现；页面不自动调用接口，不把导出加入批量派发、重试或“全部完成”的计算。
4. 定向验证导出前后既有工作流状态及附件输入清单不变，并验证导出失败路径不会产生或修改步骤尝试。

## 实施任务

1. 新增最小 DOCX 生成器，以已校验的 `redacted_markdown` 为唯一正文来源。按附件和原页码保留分界、顺序及可读段落；文件名使用题目名称，不带原附件中的个人信息。只实现本次需要的段落、标题、分页和常见表格呈现。
2. 新增独立的按需生成接口。服务端校验题目存在、发布成功、所有当前要求的可见步骤均已完成、没有活动尝试，并确认最新脱敏产物仍绑定当前附件集合；任一条件不满足即拒绝，不派发任何工作流任务。
3. 生成后将 DOCX 放入项目的独立成果目录：`<项目目录>/outputs/<题目目录标识>/脱敏材料.docx`。原始 `questions/` 树保持不变。对输出根目录做规范化与路径包含校验，避免题目目录标识导致越界写入。
4. 记录导出与脱敏尝试及脱敏产物 SHA-256 的关联，提供安全下载。重复触发时按当前脱敏指纹更新或复用同一题目导出，不累积重复文件；上游材料或脱敏结果变化后，旧 DOCX 不再显示为当前有效文件。
5. 在题目详情页只于常规流程完成后显示“生成脱敏 DOCX”按钮；生成完成后提供下载。此操作不占用出题、作答、评分或返修队列，也不触发项目批量自动化。
6. 补充项目 `outputs/README.md`、相关模块 README、架构说明及目录计划索引，记录成果目录用途和与输入目录的边界。

## 验收标准

- 在没有点击导出前，完整跑完现有工作流的结果、状态和步骤顺序与当前一致；不自动出现 DOCX 生成任务。
- 流程未完成、当前脱敏失败/过期、附件已变化或存在活动任务时，按钮不可用，服务端也拒绝直接调用接口。
- 导出不创建步骤或 worker 任务；成功时只新增／更新独立导出产物索引，失败时步骤、尝试、发布、返修状态与当前附件清单均不变。
- 完成后手动触发能生成可打开的 DOCX，中文可读，附件顺序和原页码清楚，正文来自当前脱敏产物；不混入原始 OCR 文本。
- 生成文件位于对应项目 `outputs/<题目目录标识>/`，输入 `questions/` 文件清单和指纹不变；题目详情可以下载该文件。
- 重复点击不会生成重复记录；脱敏或附件更新后不能继续下载旧文件为当前结果。
- DOCX 生成或存储失败不影响步骤、发布或返修状态；已有入库、脱敏、出题、评分、发布及项目 XLSX 导出保持原行为。
- 为新增后端行为编写并运行定向单元测试；另以 Word/LibreOffice 打开一份生成文件核对版面。真实第三方网站上传不在本计划验收范围。

## 暂不纳入

保留原扫描 PDF 版式的逐字黑块遮盖、扫描页像素级不可逆脱敏、自动上传第三方网站、PDF 导出、批量自动生成，以及用文件生成结果替代工作流脱敏审核。
