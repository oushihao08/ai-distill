## 2026-10-11：结构化脱敏与无遗漏文本输出

### 本次目标与严格边界

数据库保存具有 MinerU 内容结构的脱敏版本。出题、作答与评分使用由该版本确定性拼接的正文；DOCX 使用同一版本的结构与文字生成。唯一允许的文字变化是明确的脱敏替换，不能总结、润色、纠错、去重或省略；不能为缩短输入删除已识别内容。

图片内文字也须识别并脱敏，包括身份证、票据等；最终文本与 DOCX 不保留图片、图片链接或图片占位符。样式范围为标题层级、段落、列表、表格及必要分页，不承诺像素级复刻扫描件。

实施仅覆盖结构化代码路径和合成夹具；没有发送真实项目材料或调用真实脱敏模型，没有写远程数据库、重启服务或运行真实工作流。结构写入已按显式版本启用，旧无结构产物通过兼容路径读取；新脱敏/导出未对已有工作流批量重跑。

### 采用的最小数据方案

复用现有 artifacts：`content` 当前是存放 JSON/正文的 text 列，不假定为 JSONB。首选扩展现有 JSON 内容，不新建表、不新增业务步骤、不另建调度器。

1. `private_extracted_pages` 保留 `source_sha256`、`pages` 等兼容字段，新增有格式标识的文档结构。结构保存原块顺序、文本字段、标题层级、表格行列/合并关系及来源页；原始完整响应继续只存私有诊断边界。后续以结构中的文字为唯一提取正文来源，避免分别转换两份不一致内容。
2. `redacted_index.materials[]` 保留 `material_id`、`markdown` 等字段，并新增同一材料的脱敏结构、格式版本及其摘要。脱敏结构只含处理后的文字和必要格式；不夹带旧文字副本、原始 HTML 属性里的敏感值、外部地址或诊断响应。
3. `redacted_markdown` 继续作为现有下游的文字产物。新结构格式下，它由脱敏结构投影生成；附件、页边界由程序保留。名字沿用现有契约，内容不包含 MinerU JSON、坐标、内部块标识、图片占位符或无用诊断信息。
4. 结构、逐材料正文、合并正文和摘要在同次脱敏尝试中发布；保存前核对投影一致性，沿用当前事务、取消和当前附件指纹复核。任何一份缺失或不一致均不发布部分成功。

投影必须先明确所有“识别内容”字段：正文、标题、列表文字、表格每个单元格、图注、表注、脚注、公式及图片补识别文字。表格 HTML 先正确解码为结构和文字，不能用正则去标签导致连字或丢失单元格。结构字段与冗余展示字段之间只按已验证的格式映射选择同一内容来源，不进行文本相似去重；来源不同但文字相同的块仍分别保留。遇到未支持且可能承载正文的块/字段，保留私有原结果并明确报出待适配问题，不静默跳过。

### 逐字保留的实现依据

新格式不让模型返回改写后的整页。程序固定文档骨架和全部可处理文字字段，模型接收必要的文字、字段标识与上下文，返回本批已处理标识以及具体敏感片段的替换操作。排版属性、坐标和整份 MinerU 原始 JSON 不发送给模型。

- 操作绑定源字段/块标识与源指纹，包含原片段和替换值。程序精确定位；重复片段必须明确对应位置，不使用模糊匹配或无条件全局替换。
- 操作不能越界、重叠、指向错误材料或任意改写非敏感事实。空返回、漏处理标识和输出截断均不能被解释为整批处理成功；确认无敏感内容的块可以有已处理标识而无替换操作。
- 由程序在原始文字上应用通过校验的替换，未被替换的字符直接沿用原文。不使用 `trim()`、空白归一化、Markdown 去格式或去重处理内容文字；表格投影只增加明确分隔，不删单元格文字。
- 继续按现有有界批次运行。超长文字可按可追踪位置分片，不能截断；所有片段须完整覆盖并正确合并。保留现有取消、预算、调用记录和有限结构重试语义，不增加无限内容重试。
- 结构校验能证明“未替换位置逐字不变”，不能仅凭模型标注证明“所有替换都合理、敏感信息全部处理”。具体敏感片段选择和替换正确性另用样本差异核验，不能把正确的 JSON 当作脱敏质量通过。

逐字完整性以已经识别出的内容为基准。OCR 未识别出的文字需要在提取验收中核查；不能用后续拼接校验证明原扫描件无漏识别。

### 不破坏当前流程的兼容和启用方式

1. 不改可见步骤、ordinal、派发入口、Agent/API 并发、worker 调度、发布/达标规则和模型配置优先级。不增加自动推进、图片附件、前端设置或第三方上传功能。
2. 新结构用显式格式版本识别。历史无结构数据继续按现有文本路径读取、评分与导出；不得伪造原排版，不得自动回填或重写历史产物。非 MinerU 的 DOCX/TXT/MD 保留现有解析路径，使用明确的文本兼容格式。
3. 提取转换、脱敏输出格式和 DOCX 渲染分别参与自己的缓存/复用依据。新增结构不能复用无结构提取缓存；旧成功脱敏不能冒充新格式成功结果。已有活动任务使用派发时冻结协议，不在运行中切换。
4. 新增格式不能改变旧任务的摘要计算。新增字段通过兼容读取进入新任务；旧出题、答案、评分和达标快照继续按原绑定读取。显式重新提取或脱敏时，沿用现有下游失效规则，不能承诺重提取后旧达标结果仍有效。
5. DOCX 复用同时核对材料、脱敏尝试、结构摘要、渲染版本和实际文件摘要。在现有 artifacts 中增加同次导出的轻量 JSON 清单产物，记录上述依据及 DOCX artifact ID/摘要；其正文和自身摘要独立校验，不把清单写进二进制 DOCX artifact 的 `content`，避免破坏正文/文件 SHA-256 契约。清单与文件索引同次提交，纳入现有导出失效与重置清理；无需新建表。没有匹配新渲染依据的旧文件不得复用为新文件。
