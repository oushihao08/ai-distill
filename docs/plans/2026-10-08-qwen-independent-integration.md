# Qwen 独立接入计划

日期：2026-10-08

本文记录独立接入的实施范围、分工及验收要求。

执行更新：2026-10-08 已实施独立配置与调用模块及后端单元测试。按用户补充要求增加 OPEN_ROUTER_KEY 路径；现有密钥被官方接口识别为管理密钥，真实模型请求返回401，需要普通调用密钥完成验收。主流程接线保留既定分工。详见[验收记录](../evidence/qwen-independent-integration.md)与[主流程接线说明](2026-10-08-qwen-main-flow-handoff.md)。

## 目标与范围

完成第五步所需的 Qwen 配置校验与 API 调用能力，使后续执行器能取得真实答案、用量和明确的失败结果。先接一个模型，不扩展多提供商框架。

本任务覆盖 F42 的 Qwen 配置部分和 F43 的调用部分。第五步持久化入队、工作流状态发布、答案产物入库及页面操作由主流程接线完成；独立模块完成不能标记 F42/F43 全部验收。

F47 作答输入包作为后续任务，待第四步产物格式确定后再实施。本轮不提前设计题目包、评分结构或 Excel 导出。

## 已确认事实与待确认项

- 当前后端为 Bun + Hono，已有原生请求能力；接入优先使用现有运行环境，不新增 SDK 或修改 package.json。
- 项目设置存于 project_step_configs；当前 validateStepConfig 只接受第 2、3、4、6、7 步，第 5 步配置尚不可用。不能把现有页面设置直接视为作答模型配置。
- shared/types.ts 中项目步骤配置仅含 provider、model、reasoning_effort，尚无模型作答契约。
- 当前 worker 只执行前两步；Codex、PDF、worker 与 UnoCSS 正处于另一条修复工作范围。
- Qwen 账号区域、实际模型 ID、凭证可用性及附件处理方式尚未核实。实施时核对阿里云官方协议及本机配置；不猜测模型能力，不读取或输出凭证内容。

本轮以脱敏文字作为材料输入，不能据此宣称支持 PDF、图片、工具调用或实际文件交付。后续若题目必须保留附件版式或要求交付文件，须先确认对应模型能力与输入协议。

## 任务清单

### 1. 核实协议，确定最小调用契约

读取当前配置及官方 Qwen 接口文档，核实账号区域、端点、模型、非流式调用参数、用量字段和错误响应。优先非流式返回，避免为当前需求引入事件处理。

输入只包含明确模型配置、题面、脱敏材料、超时和取消信号；密钥从服务端环境读取，不放入任务快照。返回完整答案文本、提供商返回的确切模型 ID、请求 ID（如有）、原始 usage、开始与结束时间及实际耗时。提供商未返回的字段保留缺失，不虚构。

若没有可用模型或凭证，继续完成本地模块与受控验证，真实调用单独记录阻碍。

### 2. 实现配置校验与调用

实现 Qwen 所需配置、响应解析、超时和取消。拒绝空答案、无效响应及不支持的输入；只发送经过明确选择的输入，禁止传入 rubric、标答、目标分数、脱敏映射或原件路径。

区分配置、认证、额度或限流、网络、超时、主动取消、提供商错误与无效响应；按官方实际响应判断。客户端返回可供主流程决定重试的错误信息，本轮不自行建立重试队列或无限重试。

错误与诊断不得包含密钥、Authorization、完整请求材料或其他私密内容。模型答案属于业务结果，由主流程保存，不写入普通日志。

### 3. 验证并交付主流程接线说明

以可控请求验证实际发出的参数、返回解析及失败行为，运行针对性后端单元测试。具备凭证与可用模型后，使用合成题面和无敏感材料做一次真实调用，记录模型、时间、返回结构及 usage，不使用真实卷宗做首次冒烟。

交付调用接口及明确接线位置：第五步配置保存、入队时固定配置、执行输入筛选、答案和用量留存、发布前版本检查。主流程须沿用现有输入版本隔离，旧任务不得覆盖新版本结果。

## 验收标准

| 结果 | 必须有的证据 |
| --- | --- |
| 配置可用性校验 | 缺失密钥、无效配置被明确拒绝；密钥不进入返回值或快照 |
| 请求边界正确 | 可控请求证明只发送题面与脱敏材料，不含评审信息和私有文件 |
| 答案与用量解析 | 正常响应保存完整答案；usage 不伪造；空答案与异常结构失败 |
| 失败和取消可识别 | 针对性单元测试覆盖认证、限流、网络、超时、取消与无效响应，诊断不泄密 |
| 真实 Qwen 接入 | 一次真实 API 调用取得有效答案及实际响应记录；未调用则写“未实测” |
| 与并行修复分离 | 修改文件核对证明未改动另一条任务负责的核心实现，公共接线缺口明确列出 |

## 本次不验收

- 第五步页面配置、任务入库与答案产物持久化的完整用户流程。
- 真实法律材料作答质量、PDF/图片附件可用性、工具执行与文件交付。
- Codex 出题、独立质检、评分、达标判定、自动返修和八步闭环。
- 多模型并发、全局调度、额度恢复、费用金额换算及每周产能。

上述能力未完成时，功能台账继续保留对应缺口，不用 API 接入成功替代端到端验收。
