# 普通出题 Codex 与手动使用能力对齐

本文只讨论普通新出和普通重出。目标是让后端作者尽量具备用户在桌面端新建会话、查看指定 skill 与当前附件后出题的能力。2026-10-11 根据当前源码、最新题目 3—6 的私有输入索引和调用快照整理；已核对项和待办分开记录，不能用工具探针代替真实题目质量验收。

## 不退化原则

普通出题保留项目工作目录、正常用户配置和项目规则、完整文件／网络权限，以及实际可用的文件读写、shell／计算、网页检索和已配置 MCP。输入检查、成果格式与诊断均不得通过关闭作者工具、收紧权限、忽略配置或规定工具调用顺序实现。每次尝试新建会话，程序只主动提供本次数据库脱敏附件、指定 skill 和步骤指令，不注入历史题包、答案、评分或个人记忆。skill 明确引用的案例卡属于出题方法参考，不能替代本题事实。

被测作答器目前只接受文字、返回文字、没有工具调用循环；题包中的 text/text/tools=[] 描述这个接口，与作者 Codex 可调用的工具无关。独立评分属于另一任务，本清单不调整评分执行器。
