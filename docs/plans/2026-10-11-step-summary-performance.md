# 步骤汇总性能优化

## 范围和约束

成果归档、Excel、DOCX 本轮不处理。不修改提示词、模型参数、工具权限、附件输入、步骤顺序、版本绑定、队列派发或失败处理。不删除历史正文，不截断当前答案或原始评分报告。

## 实施

1. 作答汇总：数据库按当前题目、附件输入摘要、模型集合取各模型最新尝试，仅返回汇总需要的字段和完整当前答案。减少历史附件正文、调用数据在数据库与 worker 之间传输。已实施。
2. 评分汇总：限定当前成功答案 ID，数据库取各答案最新评分，仅返回总分、满分、有效性、争议、提取信息和绑定。原记录中的完整评分和上下文保持不变。已实施。
3. 入库扫描和文件处理移出长事务：暂不实施。必须先覆盖文件变化、并发重置及提交失败清理，避免性能调整破坏附件一致性。
4. Worker 空闲扫描合并：暂不实施。需先取得实际查询频次和等待时间证据，保留取消、过期恢复、公平性及现有轮询时效。
