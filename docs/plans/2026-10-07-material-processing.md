# 本轮任务与验收

1. 控件收紧为36px，保持14px字体，统一由主题控制。
2. 按页提取PDF。图片页、稀疏文本或乱码页采用智谱识别；保存页码和识别方式。
3. 模型识别敏感实体，规则补充证件/电话/账号，跨材料统一替换，再做残留检查。
4. API提交持久化任务，worker领取、记录结果及失败；可下载脱敏Markdown和页码索引。

验收：后端测试检查主体替换、关键数值保留、接口错误、文本页与混合页、任务去重和前置条件；真实调用验证智谱与单页OCR，真实Neon验证任务及产物持久化。视觉效果需浏览器单独核验。

边界：本轮不实现出题与评分。OCR会将扫描页发送到智谱；实体检查也向智谱发送提取文本。脱敏映射只保存在本地受限文件，不通过下载接口公开。二次检查不能保证未知隐私绝对无遗漏，异常结果不能用于后续出题。不同原文别名不自动合并为同一人。

实现边界：pdf.ts只负责页提取与渲染；vision.ts封装识别协议；redact.ts只负责确定性替换；process.ts组织材料与文件产物；jobs.ts负责数据库排队和发布。新供应商实现VisionClient即可，不依赖业务表。
