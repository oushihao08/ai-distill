# 项目规则版本自动绑定

2026-10-09 调整：项目规则是项目级设置，不再作为单题可见步骤或单独 API 操作。出题入口自动校验并绑定当前题目使用的已发布快照；历史 ordinal=3 仅保留为内部记录身份。独立评分从成功出题尝试读取同一快照并再次校验。模型作答仍只接收题面和脱敏附件，不接收 rubric 或评分标准。

- 上游提取与脱敏必须成功。
- 首次绑定选择项目最新版本；最新仍为草稿时拒绝执行，不绕回旧版。
- 已绑定题目保留原规则版本，材料版本变化后重新检查该快照并记录新尝试。
- 验证全部快照文件指纹、skill 入口及结构完整性；重复执行仍校验快照，改写或缺失时拒绝使用。
- 保存规则 ID、版本、来源摘要、文件清单、skill 入口及未决事项；不把结构验证当成规则语义、外部资格或出题质检通过。
- 项目设置页展示资料与 skill；出题时自动绑定并沿用固定规则版本。

验证：5 项针对性单测通过；`bun scripts/verify-rule-loading.ts` 的 9 项真实 PostgreSQL、HTTP、文件检查通过，临时 schema 和文件均清理。上游成功为合成夹具，不证明真实整卷提取或八步闭环。详细结果见 [rule-loading-results.json](rule-loading-results.json)。
