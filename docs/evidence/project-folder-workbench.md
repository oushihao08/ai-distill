## 语义和边界

项目创建发现题目、记录来源清单与指纹，第一步由worker保存受管理原件。目录同步新增题目；真实材料变化使该题输入版本增加，重置后续步骤。重复同步相同目录不会覆盖数据库内的材料编辑。来源文件夹不被修改；目录中移除一个题目不会自动删除数据库历史，删除题目须显式调用删除接口。

增加、替换、删除材料保存新输入版本。并发修改用输入版本校验拒绝覆盖。最后一份材料被删除后第一步失败，不能继续提取。旧版本及旧产物保留，旧任务不能发布到新版本。

项目删除是逻辑删除，停止任务并从工作台隐藏；原始文件和执行历史保留。项目skill使用本地目录，数据库保存路径；默认独立目录仅创建目录，尚未生成SKILL.md时显示待生成。不会用空目录冒充可用skill。

步骤2配置的智谱模型和推理强度实际写入新任务快照。步骤3/4/6/7可保存模型配置，但执行器尚未接入。步骤5作答模型库、完整自动推进、独立评分、返修及导出尚未接入。
