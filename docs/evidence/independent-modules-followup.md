# 独立模块跟进验收

日期：2026-10-08。范围：费用未知原因显示、项目页浏览器流程、当前 API usage 数据质量审计。

## 页面改动与浏览器流程

`web/src/views/ProjectDetail.vue` 现在在未知 API 调用总数旁显示原因分布。当前实际项目页将 7 笔未知费用显示为“缺少价格 7”，不把未知误报为零费用。

为避免改动首期项目及其运行中的材料任务，验收使用独立临时项目和合成记录：

1. 在项目页保存第七步必需模型和逐模型最低分。
2. 从页面执行第七步，页面显示完成 1 条，产量显示合格 1。
3. 点击导出并由浏览器下载文件，页面显示已导出 1。
4. 使用 openpyxl 读取下载的 XLSX，确认成果汇总、答案评分和返修费用三个工作表，成果汇总含该合成题目。
5. 删除临时项目、工作流、尝试、配置、导出数据库行、存储文件和下载副本；随后查询确认临时行数均为 0。

下载文件 SHA-256：`81fb03997582f7e4dafbf1e0150606945ffff5332eda8ae8e06e73ce23a9e8c1`。临时 XLSX 已在读回检查后清理。

验证命令：`bun run --cwd web check`，`vue-tsc --noEmit` 退出码为 0。未运行前端单元测试；按项目约定前端不新增测试。

## 浏览器导出错误恢复

在同源项目页为首次导出请求注入一次 HTTP 500，确认页面展示错误提示且导出按钮恢复可用；第二次点击不再注入故障，真实本地 API 创建导出记录并由浏览器下载 XLSX。初次复现时，下载成功后旧错误提示仍留在页面上；在 `exportProject()` 开始时清空旧错误后，重复相同流程，成功提示显示且错误提示消失。

用 openpyxl 读取重试下载，包含成果汇总、答案评分、返修费用三个工作表，汇总有 1 条合格记录。SHA-256：`339ba1c8b73bb0022355811eb43de141a652731d11d7be183ce4c2876afd9de8`。临时项目、两条导出记录、项目目录和下载文件均已清理；清理后确认项目、工作流和导出记录数为 0。后端真实存储目录失败及恢复后的验证见[集成 JSON](independent-modules-integration.json)。

## 当前真实 API usage 审计

现有首期项目指标 API 返回：`known_calls=0`、`unknown_calls=7`、`unknown_reasons.price_missing=7`。只读检查一条 106 页的 OCR 尝试：99 页复用已缓存识别，7 页实际调用智谱 `glm-5.3-flash`；这 7 笔 usage 都保存了 prompt/completion token 字段。当前价格快照列表为空，所以系统可以保留 token 用量，但不能给出金额；99 页缓存没有重复计费。

本轮没有录入价格：已查找智谱官方公开资料，未找到可核实且适用于该模型及调用日期的单价，不能用估价填补历史费用。后续取得官方价格或账单依据后，可登记带来源和生效时间的价格快照；在此之前 UI 保持“未知”。GPT/Codex 套餐消耗排除在 API Key 费用之外。

2026-10-08 再次核对时，智谱官方[价格页](https://open.bigmodel.cn/pricing)只返回需要 JavaScript 的页面外壳；官方[模型概览入口](https://docs.bigmodel.cn/cn/guide/start/introduction)能确认模型概览应展示价格，但其具体模型页本次抓取超时。官方可读文档和价格页因此没有给出可复核的 `glm-5.3-flash` 历史单价/生效日期。搜索结果中的第三方价格汇总不能证明本账号在 7 笔调用发生时的实际适用价格，所以仍不回填价格快照。

本次浏览器验收使用合成题目，不调用供应商 API，也不证明真实题目业务闭环或供应商账单一致性。

## 导出失败隔离与重试

`scripts/verify-independent-modules.ts` 在隔离存储目录中模拟 `exports` 路径被文件占用，使 XLSX 保存失败。真实 PostgreSQL 集成检查确认导出状态记为 `failed`，工作流尝试数不变；移除存储故障后再次请求，新的导出记录成功且包含 1 条合格工作流。该验证没有运行模型。浏览器另以单次 HTTP 500 注入验证错误提示、再次点击和成功后的错误清除。

本次运行结果：`export_failure_isolated=true`、`export_retry=true`、`cleanup_complete=true`，工作簿下载 SHA-256 见 [集成 JSON](independent-modules-integration.json)。
