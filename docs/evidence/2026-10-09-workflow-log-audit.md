## 最小修复

- `classifyLogError()` 原来只读取 `status`，而模型 API 错误使用 `http_status`，导致状态丢失；现在兼容两者并保留安全原因码。
- `completeJson()` 区分 `invalid_json` 和调用方业务校验失败，不把解析异常与页数/正文异常混成一个事件；调用开始记录实际超时。
- 脱敏校验直接记录安全定位字段，仍拒绝空正文/不匹配页数，不记录材料正文或失败响应全文。
- 第一步提取队列补 workflow/attempt/provider/model 上下文，附件调用补 call/material ID。仅补业务边界，未更改 provider 实现、提取逻辑或业务结果。
