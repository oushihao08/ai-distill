# 项目飞书资料

面向维护者、操作Agent和后续填报程序。通用操作脚本留在上级scripts；此目录按项目保存资源、字段对应关系和业务约定。每个项目的config.json是登记坐标和映射的机器入口，README解释用途；不要把某项目的表ID变成通用CLI默认值。

| 目录 | 用途 |
| --- | --- |
| [doubao-high-value](doubao-high-value/README.md) | 豆包高经的人员名单、模仿项目方的题目填写表、测试表，以及一人多题的身份对应约定 |

`private/snapshot.json`由CLI只读同步生成，包含姓名、手机号、专家ID、人员字段ID及已有题目归属，仅供本机操作。各项目用精确的/private/规则忽略它；不提交到Git，不作为出题/作答/评分输入，也不把整份快照复制进Agent提示词或普通日志。

项目登记不代表应用具备全部权限、已有领取关系、已完成正式交付或获得项目方验收。新增项目须登记明确资源，不能自动扫描和复制整个组织云盘。
