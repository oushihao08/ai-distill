# 路由页面

| 文件 | 职责 |
| --- | --- |
| `ProjectGroups.vue` | 主项目首页；显示跨期主项目、期次数量，创建主项目首期、编辑主项目名称并维护新项目复制的系统级提示词 |
| `ProjectList.vue` | 指定主项目的期次列表；创建期次、通过专用身份接口编辑期号/期名、编辑期次业务配置或删除期次；汇总该主项目内材料包记录和题目 |
| `MaterialLibraryView.vue` | 全局材料包新建、文件集合上传、入库/提取/脱敏派发及跨项目、跨期使用记录；列表标记材料是否已使用，并可展开查看主项目、期次和状态；切换包时不重建材料库页面，保留左侧列表及筛选状态；支持通过 `/materials/:packageId` 直达材料详情，并兼容旧 `?packageId=` 链接；提交/返修历史与加载、题目归档历史分别展示 |
| `MonitorView.vue` | 全局任务监控，显示资源摘要及 Agent／API 当前处理的项目、题目和步骤 |
| `ResultsLibraryView.vue` | 跨项目当前达标题目列表、搜索、归档状态筛选及分页 |
| `SettingsView.vue` | 全局 Agent／API 并发与 Codex 凭证、默认模型设置，复用并发配置及 `CodexConfig` 组件 |
| `ProjectDetail.vue` | 七个可见步骤的期次级批量派发、全部题目表、达标题目及 Excel 导出；顶部达标进度按本期题目数计算，材料包不计入分母；就绪数取自服务端统一判断，批次大小由服务端配置；本期模型设置、本期全局材料包加载关系表与主项目规则资料/Skill 分开管理；分组且使用材料包模式的期次不展示旧入库/脱敏主步骤入口，分期保留的 legacy 来源目录只读展示，不提供重同步入口 |
| `WorkflowDetail.vue` | 材料包详情中的脱敏版本建题表单与关联题目状态；单题详情中的来源材料包、冻结来源模式与附件、步骤执行、模型评测及产物下载；展示材料来源归档历史并支持撤回当前归档；归档达标题目时按冻结来源模式生成原文或脱敏 DOCX，并保留手动重试入口；脱敏步骤显示服务端保存的字段进度 |

新建项目固定使用材料包关系。`ProjectDetail.vue` 分别平铺材料包与全部派生题目，两表互相链接；`WorkflowDetail.vue` 的材料包详情展示成功脱敏版本、项目标签建题表单和已创建题目的独立状态，派生题详情展示来源包名称、冻结材料、场景／角色／标签及出题方向。历史项目仍按原关系读取，页面不提供模式切换，不自动隐藏或转换其既有题目。

主项目身份与期次业务分开：`ProjectGroups.vue` 是 `/` 首页，主项目改名只更新主项目显示归属；`ProjectList.vue` 在 `/project-groups/:groupId` 管理该主项目期次。新增期次在普通创建接口中使用明确期号；改动已有期号或期名走 `PATCH /api/projects/:id/phase-identity`，由服务端检查运行任务并保护业务记录。普通期次配置编辑不改期次身份、主项目归属或共享 skill 路径。旧 `/projects/:id` 和 `/workflows/:id` 深链接继续使用原期次 ID。

项目详情页在标题下直接显示本项目出题标签并提供创建／管理入口，复用项目表单的标签保存逻辑。材料包建题只选择该项目已创建的标签；修改项目标签不会回写已有题目。

项目页的材料包、题目记录和达标题目表默认每页 20 条，共用紧凑表格字号与行距；状态可点击查看尝试记录，较长原因保留在悬停提示和记录中。材料包表直接提供当前就绪的单项入库、脱敏按钮，提交后刷新项目与当前页状态。题目步骤操作收进菜单，评分明细仍可从达标题目内容弹窗查看。

材料包表的批量入库／脱敏与题目表的各步骤独立批量按钮使用当前搜索结果的全部工作流 ID，不受当前分页限制；服务端按每条工作流的实际就绪状态派发，页面分别汇总排队、完成、未就绪和失败，未执行原因可展开查看。

项目页“出题就绪”只统计已创建且可派发的题目。旧材料包兼容流程中，已成功脱敏且尚无题目的包另计为“可建题材料包”；“从材料包建题并出题”按最新成功脱敏版本各建一道题，再调用现有题目批量派发接口。`library_v1` 通过本期材料加载关系和 `ProjectLibraryMaterials` 建题，来源由期次设置决定；两条路径不应混为一种批量操作。材料包详情仍可单独创建更多题目；建题失败会显示在本次批量结果中。

页面通过 `api/client.ts` 提交操作，通过 `useResource` 读取详情；项目和单题页在打开、操作后或手动刷新时读取状态，不按活动任务定时轮询。任务监控组件独立每 10 秒刷新 worker 概况；路由出口使用 `route.fullPath` 作为 key，切换路径会重新挂载页面。

项目详情页不使用 tab：本期作答模型/策略、规则资料与 Skill 由页面顶部按钮进入；library_v1 只显示本期与全局材料包之间的加载关系表，案卷原件与提取/脱敏记录由全局材料库页面及材料详情负责。候选包搜索/分页与建题设置通过弹窗按需读取；建题弹窗收集题目名称、场景、角色视角、目标等级、出题方向和本期标签。已移除引用可在本期表恢复；使用状态先显示摘要，提交/返修事件仅在打开单条记录时请求。材料包不归属项目或期次；规则资料由同一主项目各期共享，Skill 可在本期工作区覆盖，未覆盖时回退主项目 Skill。旧目录来源项目保留来源目录同步与原题流程。步骤卡片后显示全部题目表和 `AcceptedQuestionList.vue` 达标题目表；旧材料包执行历史在 legacy 兼容区域折叠。题目归档后继续留在全部题目表；Excel 汇总所有当前有效达标题目并由浏览器下载，导出失败原因显示在下载按钮附近。导出要求每个当前附件均有对应的有效脱敏 DOCX；缺失时接口返回冲突并说明需补齐的题目。达标行“查看内容”打开宽屏弹窗，切换附件全文、完整题目包、各模型作答和评分；步骤卡片的“查看题目”仍打开 `ProjectStepRecords.vue` 查看该步骤的详细状态、结果与产物。

全局成果库只查询当前成功且 `decision=accepted` 的题目摘要，显示来源材料包名称与入口；旧目录题目明确标为旧来源。点击题目进入详情；跨项目数据由 `/api/results` 一次查询提供。任务监控和全局 Codex 设置从项目列表页移至独立路由，不改变组件轮询与保存接口。模型评测和达标判断在单题详情中展示；手动返修建议入口位于详情顶部，原通用自动返修链已移除。

题目详情页在出题已有成功尝试后显示“重新生成题目”；重复派发的活动任务由后端复用。重新生成会使依赖旧题目的作答、评分与归档状态失效。点击归档会在现有达标校验后执行项目交付脚本并按题目冻结的材料模式自动生成 DOCX；归档成功后仍可手动重复执行，同版脚本复用归档记录。

材料清单 `source_manifest` 表示目录来源；当前入库附件为 `materials.deleted_at IS NULL`，已移除的附件保留历史记录。材料没有版本号。工作流历史可能包含旧版本，当前状态判断不能无条件采用历史尝试。重置工作流会删除该题的材料、尝试、产物和管理目录副本，保留项目来源目录与清单；单题导出被删除，多题导出失效但保留其他题目数据。删除项目会清除项目下全部工作流及其数据库附件、执行结果、尝试和导出记录，并保留项目行、项目级模型／步骤配置、全局配置和本地来源／skill文件；需区分数据库记录删除与本地文件清理。

单题出题步骤通过“查看完整题目”按钮打开可滚动弹窗，连续展示题目包七部分，不折叠，直接读取 steps.result；历史结果缺少作答思路或标答时明确显示尚未保存，不用其他题目或尝试的内容填充。

单题页“本轮模型评测”提供模型作答弹窗，按模型分 Tab 展示保存的答案文本；评分失败弹窗按失败时间倒序列出 ordinal 6 的失败尝试，打开时默认选中最新记录，并在右侧只显示评分模型返回的失败原因文本。

WorkflowDetail 的“达标判断 · 执行详情”展示本次判定快照中的逐作答模型得分、满分、百分制、上限和结论；不使用最新评分替换历史分数。未通过阈值的状态显示“未达标”，由用户决定是否重新执行普通流程。


## 页面读取、刷新与导出

项目、工作流详情取消自动轮询和费用统计。题目记录每页批量读取轻量状态，步骤表格分块读取；业务详情保留当前题目、各模型作答和评分，移除通用输入／配置／输出弹窗。历史只返回有限元信息及当前结果引用；原始记录仍在服务端保存。更新来自页面打开、操作后刷新或手动刷新。任务监控和活动 skill 生成保留前台 10 秒刷新。

题目详情的 DOCX 区域按冻结来源模式显示原文或脱敏版本，并按附件逐份列出文件下载链接；后端在归档达标题目后自动为每个当前附件生成独立 DOCX，文件名随 artifact 摘要返回，失败时用户可在详情页重试。新材料库题目的详情 API 返回冻结来源模式，页面据此读取与导出；旧题仍要求已有脱敏步骤并使用脱敏 DOCX。

项目详情页的“下载全部达标题目 Excel”先顺序调用每道达标题目的当前材料 DOCX 归档接口并显示题目进度，随后生成工作簿；页面请求失败会保留错误提示，用户可再次点击续跑，已有效归档的附件由服务端复用。

单题详情统一显示并编辑角色视角、场景及出题方向；空值显示“无”。通过 `PATCH /api/workflows/:id/authoring-direction` 保存，支持部分字段更新，未传字段保留原值。修改后当前出题及后续步骤失效，入库与脱敏保留；重新出题读取新设置。

项目模型作答步骤增加“流程设置”入口，用于配置该阶段钩子；模型集合仍由顶部“作答模型设置”管理。设置表单只保存workflow局部字段，不修改模型选择。单题钩子接口尚未随API进程更新时显示明确提示，不把读取失败展示成正常空记录。

WorkflowDetail.vue 的完整题目弹窗展示 Work 独立整题信息、成果、检索、能力及内容状态，Rubric展示原始判据与实际正负分/否决，兼容历史题目；此展示不是内容验收。

Work归档页的Harbor身份改为成对选填；留空可生成Siriser五件套。归档成功后提供“下载五件套ZIP”，与通用Excel分开。填写Harbor身份不保证转换成功，状态以成果目录Harbor生成状态为准；Siriser上传仍在外部平台完成。

材料库的 `MaterialLibraryView` 使用 `LibraryPackageCreateDialog` 选择本机材料文件夹并导入，页面管理各版本的入库/提取/脱敏历史和跨项目使用关系；不输入材料正文。

材料库阅读区以窄列表/宽阅读区组织包，列表支持分页搜索；“材料文件”“项目使用”“处理记录”分开。默认逐文件查看，使用历史按需读取，避免历史查询延迟阻塞文件阅读。阅读区不显示原件预览，提供识别原文、脱敏文本及对照，并保留显式原件下载。包资料编辑与材料库共用处理设置分离，原件/文本版本和技术任务编号不混排。桌面端应用外壳固定为视口高度，左右阅读栏占满主工作区剩余高度并分别滚动；窄屏保持页面内容流布局。

材料库筛选栏支持关键词、使用项目多选及脱敏状态同时生效；项目之间取并集，筛选后详情跟随匹配列表，空结果不保留旧详情。列表与阅读区缩小留白，隐藏重复说明，不修改文件正文。

题目/旧材料包详情的材料 DOCX 按可用冻结来源或成功脱敏结果开放，生成按钮不依赖评分、达标或归档，也不因其他业务步骤活动而禁用；生成期间只禁用本次按钮，后端校验来源与文件完整性。

题目详情与出题记录增加手动返修建议入口，当前有效建议在下一次出题冻结；不自动继续出题。批量4/5/6显示已达标跳过和容量不足未派发。共享材料库题的出题按钮不要求旧步骤9。步骤执行文字优先使用服务端executions本机投影，保留共享业务成果。

项目与题目详情首次读取失败时仍显示“重新读取”；35秒截止仅结束本次页面等待，不取消后台业务任务。迟到或卸载后的读取结果不回写当前页面。

`WorkflowDetail.vue` 在当前归档成功时禁用出题、作答、评分和重复归档，保留查看、下载及显式撤回归档入口。

`WorkflowDetail.vue`从步骤8安全回执展示飞书核对通过、失败或未完成；显示差异字段、原因码和目标表链接。旧同步成功回执无核对状态时不显示核对通过，不自动重传。

批量达标判断按返回的 `decision` 展示达标、未达标、等待及需核查数量，并列出未完成原因；执行错误独立保存，不被随后的状态刷新清除。旧 API 未返回结论时明确提示未返回，不推断达标。

材料库详情在提取/脱敏后提供可选“材料整理与使用范围”面板；显示材料包总摘要、逐份摘要/标签和多组支持范围。建题自动冻结匹配结果给出题Agent参考，面板不提供候选或文书筛选；完整材料始终保留，入口失败允许跳过。
