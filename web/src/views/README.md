# 路由页面

| 文件 | 职责 |
| --- | --- |
| `ProjectList.vue` | 项目搜索、新增编辑删除 |
| `MonitorView.vue` | 全局任务监控，显示资源摘要及 Agent／API 当前处理的项目、题目和步骤 |
| `ResultsLibraryView.vue` | 跨项目当前达标题目列表、搜索、归档状态筛选及分页 |
| `SettingsView.vue` | 全局 Agent／API 并发与 Codex 凭证、默认模型设置，复用并发配置及 `CodexConfig` 组件 |
| `ProjectDetail.vue` | 七个可见步骤的项目级批量派发、设置弹窗、达标题目和分页题目记录及 Excel 导出；就绪数取自服务端统一判断，批次大小由服务端配置；作答模型与材料／skill 设置通过弹窗打开 |
| `WorkflowDetail.vue` | 单题执行、附件、模型评测、返修链、产物下载与有限执行失败诊断 |

页面通过 `api/client.ts` 提交操作，通过 `useResource` 读取详情。项目和单题页有活动任务时定时刷新；路由出口使用 `route.fullPath` 作为 key，切换路径会重新挂载页面。

项目详情页不使用 tab：作答模型和材料／skill设置由页面顶部两个设置按钮打开；材料弹窗内包含题目目录同步和本地 skill 路径。步骤卡片后先显示 `AcceptedQuestionList.vue` 中当前有效的达标题目和 Excel 下载，再由 `ProjectQuestionRecords.vue` 展示尚未归档题目的搜索和分页记录。归档成功后题目仅保留在达标题目列表；Excel 汇总所有当前有效达标题目并由浏览器下载。达标行“查看内容”打开宽屏弹窗，切换附件全文、完整题目包、各模型作答和评分；步骤卡片的“查看题目”仍打开 `ProjectStepRecords.vue` 查看该步骤的详细状态、结果与产物。

全局成果库只查询当前成功且 `decision=accepted` 的题目摘要，点击题目进入详情；跨项目数据由 `/api/results` 一次查询提供。任务监控和全局 Codex 设置从项目列表页移至独立路由，不改变组件轮询与保存接口。模型评测和返修记录仍只在单题详情中展示。

题目详情页在出题已有成功尝试后显示“重新生成题目”；重复派发的活动任务由后端复用。重新生成会使依赖旧题目的作答、评分与归档状态失效。

材料清单 `source_manifest` 表示目录来源；当前入库附件为 `materials.deleted_at IS NULL`，已移除的附件保留历史记录。材料没有版本号。工作流历史可能包含旧版本，当前状态判断不能无条件采用历史尝试。重置工作流会删除该题的材料、尝试、产物和管理目录副本，保留项目来源目录与清单；单题导出被删除，多题导出失效但保留其他题目数据。删除项目与重置工作流的含义不同，接口承担最终校验和处理。

单题出题步骤通过“查看完整题目”按钮打开可滚动弹窗，连续展示题目包七部分，不折叠，直接读取 steps.result；历史结果缺少作答思路或标答时明确显示尚未保存，不用其他题目或尝试的内容填充。

单题页“本轮模型评测”提供模型作答弹窗，按模型分 Tab 展示保存的答案文本；评分失败弹窗按失败时间倒序列出 ordinal 6 的失败尝试，打开时默认选中最新记录，并在右侧只显示评分模型返回的失败原因文本。

WorkflowDetail 的“达标或返修 · 执行详情”展示本次判定快照中的逐作答模型得分、满分、百分制、上限和结论；不使用最新评分替换历史分数。
