# 资源加载

`useResource.ts` 读取一个固定接口路径，返回 `data`、`error`、`loading` 和 `refresh`。组件挂载时加载，正在加载时合并后续刷新，确保操作完成后仍读取最新数据，卸载时取消当前请求。

调用方负责按需刷新；任务监控、活动 skill 生成和项目页活动任务有各自受限刷新；此组合函数没有缓存、自动重试或动态路径监听。路径变化需要调用方重新挂载或另行处理，当前路由外壳按 `route.fullPath` 重新挂载页面。

`usePageBreadcrumbs.ts`由期次列表、期次详情和题目详情发布已加载的主项目/期次/题目身份，AppShell提供注入入口并在路由变化时清空旧层级；不为面包屑重复请求接口。
