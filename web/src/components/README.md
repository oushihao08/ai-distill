# 业务组件

组件由页面传入项目 ID、工作流 ID 或已读取的数据；操作成功以事件通知父页面刷新，部分组件独立读取自己的接口。

| 组件 | 职责 |
| --- | --- |
| `AppShell`、`UiIcon` | 应用外壳、路由出口与固定图标；材料库桌面端使用视口高度容器，切换材料包时保留页面实例与列表状态 |
| `ProjectForm` | 创建主项目首期或新增期次；分期编辑只维护业务说明和标签、不提交材料目录/后端/工作区或共享 skill 字段；grouped legacy 目录只作为历史来源，未分期旧项目保留目录编辑兼容；项目详情以 `tagsOnly` 只保存本期题目标签 |
| `ProjectLibraryMaterials` | 在期次建立全局材料包版本的加载关系；首屏仅读取本期引用和使用摘要，材料候选搜索分页、提交历史及本期来源模式要求的成功提取或脱敏版本均按需读取；每个加载包仅创建一道活动题，包名含L2–L5时等级自动带入；可编辑场景、角色、方向和标签，支持恢复本期已移除引用；包本身不归属项目或期次，不在项目页处理原件、入库、提取或脱敏 |
| `MaterialUsePanel` | 显示主项目材料使用／提交状态；提交和返修原因在对话框编辑，事件历史通过单条使用记录接口按需读取，不随本期材料首屏加载 |
| `LibraryPackageUseMarker` | 在全局材料包列表展示未使用／已使用项目数；点开后查看每个主项目的所属期次与使用状态，不读取事件历史 |
| `ProjectMaterialRecords` | 项目材料包平铺表；逐包显示入库、脱敏状态、附件数和派生题目数，当前页读取状态；单项或按全部搜索结果批量派发入库／脱敏 |
| `ProjectQuestionRecords` | 全部题目平铺表，包含已归档题目；项目详情首屏优先复用项目接口返回的轻量工作流状态快照，不再并发请求同一批状态；无快照时按每批最多百题读取轻量步骤状态和已出题标记后筛选；支持关键词、出题标签及出题／作答／评分状态组合筛选（成功、等待、就绪、失败），以及达标判断筛选（达标、不达标；不达标对应表格“未达标”），状态与单元格显示一致，条件变化回到第一页；普通步骤批量操作使用全部匹配题目，读取中禁止批量派发；显示题目名称、标签、共享材料包或旧题目来源、逐步状态、评分步骤中的逐模型分数；达标判断尝试仅在打开详情时读取，评分明细也按需加载；返修建议可全项目批量派发并展示全部题目的判定、当前建议有效性、活动任务、失败或无法核验状态及Agent等待容量；共享材料包题不显示旧入库/脱敏操作 |
| `MaterialPackageQuestions` | 材料包详情的关联题目表；每页读取十道题的出题至归档状态和逐模型评分，不显示脱敏指纹及步骤原因；支持查看尝试历史与确认后逻辑删除单题，不删除材料包或源材料 |
| `WorkflowAttemptHistory` | 按工作流与步骤分页查看安全执行元信息；入库记录合并内部 PDF/DOCX 提取尝试 |
| `AcceptedQuestionList`、`AcceptedQuestionDetail` | 当前达标题目的共享材料包或旧来源、搜索、异常筛选、分页、模型评分概览和单题归档入口；详情弹窗按需展示当前题目包、答案、评分及脱敏附件全文 |
| `CodexConfig`、`ProjectCodexSettings`、`StepSettings` | 全局、项目、步骤 Agent 配置；步骤覆盖优先于项目，项目优先于全局；仅出题、评分及脱敏步骤开放单独设置 |
| `SystemStepPromptSettings` | 主项目首页维护出题、作答与评分的新期默认提示词（旧脱敏提示词仅兼容读取）；出题标签页分开展示固定通用规则与新项目可配置默认要求，同时维护出题专用默认模型/强度，保存仅影响之后新建的期次 |
| `WorkerConcurrencyConfig` | 系统级 Agent／API 并发设置；显示安全上限及当前生效值，保存后重启 API 与 worker 生效 |
| `AnswerModelSet` | 系统模型目录、当前期次作答模型集合及各模型百分制分数上限；这是该期达标判断的唯一配置来源 |
| `AnswerGenerationPolicySettings` | 本期作答请求上限、推理增量认定阈值及免评分策略；读取/保存 `/answer-generation-policy`，保存只影响新作答任务 |
| `LegacyMaterialOrigin` | 单题详情按需显示旧题与新材料库版本的历史关联；不改变旧题冻结附件或运行来源 |
| `MaterialPackageQuestionForm` | 旧材料包工作流详情读取成功脱敏尝试并提交派生题；选填场景、角色、本期项目标签和方向；不派发脱敏。library_v1 新题由 `ProjectLibraryMaterials` 按期次来源设置创建。 |
| `DirectoryImportForm`、`UploadForm`、`MaterialEditor` | 旧项目目录分组导入、单题工作流创建、单题附件新增或替换；浏览器接受 PDF、DOCX、TXT、MD。 |
| `ProjectStepRecords` | 指定步骤的材料包或题目状态、未进入原因、结果及产物表格弹窗；对象清单由项目页按模式过滤 |
| `MaterialRecordsTable` | 当前附件、全文与原 PDF 标签预览，允许在逐题步骤弹窗只读复用 |
| `StepResultTable` | 递归展示结构化步骤结果 |
| `StepTimeline` | 单题步骤状态及操作、下载插槽 |
| `ModelEvaluationSummary` | 关联本轮答案与评分，按模型展示百分制分数、上限及通过状态，并展示整体达标／未达标状态；弹窗按模型展示答案、按最新失败时间展示评分失败记录与文本 |
| `RevisionHistory.vue` | 空兼容占位，当前页面不引用；仅待下一次组件类型声明生成时一并清除，不提供用户入口 |
| `WorkerMonitor`、`ActiveWorkflowTasks` | WorkerMonitor 展示执行器心跳、内存、独立材料库队列和项目任务；ActiveWorkflowTasks 按 API／Agent 展示运行中的项目、题目和步骤/返修建议；由全局任务监控路由承载 |
| [rules](rules/README.md) | 规则资料、skill 候选及冻结版本 |

`ProjectStepRecords` 分批读取既有工作流详情，不派发任务；逐题详情返回的 `ready` 与 `ready_reason` 来自服务端统一就绪判断，组件不复制前置条件。未达标轮次的作答、评分显示后端返回的“须先根据返修建议重新出题”；新出题入队后沿用前置步骤等待原因。该弹窗没有定时轮询，页面刷新或用户操作后更新。`MaterialRecordsTable` 的附件进度由题目步骤推导；全文通过附件接口按需读取，共享材料题按冻结来源显示对应原文或脱敏正文，脱敏视图不返回原始提取页；旧流程附件仍可能标记脱敏却缺少附件级脱敏正文。

`AcceptedQuestionList` 只展示当前 ordinal 7 成功且判定为 accepted 的题目；模型得分、百分制、门槛和归档／导出状态来自项目详情响应。待归档行可进入题目详情，由详情页按活动尝试判断归档操作是否可用；归档成功的题目仍在全部题目表，并同时出现在达标题目表。`AcceptedQuestionDetail` 延迟读取工作流详情，附件标签仅请求 `redacted_only=true` 的脱敏正文，不读取或返回原始提取文本；题面、作答和评分文本保留换行并在弹窗滚动区域显示。列表的 Excel 操作汇总全部当前有效达标题目。

主项目由 `ProjectGroups.vue` 管理，期次由 `ProjectList.vue` 管理；主项目名称修改复用 group PATCH，期号与期名修改走专用 phase-identity PATCH。普通 `ProjectForm` 的期次编辑不提交身份字段，标签模式仅提交题目标签，避免把未显示的路径/配置一起重置。删除期次的确认会说明其题目数据删除不释放主项目材料使用记录。

上传入口支持的材料格式依组件而异：`UploadForm`、`DirectoryImportForm`、`MaterialEditor` 和材料包文件夹导入均接受 PDF、DOCX、TXT、MD；其中 `DirectoryImportForm` 按项目目录的直接子目录分组上传，`MaterialEditor` 管理单题附件。此处只说明浏览器接受的格式，不代表提取或脱敏任务已运行成功。

`StepSettings.vue` 的出题设置分别显示固定通用提示词与本项目可配置提示词；前者由作者执行器固定附加，后者按系统默认快照或项目设置派发并冻结。脱敏设置可选择独立大模型 API 或本地 Agent；API 模型选项复用 `/api/answer-models` 系统目录。`AnswerModelSet.vue` 管理作答模型集合，可登记 OpenRouter API 模型或本机 Codex Agent 的模型/推理强度；作答 worker 根据冻结 provider 分流，Codex 不经 llm-api，也不在服务器 worker 执行。

评分步骤设置显示并编辑实际执行的评分提示词；已知旧内置默认正文映射为当前默认，自定义提示词原样保留。从 `/api/agent/scoring-instructions` 读取程序调用说明和隔离参数。`ModelEvaluationSummary` 提供“查看评分”，逐模型展示已保存的实际回复和程序校验问题；历史记录未保存校验细节时不补造原因。


### 独立评分输入与历史兼容

当前独立评分通过隔离会话提供题面、Rubric、题目冻结来源对应的附件、匿名完整答案和本次评分提示词；作答思路及标准答案仅用于内部同版题目包校验，除显式校准契约外不发送给评分模型。Codex 执行为文本输出；新 `model_report_v1` 结果使用独立报告区，旧结构化报告按旧协议读取。评分输入隔离、实际调用参数和文件清单以 `server/scoring/README.md` 及执行请求为准。

评分原文与执行快照按服务端记录展示；界面不从当前提示词补造历史调用细节。评分结构验证与业务判断是不同边界，详情见服务端评分模块说明。


## 状态读取与刷新

项目详情接口提供轻量工作流状态快照供题目表复用；题目表没有快照时按每批最多 100 个 ID 读取状态。步骤记录弹窗按批读取状态且不自动轮询；题目详情、评分明细、达标判断与尝试历史按需读取。项目详情和单题详情由页面打开、操作后或手动刷新更新；任务监控与活动 Skill 生成各自有独立刷新逻辑。

## 数据库模型设置

系统、项目、步骤和 skill 生成配置均保留数据库模型与推理强度，不按本机缓存修正或拒绝；界面允许输入缓存之外的值。缓存只提供建议，实际支持范围由 CLI 执行反馈。步骤覆盖项目默认，项目覆盖系统默认，已入队任务继续使用冻结配置。不改变登录凭证、工具配置、权限或隔离。

## 项目流程扩展

`WorkflowPolicyEditor` 在出题、作答、评分步骤编辑可选 workflow JSON；评分步骤是计分规则及标答校准政策的单一来源。作答步骤通过局部保存接口只合并 workflow，不改模型集合或生成时长。其他步骤保存模型设置时保留 workflow。缺省继续原契约。

`WorkflowHookRecords` 由题目详情按需读取记录，显示同步与异步状态、附加结果、错误和重试历史；支持原尝试钩子续跑与独立异步重试。未知副作用需使用者明确确认，输入失效仍由服务端拒绝；无自动轮询。

评测摘要、达标题目列表与详情分别展示新格式原始分、模型报告指标及否决意见。原始分不参与页面换算；指标为空时等待有效评分。旧格式仍展示原百分制及逐项满分数量。

`MaterialRecordsTable` 对 DOCX 显示脱敏方式并提供确认弹窗；保存时提交当前附件 SHA-256，成功后刷新工作流。上传与材料编辑控件接受后端已有的 PDF、DOCX、TXT、MD 类型。

材料正文阅读界面不展示提取器生成的非阻断识别问题列表或计数；提取文本和原件仍可分别查看。脱敏可用性校验失败仍明确显示，旧材料流程对可复查空白页/乱码页的处理不变。

`ProjectLibraryMaterials` 的“查看全部脱敏附件”使用本期选定的脱敏版本，`LibraryMaterialPreview` 按该版本绑定的提取任务列出全部文件并逐份读取脱敏正文，不默认替换为最新版本。`ProjectQuestionRecords` 的附件数量是查看入口，按需读取该题的全部附件并复用只读 `MaterialRecordsTable`，材料库题按题目冻结来源查看，不跟随本期后续选版变化。

上述入口不在列表阶段读取正文；题目附件清单复用`view=status`轻量详情，不加载答案和评分全文。文件正文仅在选中时读取，当前已显示文件不重复请求；关闭或切换目标取消未完成请求并释放当前弹窗内容。

`LibraryPackageCreateDialog` 通过文件夹选择器导入PDF/DOCX/TXT/MD，用文件夹名称建包；上传失败保留包ID及同一上传请求标识供重试。`ProjectLibraryMaterials` 仅列出有可用成功脱敏结果的包，加载按钮要求明确选版，服务端同步校验。

`LibraryJobHistory` 按任务ID读取安全进度和错误；支持取消排队/运行任务、对失败或取消任务显式重试。脱敏重试绑定原提取任务，不读取/显示任务输入全文或提示词；不自动轮询。

- `LibraryPackageSettings`：只维护包名称、说明和标签，使用If-Match保存；模型和提示词由材料库共用设置维护。
- `LibraryMaterialPreview`：保留旧弹窗兼容组件；材料库主入口已改用逐文件阅读区，不再并排铺开历史提取按钮。

- `LibraryProcessingSettings`：打开时默认选择Agent整包代称模板；所有材料包共用Agent化名提示词模板，展示共用脱敏设置的模型与强度，不再提供旧字段映射模型控件。保存时比较共用配置版本，系统默认只应用到草稿。脱敏提示词输入框固定八行高度，长内容在框内滚动且不可拖拽调整。
- `LibraryPackageWorkspace`：默认选择Agent整包代称模板，仅列Agent化名模板，历史字段映射只读兼容；在紧凑工具栏中显示处理状态、操作、文件版本、文件选择及按需出现的脱敏版本选择；当前结果与历史任务分开，原文提取、脱敏及材料整理按文件版本显示完成、排队、处理中或失败；整理完成需匹配版本、来源和项目上下文，状态读取失败不当作未处理。阅读区不预览原件，仍提供显式下载。
- `LibraryFileReader`：原PDF/DOCX（本地PDF副本）/文本、识别原文、单文件脱敏文本及逐页对照；查看模式和脱敏版本由父级工具栏控制，对照锁定所选脱敏版本实际引用的提取任务，切换文件或版本会取消旧读取；正文自然展开，统一由材料详情容器滚动，避免嵌套纵向滚动条。
- `LibraryUsageSummary`：材料详情展示主项目跨期使用状态与提交/返修事件、项目加载关系及题目归档/撤回时间线；不把当前状态重复标在每次历史操作上。

材料库共用设置支持编辑多个独立脱敏模板；所选模板的完整提示词在自适应多行编辑框中显示，长内容由设置面板滚动查看。材料包工作区只派发codex_plan；可在化名模式内选择不同提示词模板，省略模板使用aliases。历史mask设置须先明确调整，不静默换流程。

材料处理当前两种模式由`StepSettings.vue`保存到期次步骤4的`material_processing_mode`。`ProjectLibraryMaterials.vue`按模式过滤结果、允许先加载待处理版本，并把期次上下文传给材料详情；`LibraryPackageWorkspace.vue`在该上下文锁定处理方式。前端不执行脱敏、不替代后端模式核验；已有题目的来源不随设置改变。

面包屑由AppShell渲染，三级业务页面通过usePageBreadcrumbs使用各自已加载的API身份；主项目、期次和题目逐层跳转。StepSettings表单使用视口上限，标题与底部操作固定，主体独立滚动；长提示词不应撑出窗口。

`WorkerMonitor.vue`在local队列模式显示本机执行器、Agent/API实际排队和运行数，以及待同步/待核实数量；当前占用明细包含运行中的工作流步骤和本机返修建议任务，返修建议归入Agent通道；恢复任务折叠列表显示任务ID、通道及更新时间，支持滚动；业务历史与执行状态分开。数据契约和切换边界见`server/execution-queue/README.md`。

本期材料refresh使用请求序号及AbortSignal隔离：旧期次/旧请求不能覆盖当前结果，卸载停止读请求；写后刷新仍执行。建题与材料处理恢复请求键的规则见[API请求](../api/README.md)。

`PhasePreparation.vue`只读核对本期规则/Skill、出题配置、作答模型、材料加载数量及匹配来源的可用数量，提供各自设置入口；不整体阻断，不派发任务，原文不要求脱敏。`ProjectForm.vue`首期显式共享Skill，后续期次回读共享路径；未知创建结果通过服务端只读回执查询（含目录规范化与显式出题参数核对）提供原期入口，不自动重建。

`RevisionAdvice.vue`按workflowId手动读取/生成建议并展示最近历史及版本有效标记；“触发返修建议”位于题目表的题名下方、出题记录和题目详情顶部，打开弹窗后才读取正文。不能生成时展示原因，查看历史入口不隐藏；生成建议不自动重新出题。题目表的批量返修建议不受当前关键词、标签、状态筛选或分页影响，重新读取全项目工作流后仅处理当前未达标题目；跳过任一版本已有成功有效文本的建议及建议活动任务。核对面板逐题显示现有建议（标明来源版本是否变化）、等待/运行、待触发、失败及无法核验，并列出非未达标题目的判定状态。返修题重出时会带入该题最近一条成功有效建议，即使建议来源版本已变化。批量派发提交前后读取本机Agent容量，按`running + queued + reserved`补位至执行上限；报告运行槽位和独立等待队列的排队/预留/可用容量。容量接口不可读或服务端拒绝时停止后续派发，未知写回执不重发。当前已达标题目的建议生成按钮禁用，服务端仍复核。步骤状态投影显示本机、他机及待核实，不能将云端running视为本机占用。

`ProjectAnswerModelsSummary.vue`在项目作答步骤和步骤5设置中只读展示本期模型集合，与实际新作答选择共用`/projects/:id/answer-models`。模型集合保存后通过`AnswerModelSet.saved`事件刷新项目摘要；不读取旧步骤5的单模型字段，不改变历史任务冻结模型。读取失败显示错误和重试，未配置集合明确提示。

`ProjectQuestionRecords.vue` 对已归档题目不提供普通执行菜单；批量执行显示 `already_archived` 跳过数量并继续其他题目。

`LibraryPreparationPanel.vue`由材料库详情和期次建题弹窗挂载，展示包总摘要、真实文书/未归类项计数、逐份摘要/标签/可见性及多组支持范围。旧结果缺文书类型时显示整理条目数并说明真实份数未知。人工预览仍保留全文；模型和DOCX按可见标记过滤。整理可跳过，独立busy/error不禁用建题。HTTP契约见[材料库](../../../server/material-library/README.md#材料整理与使用范围)。

`LibraryPreparationPanel`：材料库由顶部“材料整理”按钮打开，期次建题弹窗继续复用；包摘要、文书清单和支持任务组合分区展示，清单与组合使用表格，说明及人工全文按需展开。组件不固定内容高度，统一使用父级弹窗滚动；刷新或派发后通知父页面更新处理状态。

LibraryPreparationPanel刷新时恢复该版本最近整理任务，展示当前阶段、材料数与截至刷新时的耗时；终态覆盖旧阶段显示。Agent内部无真实百分比，页面不估算完成比例；成功刷新自动展示该任务结果。

题目记录状态补读绑定组件生命周期：卸载或父级提供新状态投影时取消旧请求，旧响应不覆盖新投影。项目批量派发与筛选批量派发共用 `../api/batch-dispatch.ts` 的分批回执和未知结果停发逻辑。

`LibraryPackageCreateDialog.vue`通过独立imports上传任务，不再先建立空包；submitted事件返回任务ID，成功前不返回正式package ID。失败/未知请求保留原request_key，不自动重发。
