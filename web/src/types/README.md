# 前端业务类型

`api.ts` 重新导出根目录 `shared/types.ts` 的契约，供页面和组件使用。共享步骤标识定义于 `shared/step-registry.ts`，显示顺序与持久化 ordinal 不能互换。

跨前后端的字段调整应同步共享契约及接口实现，不在本目录重复定义同一业务类型。部分组件仍有局部接口类型，例如执行器监控引用服务端类型；类型本身不验证接口实际响应。

`material-library.ts` 从共享材料库类型投影文件/任务/版本的阅读字段，并定义项目使用的页面摘要；不复制任务执行配置或来源存储路径。
