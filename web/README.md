# 前端工作台

本模块提供本机出题项目、材料包及逐题工作流界面，技术栈为 Vue 3、TypeScript、Vite、UnoCSS 和 Vuetify。业务执行与持久化由 `../server/` 负责，接口契约来自 `../shared/`。

## 入口与模块

- `src/main.ts`：主题变量、样式、Vuetify、路由与应用挂载。
- `index.html`：Vite 的 HTML 文档外壳，提供 `#app` 挂载点并加载 `src/main.ts`。
- `src/App.vue` → `src/components/AppShell.vue`：应用外壳与路由出口。
- [页面](src/views/README.md)：项目列表、任务监控、成果库、系统设置、项目详情和单题详情。
- [组件](src/components/README.md)：材料、逐题步骤表格、配置、评测与历史。
- [源码导航](src/README.md)：布局、请求、类型及样式等基础模块。
- `vite.config.ts`：构建插件、Vue API 与组件自动导入；开发服务器默认监听 `127.0.0.1:3800`，并将 `/api` 转发到后端 `127.0.0.1:3700`。
- `uno.config.ts` 与 `src/theme.ts`：原子样式规则与共享主题。
- `package.json` 与 `tsconfig.json`：前端工作区依赖／脚本及 TypeScript 配置；JSON 不支持注释，以本说明登记用途。
- 源码导入约定：`@/` 指向 `src/`，`@shared/` 指向仓库根目录 `shared/`，`@server/` 仅用于前端必要的服务端类型引用；同目录或相邻文件保留短相对路径。
- `dist/`、`node_modules/`：构建与依赖生成目录，不手工维护、不放 README。

## 状态与执行边界

主项目与期次分层：`ProjectGroups.vue` 管理跨期主项目，`ProjectList.vue` 管理期次，`ProjectDetail.vue` 按期次展示题目与设置。作答模型、期次说明和题目评测数据按期次隔离；规则与 skill 按主项目共享；材料包保存在全局材料库，通过本期关系表加载，并进入永久主项目材料使用账本。完整关系见 `src/views/README.md` 与 `src/components/README.md`。

项目接口提供七个可见步骤；稳定业务标识和显示顺序由 `../shared/step-registry.ts` 定义。PDF/DOCX 提取（ordinal 2）仍是入库内部任务；规则绑定（ordinal 3）和独立审查（ordinal 10）仅保留历史身份；脱敏的稳定 ordinal 为 9，出题为 4，不能把显示序号当数据库标识。新建期次固定采用“一份材料包 → 多道题目”：材料包与全部题目分别平铺展示，材料包显示入库／脱敏，派生题目从出题开始并显示冻结来源及本期标签。旧目录项目继续按既有关系读取，不自动转换或隐藏；已归档题目仍显示在全部题目表。模型作答在当前出题成功且输入绑定有效后开放。

项目步骤数量来自后端聚合；“查看题目”从各工作流详情推导本步状态并展示结果。排队和处理中的尝试依据当前步骤的活动状态；批量派发按同一就绪口径逐题检查，页面显示实际新派发、复用、未就绪及失败数量。刷新遇到进行中的读取时会补发一次读取，避免派发后的状态刷新被丢弃。附件变更会取消旧任务，实际派发资格仍以服务端为准。附件表格的进度由题目步骤与材料状态推导，不能视为每份附件的独立任务监控。

页面提供操作入口、接口已有实现、真实模型成功和浏览器验收是不同证据层次；本文只描述源码与接口，不代表真实运行验收。

## 维护约定

遵循 [样式与主题约定](STYLE_GUIDE.md)：`script setup`、Row/Column、UnoCSS、共享主题和统一控件尺寸。Vue API 与已注册目录组件使用现有自动导入；`auto-imports.d.ts`、`components.d.ts` 为自动生成声明，不手改。页面局部状态通过 props/emits 与显式 API 刷新协调，当前没有 Pinia 全局业务 store。

运行命令及环境准备见根目录 README。任务未明确要求时，不运行测试、lint、开发服务或安装依赖。本文档描述源码结构，不代表已完成真实运行验收。


## 页面读取、刷新与导出

项目、工作流详情取消自动轮询和费用统计。题目记录为支持跨页状态筛选，按每批最多 100 题读取全部轻量状态并在本地分页；旧列表接口缺少评分汇总时，仅补读已执行评分题目的状态详情，评分正文点击“查看评分”后再读取。步骤表格分块读取；业务详情保留当前题目、各模型作答和评分，移除通用输入／配置／输出弹窗。历史只返回有限元信息及当前结果引用；原始记录仍在服务端保存。更新来自页面打开、操作后刷新或手动刷新。任务监控和活动 skill 生成保留前台 10 秒刷新。

开发代理的后端端口优先读取进程 PORT，其次根 `.env` 的 PORT，默认3700；读取配置仅用于代理，不注入浏览器端。

新建项目页面默认并固定采用独立材料库：指定规则工作区后创建library_v1项目，再按本期来源设置加载有可用提取原文或脱敏版本的材料包。已有legacy项目的编辑和执行入口保留；HTTP创建接口仍接受旧客户端显式/缺省legacy参数，以保持兼容，不迁移旧数据。
