# 前端工作台

本模块提供本机出题项目与逐题工作流界面，技术栈为 Vue 3、TypeScript、Vite、UnoCSS 和 Vuetify。业务执行与持久化由 `../server/` 负责，接口契约来自 `../shared/`。

## 入口与模块

- `src/main.ts`：主题变量、样式、Vuetify、路由与应用挂载。
- `src/App.vue` → `src/components/AppShell.vue`：应用外壳与路由出口。
- [页面](src/views/README.md)：项目列表、任务监控、成果库、系统设置、项目详情和单题详情。
- [组件](src/components/README.md)：材料、逐题步骤表格、配置、评测与历史。
- [源码导航](src/README.md)：布局、请求、类型及样式等基础模块。
- `vite.config.ts`：构建插件、Vue API 与组件自动导入；开发时将 `/api` 转发到 `127.0.0.1:3100`。
- `uno.config.ts` 与 `src/theme.ts`：原子样式规则与共享主题。
- `package.json` 与 `tsconfig.json`：前端工作区依赖／脚本及 TypeScript 配置；JSON 不支持注释，以本说明登记用途。
- 源码导入约定：`@/` 指向 `src/`，`@shared/` 指向仓库根目录 `shared/`，`@server/` 仅用于前端必要的服务端类型引用；同目录或相邻文件保留短相对路径。
- `dist/`、`node_modules/`：构建与依赖生成目录，不手工维护、不放 README。

## 状态与执行边界

项目接口提供七个可见步骤；稳定业务标识和显示顺序由 `../shared/step-registry.ts` 定义。PDF 提取（ordinal 2）、规则绑定（ordinal 3）和独立审查（ordinal 10）仅作为旧数据库记录保留，不再返回工作流详情或执行历史；脱敏的稳定 ordinal 为 9，出题为 4，不能把显示序号当数据库标识。模型作答在当前出题成功且输入绑定有效后开放。

项目步骤数量来自后端聚合；“查看题目”从各工作流详情推导本步状态并展示结果。排队和处理中的尝试依据当前步骤的活动状态；批量派发按同一就绪口径逐题检查，页面显示实际新派发、复用、未就绪及失败数量。刷新遇到进行中的读取时会补发一次读取，避免派发后的状态刷新被丢弃。附件变更会取消旧任务，实际派发资格仍以服务端为准。附件表格的进度由题目步骤与材料状态推导，不能视为每份附件的独立任务监控。

页面的既有静态“2 / 8”“待开放”等文案可能落后于当前接口能力，不能用作执行器接入或验收的依据。页面提供操作入口、接口已有实现、真实模型成功和浏览器验收是不同证据层次。

## 维护约定

遵循 [样式与主题约定](STYLE_GUIDE.md)：`script setup`、Row/Column、UnoCSS、共享主题和统一控件尺寸。Vue API 与已注册目录组件使用现有自动导入；`auto-imports.d.ts`、`components.d.ts` 为自动生成声明，不手改。页面局部状态通过 props/emits 与显式 API 刷新协调，当前没有 Pinia 全局业务 store。

运行命令及环境准备见根目录 README。任务未明确要求时，不运行测试、lint、开发服务或安装依赖。本文档描述源码结构，不代表已完成真实运行验收。
