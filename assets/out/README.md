# 可见导出与附件库

`附件库/<项目名>--<项目ID>/<题目名>--<题目ID>/` 是用户手动触发“生成脱敏 DOCX”后创建的题目归档目录。`原件/` 保存从 `.storage` 读取、经数据库 SHA-256 和文件大小校验后的当前附件副本；`成果/脱敏材料.docx` 只由数据库当前脱敏文本生成。它不写回题目来源目录，也不参与项目目录同步。

附件库内容是运行时用户数据，不进入 Git；`.gitignore` 只忽略 `附件库/`，本说明文件保留在版本管理中。工作流整条重置会清理该题目的归档目录，同项目的其他题目保留。不要手工把此目录内容当作未脱敏原件来源；数据库中的当前附件与脱敏结果仍是工作流状态校验的依据。
