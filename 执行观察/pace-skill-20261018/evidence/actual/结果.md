# Pace实际隔离执行测试

本轮按用户“执行测试”授权实际运行文件任务：同一组合成ZIP分别交由不加载Pace、加载Pace的独立Agent执行。父Agent独立回读全部产物，对照预置结果、源文件、既有输出、ZIP清单与CRC核验。

| 实际情境 | 不加载Pace | 加载Pace |
| --- | --- | --- |
| 有效包，可信校验缓存与当前源SHA一致 | 正确交付 | 正确交付 |
| 同名且内容相同的已有输出 | 复用，未重写 | 复用，未重写 |
| 同名但内容不同的已有输出 | 报冲突，未覆盖 | 报冲突，未覆盖 |
| 缺少必交文件 | 拒绝，继续处理其他包 | 拒绝，继续处理其他包 |
| 源包变化但保留旧成功缓存 | SHA不符后重查，发现缺Rubric并拒绝 | SHA不符后重查，发现缺Rubric并拒绝 |
| 无缓存的有效包 | 检查清单及CRC后交付 | 检查清单及CRC后交付 |
| 同一任务实际复跑 | 新交付转为复用；源和输出SHA及mtime_ns全部不变 | 新交付转为复用；源和输出SHA及mtime_ns全部不变 |
| 附加真实CRC损坏包，必需条目齐全 | 本轮未做 | 实读发现instruction.json CRC失败，拒绝；无Q7输出 |

两组首轮均6/6符合预置结果；两组复跑均6/6符合预置结果，父Agent验证零源/输出文件重写。Pace附加CRC损坏包正确拒绝。完整回执、规范及合成夹具见本目录。

## 耗时与边界

首轮基线自报处理区间约4.87秒，但排除此前3次探索；Pace约15.72秒，自报从目录检查开始且排除Skill读取。两个计时口径不同，不能比较提速或退化比例。两组复跑均在一次命令内完成，说明这个小任务的基线本身已足够高效。

实际结论：Pace在这些本地文件任务中保持了正确性、隔离、缓存失效识别及重复执行安全；本轮没有证明比基线更快。工具调用数为Agent自报，不是独立事件统计。未测真实模型时长、弹性并发、等待编排或Siriser在线上传；合成题包清单不是正式平台格式验收。未据此修改业务系统、并发或Skill。
