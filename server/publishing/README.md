# 达标题目归档

复核当前项目模型集合、达标来源和文件指纹，在数据库记录归档状态与版本摘要。归档后题目从“题目记录”移出，仍保留在“达标题目”中查看。

## 文件职责

| 文件 | 说明 |
| --- | --- |
| `jobs.ts` | 归档事务：重新验证当前达标依据与产物指纹，只更新步骤和尝试记录，不生成额外发布文件。 |

## 数据流与依赖

jobs.ts 读取当前题目／答案／评分／达标快照 → 校验来源摘要及文件 → 在事务内记录 ordinal 8 归档状态。reporting 模块导出项目内全部当前有效的达标题目。

## 维护边界

归档只是一项数据库标记，不改变题目内容；附件、题面、rubric 或达标依据改变后必须重新检查当前版本。归档不生成发布文件，Excel 由 reporting 模块统一写入系统管理的存储目录并通过下载接口提供给浏览器。

本模块的 `*.test.ts` 保留既有验证意图；存在测试文件不表示本次运行。执行与授权遵循 [项目规则](../../AGENTS.md)。
