# 项目 skill 候选生成

用完整模板及当前项目资料生成项目级候选，校验入口、引用和问题清单，供采用为当前项目 skill。

## 文件职责

| 文件 | 说明 |
| --- | --- |
| `generate.ts` | 项目 skill 候选生成：复制固定资料和模板，应用受限文本修改并检查候选入口与引用。 |
| `jobs.ts` | 项目级 skill 队列：冻结生成来源和模型配置，保存候选结果并阻止过期来源发布。 |

## 数据流与依赖

jobs.ts 固定本次生成来源及模型配置、排队和候选记录 → generate.ts 在受限工作区调用 Codex并检查候选；server/rules.ts 负责将候选采用为项目当前 skill。

## 维护边界

候选不覆盖当前 skill；采用后更新项目当前 skill 路径，后续任务读取新内容。内部资料完整性与正式资格不同；外部资格不确定必须保留问题，不能伪装已确认。生成成功和采用分别表述。当前与脱敏／出题／评分共享 worker 的单路 Codex 消费。

本模块的 `*.test.ts` 保留既有验证意图；存在测试文件不表示本次运行。执行与授权遵循 [项目规则](../../AGENTS.md)。
