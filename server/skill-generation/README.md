# 项目 skill 候选生成

用主项目共享规则资料、当前共享 skill 和期次登记信息生成候选，校验入口、引用和问题清单，供采用为主项目共享 skill。期次仍各自保留工作流与生成尝试记录。

## 文件职责

| 文件 | 说明 |
| --- | --- |
| `generate.ts` | 项目 skill 候选生成：复制固定资料和模板，应用受限文本修改并检查候选入口与引用。 |
| `jobs.ts` | 项目级 skill 队列：冻结生成来源和模型配置，保存候选结果并阻止过期来源发布。 |

## 数据流与依赖

jobs.ts 固定主项目共享规则资料、共享模板、期次 `project.json` 及模型配置 → generate.ts 在受限工作区调用 Codex并检查候选；server/rules.ts 将候选安全复制到当前稳定 skill 目录，并同步该主项目所有活动期次的路径。生成候选留在 `.storage/` 作为尝试历史，不替换项目目录。

## 维护边界

候选不覆盖当前 skill；采用时先校验并暂存完整候选，再替换稳定的项目目录中的内容，数据库提交失败时恢复旧目录。已有稳定项目路径会保持不变，同主项目的活动期次继续指向同一目录；当前 skill 尚位于 `.storage/` 的旧项目保持既有的候选路径切换行为。内部资料完整性与正式资格不同；外部资格不确定必须保留问题，不能伪装已确认。生成成功和采用分别表述。当前与脱敏／出题／评分共享 worker 的单路 Codex 消费。

本模块的 `*.test.ts` 保留既有验证意图；存在测试文件不表示本次运行。执行与授权遵循 [项目规则](../../AGENTS.md)。

基础模板默认使用仓库 `templates/company-legal-task/`；`SKILL_BASE_TEMPLATE_DIR` 或显式 template 参数优先，相对地址按仓库根目录解析。已有任务继续读取冻结的 template_path 与 snapshot，不替换历史输入。
