# 成果与 Excel 导出

本模块只提供当前有效达标题目的查询及按需 Excel 导出。费用、产量统计、价格管理接口与对应计算模块已删除；历史数据库用量记录和迁移保留，不进行数据删除。

| 文件 | 职责 |
| --- | --- |
| `export.ts` | 用户点击导出时读取达标题目的题面、答案、评分及返修来源，不读取提取／脱敏历史正文。 |
| `results.ts` | 按批次构造题目、作答、评分和返修记录页签，不生成费用表。 |
| `xlsx.ts` | 生成 OOXML／ZIP，处理表名、特殊字符与超长单元格。 |

路由保存导出记录和失效状态，生成文件暂存在系统存储目录，经下载接口交给浏览器。导出失败只重试导出，不重做业务步骤。保留既有测试文件不代表本轮运行了测试。
