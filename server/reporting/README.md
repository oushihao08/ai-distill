# 统计、费用与 Excel 导出

从当前题目版本及归档状态取数，提供跨项目达标成果摘要、汇总全部当前有效达标题目生成项目工作簿，并按 API token 用量与价格快照计算可知费用。

## 文件职责

| 文件 | 说明 |
| --- | --- |
| `export.ts` | 项目报表取数：关联当前产物及历史调用费用，筛选当前有效达标题目用于导出。 |
| `app.ts` 的 `/api/results` | 返回当前有效且已达标题目的安全摘要，供工作台跨项目成果库使用；不返回材料全文。 |
| `metrics.ts` | 项目产量纯统计：仅聚合各题目当前步骤状态的处理、质检、评分、达标和导出状态。 |
| `prices.ts` | API 价格输入校验：核对供应商、模型、币种、token 单价、来源和有效期。 |
| `results.ts` | 成果工作簿结构：按批次组织题面、模型答案、逐项评分、返修和 API 费用表。 |
| `usage.ts` | API 用量计费：按完整 token 和价格快照计算费用，缺数据保留未知并排除套餐计费。 |
| `xlsx.ts` | 轻量 XLSX 写入：构建 OOXML 与 ZIP，处理表名、XML 字符及超长单元格拆分。 |

## 数据流与依赖

export.ts 查询／组织来源；metrics.ts 聚合当前版本产量；usage.ts 与 prices.ts 核验费用依据；results.ts 构造工作簿；xlsx.ts 生成 OOXML／ZIP。路由保存 project_exports 状态、下载与旧版本失效检查。

## 维护边界

缺 usage、价格或币种依据显示未知，不当成零。GPT／Codex 套餐不按 API token 单价计费。导出失败只重试导出，不重做题目；工作簿暂存于系统管理的存储目录，再通过下载接口交给浏览器，纳入当前有效的达标题目。报表或合成夹具通过不证明真实业务产能。

本模块的 `*.test.ts` 保留既有验证意图；存在测试文件不表示本次运行。执行与授权遵循 [项目规则](../../AGENTS.md)。
