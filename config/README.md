# 材料提取配置

`extraction.json` 保存文本识别与相关处理参数，不包含密钥。`server/materials/config.ts` 从 `EXTRACTION_CONFIG_PATH` 指定的文件或此默认文件读取，并校验字段。

主要字段包括识别／实体提示词、推理强度、输出 token 上限、是否逐页容错、是否实体复查，以及文本排版／遮盖方式。字段在不同提取路径中的实际作用以 `server/materials/` 的调用方为准；不能仅凭字段名认定当前路径一定执行脱敏。

PDF provider 与服务端密钥由环境及任务创建逻辑解析，见 [材料模块](../server/materials/README.md)。提取任务会保存配置快照，修改此文件只影响后续创建的任务。第二步 Codex 独立脱敏配置来自项目步骤设置，不与 PDF 提取混为一步。

修改前核对当前调用路径和 provider；保留用户提示词，不随意扩大用途。JSON 不支持注释，字段说明写在本文，不往配置加入非标准注释。
