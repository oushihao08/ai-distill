# 医疗实务题的临床语气与表达建议

**核心：**让五字段文字完全贴合真实医疗岗位的临床交办、审签会诊、跨科交接与医患沟通方式。

**作用：**表达修订：消除空泛套话、跨题同构骨架与产线残留；不改变病历事实、定量精度、文件义务与判分边界。

**阅读方式：**目录用于定位；正文中的适用条件、例外和引用共同构成要求。按本例临床关系选用，不设固定句式配额。

本文件用于任务名称、题面、考点、作答思路和标准答案的成稿与去模板化修订。“去 AI 化”是指清除脱离具体病例的万金油套话、千篇一律的首尾公文壳子以及评测产线残留，使文字呈现真实医护、药学、康复、营养与质控人员的日常书面工作状态；不迎合机械检测器，不使用生硬禁词替换率，也绝不故意制造错别字、口头禅或病历歧义。

临床范围、定量深度、事实边界与评分规则严格按[医疗场景、方向与交付设计](references/医疗场景与工作流程.md)、[出题设计方法](references/出题设计方法.md)、[题目格式与交付](references/题目格式与交付.md)及[评分与难度验证](references/评分与难度验证.md)执行。本文件只决定怎样自然表达，绝不删减或新增实质临床任务。

## 写作前的表达定位

完成整包盘点、临床求解、脚本实算与复合 rubric 后，先在内部确认下列五项（仅供作者决定行文方式，严禁将该定位表写进题包）：

| 判断项 | 从本例确定什么 | 对五字段表达的实际影响 |
| --- | --- | --- |
| 岗位与协作关系 | 哪个岗位的专业人员在什么层级机构处理此事，执业权限到哪里，提交给谁 | 决定交办口吻、临床术语颗粒度及越权边界嵌入位置 |
| 任务触发点 | 眼下因何启动：危急值／药敏新回报、待审医嘱矛盾、限期手术 D0 卡点、多年体检异常爬升、术后突发症状或出院下转交接 | 决定题面首句从哪个具体医疗事件切入，彻底摆脱默认人名或头衔起笔 |
| 成果使用人 | 主诊医师组、手术麻醉团队、当班护士、康复治疗师、基层接诊医生、医务质控部门或患者／家属照护者 | 决定专业文书体例与患方通俗指引的语言分层及监测条件显性程度 |
| 成果实际用途 | 床旁紧急处置、医嘱重整审签、围术期停启排程、24h 液体营养调配、训练负荷调整、检后早筛分流或质控督办 | 决定标答首屏先给正式执行单、直入核心裁决、院内签报还是核心核算总表 |
| 信息组织关系 | 病历事实呈纵向时间轴演变、多源药单／检验比对、多科竞争方案权衡、多样本队列核查还是跨节点动态更新 | 决定采用时序推进、分系统／分问题对照、矩阵表格还是正式临床文书，不随机套外观 |

定位必须 100% 来自当前可见材料与已定临床设计；严禁为换语气凭空编造主任晨交班训话、家属医闹催促、院办紧急红头文件或原卷不存在的检查结果。

## 按临床条件选择说法

具体起笔、展开、局部排版与收束从[书面表达组合库](assets/书面表达组合库.txt)拆散选取。只有当本例确实存在多接收人、竞争性备选治疗路径或跨节点复评回报时，才选用对应的分接收人、方案比选或阶段递进写法；单一接收人或单一明确路径直接写透，绝不为求异硬拆文件或硬造假分支。

## 五个字段分别按职责写

### 任务名称

- 用本例最具区分度的单一临床冲突、核心待办事项或关键文书用途命名，最后定稿。严禁整批写成“［患者／疾病］的［四字动作］与［四字动作］”对称并列句式，严禁扎堆使用“综合、全面、全套、闭环、专项、深度、一体化、接管、核校”等包装词，不串列所有交付文件名，不提前点破待求的最终诊断、致病菌或唯一调药答案。

### 题面

- 像科室内上级医师、会诊发起方、主检负责人或质控主管布置一项真实待办工作：从当前触发评估的危急回报、遗留医嘱出入、手术窗口倒计时、多院用药冲突或交接需求直接切入，不默认拿患者姓名或“你是XX医院主任医师”作首词，也不在首段末尾堆砌“接诊设定声明＋四连越权禁令”公式（模拟时点与假定前提用自然临床措辞明确标示，不越权开方／代签等边界紧邻待审医嘱或患方沟通段落就近交代）。
- 将权威指南与 NMPA 说明书原文联网核验、可编辑正式医疗文书（DOCX）、全公式驱动的多分表临床核算工作簿（XLSX）重算读回与动态／敏感性情景试算、全套主报告＋正式执行交接患方文书＋横向适配多栏附表导出分页 PDF 及逐页转图版式与跨件一致性校改，点名融入本例具体文书与底稿段落中；严禁照抄 Skill 内部缩略词串，严禁开头写“请先详细规划”，严禁末尾单挂统包式技术尾段。题面提供完整客观病历与待审文本，绝不单拎错误医嘱反问或喂给公式阈值。

### 考点

- 每条直接陈述所验收的复合临床结果、原件与权威规范判据、定量容差、排他失败边界与正面产物实证要求，不用题面交办口吻，不写成能力赞美或标答目录。严禁出现 `本条评价……`、`附件1` 或 `评分端／轨迹未传／评测条件不满足／不作为有效专业难度成绩` 等产线黑话；案件化整体失效条件融入最直接相关的那条 criterion 中并以贴合本例临床后果的自然行文写明整题归零后果，不复读固定尾句。

### 作答思路

- 像资深临床／药学／康复／质控骨干向同行复盘核心取舍：直接从决定本例走向的检验伪影排除、多源记录矛盾、指南版本与人群限制、定量折算逻辑或竞争路径权衡切入，串联证据与结论；严禁逐条复述题面，严禁用“首先—其次—最后”工具流水账充当医学推理。

### 标准答案

- 直接交付接收人立即可用的专业成果，首屏按本例核心用途分流切入（正式执行／会诊／排程／交接文书前置、无信头直入核心临床裁决、院内审方／MDT／质控签报纪要式、或核心定量重整／液体营养／风险分层总表先行），**严禁整批默认套用“［XX评估意见（书）］＋致／接收科室：XX＋评估基准日：XXXX年X月X日”三行公文信头**。医疗文书必需的患者抬头、核定医嘱项、警示栏与审签留白属于正常业务体例，照常保留；医护专业版与患者通俗版严禁只把“患者”替换成“您”敷衍了事，同时两边剂量、频次与停药红线必须丝毫不差。

## 多样性来自真实临床组织

- **打破内部流程外化同构**：作者内部的“全卷盘点 → 去伪底账 → 脚本核算 → 文书定稿”只用于保证工作深度，**严禁每次都把这四步原样照搬成四段题面、同序四条考点和同序四节标答**。急症转运题按抢救时序与交接推进，围术期题围绕手术指征与 D0 时间窗组织，体检慢病题沿跨年斜率与分层随访展开，质控研究题按样本纳排分母与系统整改编排。
- 存在 `batch-context.json` 同期白名单摘要时，主动比对并错开已密集出现的科室岗位、定量模型类别与文书组合；无同期摘要时专注把本例特有的临床冲突写实写透，不虚构跨题对比结论。

## 七步成稿复核并直接改写

1. **临床真实工作感**：遮去首句头衔后，能否一眼看出此时为何紧急或必须处理、依据哪份病历记录、交付给谁下一步干什么？看不出就补具体临床衔接，不加抒情套话。
2. **五字段是否脱模**：按[表述方法](references/表述方法.md#成稿复核)检查五字段各自独立履职、未互相照抄同一目录；检查首句、模拟标示、文书嵌入方式与标答首屏均贴合本例，无克隆句架。
3. **要求是否落到具体临床对象**：删去“全面、系统、深度、闭环”等修饰词后，核查对象、定量口径与交付文书是否依然清晰可验？不清楚处补实具体医疗事项。
4. **重复是否确有临床职责**：合并题面中无增量的重复叮嘱；保留医嘱单、护理配制单与患者服药卡之间为保障患者安全所必需的精确剂量与禁忌对应。
5. **是否误泄诊断或解法**：排查题面是否混入了作者已判定的假性异常结论、复方重复点位、指定公式名称或分期阈值；若有立即退回客观待审文本与业务目标描述。
6. **是否彻底清除生产残留**：清零 Markdown 标记符号、代码块、生成脚本、本机路径、`附件1`／`附件 1` 编号、页码、评测产线黑话与模型自述；完整保留临床计量单位、给药频次途径、Excel 活公式说明与权威出处链接。
7. **是否 100% 保义零减损**：双向核对患者代号、生理数值、时间节点、岗位权限、模拟边界、四项硬性文件与视觉校改动作、PDF 18MB 分册规则及逐条 rubric 的 `0/1` 判定边界完全未变。仅获准润色旧题时，严格执行[保义改写规则](references/表述方法.md#已有题目的保义改写)。
