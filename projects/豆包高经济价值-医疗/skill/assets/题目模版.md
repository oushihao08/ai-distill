# 医疗题目包模板

按本次返回 schema 填写以下七项；括号内是作者填写提示，完成时替换，不进入业务正文。此模板不固定诊疗路径、考点数、成果数量或文书体例。题面可对应 `question`，标答可对应 `reference_answer`，实际字段名以当前 schema 为准。

## 表头

题目 ID：（本次关联 ID，不放入临床正文）
一级/二级行业：（当前分类允许的单一行业及细分，按任务所在业务选择）
L1 职业簇/L2 职业：（负责交付的实际岗位）
任务形式：（单轮或具有实际承接依赖且环境支持的多轮）
输入附件：（作答者实际可见的名称/序号，保留来源边界）

## 任务名称

（本题的具体事项和核心工作；不提前给待求诊断，不写内部评测目标。）

## 任务类型

（按实际成果用途选择当前规则允许的主要类型，不虚构枚举。）

## prompt

（按本题真实触发和使用人组织交办：岗位、场所、时点与可见信息、对象范围、资源与权限、当前工作及可使用成果。具体说明必要依据、计算与核验；需要文件就交办实际制作和读回。已获准的模拟条件明示，不透露正确路径或冲突位置。）

（确有持续照护时给出后续事件及其信息时点，要求承接前阶段结果、实际修订并交当前有效内容；没有事件不虚构已复评。单轮一次提供全部必要材料。）

## 考点 rubric

1、（验收一个复合专业结果：具体对象/时点、决定性输入、适用医学依据及版本、正确结果/条件、必要计算和容差、可接受替代、关键失败和实际证据。不要保留这些栏目名作为固定句型。）
2、（下一独立结果；按真实用途及新增判断继续，不按文件/药品/工具数量凑项。）

（阅读稿用普通编号；结构化返回按 schema 保留 R1、R2 等 ID 和 max_score=1，criterion 不重复 ID/分值。共享前提、下游独立义务及共用文件证据的归属就近写清。能够论证的整体失效条件只写一次：具体最终行为、证据、核心用途后果、整题归零及不触发边界；不另占普通分母，不套“存在医疗风险即零分”。）

## 作答思路

（提供可核查的专业论证：决定性记录支持什么、适用依据为何适用、哪些竞争解释保留/排除、必要核算及不确定性如何改变当前处理。按本题实际关系组织，不输出隐藏思维过程或工具流水账。）

## 标准答案-文本

（完成全部题面工作，按实际接收人的文体写出可用正文、必要计算、依据、分支和执行条件。专业成果与患者说明按用途组织，数据和方案一致，不用“另行拟定”替代正文，不虚构签发和执行。）

（连续照护题给出各时点实际结果、调整及保留内容和当前有效版本，后见信息不倒灌。文件题的文本标答写全正文和公式；实际文件与核验按契约另行交付校准，执行缺口放允许的完成说明，不在 schema 外造字段或链接。）
