# 医疗题目包字段模板

按本次返回 schema 填写以下七项内容；花括号、Markdown 标题与列表仅用于说明字段职责，成稿时全部替换为实际业务文字，绝不把括号提示、Markdown 标记、内部组件名或输入路径序号带入五字段正文。`question`＝题面，`reference_answer`＝标准答案。

先按[医疗场景、方向与交付设计](../references/医疗场景与工作流程.md)、[临床决策分支](../references/临床决策分支.md)、[出题设计方法](../references/出题设计方法.md)、[医学依据与专业核验](../references/医学依据与专业核验.md)和[评分与难度验证](../references/评分与难度验证.md)完成全卷盘点、集中脚本实算、权威医学原文核对与自足复合判据，再按[临床语气与去模板化建议](../去%20ai%20化建议.md)、[表述方法](../references/表述方法.md)及[书面表达组合库](书面表达组合库.txt)为五个字段独立拆散组合自然书面表达。

## 表头

题目 ID：{本次关联 ID，仅用于题包登记，严禁放入业务正文}
一级／二级行业：{按任务发生机构的主营行业及细分单选填写}
任务形式：{按本次契约且具真实前后依赖的形式填写，单轮题一次给全全部阶段输入，不机械拆轮}
输入附件：{表头按实际登记可见原件名填写；题面、rubric、思路、标答业务正文统一自然写“附件”“所附病历”或具体医疗文书名称，严禁写“附件1”“附件 1”}
L1 职业簇／L2 职业：{负责最终交付的实际医疗卫生或质控研究岗位，严禁把患者／家属身份填作职业}

## 任务名称

{用最具区分度的单一临床核心事项、待决治疗／管理冲突或关键文书用途命名；在题面与标答完成后最后核定，不照抄文件夹路径，不串列全部交付文件名，不提前泄漏待求诊断、致病菌或调药答案；严禁写成“［患者／疾病］的［四字动作］与［四字动作］”对称并列句式，严禁滥用“综合、全面、全套、闭环、专项、深度、一体化、接管、核校”等高频包装词。}

## 任务类型

{根据材料实质工作与最终交付物的主要业务用途单选本期适用类型，不按附件格式或目录名机械分类。}

## prompt

{按[场景规范](../references/医疗场景与工作流程.md)、[设计方法](../references/出题设计方法.md)及[交付规范](../references/题目格式与交付.md)写清真实岗位职责、机构场所、信息截止时点、可见边界与成果接收人。首句随本例真实临床或业务触发点轮换（危急值／药敏新回报、待审医嘱或总检草稿出入、限期手术 D0 停药窗口冲突、跨年体检异常爬升、多院用药重叠或转科出院交接缺口），严禁默认拿患者姓名／代号或“你是某科主任医师”起笔，严禁在首段末尾堆砌“角色设定＋基准日＋‘该接诊关系为本题设定’＋四连禁令”公式。模拟评估时点、假定排程前提或新增模拟复评记录须用自然临床语言明确标示模拟／假定身份（禁止逐题复读同一句设定套话）；不越权独立开方、不实际执行有创操作、不代患方签字等执业边界紧邻对应待审医嘱建议稿或患方沟通段落就近交代。引用病历统一称“附件”或具体医疗文书名，严禁写“附件1”。}

{按[作答端检索、依据与实体交付核验](../references/题目格式与交付.md#作答端检索依据与实体交付核验)完整交办盘点确定的全部实质工作与可用成果，点名本例具体文书与底稿名称拆散融入对应成果段落中：联网检索并实际打开卫健委规范、NMPA 正式药品说明书或专业学会权威指南原文核对版本、适用人群、折点与例外；制作可直接审签／交接／发放的可编辑正式医疗文书（DOCX）及全部由公式驱动的多分表临床核算工作簿（XLSX，依本例材料形态贴合选用纵向趋势与风险积分、药代封顶配制、24h 显隐性液体酸碱热氮、围术期 D0 排程、肿瘤周期毒性、康复 FITT-VP 容量、妇儿生长阈值或质控流调矩阵等结构，拒绝不论病种硬套单一用药表），实际执行公式重算并读回；完成工作簿动态联动核验（跨节点题承接新增回报触发重算更新并读回；单窗口静态题围绕本例真实估算口径分歧、生理临界波动、手术改期或备选路径设置临床敏感性／情景对比试算栏验证公式自动联动并读回，与正式执行主表区分，严禁写“在与病例事实隔离的核验副本中改变一项关键输入”套话）；将主报告全文、全部正式执行／排程／交接／患者指导文书及经横向或列宽适配的多栏核算宽表全套导出为分页 PDF（遵守单文件 ≤18MB 连续页拆分规则），并将全部 PDF 逐页转为页面图像排查宽表横向劈裂、审签／警示框孤行跨页、剂量单位截断及跨文书药名／剂量／频次／红线出入后回改源 DOCX/XLSX 重导核准。严禁原词照抄内部缩略术语，严禁开头写“请先详细规划”，严禁末尾单挂统包技术尾段，严禁单交《文件交付回执》。}

{依材料形态选用跨节点动态照护（单次关键新证据连锁重算、同节点多源冲突输入并行汇入、严格生理或流程先后依赖推进）或单窗口深度审校定稿，单轮内按时点提供全部客观记录与自然待审文本；严禁构造一段话内集中暴露多处低级医疗常识错误的“稻草人草稿”，严禁单拎错误医嘱反问，严禁在题面喂给计算公式、量表权重、指南分期阈值或常规停药洗脱天数。有临床原图时交叉核对图文，无原图仅文字报告时不盲考图形且绝不降格输出端文件、计算与检索要求。}

## 考点 rubric

{按[评分规范](../references/评分与难度验证.md#考点)划分独立复合专业结果，等权 0/1 换算百分制，无固定条数：同源基线消歧、人群公式估算、隐性负荷累加、极量／速率封顶与可分取配制排程合并为一条复合定量核算 R（严禁拆条送分）；基础病史与常规体征摘录并入所支撑的决策 R（零送分项）；证明逻辑独立、服务不同接收动作的多项实质任务分别设 R（严禁过度粗捆成 ≤3 条大总包 R）。每题在最直接相关的那一条 criterion 中写入经本例证据论证的案件化整体失效条件（全题只出现一次，不固定塞在末条末尾，不用“一票否决”标题），写清具体最终致命行为、核验依据、对核心医疗安全或用途的破坏，并以贴合本例的自然临床表述写明全题计零分后果（禁止逐字复读固定句尾）。}

1、{直接点明本条验收的具体临床裁决、定量核定方案或实体文件使用能力（禁止以“本条评价……”起笔），自足写清共同成立判断、附件决定性记录与数值（称“附件”或具体文书名，禁写“附件1”与页码）、权威指南／NMPA 说明书要旨及版本边界、计算口径与合理容差、合法等效替代、排他失败边界（含封堵“完善检查／请会诊／密切观察／待结果再定”万金油套话）及验收落点。}
2、{下一项独立复合专业结果；涉及工作簿公式联动与全套分页 PDF 版式一致性的单条复合载体／交接 R，须点名本例具体文书与表册名称并明确“仅列文件名、口头自述已完成、手填静态常数或仅交未执行脚本均不成立”；严禁将“评分端”“轨迹未传”“评测条件不满足”“不作为有效专业难度成绩”等内部评测流水线术语写进 criterion。}

{以上 1、2 为阅读稿普通编号；结构化 JSON 按当前 schema 保留 R1、R2 等 id 与 max_score=1（或其他契约字段），criterion 正文不重复序号、分值标签或“全部满足得分”尾句。}

## 作答思路

{以资深临床／药学／康复／质控同行复盘口吻，直接展开决定本例取舍的原始记录对应、检验与执行伪影排除、权威指南与说明书版本适用、全链路定量推导及竞争方案排除理由；跨节点题阐明新证据改变了基线哪项成立前提与哪些仍保留。严禁复述题面，严禁写成工具操作步骤清单、代码脚本或作者自查说明。}

## 标准答案-文本

{首屏严格按四类临床主成果体例分散切入（正式执行／会诊／排程／交接文书前置、无信头直入核心临床裁决、院内审方／MDT／质控签报纪要式、或核心定量重整／液体营养／纵向分层总表先行），严禁整批套用“［XX评估意见（书）］＋致／接收科室：XX＋评估基准日：XXXX年X月X日”三行公文信头。完整写出各阶段可直接使用的医疗专业文书全文、患方／监护人通俗指导全文（确保两边药名、单次量、频次、时间窗与停用红线 100% 一致）、工作簿分表结构与字段口径、关键 Excel 活公式写法、分项汇总勾稽与动态／敏感性试算结果，以及全部冲突、伪影、重复、禁忌或调整项的逐笔处理明细；附件已明确且无争议的大批量常规监测或发药流水按来源范围、记录笔数与区间统计归并引用，不在文本标答逐行重抄。不用代码脚本或“另行拟定”代替正文；普通出题会话不在内部制作抛弃型办公实物，作答端环境缺口仅在会话收尾简述。}

## 独立使用与组合规则

临床设计与判据冻结后必读[临床语气与去模板化建议](../去%20ai%20化建议.md)、[表述方法](../references/表述方法.md#独立使用与组合规则)与[书面表达组合库](书面表达组合库.txt)。五个字段依本例触发事件、信息关系、接收人与用途独立拆散组合，双向核验改写前后全部临床工作、文件义务与 `0/1` 判分边界丝毫不变；内部组件名与核对过程不进入题包。

## 已有题目的保义改写

仅获准润色既有题目时严格执行[保义改写规则](../references/表述方法.md#已有题目的保义改写)，不借改写改变临床范围、定量精度、文件要求或 rubric 判定结论。成稿收尾按[每项工作与各阶段材料完整交付](../references/出题设计方法.md#每项工作与各阶段材料完整交付)及[执行复杂度与实测证据](../references/评分与难度验证.md#执行复杂度与实测证据)完成双向核对，未完成独立模型实测与医学专家校准前严禁宣称已达标或已通过临床验收。
