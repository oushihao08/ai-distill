# 医疗任务设计与安全边界

## 适用范围

本文用于根据已授权、已冻结的医疗材料设计专业任务。它不是临床指南，不代替医疗专家审定，也不授权处理真实患者数据。

## 材料准入

按真实文书边界盘点材料，至少记录：

- 文书类型、时间、机构类型、页数和相互引用关系；
- 可确认事实、需要视觉核对的图像/表格、提取模糊项和缺失页；
- 同一患者的时间序列、不同患者边界、重复转写或同源版本；
- 题目所需但附件没有的必要信息。

转写文本可用于检索和候选事实，但原始 PDF/DOCX 的布局、印章、手写批注、检验单表格和图像信息需要回到渲染页核对。没有原件时，不设计必须判断转写正误的任务。

## 任务选择

从材料真正支持的专业用途出发，不按附件名称或诊断词生搬题型。

| 材料结构 | 可考虑的专业工作 | 不充分时应避免 |
| --- | --- | --- |
| 同人多时点体检/检验 | 指标口径统一、趋势、持续/新增异常、风险分层、随访清单 | 仅复述报告已给建议；直接确诊 |
| 同次就诊的病历、检验和用药 | 时间线、诊断—检查—用药对应、用药交代完整性、缺口升级 | 缺体重/过敏史时确定儿童剂量；替代处方 |
| 住院病案与手术/出院记录 | 病案质量、诊断与操作一致性、编码候选、缺件清单 | 仅凭首页评判诊疗正当性；忽略不同患者边界 |
| 两份同源转写 | 差异清单、差异对下游判断的影响 | 无原件却判定哪份正确；把重复字数当工作量 |

如果材料同时具有保险、司法鉴定或诉讼语境，先确定本题的最终用途。医疗任务只处理医疗专业产品；责任认定、因果关系法律结论、赔偿计算和诉讼策略属于法律/鉴定边界，不因材料包含病历就归入医疗题。

## 专业依据和时点

题面写明任务基准日。当结论依赖外部医学依据时：

- 优先使用截至基准日适用的国家卫生健康部门、药品监管部门、正式指南发布机构、药品说明书或同等权威来源；
- 记录名称、版本/发布日、适用人群、关键规则及其支持的结果；
- 不用基准日之后的指南倒推当时应当处理，除非题面明确要求追溯比较；
- 不以单篇二手科普、搜索摘要或模型常识替代决定性依据。

外部依据能完善专业处理，但不能补造附件中不存在的患者事实。

## 标答与 rubric

标答必须能完整示范交付物，而不是只给提纲。对每个决定性结果保留：

1. 附件事实及定位；
2. 使用的医学依据或计算规则；
3. 结论的适用范围和不确定性；
4. 会改变结论的缺失信息；
5. 在最终交付物中的具体呈现。

rubric的分组跟随可独立成立或失败的专业结果，不跟随页数、文书数或句子数。一个结果同时需要数据、判断和交付呈现时，在同一判定中写清必要条件，避免对同一错误重复扣分。

标答和 rubric 在作答前冻结。之后发现附件或专家依据错误时，修正输入并从头重测；不根据某个模型的具体错误临时追加考点。
