# 医疗复合判断与出题设计方法

用于材料驱动的医疗新题设计与获准的实质修订。先明确责任岗位在特定照护或管理时点必须解决的真实问题，再据此构建证据消歧链、多表定量模型与实体交付物；严禁从固定疾病名词、固定“审方三件套”或预设考点数反推病历。岗位与多场景匹配见[医疗场景、方向与交付设计](医疗场景与工作流程.md)，临床推理选路见[临床决策分支](临床决策分支.md)，循证与核算细节见[医学依据与专业核验](医学依据与专业核验.md)，计分边界见[评分与难度验证](评分与难度验证.md)。本文件是作者内部设计方法，不是题面目录或固定答题模板。

## 找茬的对象与时点盲界

先确认责任岗位、机构资源、信息截止时点与成果接收人，再逐份精读全部冻结附件：

- **严格区分事实层级**：患者／家属主诉自述、查体客观体征、原始检验／检查正式报告、外院病历转抄摘要、既往初步／疑似诊断标签、已开立医嘱（拟议／长期／临时／备用）与护理实际给药执行／患者院外真实服药状态，绝不混写为同级已证实事实。
- **区分独立证据与同源转抄**：同一检查数值或既往病史在门诊病历、入院记录、病程录和出院小结中被反复复制粘贴，只算单一来源，不按出现次数叠加证明力；多患者抽查或队列材料逐例独立建账，严禁跨患者串接体征、体重或化验单。
- **严守决策时点盲界**：较早临床节点不得偷用后续才回报的培养药敏、病理免疫组化、复查影像或转归结局；事后病案质控或不良事件复盘须明确拆分“当时可得信息下处置是否合规”与“事后全貌下的流程改进”。
- **纵向矛盾穿透原则**：不同日期、不同院区或不同文书出现数据矛盾时，按原始报告优先级、采样／测量条件（空腹、体位、输液侧、给药峰谷时间窗）、检测方法学与单位量纲穿透核实，绝不机械认定“最新一条必然正确”；确属现有材料无法唯一消除的冲突，转入明确条件分支，不篡改原件数值或盲猜脱敏遮蔽值。

## 任务盘点与范围确定

先全量盘点，再确定委托边界。完整阅读整包材料后，在同一岗位职责、执业权限与信息时点内查全所有可完成的实质工作，供最终成稿双向核对（仅在会话内部完成，不单独落盘写核对文档，不新增返回字段，也不要求作答者交盘点表）：

1. **必查垂类参考矩阵**：每次选题必须查阅[医疗垂类评测（材料-场景-交付物）参考](../assets/医疗垂类评测（材料-场景-交付物）参考.md)中与本包材料相符的方向，逐项核对材料位置、待决临床或管理冲突、实质处理、可用交付物及纳入／排除依据；参考表外有材料支撑的必要工作一并纳入。排除某项候选只能基于材料缺失、执业越权、时点冲突或用途完全重复，严禁以“参考非强制”“篇幅已够长”“省事好套模板”为由整行跳过。
2. **严禁作者自设缩水范围**：作者设定任务委托时，必须在全包盘点后再划定合理工作范围；严禁预先添加“仅作健康科普”“只谈诊疗大原则”“不做具体剂量／液体／风险积分核算”“不拟定待审医嘱／排程／交接正文”等限制来逃避材料支持的实质工作。未获现场独立签发处方或实施手术授权，不等于不能交付供主诊医师／团队审签使用的完整修订定稿、全口径公式工作簿及配套交接／患方执行文件。
3. **无现成大表时构建必经底层穿透底账**：当附件以文字病程、多期体检报告、零散化验单、会诊记录或前手草稿为主、缺乏现成结构化大表时，必须围绕卷内跨源差异构建作答者必经的逐项消歧底账（如跨年度／跨机构检验单位折算与真伪异常去伪表、长期／临时医嘱与护理执行及自备药复方成分穿透表、围术期多药半衰期与器官功能停启矩阵、多科室冲突约束对照表、多病案抽查指标分子分母逐例核定表），使底账清洗与核算结果直接决定下游风险分层、治疗路径、给药参数与文书条款；严禁靠禁止批处理、硬拆调用次数或人为等待凑步长。
4. **反查遗漏与基础摘录归位**：将拟定委托与整包候选逐一反查，补回过早排除的相容独立事项。无争议的一般病史梳理、常规生命体征抄录或直球标准条文套用一律作为支撑核心决策的前置底座并入对应争议任务，严禁单列充当核心任务或送分考点；仅在明确获准扩展既有题目时逐项核对原题难点、成果与判据不丢失。

### 每项工作与各阶段材料完整交付

为每项纳入工作明确：**“可见输入依据 → 加工消歧对象 → 实体医疗文书或全公式工作簿 → 接收人下一步具体动作”**。

- **按真实接收动作定载体**：需要主诊审签、跨科会诊执行、当班护理核对、康复师实施、基层机构承接、质控办督办或患者居家照护的成果，分别提供可直接投入使用的实体文件；同一合册能清晰支撑同一接收人连续动作时允许整合，但各阶段结论、调整前—后逐项对照依据与生效边界必须可定位、可复算、可更新，不得以“已在总评估报告提及”省去执行药单、围术期排程日历、液体营养配比底稿或患者通俗行动卡。
- **阶段有效态与联动真伪**：保留“其余沿用前版”时，交付包内须含完整前版且替换边界清楚，绝不让接手医护或患者自行拼凑残片。工作簿必须以清洗后的原始输入驱动活公式自动计算，严禁预填静态常数格冒充公式联动；正式医嘱建议、会诊意见与患者指导必须把分析中识别的禁忌、启用前置条件与停药复评红线完整写入执行正文，严禁前文分析谨慎、后文医嘱无条件照开。
- **文本标答与作答者文件的边界**：作者在 `reference_answer` 文本标答中完整写出各阶段正式可用文书全文、工作簿分表结构与字段口径、关键活公式写法、分项汇总勾稽及所有冲突、干扰、重复、禁忌或调整项的逐笔处理明细；对于附件已明确记载且无争议的大批量常规监测、平稳检验或常规发药流水，在文本标答中按来源范围、筛选口径、记录笔数与区间统计／分项小计归并引用，不在文本标答逐行重抄原始长表（题面对作答者实际工作簿的全量明细处理义务不受影响）。普通出题会话用集中计算脚本与联网原文核验完成自证，不在出题会话内另行生成抛弃型 DOCX、XLSX、PDF、PNG 实物。

### 按材料展开实质临床工作

对盘点出的未决问题按下表匹配可见材料展开，四类专业动作可独立成题或依真实依赖组合，不要求每题集齐：

| 工作形态与触发输入 | 作者先求解的专业处理 | 题目应要求实际完成的成果 |
| --- | --- | --- |
| 审用与修订既有方案：有前手诊疗计划、待审医嘱、围术期排程、营养配方、康复处方、体检总检建议或出院草稿 | 逐条对照原始病历、最新器官功能、标本质量、权威指南与说明书原文；区分安全保留、必须修订／停用及因缺证附条件启用项，核算局部改动对关联治疗的连锁影响。绝不预设原稿全部错误 | 交付可直接审签／执行的完整修订定稿及逐项修改对照依据；确属原方案合规有效时交付有充分循证依据的维持／观察定论。严禁只提风险意见而把改稿推给接手人 |
| 裁决临床分歧与竞争目标冲突：存在跨科会诊分歧、检验与体征背离、患方拒绝首选方案，或出血 vs 抗栓、控感 vs 免疫、限液 vs 灌注等互斥约束 | 还原各方循证依据、时效窗口与不可逆伤害权重，剔除采样或方法学伪影；在共同安全边界内求解时序错峰、桥接折中或次优安全替代路径，划清启用与逆转条件 | 交付正式会诊／MDT 裁决意见书与多目标约束比对决策表，写明首选路径、备选触发阈值与患方共同决策沟通文本；如实保留合法不利事实，不强凑虚假一致 |
| 穿透多源纵向记录与定量配比：跨年体检、多院处方／自备药、多日出入量血气、复杂给药／营养／康复参数或多病例质控队列 | 穿透单位差异、复方隐藏成分、已开未执行错位及隐性溶媒水钠热卡；按人群专属公式求解生理指标、风险积分、剂量极量、纠偏速率、训练靶区或质控分母 | 交付可逐笔回溯原件的穿透底账、全公式驱动的多分表核算工作簿及口径完全一致的执行文书；局部缺证时给出定量条件分支 |
| 照护转换与跨节点动态修订：存在急诊转住院、ICU 转普通病房、围术期前后衔接、出院下转社区，或给定新回报数据承接前版更新 | 核清前阶段已执行状态、残余生理负荷、已送检未回报项目及接收方资源限制；判断新输入推翻了哪项基线前提、保留哪些有效安排，重算受影响参数 | 交付接收方零猜测可接手的转运／跨班／出院交接定稿、待报追踪责任单、患者通俗行动卡及更新后最新有效工作簿与医嘱建议 |

按四步落入题包：①**核输入**（确认待审原稿、原始检验、用药／操作记录及时间节点均在可见附件中，有原图核原图，无原图不盲考图形形态）；②**定边界**（证据充分处直接给出排他结论与精确数值，真实缺口处写明缺哪项、影响哪一步、回报前安全过渡方案及回报后分支）；③**求实解**（用集中计算脚本实算全部公式并联网打开权威指南／说明书原文核实，先定标答与交付物，再写判据、思路与题面）；④**查增量**（若增加段落或文件未带来新的临床消歧、定量判断或独立接收用途，重返材料深化任务）。

## 材料到成果的工作链与临床交接

在内部画出并逐箭头核验：**“原始病历／检验／样本单位 → 中间去伪消歧与定量底账 → 临床／业务专业裁决 → 实体文书与全公式工作簿 → 接收人下一步具体动作”**。若抽掉中间底账或计算表仍能凭直觉写出同等精度的最终文书，说明工作链尚未咬合，须回到材料补足跨源穿透与定量依赖。

### 八类医疗原生定量与多表穿透模型（按材料自然选用，破除“唯肾功算药”单一模板）

需要构建多表全公式工作簿（XLSX）及敏感性／动态联动核验时，严禁无视材料生搬硬套“肾功调抗生素”，应按本包真实材料形态选用匹配的定量建模结构：

1. **纵向体检／慢病随访标准化趋势与风险分层模型**：跨年度／跨机构检验单位折算、基线变化率／年下降斜率（如 eGFR 斜率、肺结节倍增／代谢指标趋势）、心血管／肝纤维化／骨松／肿瘤早筛风险积分核算及分级复查排程表；
2. **多源复方穿透、TDM 与个体化药代封顶模型**：院内外处方与中成药隐藏同名成分累加、TDM 稳态合规剔除、特殊体型（TBW／IBW／ABW／BSA）与动态肝肾功清除率折算、儿童按体重计算与成人极量封顶交叉核验、制剂可分取规格及微量泵浓度滴速表；
3. **重症／住院 24h 全口径出入量、酸碱代偿与临床营养模型**：逐班显性出入量＋内生水／非显性失水、全部静脉溶媒（盐水／糖水／丙泊酚脂肪乳／抗生素钠钾盐）隐性水钠与非营养热卡穿透、混合性酸碱失衡预计代偿区间、低钠／高钠安全纠偏速率上限及 EN／PN 热氮比配比表；
4. **围术期／围内镜 D0 多药停启洗脱与桥接排程模型**：锚定手术／操作日（D0），结合药物半衰期、手术出血／血栓风险等级及患者肾功核定抗凝、抗板、SGLT2i、GLP-1RA、降压利尿与糖皮质激素应激覆盖的逐日停药、肝素桥接与术后重启达标排程表；
5. **肿瘤周期给药、累计毒性封顶与 CTCAE 减停矩阵**：基于最新身高体重的 BSA／Calvert AUC 周期剂量计算、终身累计心脏／肺／神经毒性封顶剩余额度核查、CTCAE 分级对应的按比例减量／延迟／停药及支持用药联动表；
6. **康复功能分期、FITT-VP 靶心率修正与负荷进阶模型**：结合年龄、静息心率、运动试验表现及负性变时药物修正的靶心率／RPE 区间、抗阻／有氧周训练总容量（组×次×负荷×频次）核算、术后阶段负重上限与进阶／降阶阈值对照表；
7. **妇产孕周核正／儿科校正年龄生长 Z-score 与阈值排程模型**：早期超声核正孕周与产检时间窗、早产儿校正月龄身长体重头围百分位／Z-score、新生儿小时龄胆红素光疗／换血曲线比对、追赶生长热卡液量或漏种疫苗最小间隔补种日历；
8. **院感时空流调、病案质控／DRG 分母穿透与临床研究稽查模型**：多病例床位／操作／人员时空交集暴露矩阵、质控指标原始个案纳排筛查与分子分母重算对照表、受试者访视时间窗偏差天数与方案违背分级核查表。

### 成果落地与临床交接维度

以接收人（主诊／接班医师、驻科药师、当班护士、康复治疗师、基层接诊医师、质控部门或患者／照护者）能零猜测安全接手为完成标准：

- **审签启用与执行前置条件明确**：写明哪份文书须经何种资质人员审签后生效、启用前必须核实的床旁指标（如收缩压、血钾、INR、引流液量或吞咽分级）、精确配制溶媒与泵速、不可压碎／不可同通路配伍硬红线。
- **急缓时序与未回报追踪闭环**：区分床旁立即执行动作、并行检查与择期调整；对全部已采样未回报的培养、病理、分子检测或外送检查，逐项落实预计回报窗、负责追踪岗位及阳性／危急回报后的应急召回或换路预案。
- **可观测升级红旗替代套话**：写明触发立即停药、呼叫上级医师、转入 ICU 或返院急诊的具体体征与数值变化，严禁以“密切观察病情变化、不适随诊、谨遵医嘱”充当交接。
- **多端文件绝对同源一致**：医护专业文书、全公式工作簿与面向患者／家属的通俗执行卡必须共享同一套核定后的诊断分层、药名、单次剂量、频次、执行时间窗与停用红线。

## 连续照护与跨节点修订

依据本包材料自身形态选择任务结构，严禁整批倒向单一静态模板或克隆同一种“首次全套基线＋次日戏剧化恶化来信＋保留两版”套路：

- **跨节点动态照护（材料支持时优先选用）**：只要病历或业务资料客观支持病情演变、分批检查回报、术前术后转换、阶段训练／治疗反应或跨机构交接且存在真实状态依赖，优先从下列三种结构中择一（或相容组合），并结合 `batch-context.json` 错开变化来源（变化源可来自微生物涂片与药敏分批出炉、标本溶血复测更正、术后引流与血红蛋白变化、动态血糖与症状日记背离、康复负荷试验异常反应、患方拒绝有创方案后的路径切换、下转社区药品可及性限制等，不默认一律写成“次日肌酐升高调抗生素”）：
  1. **单次关键新证据连锁重算**：给定一项决定性新报告或临床反馈，触发诊断分层、多药配伍剂量、液体营养配比、监测频率与医患交接文书的全面联动重算及路径切换；

## 从结果反推必要判断与临床加压机制

对每个拟计分复合结果，沿 **“可见病历／报告记录 → 待判临床或管理关系 → 权威指南／说明书成立条件与定量边界 → 安全可实施方案 → 接收人可用正文与表格”** 逐项反查：

- **必要性**：缺了该项消歧或核验，是否必然导致诊断分层错误、超量中毒／亚治疗无效、触犯禁忌、遗漏红旗或接收人无法安全执行？若不成立则移出必要条件；表达凝练但依据与结果完整的合法替代方案正常通过。
- **关联性与失效范围**：分清哪些差错仅影响可分离的局部结果（归普通复合 R），哪些致命错误直接摧毁本次医疗任务赖以成立的患者身份、关键事实时点、生命安全底线或跨文书指令一致性（经本案具体论证后，择最直接相关的一条 R 融入单处整体失效归零条件）。

## 核对有依据的竞争解释

先求证据链最严密、患者净获益最安全的首选解，再推演表面看似合理却漏掉关键临床约束的竞争方案，确保两者产生可核验的实质差异：

- **五类高判别力临床证据与规则边界（开放选用，结合同期白名单摘要错开组合）**：
  1. **检验前质量与医嘱执行真相制约主裁决**：输液同侧采血／溶血致假性危急值、TDM 非谷浓度采样、不合格痰标本定植菌、低白蛋白未校正总钙、传感器压迫伪低血糖、医嘱开立但护理未执行或患者私自停服／加服，直接颠覆直读报告得出的表面结论；
  2. **特殊生理状态与动态器官功能触发模型跃迁**：重度肥胖／水肿／截肢／恶液质致实际体重与理想／校正体重显著背离、AKI 肌酐快速爬升期稳态 eGFR／CG 公式严重高估肾功能、早产儿校正月龄与儿童按体重计算反超成人极量封顶、妊娠早中晚期与哺乳期药物安全等级切换、β阻滞剂钝化康复靶心率反应；
  3. **多通道隐性负荷与跨制剂成分穿透累计**：感冒止痛／降压中西复方制剂隐藏同名化学成分累加超极量、多组静脉抗菌药／血管活性药溶媒与丙泊酚脂肪乳带入的隐性水钠及非营养热卡挤占限额、钙铁钾元素量与盐基质量混淆；
  4. **多病共病竞争性治疗窗口协同**：新近血栓／支架抗栓与活动性出血或限期手术止血窗口、重症感染与免疫抑制剂撤减／应激激素覆盖、心衰去容量与肾灌注维持、肿瘤疗效维持与免疫／化疗器官毒性逆转，单线思维必然顾此失彼；
  5. **关键检查待回报下的双层安全过渡**：核心培养、病理、基因或复查影像尚未回报时，合法成果必须同时给出“不掩盖关键诊断且即时保障生命／器官安全的过渡处置”与“回报阳／阴性或触发具体红旗数值后的排他切换方案”，彻底封死“完善检查、请会诊、待结果回报再议”。
