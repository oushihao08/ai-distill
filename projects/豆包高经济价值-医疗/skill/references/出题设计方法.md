# 出题设计方法

用于材料驱动的新题和获准的实质修订。先确定岗位要解决什么，再选择难度与载体；不从固定诊断、文书数量或考点数反推材料。

## 材料与任务盘点

完整读取附件，内部保留以下对应关系，供后续题面—标答—rubric 核对；不增加返回字段或要求作答者交作者盘点表。

| 盘点对象 | 需要查清的内容 |
| --- | --- |
| 来源与边界 | 原始文档、转写和汇编的关系；独立患者/就诊/样本；重复附件与缺页；本次可见范围 |
| 时间与状态 | 事件发生、采样、报告、记录、医嘱下达及实际执行时间；每个决策时点可用哪些信息 |
| 事实属性 | 患者自述、查体观察、检查结果、既往诊断、拟议方案、已执行干预及疗效，不混写为同级事实 |
| 现实问题 | 哪项判断或执行安排仍未解决，继续拖延/做错会影响什么，当前由谁负责 |
| 可办工作 | 材料依据、专业处理、接收人下一步动作、实际成果及验收证据 |
| 范围取舍 | 纳入或排除的具体原因；材料不足、角色无权、与任务无关、已经解决分别记录 |

处理多患者材料时分别建关系，再判断是否存在科室质控、资源配置等真实共同任务；不将不同患者的体重、检验或用药拼成一个病例。重复转写不算独立佐证，重复测量与重复文件也不能混同。跨期材料复用只依据本次冻结来源及明确的新方向，不能偷读旧答案确定新题。

附件有相矛盾信息时，按原件、记录时间、采集方法和证明范围核查；不机械认定“最新一条必然正确”。无法消除的冲突进入具体分支，不擅自改原件。去标识化应保留完成任务必需的医学关系；年龄、体重、日期间隔等关键量被遮蔽时，不猜回原值。

## 从真实工作选择任务

| 触发输入 | 需要完成的专业工作 | 可验收的结果 |
| --- | --- | --- |
| 新症状、检查、既往史与正在使用的药物 | 确定当下优先级，比较竞争解释，选择能改变处理的进一步评估，形成相容方案 | 有依据的临床判断及当前行动，不是疾病百科或无差别检查清单 |
| 已有诊疗/用药/康复方案及执行记录 | 审用原方案，区分可保留、需修订与无法判断内容 | 实际修订方案及变更依据，不预设有固定数量的错误 |
| 会诊分歧、患者拒绝或不同治疗提案 | 比较各方案适用条件、风险收益、偏好与资源约束 | 能用于共同决策的意见、替代及启用条件，不强求统一结论 |
| 多病共存、多药或跨科室记录 | 识别干预间作用、目标冲突和职责交界，协调优先级 | 同时可实施的整体安排，不能把互相冲突的专科建议简单相加 |
| 已有干预后的新检查、症状、依从性或功能反馈 | 判断反应与可能原因，重估原方案，更新当前有效成果 | 已完成的阶段调整及后续监测，不是泛泛“定期复诊” |
| 交班、转科、转院、出院或家庭照护 | 核对当前问题、已做措施、尚待结果、下一责任人与升级条件 | 接收方能继续工作的交接内容、药物清单或照护计划 |
| 已授权的流程、队列或不良事件资料 | 重建流程，核验分母和事件定义，区分相关性与因果，设计可评估的改进 | 有数据依据的业务方案及效果衡量，不以记录缺失直接认定人员过错 |

这些是选择机制，不是每题套餐。使用[场景与流程](医疗场景与工作流程.md)细化本题的岗位、材料和成果；不要为了增加任务横跨没有业务联系的多个专科。

## 材料到成果的依赖

对拟纳入工作逐项说明：哪些记录支持哪个中间判断，该判断如何影响检查、治疗、照护、沟通或流程，最后进入哪份成果。前一结果确实约束后一决策时保留依赖；独立工作可并行，不强行串行。

- 初步诊断、严重程度、处理优先级、治疗选择和监测计划有不同用途，不强行合并，也不自动拆成五个简单考点。按独立专业结果与实际判断边界划分。
- 症状稳定不自动代表疾病已排除；检查异常不自动等于病因；医嘱已开不等于患者已用；未记录不等于阴性。这些区别只有影响本题决策时才成为判据。
- 同一患者可以有多个并行问题；共同约束必须落实到最终安排，不能一段写禁忌另一段照常执行。患者目标、照护能力、可及性与费用资料按已有证据纳入，不虚构偏好或用成本替代必要照护。
- 已足够的信息直接得出可支持的结论；不足信息写清缺哪项、影响哪步、取得前能做什么及取得后怎样分支。不能整题一律“咨询专科”，也不能用“假定均正常”抹掉关键未知。

## 连续诊疗和方案更新

存在复评或跨场所持续使用关系时，按“基线成果—新信息—重新判断—实际修订—接收方使用”设计。每次新事件须产生独立判断或真实状态更新，不能只换日期、复制整份方案或做无业务意义的改值。

1. 给出基线时点的材料与任务，使当时决策可独立核验。
2. 给出有来源的后续记录；需新增模拟事件时先确认本次允许模拟，在输入中标识。模拟症状、结果和反应须专业相容，不伪装原始病历，不虚构已完成操作。
3. 标明信息何时可得。最终结果可以帮助回顾，但不能据后来培养、影像或结局惩罚当时合理决策；疗效好坏也不能单独证明先前决策正确与否。
4. 要求作答者判断保留、调整、停止、升级或转交哪些内容，并实际更新受影响的方案、核算和患者说明；保持未受影响部分，明确当前有效版本。
5. 单轮题一次给全所需事件，按时点评价；真正多轮须运行环境能按轮提供新信息并承接前轮成果。不能在一次提供全部资料时声称模型被盲法隔离。

一次静态会诊可以只完成当下意见及具体随访条件；没有后续事件时，不声称已经完成动态复评。急救场景的立即措施与紧随复评属于时效工作，不用冗长报告、联网或制表延误场景中的处置。

## 工具工作与实际成果

从用途决定工具，允许高效合并操作；不规定调用品牌或次数。

| 工作 | 下游必须使用的结果 | 实际核验 |
| --- | --- | --- |
| 检索医学依据 | 适用人群、时点、地区、推荐条件及不确定性，落实到本题方案 | 打开权威原文核对，不只抄摘要；具体规则见医学依据文件 |
| 读取和整理附件 | 患者、时间、药物、检查或功能状态的正确对应 | 回读决定性原件；OCR 与单位、阴性表达不符时修正或保留缺口 |
| 核算和比较 | 正确量纲、剂量/速率/营养/评分等结果及其临床影响 | 复核输入、公式适用条件、分项总量和舍入，不能只展示代码 |
| 制作业务文件 | 符合接收人工作需要的完整正文、清单或可更新工作表 | 文件确实存在、可打开；核对患者、时点、内容及必要公式 |
| 持续更新 | 新信息进入既有工作文件后形成正确当前结果 | 检查受影响与应保持内容、跨文件一致性及旧稿替换关系 |
| 导出与交接 | 固定版式、可打印患者说明或可编辑专业稿 | 按用途读回或渲染，检查表格、单位、分页及重要提醒是否遗漏 |

一份文件能承载相同使用动作就合并；不同接收人或数据能力确需独立载体才拆分。不默认 DOCX、XLSX、PDF 三件套。题包的文本/JSON 返回契约不等于作答只能输出文字；实际能力缺口单列，不偷偷删除任务所需文件能力。

## 难度与完整性

- 用最简正确完整解检查：若仅凭抄出诊断、复制指南或计算一个代入值即可完成主要任务，重新选择材料支持的未解决工作；不靠隐藏关键输入阻断正确捷径。
- 加深已有工作可通过相互作用的条件、时间变化、多个可接受方案的取舍、原稿修订及跨成果落实。更多疾病名称、更罕见病种、更多附件或更长文字本身不证明高价值。
- 题面写清目标、范围、角色、时点、必要依据和成果；不泄露错误位置、正确药物、筛选后的证据或核心推理路径。既有记录本来就有的诊断不删去，转而选择仍未解决的问题。
- 逐项核对可见输入、题面交办、标答完整结果与 rubric 验收。遗漏应补齐；确实不可完成的部分标明缺口和影响，不伪造输入、手签、执行记录或医学专家结论。
- 高风险内容需要专业校准时记录具体争议和校准范围，不将整题降为“仅建议就医”，也不将作者自查写成已获临床使用认可。
