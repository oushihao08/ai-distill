# 题目格式与交付

用于已完成业务设计后的题面、判据、论证和标答成稿。以当前返回 schema 为字段权威，[题包模板](../assets/题目模版.md)仅提供七项内容的填写位置，不新增字段或固定正文目录。

## 题面应交代什么

- 具体岗位、当前场所与决策时点，正在处理什么问题，成果给谁使用。不要只写“你是精通所有医学的超级医生”而省略实际职责。
- 可见材料、对象范围、当时信息、关键资源和权限。病例原有事实保留在附件；题面只补必要背景和明确获准的模拟条件，不另造已做检查、患者偏好或治疗效果。
- 完整工作与实际成果：要审用哪份方案、分析哪些对象、形成何种决定或修订内容，以及接收人如何使用。用完整核对、计算、比较、修订、制定、交接等具体动作，避免只有“深入分析、全面建议”。
- 依据与核验：对决定处理的医学问题核验适用来源，给出可追溯依据和本题适用理由；数值说明必要输入、口径、结果和复核。权威原文充分时不为凑数要求多个来源。
- 文件确有用途时写明实际制作、必要数据能力及读回检查；相同共同要求集中一次，专属条件紧邻对应成果。不能只列拟生成文件名或以后再做的计划。
- 依赖多项工作时要求按实际依赖安排并执行至可完成部分交付；规划服务于工作，不默认另交计划书。受阻时具体说明影响和后续条件，继续完成不受影响部分。

题面交办业务，保留需要自行发现的证据关系、竞争解释与决策。不得提前说明“找出三处剂量错误”“必须诊断某病”“采用某方案才能得分”，除非相应事实本来已确定且真正任务在后续处理。隐含专业判断须有可见证据，隐藏交付义务不能用于评分。

急救任务的立即处理顺序与事后依据说明分开，不能一律要求先写长报告。简明的交班卡或患者指引可以是完整成果；不能以篇幅短认定工作不足，也不能用“简要概述”省略本题必需判断。

## 字段各自的职责

| 字段 | 写什么 | 避免什么 |
| --- | --- | --- |
| 表头 | 本次 ID、实际可见附件、场景所属行业和负责交付的职业、任务形式 | 编造分类枚举，按所有疾病跨选多个行业，把病人身份填成职业 |
| 任务名称 | 具体事项与主要工作，按最终题面命名 | 内部编号、全部文件名堆叠、待求诊断泄漏、泛称“综合分析” |
| 任务类型 | 按最终用途选择当前允许的主要类型 | 按中间工具或附件格式并列多个主类型 |
| prompt/题面 | 真实交办、输入与完成条件 | 评分尺、正确答案、作者工作日志 |
| rubric | 每个结果的自足通过/失败边界和合理替代 | “专业、准确、全面”等不可判分的形容词，依赖不可见标答 |
| 作答思路 | 决定性证据、适用依据、关键计算和取舍的可核查说明 | 隐藏思维过程、工具日志、泛泛求解计划、评分策略 |
| 标准答案-文本 | 已完成的全部专业成果及必要依据、条件和正文 | “另拟处方/计划”、文件名列表、脚本或未来操作说明代替成果 |

任务形式以实际输入和交互能力为准。单轮内多阶段不自动属于多轮；行业/职业等只能使用本次允许的分类，分类表缺失时说明待映射，不造出平台标签。

## 成果写到能被使用

按使用人选择信息和文体：专业会诊意见写清判断和处理依据；有效用药清单写清执行安排；康复计划写清目标、具体干预与复评；交班交接写清当前状态、已做事项、待办责任及升级条件；患者说明用可理解语言保留关键动作与限制。只取本题需要的成果，不集齐以上文种。

条件要留在它约束的正文内，不能在分析中限制用药、在最终药单却写无条件执行。医嘱/处方建议稿按题设权限交给相应专业人员审用，不伪造真实签名、执行、治疗反应或已完成告知。

需要连续更新时，呈现基线及各节点的判断、实际修订和当前有效内容。可用完整稿、明确替换位置与完整替换正文或带状态的工作表组织，不强制每次复制整套文件；接收人须能辨认何者有效。

标准答案须完成全部题面工作。文本标答写全必要正文、计算与公式；题目需要实际文件时，文本不能证明文件存在、联动正确或渲染通过。实际产物按当前契约交付校准；契约只收文本时，在允许的完成说明报告文件校准缺口，不新增字段、不造链接、不把制作脚本塞入业务成果。

## 自然表达与保义

先固定事实、岗位、时点、工作、成果与评分关系，再组织文字。依据本题触发点、信息关系、使用人和文种选用连贯交办、分对象、分时点、方案比较或正式业务体例；没有对应事实不为了换风格新增会议、紧急催办或接收人。

五个业务字段不复制同一套目录：名称概括工作、题面交办、rubric 验收、思路解释、标答完成。共同条件只说明一次；必要的跨成果一致性和正式医疗文书结构保留，不为“去模板化”删掉。

业务正文采用自然段、普通标题编号、必要的业务表格、算式和可追溯来源。除本次格式另有要求，不把 Markdown 标记、代码围栏、HTML/XML、生成脚本或程序字段名写进业务文书。结构化题包外壳和本 Skill 文件不受这一正文排版要求限制。

删除模型自述、内部路径、出题目的、目标分数、模板选型与制作过程。保留医学限制、模拟披露、隐私必要说明、公式和正常业务流程；不能为去除“AI 痕迹”伪造医师经历、人工原创或真实病例来源，不保证检测分数。

只授权润色时保持主体、时间、单位、否定、条件、权限、成果范围和逐条计分关系不变。有歧义需实质选择时单列问题，不能借润色改诊断或判分。若本次没有批次题目作为允许输入，不读取旧题或宣称全批次表达已去重。

## 完成前对照

沿设计阶段盘点逐项核对：输入确实可读；题面交办完整；标答有实际内容；rubric 能独立验收；跨成果对象、单位、时点、方案及有效状态相容。完整解、简洁等效解、缺关键条件的近似解和成果矛盾答案在表达调整前后应判定一致。

题目内容就绪、文件校准、专家审阅、模型实测和平台接收分别报告。完成说明放作者允许的报告位置，不把“内部候选”“尚未跑模型”等制作状态强塞进每份临床业务正文。
