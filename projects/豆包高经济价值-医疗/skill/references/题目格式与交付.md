## 题面设计契约

### 岗位职责与首段去公式化

- 写清当前承担任务的医疗卫生岗位（如急诊接诊医师、普外／骨科住院总、专科会诊医师、驻科临床药师、ICU 责任护士、康复治疗师、临床营养师、全科／检后主检医师、院感／病案质控员等）、所在机构场景、决策截止时点、可用资源与成果接收人；严禁把“患者／受检者／家属”填作职业，严禁塑造成无执业边界的“全能医学专家”。
- **首句随临床触发点轮换，严禁首段四步公式**：首句必须直接从本例眼下亟待处理的临床或业务事件切入（如刚回报的危急值／培养药敏折点、前手待审医嘱或总检草稿出入、限期手术 D0 停药倒计时冲突、跨院多处方叠加风险、术后引流突变或转科出院交接缺口），**严禁默认拿患者姓名／代号或“你是某医院XX科主任医师”作全题首词**，**严禁在首段末尾集中背诵“该接诊关系及评估时点为本题设定＋不实际签发处方／不实际给药／不联系患者／不改电子病历”四连负面清单**。
- **模拟前提自然标示，执业边界随文下沉**：模拟评估基准日、假定手术排程日或获准补充的模拟复评回报，必须用自然临床交办语言明确标示其模拟／假定身份（严禁伪装成原始病历既成事实，且严禁每题逐字复读同一句设定套话）；不代签手术／知情同意书、不越权独立签发处方、不直接外联患者等执业边界，紧邻对应的待审医嘱建议稿、排程表或患方沟通材料段落就近写出。

### 作答端检索、依据与实体交付核验

将以下能力要求转化为**点名本例具体医疗文书与核算工作簿名称**的自然临床交办语言，拆散融入对应成果段落与审签交接要求中，并在 `reference_answer` 中实际完成；**严禁原词照抄内部压缩术语（如“多表活公式XLSX”“定版分页PDF”“宽表横向截断成碎页”“发现问题回改源文件后重导重验”“隔离核验副本”），严禁在开头加“请先详细规划／分步安排”，严禁在结尾单挂一段统包式技术收尾段，也严禁要求单独交付《文件交付回执》**：

- **正向深度交办**：用核对、穿透、折算、比选、起草、修订等具体专业动词绑定本例真实对象（如纵向检验流水、长期／临时医嘱与护理执行单、多期体检报告、围术期慢病药单、24h 出入量与营养配方、质控抽查个案）；**严禁出现“简短回复”“简要说明”“无需展开”“只需概述”“仅列要点”等压缩作答深度的表述**。
- **权威医学原文联网核验**：对决定本例诊断分层、手术／操作指征、给药阈值与禁忌的规范问题，要求联网检索并实际打开国家卫健委诊疗规范／质控标准、NMPA 批准的正式药品说明书原文或中华医学会／国际权威专科指南原文，核实发布机构、版本年份、适用人群、单位折点与例外条件并附可追溯链接（搜索摘要、科普百科不替代权威原文；历史病案复盘按医疗行为发生当时有效版本核对）。
- **四项硬性文件与视觉校改动作（100% 保留动作强度，随具体成果点名嵌入）**：
  1. **可编辑正式医疗文书与全公式多分表工作簿制作及重算读回**：按接收人实际用途交付可直接审签、交接或发放的可编辑正式文书（DOCX，如专科会诊裁决书、待审医嘱修订定稿、围术期停启排程书、检后分层管理报告、患者通俗执行指引）及全部由公式驱动的多分表临床核算工作簿（XLSX，依[八类医疗定量模型](出题设计方法.md#材料到成果的工作链与临床交接)贴合本例材料构建，严禁不论病种硬套单一用药表），实际运行公式重算并读回核验结果。
  2. **工作簿动态联动核验**：跨节点动态照护题以给定新增检验／药敏／病情反馈进入工作簿触发公式重算更新并读回检验联动；单窗口静态题须结合本例真实存在的生理参数估算口径分歧（如不同合理体重或清除率口径）、器官功能／电解质临界波动、手术改期窗口或备选治疗／营养／康复路径，在工作簿内专门设置临床敏感性／备选情景对比试算栏核验公式自动联动并读回（与正式执行主表明确分区，严禁写“在与病例事实隔离的核验副本中改变一项关键输入”套话）。
  3. **全套正式成果导出分页 PDF**：将全套正式成果——包括主评估／会诊／审方／质控报告全文、全部正式执行／排程／交接／患者指导文书，以及经横向页面或列宽适配后的多栏重整／剂量／液体营养／排程／质控核算附表——悉数导出为分页 PDF（严禁只导短篇交接卡／患者单而漏导主报告或宽表附表，也严禁只列文件名）。
  4. **全部 PDF 逐页转图像目检与回改重导闭环**：将导出的全部 PDF（含拆分分册）逐页渲染为页面图像，逐页检查是否存在多栏宽表跨页横向劈裂、审签落款或高危警示框孤行跨页、微克／毫摩尔／泵速单位截断，以及主报告、执行医嘱表与患者通俗指导卡之间的药名、单次量、频次、时间窗与停用红线不一致；一旦发现排版错位或跨件数值出入，必须回改源 DOCX／XLSX 文件后重新导出并复检确认。
- **缺证与环境缺口处理**：附件确有局部临床信息缺口时，要求完成证据充分部分的确定方案，并在主文书或交接说明中写明待补查项目、回报前安全过渡处置与启用条件；作答运行环境若暂未接通某项导出或渲染能力，仅由作者在会话收尾简述环境缺口（严禁写进题面、rubric、思路或标答），绝不擅自将文件与检索义务降格为纯文本回答。

### 工作布置与泄题提示的边界

提供混有常规合理记录与未标明隐患（如采样溶血／稀释伪影、复方隐藏同名成分、已开未执行错位、稳态公式误用于 AKI、隐性溶媒钠糖超限、围术期洗脱期不足或质控分母错纳）的自然完整文本，由作答者自行穿透裁决；**严禁在题面单拎错误医嘱反问、严禁预告有几处错误、严禁喂给生理计算公式／量表子项权重／指南分期阈值／常规停药洗脱天数**（仅医院确有严于常规的特殊内部限方或质控管理规定时才作为背景条件披露，并要求与法定／权威规范对照处理）：

| 合理的自然临床交办 | 严禁出现的泄题或喂解法写法 |
| --- | --- |
| 审定所附拟行限期手术患者的术前记录与长期用药清单，形成可直接呈交主诊组审签的以手术日为基准的停启排程定稿与患方停药核对卡 | 草稿中利伐沙班仅术前停 1 天且恩格列净未停存在酮症风险，请按 CrCl 公式重算停药天数并修正 |
| 对照近三年健康体检报告与本次复查单，建立跨机构标准化趋势底稿，完成异常分层、优选复查排程与受检者随访指引 | 请把 2023 年 mg/dL 换算为 mmol/L，剔除溶血导致的假性血钾升高，并用 FIB-4 公式计算肝纤维化风险 |
| 结合重症护理出入量单、血气电解质流水与现行营养静脉医嘱，核定未来 24 小时全口径液体电解质及能量氮量调整方案 | 请扣减丙泊酚脂肪乳每毫升 1.1 千卡热卡和抗生素生理盐水溶媒含钠量后重新配比肠内肠外营养 |

### 双向图文可见边界

- 附件实际传入心电、影像、内镜、皮损或生长／监测曲线图像时，正常要求结合图面客观征象与文字报告交叉核验；
- 附件仅传入检验单与超声／CT／MRI／病理**文字报告**而无原始图像时，严禁考察未提供图像的形态学盲猜，同时**100% 保留输出端多源消歧、权威原文检索、全公式 XLSX 联动、正式 DOCX 与全套分页 PDF 逐页转图校改要求**。

## 七项返回内容与命名分类检查

### 七项字段规范

| 字段 | 职责与实质要求 | 严禁出现 |
| --- | --- | --- |
| 表头 header | 题目 ID、单一主营一级／二级行业、任务形式、实际登记的可见原件名、负责最终交付的 L1 职业簇／L2 医疗岗位 | 把患者／家属填成职业；跨选多个一级行业；将表头内部编号带入业务正文 |
| 任务名称 task_name | 用最具辨识度的单一临床核心事项、待决治疗／管理冲突或关键文书用途命名（可用紧凑医学短语或直接交办短句） | `[患者／病名]的[四字动作]与[四字动作]` 对称并列句式；“综合、全面、全套、闭环、专项、深度、一体化、接管、核校”高频包装词；串列全部文件名；提前泄漏待求诊断、病原或调药结论 |
| 任务类型 task_type | 根据材料实质工作与最终交付物的主要业务用途单选本期适用类别 | 按附件扩展名或目录名机械分类；并列堆砌多个主类型 |
| 题面 question | 临床触发点起笔、岗位与场所、时点盲界、自然模拟披露、完整待办工作及点名嵌入的四项硬性文件与检索核验要求 | 默认人名／头衔首词；首段四连禁令公式；`附件1` 内部序号；末尾统包技术尾段；单拎错误医嘱；喂公式或阈值；“简短说明／只需概述” |
| 考点 rubric | 等权 0/1 复合专业结果自足判据（结论、原件与权威规范要旨、计算口径容差、合法替代、排他失败边界、单条载体联动实证）＋单处自然归零整体失效条件 | `本条评价……`、`得1分／得0分`、`全部满足得分`、`附件1`、页码、任何 `评分端／轨迹未传／评测条件不满足／不作为有效专业难度成绩` 产线术语、固定末条“一票否决”标题 |
| 作答思路 answer_approach | 决定性病历／报告证据关系、伪影剔除推导、指南说明书版本取舍、定量口径追溯与竞争方案排除理由 | 复述题面；“先读附件→再检索→再做XLSX/PDF”操作流水账；作者自检说明 |
| 标准答案 reference_answer | 首屏按四类临床主成果体例直接切入（禁统一三行公文信头），完整写出各阶段正式医疗文书全文、患方指引全文、工作簿分表结构与活公式写法、汇总勾稽及异常冲突项逐笔明细；无争议大批量常规流水按区间归并引用 | 统一“［XX意见书］＋致XX＋评估基准日”三行信头；“另拟药单／详见附表”空话；Python／Shell 脚本代码；Markdown 标记符号 |

### 命名与分类收尾核对

先完成 `question`、`reference_answer` 与 `rubric`，最后核定 `task_name` 与 `task_type`：自问“这道题与同期其他医疗题最核心的临床冲突或业务动作区别是什么？”，确保标题一眼辨识本题专有事项，绝不拿同一套句架只换人名或病名。

## 输出形式与 PDF 分册上限

- 结构化外层严格按本次任务返回 schema 输出；五字段内部的业务文字一律采用日常医疗书面排版（自然段、普通小标题、`1、2、3` 或 `一、（一）` 常规编号、临床算式与纯文本分栏明细），禁用 `#`、`**`、`` ` ``、` ``` `、`|---|`、HTML/XML 标签及表情符号。
- 作答者交付的实体办公文件（DOCX、XLSX、PDF 等）服务于真实审签、配比重算、床旁执行、院际交接与患者留存，不以纯文本回复替代需要编辑或公式联动的业务载体。
- **PDF 单文件大小与连续页分册硬规则**：单个 PDF 文件不得超过 `18,000,000` 字节（`18MB`）。若导出文件超限，必须按连续页、页数尽量均衡拆分为多份 PDF 分册，文件名清楚标明原始页码区间并按原顺序完整交付全部分册；**严禁删减页数、截断宽表正文、遗漏核算附表或通过压缩糊化图像清晰度规避拆分**。拆分后须核对各分册页数总和与页序同原件完全一致，且逐页转图像版式与数据一致性核验必须覆盖全部分册；若极端情况下单页独立保存仍超 18MB，如实报告具体页码，不交付残缺文件。飞书【输入附件】同步遵守相同 18MB 上限。

## 引用与生产残留红线

- **附件自然称谓**：业务正文中引用卷宗病历统一自然写为“附件”“所附病历”“所附体检报告”或直接点名具体医疗文书名称（如“入院记录”“急诊血气分析报告单”“护理给药执行单”“外院出院小结”）；`input/attachments/附件1.txt` 仅属出题容器内部路径，**严禁在任务名称、题面、rubric、作答思路或标准答案任何一处出现 `附件1`、`附件 1`、`附件2` 等编号或页码**。
- **零内部信息残留**：五字段严禁出现数据库 ID、本机绝对路径、评测系统产线状态词、目标压分／目标步数／目标时长数字、模型身份自述或出题过程说明。
- **跨文书生死线一致性**：最终提交前逐字核对主评估／会诊文书、待审执行医嘱／排程表、工作簿公式汇总、护理／转诊交接单与患者通俗指导五端之间的患者化名代号、年龄体重／孕周／肾功前提、药品通用名与剂型规格、单次及每日剂量、给药途径与频次、禁用／停药红线及当前有效版本标记 100% 一致。
