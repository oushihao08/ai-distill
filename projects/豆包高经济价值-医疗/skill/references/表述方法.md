# 医疗五字段表述方法

用于任务名称、prompt、rubric、作答思路、标准答案-文本的组合组织与保义核对。先按设计方法与医学核验规范完成全卷盘点、临床求解、脚本实算与复合判据，再读[临床语气与去模板化建议](../去%20ai%20化建议.md)和[书面表达组合库](../assets/书面表达组合库.txt)选择表达组件；七项返回字段遵循[题目模版](../assets/题目模版.md)与[题目格式与交付](题目格式与交付.md)。本页规定组合边界、强度不变量与保义改写契约，不重复罗列组合库菜单。

## 独立使用与组合规则

1. **先定临床实质，后选表达结构**：先完成全部附件精读、垂类参考方向盘点、集中脚本实算、权威指南／说明书原文核对及自足复合 rubric，再依[写作前的表达定位](../去%20ai%20化建议.md#写作前的表达定位)确定岗位协作关系、临床触发点、成果接收人、实际用途与信息组织关系。表达组件绝不反向参与选题、删减定量环节或改变判分条件。
2. **五字段独立拆散组合**：以未做文风调整的专业底稿为基准，分别为五个字段挑选贴合本例的起笔、展开、局部排版与收束；组合库中的搭配示范仅供理解拆散方式，严禁整套按题号轮换。没有多接收人不硬拆多份文件；没有真实备选临床路径不硬凑方案比选表；没有材料或设计确定的后续事件不编造时间线。
3. **五字段各司其职，禁共用同一目录骨架**：`task_name` 辨识核心临床冲突或事项，`question` 自然交办待办工作与实体成果要求，`rubric` 自足界定复合 0/1 判分与产物实证，`answer_approach` 阐明关键去伪推导与方案取舍，`reference_answer` 直接交付全套可用文书与工作簿公式结构。严禁将内部工作链机械翻印为“任务一至四”同序段落。
4. **同期白名单避重边界**：若本次输入提供 `batch-context.json`，必须在盘点与定稿阶段核对临床目标、岗位角色、定量模型类型与成果用途，主动避开仅换患者化名或疾病名的同构设计；不读取历史题包正文，无摘要时不虚构跨题比较结论。
5. **医学保义绝对优先**：当某种表达写法与临床时效逻辑、执业权限、剂量单位精度、文件联动渲染要求或 rubric 判分边界发生任何冲突时，一律更换表达方式，绝不折损临床任务或评分严谨性。

## 日常医疗书面表达与载体边界

- 五字段业务文字统一采用自然段、普通小标题、`1、2、3` 或 `一、（一）` 常规编号、临床算式及纯文本分栏明细；严禁出现 Markdown 标题井号、加粗星号、反引号、代码围栏、管道表格、HTML/XML 标签、表情图标或 Python／Shell 生成脚本。结构化 JSON 返回外壳按当前 schema 完整保留。
- 涉及审签执行、持续参数折算、排程联动、院际交接或患者居家核对的工作，按[交付规范](题目格式与交付.md#作答端检索依据与实体交付核验)保留可编辑正式文书（DOCX）、全公式多分表工作簿（XLSX）及全套分页 PDF（含 18MB 分册上限）导出与逐页转图像版式校改要求；严禁用纯文本回复或静态 TXT 替代必须具备公式自动联动与固定版式核验的临床载体。
- 正式医嘱建议、会诊意见、围术期排程表与患者通俗指引必须把适用前提、禁用条件、复查窗口与停药就医红线直接写进正文，严禁把安全限制留在内部说明区而在执行单上开出无条件指令；权威医学来源采用含发布机构、文件全称、年份、核心要旨及可追溯网址的日常书面引注。

## 强度不变铁律

- **题面零减损**：全部临床待办对象、信息时点、自然标示的模拟前提、就近下沉的执业权限边界、权威指南／NMPA 说明书原文联网核验，以及点名嵌入具体文书与底稿段落的四项硬性文件与逐页图像校改动作逐项完整保留（“必须”不得弱化为“建议／可考虑”；禁首段四连禁令、禁开头“先详细规划”、禁照抄内部缩略词串、禁末尾统包技术尾段、禁单交交付回执、禁出现 `附件1` 或泄题提示）。
- **rubric 零变形**：条目数量、ID、`max_score`、同源耦合定量链合并关系、排他性防套话锚点、合法替代通过边界、同源错误共享前提归属及单条复合载体实证要求在表达调整前后丝毫不变。子条件分行不产生部分分，严禁把“且”改成“或”；严禁混入 `本条评价……`、`附件1`、页码或 `评分端／轨迹未传／评测条件不满足／不作为有效专业难度成绩` 等产线术语；单处案件化整体失效条件融入最直接相关的那条 criterion 并以自然临床后果写明全题归零，不复读固定句尾。
- **思路与标答零缩水**：`answer_approach` 保留完整去伪推导、指南说明书适用论证、计算口径追溯与竞争方案排除理由；`reference_answer` 按四类临床主成果体例直接切入首屏（禁用统一三行公文信头），完整写出各阶段正式专业文书全文、患方通俗指引全文（两边药名、剂量、频次与红线 100% 一致）、工作簿分表结构与关键活公式写法、汇总勾稽及争议异常项逐笔明细，无争议大批量常规流水按来源范围、笔数与区间统计归并引用。跨节点照护题保留基线可回查、新增回报承接重算与当前最终有效定稿，绝不压成单次改值演示或未来跟进口号。

## 成稿复核

1. 对照[出题设计方法](出题设计方法.md)的内部任务盘点，双向核验表达调整前后的临床范围、定量精度、全部文件动作与逐条判据完全对应，无遗漏、无降格、无新增未交办义务。
2. 用完整正确解、简洁合法替代解、漏一项必要消歧／禁忌／换算的近似解、万金油套话解及前后文书矛盾解作静态对照，确认改写前后逐条 `0/1` 与整题归零判定完全一致。
3. 核查 `task_name` 无对称四字并列与高频包装词，`question` 首句从临床触发点切入且无首段公式与末尾技术段，`rubric` 无产线术语与固定归零句尾，`reference_answer` 无统一三行公文信头，五字段无Markdown与 `附件1` 残留。
4. 作答端工具环境缺口仅在作者会话回复末尾简短说明，不另写落盘说明文档，也不混入五字段正文；文字自然与静态复核通过不冒充独立模型实测或医学专家验收。

## 已有题目的保义改写

仅获准对既有医疗题做表达润色时，严禁重启选题、增减交付文件或改动 rubric 判分边界：

1. 先在内部完整提取原题的患者代号、生理与检验数值、单位量纲、时间节点、岗位权限、材料范围、全部待办事项与实体交付物、模拟披露条件、临床分支及每条 criterion 的成立／失败／归零逻辑；
2. 依据原题既定临床关系从组合库重组五字段表达，严格保持义务强度、否定词、数量、剂量精度、容差区间与文件核验要求不变，不得把待审建议改成已执行事实，不得把不确定分支改成唯一武断结论，也不得把完整文书缩成要点清单；
3. 改写后逐字段双向核对，确保完整正确解、合法替代解、缺必要条件近似解与文书自相矛盾解的逐条判定与原题 100% 一致；若发现原题本身存在医学事实冲突或判据歧义需作实质修改，单独报告并按授权边界处理，不借润色名义擅自改题。
