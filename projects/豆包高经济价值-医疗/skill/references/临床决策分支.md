# 临床决策分支

用于作者从冻结医疗材料生成高判别力临床或医疗管理任务、完成严谨求解并划定自足验收边界。与[医疗场景、方向与交付设计](医疗场景与工作流程.md)及[医疗垂类评测（材料-场景-交付物）参考](../assets/医疗垂类评测（材料-场景-交付物）参考.md)配合：本文件负责临床选路、证据去伪、竞争目标权衡、合理观察与动态换路逻辑。所有分支依本包材料条件启用，不是每题必走固定流程，也不替代当题联网核验的权威医学原文。

## 一、先界定真实临床事件与决策主轴

内部先行核清：责任岗位及执业权限、患者／样本队列对象、机构层级与可用资源、信息截止时点、当前待决主问题、患者已知目标或偏好、已执行与未执行干预、以及成果接收人。严格分离已证实客观记录、转抄线索、待回报项目与获准明示的模拟条件，绝不将“病历未记载”自动填成“检查正常”或“无禁忌”。

依据材料自身形态选择主轴，仅在存在真实前后或共同约束依赖时组合多个主轴：

- 未明确病因或存在高危红旗的分层鉴别、跨年趋势评估与有决策价值的检查优选；
- 已明确主诊断但存在多病共病冲突、特殊人群生理限制或检验干扰的方案裁决；
- 前手待审诊疗计划、医嘱单、围术期排程、营养配方、康复处方或出院草稿的对照审校与定稿；
- 原方案疗效不佳、出现不良反应或新检验／培养药敏／TDM／训练反应回报后的复评与换路；
- 急危重症床旁分级处置、围术期 D0 停启桥接、转科转院或出院下转交接；
- 多例病案首页／DRG 编码质控、院感聚集流调溯源或临床研究入排偏倚／SAE 稽查。

仅因病历已载明初步诊断绝不意味着缺少高价值考点——真实临床大量核心难点正在于**“诊断标签背后的真伪证据复核、竞争治疗目标协同、个体化定量折算、前手医嘱隐蔽错位纠正与跨节点动态换路”**。

## 二、按临床证据选路与干扰剔除

| 当前材料条件 | 作者需要求解的核心决定 | 后续承接与交接要求 |
| --- | --- | --- |
| 存在时间敏感致死致残风险或生命体征恶化 | 哪些床旁 ABCDE 生命支持／首剂处置刻不容缓，哪些关键检查可床旁并行，本机构资源能否兜底 | 临床方案首层必须给出立即处置动作、急救配制滴速及升级／转运指征；稳定后交接层再展开完整依据与监测矩阵，严禁让抢救等待长篇文献或常规慢检 |
| 纵向数据矛盾、跨院单位不一或采样条件可疑 | 属于溶血／输液同侧稀释／非稳态误采／传感器伪影／痰涂片污染定植，还是真实病情进展 | 逐笔明确采信、剔除或限期复测的依据，并用清洁后数据重算下游分期与剂量；不因等待次要复测冻结当前必要安全处置 |
| 病因、分期或病原性质尚待关键回报 | 哪些竞争性解释最贴合现证，哪些低概率高致死红旗必须先堵住，哪项检查结果会实质改变路径 | 落实**双层临床防御**：①回报前当下可立即实施且不掩盖后续诊断的安全过渡措施；②一旦回报阳性／阴性或跨过具体数值阈值即刻切换的排他动作，严禁写“完善检查后待定” |
| 干预指征明确或需权衡“干预 vs 主动观察” | 主动监测观察（Watchful Waiting）、去处方减停（Deprescribing）、非药物／康复营养、药物调整、内镜介入或外科手术中何者净获益最优 | 当既有方案已安全达标或有创／加药风险大于获益时，有依据地作出**维持原方案、主动观察或逐步减停**裁决，明确复评窗口与升级红旗，防止题目诱导过度检查与过度医疗 |
| 原治疗反应不佳、不耐受或出现新异常指标 | 区分原诊断偏差、医嘱漏执行／患者漏服、药物相互作用、器官清除率骤变（如 AKI／低蛋白）还是真实药物毒性／耐药 | 对症下策：保留有效部分，精准减量、停药逆转、IV-to-PO 序贯、等效换药或重启病因排查；绝不把每次复评都写成机械加药加量 |
| 面临跨班、转科、围术期衔接或出院下转 | 当前场所能否安全交出，哪些已送检项目未出结果，接收方（含基层机构或家属）具备何种执行与监测条件 | 交付零猜测可执行的当前有效定稿，逐项列明待报检查追踪责任人与时限、术后／下转启用前置条件及可观测就医红旗，禁写“请专科随诊”推责 |
| 材料为多期体检、质控抽查、院感流调或研究样本 | 跨期／跨例统一口径、分子分母定义、混杂偏倚、时间窗违背与系统流程漏洞在哪里 | 按纵向趋势或底层个案逐一穿透重算，输出分级管理或量化质控整改方案，不硬套单次住院开药模板 |

## 三、做实高判别力临床决策节点

对决定最终成果成败的核心节点，在作者内部串联：**“可见记录与时点 → 待判临床关系 → 权威指南／说明书成立条件与冲突边界 → 排他性临床决定与定量核算 → 复评触发与接收人动作”**。

- **有决策价值的检查优选**：只保留结果会直接改变风险分层、手术时机或药物停启的检查，写明阳性／阴性分支如何切换处置，并可依据规范作出“无需重复某项高耗／有创检查”的明确裁决。
- **多目标竞争约束协同求解**：当并存疾病或治疗目标正面冲突（如急性肺栓塞／冠脉新支架抗栓 vs 活动性消化道出血或急诊手术止血；重症感染控感 vs 器官移植／重症狼疮免疫抑制；心衰容量超负荷限液利尿 vs 肾前性低灌注氮质血症；肿瘤强效治疗获益 vs CTCAE 3—4 级器官毒性；骨科内固定早期保护制动 vs VTE 预防与关节防粘连），必须在共同生理安全窗口内给出时序错峰、桥接替代或量化容忍边界，严禁分析段写禁忌、医嘱表却无条件照开。
- **全链路药物审用、减停与序贯转换**：穿透院前自备药、院内长期／临时医嘱与护理实际执行单，核清复方隐藏成分、盐型／剂型限制及器官功能折算（详按[医学依据与专业核验](医学依据与专业核验.md)）。确有指征时坚决执行去处方撤减（附防反跳阶梯表）、停用定植菌过度覆盖抗菌药、完成静脉转口服或阿片／糖皮质激素跨途径等效转换，绝不只写“建议药师审核”。
- **外科／介入时机与围术期 D0 排程**：先裁决手术／内镜／介入指征是否成立及紧急分级，再把麻醉风险、心肺肾凝血储备及抗凝／抗板／SGLT2i／GLP-1RA／二甲双胍／激素的停药洗脱天数与桥接方案精确锚定至手术日（D0），明确术后恢复给药的客观安全前提（引流液性状量、血红蛋白／血小板及肾功达标线）。
- **量化监测与客观换路阈值**：已给新回报数据时实际完成重算修订；未给新回报时设定具体可测指标（如干体重日／周增幅、血钾／肌酐／胆红素／乳酸具体阈值、靶心率与 SpO2 停训线、切口引流量与性状）、复查间隔、责任岗位及触发后的具体换路动作，不编造脱离依据的万能数字。

## 四、患者个体修正因素与双向图文输入边界

### 个体化生理与社会照护修正

临床方案必须随材料实有修正因素实质改写，严禁套用均质化成人模板后加一句“特殊人群慎用”：
- 实足年龄、早产儿胎龄／校正月龄、身高体重及肥胖／恶液质／水肿状态下的体重折算口径（TBW／IBW／ABW／BSA）；
- 精确孕周、分娩时机与实际母乳喂养状态；
- 动态肾功能（稳态 CrCl／eGFR vs AKI 非稳态肌酐趋势及 CRRT／血透清除）与肝功能分级（Child-Pugh／MELD）；
- 老年虚弱程度（CFS）、认知与谵妄风险、吞咽功能分级（决定能否口服整片／是否需禁掰碎缓控释制剂或改管饲剂型）及胃肠吸收状态；
- 过敏史真伪与严重度（区分 IgE 介导速发过敏／重症药疹 vs 胃肠道轻度不耐受，核对β内酰胺等交叉过敏边界）；
- 患者已明确表达的治疗意愿、基层或居家照护者实际执行与监测能力。

### 双向界定图文可见输入与输出端工具要求

1. **当冻结附件包含可见临床图像／波形／曲线图时**（如心电图、影像关键层面图、内镜／皮损照片、生长发育曲线、动态血糖／胎心监护图）：应将图面可见客观征象与文字报告、病程记录交叉核对；若文字摘要漏报或与图面关键征象存在出入，可将其作为高价值跨源消歧点，但须确保所考特征在传入图像中清晰可辨。
2. **当冻结附件仅有文字报告而无原始图像传入时**（仅有 CT／MRI／超声／心电／病理文字报告）：**绝对禁止**考察未提供图像的形态学盲猜（如要求自行目测肺结节实性占比或未描述的微小波形改变）。
3. **输出端工具与实体交付深度绝不因输入无原图而降格**：无论输入是否含原始医学影像，只要病程、检验数值、用药或业务流水完整可读，输出端仍须按真实接收用途完整布置权威指南／说明书原文联网核验、多分表全公式 XLSX 核算与动态联动试算、可编辑正式医疗文书（DOCX）以及全套分页 PDF 导出与逐页转图像版式校改，严禁借口“无 DICOM 原图”把题目缩水成简短纯文本问答。

## 五、让难度与时长源自真实临床依赖链

选题定稿前执行**“删环检验”**：若删去某一中间底账、某一步生理／风险重算或某份配套文书，下游临床决定与接收人动作完全不受影响，说明该环节是凑字数的无效包装，必须合并或重选；反之，只有先剔除溶血假性高钾与未执行医嘱、穿透出中成药隐藏西药成分并核准权威说明书肾功阈值，才能算出正确给药配比与停启日历，进而同步改写主诊会诊单、护理输注表与患者服药卡——这种环环相扣的前后消费关系才是驱动高判别力与真实长执行步数的核心来源。

## 六、与题面、标答和评分的闭合衔接

题面只提供岗位职责、截止时点可见信息、自然披露的模拟条件、混有常规合理内容与隐蔽矛盾的完整待审记录及成果用途，**严禁将本文件的选路框架、错误医嘱定位、计算公式或正确分支提前剧透给作答者**。标答完整交付推理依据、全口径公式结构与零猜测可用的专业／患方正文；rubric 按独立复合临床结果核验核心结论、决定性依据与文件实证，保护有权威依据的等价合法替代方案。
