# 医疗复合 R、评分与难度验证

用于编制自足 rubric、作答思路、标准答案及审查实测反馈。评分尺必须在看到被测模型回答前冻结；题目难度不足只能通过深化临床与业务任务解决，完整正确完成全部任务的答案始终应得满分。

## 考点

每条 R 只评价一个具备独立临床或医疗管理用途的**复合专业结果**，由多项前后依赖或共同约束的实质判断共同决定其成立与可用性。依据**核心结论、决定性依据与实体成果可用性**作 `0` 或 `1` 二元判定；不影响患者安全、临床决策与接收人实际执行的次要措辞差异不否定本项。

各条等权，结构化旧契约保留 `max_score = 1`，其他契约按实际 schema 返回；未触发整题归零时，题目百分制得分＝`成立条数 ÷ 有效考点总条数 × 100`。判据正文不写“得1分／得0分”或“全部满足得分”等重复尾句。考点条数由完整、去重的独立业务用途决定，不设固定条数配额。

每条 R 定稿前先做**二分独立性试判**：假设答案前半部分正确、后半部分错误——若正确的那一半仍能作为独立临床成果安全移交接收人使用，而错误只损害另一项独立下游动作，则应拆分为两条独立 R；若任一部分出错就会直接导致同一份治疗方案、排程日历、液体配比或交接单失效乃至危及安全，则必须保留为同一条复合 R。严禁借口“同一个患者”“写在同一份会诊单里”把多项无关任务硬塞成一条，也严禁把不可分割的耦合判断拆碎送分。

| --- | --- | --- |
| 岗位职责与患者身份对应 | 最终有效成果将不同患者的检验、体重、过敏史或手术部位混拼错配；或越权伪造医师已手签处方、谎称已完成有创操作／床旁查体、替代患方签署知情同意 | 在本岗权限内提交供主诊医师／团队审签的完整医嘱建议稿、排程草案，或按规范建议上级医院转诊会诊，不构成越权 |
| 决定性临床事实与检验真实性 | 凭空捏造附件不存在的关键体征、病理确诊、培养药敏结果或患者明确偏好，或无视附件已醒目记载的严重过敏／绝对禁忌并据此开立最终执行方案 | 附件未记录项作未知处理、基于纵向客观数据作合理病理生理推论、明确披露的题设模拟条件及合法条件分支，不按虚构处理 |
| 核心定量核算与关键依据可追溯性 | 决定救治安全的核心剂量、微量泵流速、电解质纠偏速率、营养热氮、辐射／物理因子强度或围术期停药天数无法由可见数据与公认公式复算，且造成严重超极量中毒、致命失衡或完全无效；或伪造不存在的指南条文／说明书适应证 | 选用公认等价公式（如合规选用 IBW／ABW、不同公认 BSA／CKD 公式且落入临床安全容差）、合理舍入差异及不同引注格式，不触发 |
| 当前有效成果跨文书一致性 | 同一患者同一时点的当前有效成果（如主会诊结论、待审医嘱表、护理配制单与患者居家服药／康复卡）对同一高危药物／关键限制给出相反指令且未标明效力层级，导致接手人或患者面临直接执行危害 | 已清晰标示历史作废稿 vs 当前最终定稿、不同假设条件下的明确备选方案，以及已在最终执行稿修正的局部笔误，不构成冲突 |
| 绝对禁忌、急症致命延误与核心病理生理推导 | 在已知明确绝对禁忌下仍于最终有效方案无条件启用致命药物、有创操作或物理因子；在休克、气道梗阻、过敏性休克、卒中／胸痛黄金窗等危重急症中要求等待慢检回报或长篇文书完成后再启动生命支持；或颠倒核心病理生理因果致救治方向完全相反 | 关键结果未回报前采取的安全过渡方案、有权威循证支持的二线替代药物／非手术路径、以及次要对症处理的合理差异，不触发 |

设计完成时逐一用“保留该严重错误的答案”与“仅有相邻局部瑕疵或采用合法替代的答案”双向校验：前者必须命中归零，后者与完整正确解绝不能误触发；说不清具体证据和全局危害的情形退回普通考点处理。

### 从评价维度形成复合考点

划分 R 前先用以下三个维度检查整题覆盖是否无死角（仅供覆盖核查，严禁机械切成固定三条考点）：

| 评价维度 | 核对的问题 | 纳入复合考点的条件 |
| --- | --- | --- |
| 临床数据与依据可信性 | 患者／样本是否一一对应、同源转抄与原始记录是否分清、采样干扰与单位差异是否穿透剔除 | 支撑后续临床裁决；仅当清洗底账本身承载独立核查用途且含多项去伪判断时才独立设 R |
| 临床裁决与定量处理成立性 | 鉴别分层、多目标冲突权衡、人群专属指南与说明书边界、生理／剂量／液体／排程计算是否同时成立 | 按独立临床或管理用途分项，将共同决定同一方案安全可用的判断留在同一条 R |
| 实体成果与交接可用性 | 核定结论是否落入可编辑文书、全公式联动工作簿、全套分页 PDF 版面及医患双端零猜测交接 | 验收新增的实际应用、公式联动与跨文书一致性，不把前面已评过的同一结论换壳重评 |

### 设项与覆盖五步法

1. **锚定独立临床结果**：从已完成的完整标答出发，列出题面已明确交办且服务独立下游动作的全部专业结果。
2. **合并耦合定量链，严防拆条送分與粗捆碰运气**：
   - **同源定量耦合必合并**：当基线指标去伪消歧、特殊人群参数估算（体重折算、BSA、CrCl／eGFR、校正钠／钙、风险积分或靶心率修正）、隐性溶媒／复方负荷累加、成人极量或纠偏速率封顶、制剂可分取规格与配制滴速／排程天数共同决定同一张执行医嘱单、营养液体表、围术期日历或康复处方能否安全使用时，**必须合并为一条复合定量核算 R**；严禁拆成 3—5 条常规分段算术 R 让模型靠“上游误差传递”免责白拿后续算式分。
   - **独立逻辑与独立用途必分设**：当多项任务具有各自独立的证据链与不同下游接收动作（如“跨年体检或入院多源检验去伪与风险分层”“围术期抗栓降糖 D0 停启桥接排程”“术后早期发热标本鉴别与抗菌降阶”“患方通俗居家执行与红旗警示卡”“全套工作簿公式联动与分页 PDF 逐页版式校改”）时，应分别设 R，**严禁把整道题过度粗捆成 ≤3 条大总包 R**（防止模型偶发答对一两条即冲高总分占比）。
3. **逐条件追问临床失败后果**：冻结前对条内每个子条件追问“漏掉或判错这一项，会导致什么具体临床风险、数值越界或执行障碍？”答不出实质后果的背景复述或常规常识一律移出判分门槛；接受表达简洁但决定性依据、数值与执行文本完整的等价答案。
4. **封堵医疗防御性万金油套话**：每条独立 R 必须至少包含一处有材料依据的跨源数据消歧、检验／执行伪影剔除、人群／版本规范跃迁、多病竞争约束协同或动态换路重算。鉴别、会诊、审方、康复与质控类 R 必须落到**排他性临床裁决、具体重复／禁忌／误采项剔除或多文书同步改定**，对已有充分依据可判之事仅写“考虑XX可能、建议完善相关检查、请专科会诊、密切观察、个体化调整、不适随诊”的一律判 `0`；对确有待回报缺口之事，未同时给出“回报前当下安全过渡处置＋回报阳／阴性后排他切换动作”而仅写“待结果回报后决定”的一律判 `0`。无争议病史摘录与常规生命体征抄录全部并入其支撑的决策 R，**零常规送分项**。
5. **去重与分母复核**：同一临床判断同步体现在主会诊报告、医嘱表与患者卡中，属于同一复合结果的完整落地条件，不得拆成三条重复计分。

### 一条 R 必须写清什么

独立评分者只读取同版题面、允许附件、rubric 及匿名完整答案（含生成文件），不读取本 Skill、作答思路或默认标答。每条 `criterion` 必须完全自足：

| 必备要素 | 自足写法要求（自然连贯行文，不强制套同名小标题） |
| --- | --- |
| 结果与临床用途 | 开门见山点明本条验收的具体临床裁决、定量方案或实体文件使用能力（**严禁以“本条评价……”起笔**） |
| 共同成立判断 | 写清哪些证据去伪、规则边界、定量折算与文书落地必须同时满足；存在合法分支时写明各分支成立条件 |
| 原件与规范依据 | 指明附件中的决定性记录与具体数值（统一自然写“附件”或点明具体病历／检验单／处方名称，**严禁写 `附件1`、`附件 1` 或页码**）；写明权威指南／NMPA 说明书全称、年份版本、人群阈值与核心要旨 |
| 计算口径与容差 | 给出公认公式、单位转换、制剂规格／设备步进约束、关键核定数值及允许的合理容差区间 |
| 排他失败边界 | 明确漏剔哪项伪影、保留哪条禁忌医嘱、算错哪项限额或仅写哪类空泛套话即导致本条判 `0` |
| 等价兼容与归属 | 说明合法替代药物／路径的通过条件；存在共享前提时写清本条独立新增判断边界 |
| 验收落点 | 指明在答案正文或哪份具体医疗文书／工作簿分表中核查实质内容；共用文件生成与渲染要求按下节集中归属 |

### 共享前提与重复处罚四原则

必须在模型作答前划清同源数据的计分归属，严禁看答案后临时调整宽严：

1. **同结论跨载体合一**：同一剂量或停药决定在评估意见、重整表与患者指导卡中的一致呈现，合并在对应复合 R 内一次验收，不跨条重复计分或重复扣分。
2. **严限上游误差传递的适用范围**：仅当下游 `R₂` 具备**完全独立的新证据鉴别与新医学规则适用逻辑**（而非上游同一生理基数的简单乘除顺延），且仅引用了 `R₁` 的某项核定结果时，才可在 `R₂` 中预先写明条件式判据（纯粹沿用上游轻微数值偏差但本条新证据鉴别、新规则选择及安全校核完全正确时不重复扣分，同时如实记录“上游误差传递”，不宣称整份文书数值绝对无误）。**严禁把同源生理估算、剂量配比、溶媒负荷与封顶核对拆成多条算术 R 后用上游误差免责放水**。
3. **跨越临床分期或禁忌红线时禁止笼统免责**：若上游错判（如漏识溶血假性高钾、错用稳态公式严重高估 AKI 肾功、漏算复方对乙酰氨基酚超极量）直接导致下游选错治疗路径、跨过禁用红线或漏掉抢救措施，则两者属于不可分割的耦合判断——要么合并为同一复合 R，要么在下游明确验收其独立复核拦截义务，绝不能免除下游错误。
4. **禁止前后自相矛盾的判据**：同一条 `criterion` 内不得既写“必须精确等于某唯一数值”又写“不因上游误差重复扣分”；所有条件式边界必须在冻结前自洽写清。

### 内容、文件和执行的归属

- 临床判断内容与实体办公文件能力分别定界，**绝不把“须生成 DOCX/XLSX/PDF 并读回”机械粘贴到每一条临床内容 R 末尾**。
- 在对应的单条**复合载体、联动与版式交接 R** 中，**点名本例具体医疗文书与核算工作簿名称**集中核验（避免照抄内部缩略词或每题统一以“交接成果须……集中核验……”死板起笔）：
  1. 工作簿内全部纵向数据折算、生理／风险参数、剂量速率／液体热氮／D0 排程汇总以及跨节点更新（或单窗口静态题围绕本例真实存在的口径分歧、生理临界波动或备选路径设置的临床敏感性／情景对比试算栏）均由活公式驱动并实际完成重算读回（手填静态常数、`SUM` 漏行、单位混算或跨时点串格不成立）；
  2. 全套分页 PDF 完整覆盖主评估／会诊／审方／质控报告全文、全部正式执行／排程／交接／患者指导文书，以及经横向页面或列宽适配后的多栏核算宽表（单文件 ≤18MB，超限按连续页完整拆分且页序无缺漏；仅导出短篇交接卡或只列文件名不成立）；
  3. 经全部 PDF 逐页转图像检查后的最终定稿无宽表跨页横向劈裂成碎页、无审签落款／高危警示框孤行跨页、无剂量浓度单位截断，且主报告、执行医嘱表与患方指导卡之间的药名、剂量、频次、执行窗口与停用红线完全一致（残留严重版面劈裂或跨件指令矛盾未回改源稿重导的不成立）；
  4. 明确“仅罗列文件名、口头声称已检索或已导出渲染、手填常数结果或仅附上未执行代码脚本均不成立”。
- **物理隔离评测产线异常术语**：下表仅供本机评分执行器与评测复盘区分运行状态，**严禁作者把表中的 `评分端`、`轨迹未传`、`评测条件不满足`、`不作为有效专业难度成绩`、`纳入有效成绩均值` 等任何内部流水线黑话写进 rubric 正文**：

| 评测运行异常状态（仅评分执行器与复盘使用，禁入 rubric 正文） | 运行与复盘处理原则 |
| --- | --- |
| 必需工具与产物能力可用，完整答案明确漏做或现有产物证实未完成 | 按冻结判据判对应条目 `0`；自述已完成、列文件名或交未运行脚本不证明完成 |
| 产物或工具轨迹在评测传输环节缺失，无法确认实际执行状态 | 评分执行器单列证据缺口说明，保留可确认的内容判分，不凭空推断未做或冒充通过 |
| 经运行配置或错误日志确认必需工具未接通、输入缺件或传输故障 | 复盘记为运行异常，绝不把环境故障造成的低分当作题目专业难度达标证据 |
| 模型仅口头声称无工具，但实际运行配置与失败日志尚未核实 | 复盘核查真实运行配置，不单凭模型自述豁免漏做责任 |

### 连续照护的结果验收

本题采用跨节点动态照护时，严格沿实际临床状态演变链验收，**严禁单设“完成两阶段模拟”或“多交一份更新文件”的形式分**：

- `rubric` 必须自足写清给定新记录（如新回报药敏、复查血气肌酐、术后引流或阶段训练反应）的具体内容、时点证明范围、触发的指南／说明书跃迁条件、受影响的定量重算结果及必须同步改定的当前有效文书范围。
- 严格区分**基线当时合理决策**与**新节点修订义务**：绝不用后阶段才出现的培养结果或病情恶化反扣基线时点合规的经验性处置；同时核查新事件进入工作簿后是否由公式真实传导更新，严惩沿用已失效旧医嘱或新旧两套剂量混杂不清无法辨认当前有效稿的答案。

### 逐 R 评分输出与争议留痕契约

独立评分逐条输出须包含：`ID`、`0` 或 `1`（或契约规定的二元值）、答案／交付文件对应位置与关键短引、各必要条件满足情况、决定性未满足条件及其按冻结判据造成的临床／使用失败后果，最后核对成立条数、总条数与百分制换算无误。若发现冻结 rubric 与原始附件事实冲突或误排斥有权威依据的合法临床方案，如实记录评分争议，不临时篡改判据或改分母。

## 关系型医疗复合考点示例

以下两例分别演示非药学围术期排程与多源用药转换的复合耦合结构，仅供理解“多项判断共同决定同一可用成果”，**严禁在新题中照搬示例病种、数值或句式**。

**示例一（外科围术期时机与 D0 多药停启桥接排程）**：针对附件所载拟行限期结肠切除术合并非瓣膜性房颤、2 型糖尿病及慢性肾病患者的术前记录，结合入院复查血肌酐估算清除率（写明公认公式口径与安全容差）及高出血风险手术分级，依据现行围术期抗栓与降糖权威指南及对应 NMPA 药品说明书，核定直接口服抗凝药随肾功延长的术前精确停药天数、排除无需肝素桥接的出血叠加风险、同步落实 SGLT2 抑制剂术前停药窗口（防范正常血糖酮症酸中毒）及术晨基础胰岛素折减方案，并将以手术日（D0）为基准的逐日停启时间表完整落入《围术期高危慢病用药排程表》与《患者术前停药核对卡》。把低中危血栓患者在肾功减退期仍套用常规 24 小时停抗凝或无指征叠加全量低分子肝素桥接、漏停 SGLT2i，或仅写“术前停抗凝药并请心内科内分泌科会诊”而无精确 D0 日历的，本项不成立。

**示例二（多源用药穿透、检验伪影剔除与出院医患双端重整）**：结合附件中患者院外自备感冒止痛复方与中成药、住院长期／临时医嘱及护理实际执行记录，先识别住院第 4 天血钾危急值系备注溶血标本所致（复查正常后剔除假性高钾干扰，不误停心衰核心获益药），同时穿透剔除两组含对乙酰氨基酚的隐藏重复成分及已无指征的院内临时镇静药，按稳定期肾功核定出院保留药物的精确单次量与频次，并同步写入供主诊审签的《拟出院有效用药重整单》与《患者居家分时段服药及复查警示卡》使其药名、剂量、频次与停药红线完全一致（若在最终有效出院药单与患者服药卡之间对高危抗凝药或强效降糖药给出相互矛盾的停启剂量且未标明效力关系，直接诱发居家致命误服风险，整题按零分处理）。
