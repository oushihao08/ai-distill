# 评分与难度验证

用于在看模型答案前建立公平、可独立执行的评分尺。它是医疗项目的本地设计方法，不自行确定平台当期阈值，不授权发起真实模型评测。

## 复合专业结果

每项 R 验收一个有独立用途的专业结果，包含共同决定其成立的必要判断。按核心结论、决定性依据及成果可用性判为 0 或 1，各项等权。普通得分为 `100 × 成立项数 / 有效考点总数`；结构化契约使用 `id / criterion / max_score` 时，`max_score=1`。显示精度按当前契约，不用舍入改变达标判断。

- 按用途和新增判断划分考点，不按材料份数、段落、工具步骤或专业名词数分配。不同问题在同一文书里仍可独立评分；同一判断出现在多个成果中不重复得分。
- 核心结论、必要依据和落实条件必须共同成立；不影响结论和实际使用的次要措辞或背景遗漏不判失败。需要完整处理但不要求逐字复述标答。
- 纯事实抄录、列出药名、给出公式或重复“及时就医”通常只是上游条件，纳入其支撑的专业结果，不单独凑简单分。
- 独立用途需另有实质判断才单设 R；不能把全部诊断、处方、患者教育和流程文书捆成一个巨大考点，也不能把同一剂量的单位换算拆成数个简单考点。

## 自足 criterion

评分者通常只见同版题面、允许附件、rubric 和匿名答案，不读本 Skill、作答思路或默认标答。每条判据把实际需要的信息写全，不引用“按本 Skill”或“与参考答案一致”。

| 判分所需内容 | 应写入本题的内容 |
| --- | --- |
| 要验收的结果 | 对象、时点、用途，以及何种结果可以使用 |
| 决定性输入 | 附件名/序号、可辨识记录和关键数据；不要只写页码或“见材料” |
| 专业依据 | 规则要旨、适用人群/条件、来源及版本；只列指南名称或链接不够 |
| 成立条件 | 共同决定结果的具体判断和联系，必要计算、数值/范围、单位及容差 |
| 合理替代 | 哪些方案或论证可等效完成任务，何种前提下不同结论也可通过 |
| 失败边界 | 缺什么会实际改变结论或使成果不可用；与不影响结果的轻微错漏区分 |
| 验收证据 | 正文、实际文件、工作表结果或可核实操作证据，证据缺失如何归属 |

适用分支应给出可判定条件，未知事实不编成唯一答案。回答提出未预列但有充分依据的合理方案时，按已写明的目的、约束和等效标准核验；尚需专家解决的实质争议标为待复核，不能强行凑成唯一判分后宣称验收完成。

不将每项固定写成七个栏目；按结果自然组织，但上述必要信息不能丢失。标答和 rubric 不相容时修正有误的一方，不为维护答案键排除合理医学方案。

## 分支与真实工作深度

按[临床决策分支](临床决策分支.md)审查本题选中的路径，而非要求作答者重画作者的决策树。每个专业结果只评价影响它的条件：进入该路径是否有证据，选择是否适用于本患者和时点，必要前置条件是否满足，行动与监测/换路是否一致。资料本身不能决定的分支，接受有依据的条件化方案；资料足够时，不能以罗列所有可能性代替当前选择。

| 需要区分的答案 | 判据怎样避免误判 |
| --- | --- |
| 方法不同但完成同一工作 | 比较用途、适用条件及结果，不要求相同药物排序、文书顺序或叙述路径；具体等效边界事先写明 |
| 合理观察/维持/减停与漏做 | 前者有依据、适用条件和必要复评，后者没有解决当前问题；不能以干预少判错 |
| 有目标的进一步检查与无差别检查 | 前者能说明对决策的影响；额外检查只有造成可论证的延误、风险或违背题设限制时才影响相关结果，不因清单长短直接判分 |
| 真实新阶段与重复旧稿 | 新阶段确有新判断并更新受影响成果才评价新增结果；复制同一建议不增加独立得分 |
| 临床先后与书写先后 | 评价明确行动是否遵守时效和前置条件，不能只因把依据写在正文前面就认定实际延误 |
| 缺关键图像与有报告可作决定 | 未提供图像不考图像发现；已有报告能支持的解读和处置正常验收，不能补造形态来凑完整答案 |

思考量以必要的证据整合、取舍、计算、条件转换和成果修订体现，不按展示的思维链长度、工具调用次数或写了多少步骤评分。作者应能指出每个新增环节如何影响核心用途；没有新增判断的包装不构成难度证据。

## 同源错误与独立义务

冻结前指明共享前提的所属 R、下游允许的条件性承接以及下游独立判断。一个体重抄错不能仅因复制到三份文件就扣三次；但下游若另有明确的剂量上限、异常识别或独立核对义务，且本题输入足以履行，可按该新义务判定。

条件性承接不把危险结果当作医学正确。记录上游值和据此推出的下游关系是否自洽，同时区分阈值跨越、路径变化及独立风险。只有预先写明且确实符合本题整体失效条件时，才能转为整题归零。

新增阶段按新增判断计分。重复表达原决定不新增 R；新肾功能、培养结果或功能反应改变方案适用条件时，可验收新的调整结果，但须写明当时输入、前阶段状态、调整/保留内容及有效成果。不能用后来信息反向否定当时合理处理。

## 整体失效与局部错误

每题都检查核心成果的成立基础。只有能从本题输入与医学依据证明某种具体错误破坏整项核心用途时，设置整题最终得分归零条件；普通局部错漏只影响对应 R。不能仅写“有医疗安全问题则零分”，也不为了每题都有严重错误而编造风险。

对可能失效的行为逐一论证：患者/对象错配、决定性事实或来源捏造、已知条件下不安全的执行方案、延误必要紧急处理、最终方案的关键矛盾等，是否在本题具体导致核心成果失效。上述是审查方向，不是每题自动触发的通用清单。

写入的规则必须同时说明：具体对象与最终行为、触发所需证据、适用依据、为何足以破坏本题核心用途、整题归零后果，以及相邻不触发情况。若现有 schema 无独立整体规则字段，放在最相关 criterion 中单独一段，只出现一次，不增加普通考点或分母。

合理竞争解释、符合适用条件的替代治疗、明确限定的备选、已在最终有效稿中纠正的错误和无充分证据的怀疑均不能推定触发。附一句免责声明不能抵消最终有效方案中的危险指令；出现两个未区分效力且互相矛盾的最终方案时，按预设判据评其实际影响。

没有可论证的整项失效行为时，按普通复合考点完整验收；不要直接复制法律题的诉讼立场、权益损失或固定否决条件。程序是否支持记录/应用整体归零须另行核对，不能从文字有该规则推定运行已生效。

## 内容、文件与执行证据

- 内容正确、文件可用和操作已完成分别验收。实际文件按其专业使用能力归入相应复合结果，共用文件缺口不逐 R 重复扣；文件名、空壳模板或一段生成代码不证明成果已交付。
- 有公式联动需求时，验收输入变化后正确更新及应保持内容；需要固定版式时检查导出/渲染。无需这些能力的题目不强加文件门槛。
- 作答环境没有必需工具、传输漏件或评分者没取得成果，属于环境/证据异常；先定位，不能直接填零制造低分。环境已支持、题面已交办但完整答案明确漏做，才按预定失败边界判分。
- 自述“已查指南、已生成、已复核”不替代可查来源或产物。没有工具轨迹时记录执行未知，不由答案长度推定调用次数。
- 临床实际操作或疗效没有观测输入时只评价方案，不把文字步骤当作已给药、已完成手法训练或已改善患者结局。

## 复合考点的结构示意

以下仅演示划分，不是可直接复制的医学判据；具体病例的药物、参数、阶段、数值和依据须作者求解后填实。

**出院药物重整**：对一个存在真实清单差异的患者，识别实际使用与拟继续方案，结合适应证和相关个体条件判定保留/调整/停用，在当前药单和患者说明中落实一致安排及必要监测。这个结果同时依赖来源辨识、专业判断与可执行药单；“列出全部药物”不是单独满分项。若另有独立的待报结果追踪与跨机构责任交接，且需要新的判断，可另设 R，不按药品数量机械计分。

**康复进阶更新**：在既定功能目标、负重限制及新训练反应下，判断原方案能否继续，选择有依据的进阶/维持/降阶，写出本次具体修订与复评条件，并同步家庭练习内容。不得把任意增加强度当作正确答案；仅因患者年龄或分数变化而没有适用分析不足以完成。具体允许范围、必要限制及失败后果必须进入实际 criterion，不留给评分者自行猜。

## 冻结前的作者核对

用同版输入和已完成标答做静态对照，不另调用模型。以下结果应同时成立：

| 对照内容 | 应有的判定 |
| --- | --- |
| 完整正确解 | 全部内容判据成立，不触发整体失效；文件是否真实通过另取产物证据 |
| 简洁但完整的等效方案 | 与完整正确解同样通过，不因顺序或措辞不同扣分 |
| 缺少一项真正必要判断的近似解 | 对应结果不成立；若仍可安全完成任务，重新审查该条件是否必要 |
| 通用建议、百科罗列或全盘待核 | 未解决本题独立专业结果的部分不成立 |
| 局部分析正确但最终成果矛盾 | 按矛盾对实际用途的影响判定，不被前文风险提示抵消 |
| 单个上游错误在多处传播 | 按预设归属处理，新的独立错误另判，不同义重复处罚 |
| 严重错误及相邻轻微错误 | 仅严格满足已定义整体失效条件者归零，不能扩大触发范围 |
| 缺件或评分证据不完整 | 记具体异常，不能假称已完成公平评分 |

## 实测和达标解释

获准实测后，先冻结题面、附件、rubric、标答、模型/工具/预算、计时和异常口径。新会话作答只接收题面和允许附件；评分保持匿名、同版及自足，不透露目标分数或模型身份。默认不提供标答；本次明确使用冻结校准政策时可提供标答作为校准参考，不能当作唯一答案键。

保存完整答案、实际成果、逐 R 证据、工具轨迹、终止状态及运行耗时；请求模型与可核实返回模型分开记录。首先解决标答误拒、等效解误扣、文件传输和同源错误重复扣分，再解释题目难度。

当前适用平台规则明确要求的分数、执行步数或时长才是验收门槛。法律项目摘录中的“得分率不高于 50，且至少 50 步或超过 40 分钟”是既有外部规则记录，不能未经适用性确认自动变为医疗项目运行配置；一旦本期明确采用，按其原口径验证，不向作答者或评分者注入指标。禁止用等待、文件拆分、无关工作或故障耗时凑门槛。

记录预定样本数、有效样本数、异常及未完成范围，不挑最低分、不把技术截断填零；回答短或漏答本身不证明技术截断。不同考点数、输入、模型或运行条件的总分不可直接证明设计方法效果。真实执行轮次、工具调用、业务阶段及墙钟耗时分别计，不能互换。

修改题面、附件、rubric 或其他影响结果的输入后，对新版本重新作答、评分；不继承旧成绩。看过并用于调整的样本属于开发样本，独立验收按事先确定的未见样本与口径进行。静态核对、文件校准、医学专家审阅、模型达标和平台接收分别报告。
