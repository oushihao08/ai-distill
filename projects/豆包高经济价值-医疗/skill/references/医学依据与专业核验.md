# 医学依据与专业核验

用于作者临床与业务求解、编写完全自足的 rubric 判据及校准标准答案。本文件规定强制性的权威医学原文检索、个案证据去伪消歧、跨专科定量核算及伦理隐私边界，不预置通用诊断阈值或固定给药表；每道新题的决定性医学依据均须针对本例人群、场所与决策时点重新联网核验权威原文。

## 一、权威医学依据联网检索与版本核对

1. **界定精确临床或业务问题（PICO／岗位／时点）**：明确本例对象特征（实足／校正年龄、性别、孕哺状态、身高体重与体成分特征、动态肝肾心肺基线及并存病）、照护场所与资源层级、拟审定或比选的干预／检查／管理措施、关键安全与功能结局，以及决策所属时点（当下诊疗决策 vs 历史病案事后复盘）。
2. **权威来源优先级**：
   - **第一顺位**：国家卫生健康委员会发布的诊疗规范／临床路径／医疗质量控制指标／卫生行业标准（WS 系列）、国家药品监督管理局（NMPA）批准的最新**正式药品说明书原文**、中华医学会／中国医师协会／国家医学中心现行权威专科指南与专家共识、中国药典、WHO 及国际公认顶级学会（如 ESC、AHA/ACC、ADA、KDIGO、IDSA、NCCN、SCCM、ACOG、AAP、ESPGHAN、ESPEN、ACSM 等）正式指南原文；
   - **第二顺位**：现行规范与指南尚未明确覆盖的精细交叉问题，采用高质量系统评价（Cochrane 等）、Meta 分析或改变临床实践的关键随机对照试验／真实世界队列原始论文全文，并如实界定证据外推边界；
   - **严禁**：仅凭搜索引擎摘要卡片、大众养生科普号、商业医药词条、论坛转述或模型记忆编造推荐等级、诊断截断值、给药极量、条文编号或网址链接。
3. **实际打开原文核实关键边界**：冻结题包前，作者必须实际打开权威发布页面或正式全文，逐项核实**发布机构、文件全称、发布／修订年份、具体推荐意见与证据级别、适用人群排除条件、特殊人群（肝肾功不全／儿童／孕哺／老年）折算表，以及国内外批准适应证／规格／折点差异**（如国内 NMPA 说明书肾功截断值与国外指南推荐不一致时，须如实写明合规衔接条件），保留完整出处与可追溯链接。
4. **决策时点版本对齐**：当下临床任务采用现行有效权威依据；明确设定为历史病案质控、医疗安全复盘或过往临床试验稽查的任务，必须核对**医疗行为发生当时有效的规范／说明书版本**，严禁拿事后数年新修订的指南标准倒扣当年合规的临床处置（事后改进建议可结合现行新标准另列说明）。
5. **兼容有循证支持的合法替代路径**：当国内外权威指南或不同专科共识对同一临床情境存在均具高级别证据的合理路径（如目标血压区间、围术期桥接策略、二线等效抗菌／镇痛／康复方案）时，在思路中比较适用条件，并在 rubric 中将决定性规范要旨、版本边界与合法等效方案一并写清，绝不只贴一条网址让独立评分者盲猜。
6. **检索隐私安全红线**：公开网络检索仅限查询疾病规范、指南标准、量表公式与药品公开信息，**严禁将任何真实患者姓名、证件号、医院病案号或大段原始病历文本拼入外部搜索词**。

## 二、个案证据穿透与诊断／检查解释边界

- **跨源检验与测量数据六维对齐**：横向或纵向比对多次检验、体检或生命体征记录时，同步核查**患者身份对应、标本类型（动脉／静脉／末梢血、清洁中段尿／导尿管尿、深部痰／咽拭子）、采样时间窗（空腹／餐后、体位、给药前谷值／给药后峰值、运动／透析前后）、检测方法学（如酶法 vs 苦味酸法肌酐、直接法 vs 间接离子选择电极血钠）、计量单位（如 `mmol/L` vs `mg/dL`、`μmol/L` vs `mg/dL`、`g/L` vs `g/dL`、`ng/mL` vs `nmol/L`、`IU/mL` vs `copies/mL`）及各检测实验室参考区间**；单位或方法学不同须先规范换算或说明不可直接相减计算斜率。
- **强制排查检验前／分析中伪影与执行干扰**：重点识别溶血标本致假性高钾／AST／LDH 升高、EDTA 抗凝管致假性血小板减少或假性低钙高钾、输液同侧采血致血液稀释或假性高糖／高钠／高钾、严重高脂血症／高血糖导致的假性低钠、低白蛋白血症未校正的假性低总钙、TDM 未达稳态（通常需 4—5 个半衰期）或输注管路误采致假性中毒浓度、痰涂片鳞状上皮细胞超标提示口腔污染／定植菌、动态血糖传感器受压假性夜间低血糖。未先排除上述干扰不得直接驱动高危临床干预。
- **诊断确定度与阴性边界**：严格区分主诉症状、初步工作诊断、待排高危鉴别诊断与病理／病原／金标准确诊；既往文书转抄的“XX病？”或外院口头诊断不等于已核实确诊；“病程未记载某体征”不自动等于“查体阴性”，窗口期内单次阴性标志物／影像（如超早期心梗肌钙蛋白、超早期缺血性卒中平扫 CT）绝不等于排除高危急症。
- **临床评分量表与风险积分逐子项核实**：应用任何诊断、预后、围术期、营养、康复或早筛评分（如 SOFA、qSOFA、APACHE II、CHA2DS2-VASc、HAS-BLED、Caprini、Padua、Wells、Geneva、Child-Pugh、MELD、RCRI、NRS-2002、GLIM、CFS、Barthel、NIHSS、mRS、CTCAE、SCORE2／China-PAR、FIB-4、TI-RADS／BI-RADS／Lung-RADS 等）时，必须逐个子变量核对附件实测依据、计分权重、适用人群排除条件与缺失值合规处理，严禁凭印象估分。
- **有图核图、无图守界**：附件含可见心电、影像、内镜、皮损或曲线原图时核对图文一致性；附件仅含文字报告时基于报告描述与临床数据深度推演，严禁要求辨认未传入图像的形态细节。

## 三、多领域个体化定量核算核验（覆盖药学、重症液体酸碱、营养、围术期、妇儿、肿瘤、康复与质控）

涉及任何定量测算时，作者须对以下适用维度逐项穿透并用集中计算脚本完成闭环验算：

| 定量核验领域 | 必须穿透与核对的核心专业口径 |
| --- | --- |
| 1. 药物身份、复方与真实暴露 | 核准化学通用名、盐型结晶水差异（如琥珀酸 vs 酒石酸美托洛尔、不同钙盐／铁盐／钾盐的**元素量 vs 盐质量换算**）、缓控释／肠溶／微球剂型（能否掰开、研磨或经鼻胃／空肠管给药）及**中西复方制剂隐藏同名成分**；严格区分“院外实际自服、既往处方已停、院内长期／临时新开、护理执行单实给、已临停未撤药及拟出院带药” |
| 2. 体型修正与动态器官清除率 | 区分实际体重（TBW）、理想体重（IBW）、肥胖校正体重（ABW）、瘦体重或体表面积（BSA，注明 Mosteller／DuBois 等公式）；明确采用 Cockcroft-Gault（CrCl，核对 NMPA 说明书指定口径）或 CKD-EPI（eGFR，注意是否去体表面积标准化 `mL/min` vs `mL/min/1.73m²`）；**AKI 血肌酐急性波动期严禁盲信稳态公式高估肾功**，合并 CRRT／血液透析时核对滤器清除与给药时机 |
| 3. 剂量量纲、成人封顶与可分取配制 | 逐一核对`单次量 vs 日总量`、`mg vs μg`、`mmol vs mEq vs g`、`% (w/v) 浓度折算`、`负荷量 vs 维持量`；儿科／按体重给药**必须交叉核验是否触及成人单次／每日极量封顶**；理论剂量须折算为药房实际规格可分取单位（整片／刻痕半片／整支毫升数）、相容配制溶媒、终浓度渗透压上限、避光稳定时限及输液泵 `mL/h` 精确流速 |
| 4. 液体出入量、酸碱代偿与电解质速率 | 24h 平衡须计入全部静脉输液溶媒（0.9% NaCl 每升含钠 `154 mmol`、5% GS 自由水及热卡）、冲管液、肠内营养水分、发热／气管切开非显性失水与引流液；血气分析核对阴离子间隙（含低白蛋白校正 AG）与预计代偿公式；低钠／高钠血症核定每 24 小时血钠纠正安全上限，严防渗透性脱髓鞘或脑水肿 |
| 5. 临床营养热氮液与再喂养防线 | 筛查再喂养综合征高危人群（低 BMI、近期显著体重下降、禁食多日、基线低磷低钾低镁）并按低热卡起点阶梯递增；**必须扣减丙泊酚脂肪乳（约 `1.1 kcal/mL`）、枸橼酸抗凝及含糖静脉溶媒提供的非营养性热卡**，核准真实目标能量、蛋白质／氮量、非蛋白热氮比、糖脂比、液体限额与维生素 B1／磷钾镁同步补给 |
| 6. 围术期排程、肿瘤周期与等效换算 | 围术期以手术／操作日（D0）为基准，按药物半衰期、肾功及手术出血等级核定停药天数、桥接肝素停针时点与术后重启门槛；肿瘤方案核准最新体重 BSA 或肾功 Calvert 公式 AUC 剂量、历史蒽环／博来霉素等终身累计剂量上限及 CTCAE 减量比例；阿片类或糖皮质激素跨品种／跨给药途径转换核准公认等效折算比、不完全交叉耐药折减系数与爆发痛解救量 |
| 7. 康复训练负荷与妇儿生长曲线 | 运动处方核准药物（如β阻滞剂）修正后的靶心率公式、RPE、间歇与周总运动量；儿科／新生儿核准早产校正月龄、WHO／国内标准生长百分位或 Z-score、日龄小时胆红素风险区及追赶喂养配奶浓度与渗透压 |
| 8. 质控率值分母与流调／研究时间窗 | 病案质控与 DRG／DIP 核查必须回到原始个案逐例判定分子纳入条件、分母排除项（如禁忌证排除、自动出院、死亡或转院截尾）及主诊断／主手术选择逻辑；临床研究稽查精确计算筛选洗脱期、访视允许时间窗偏差天数与依从率百分比 |

- **脚本验算闭环与临界容差**：作者用集中脚本一次算清全部公式、单位换算与敏感性试算结果（脚本不进入五字段正文）。若患者指标恰处临床分界附近（如 CrCl 接近 `30` 或 `50 mL/min`、校正钙／钠接近干预线、BMI 接近肥胖折算线），必须同时验算分项舍入与全精度汇总后舍入、或两种合法公认公式的结果差异：若均落入临床安全合理区间，须在 rubric 明确兼容两种口径的对应数值；若其中一种因忽略明确人群禁忌而越界，则在 rubric 写明排除该错误口径的具体医学依据。
- **超说明书用药与执业权限底线**：确有高级别循证支持但超出国内 NMPA 说明书适应证、人群或剂量的方案，必须写明循证依据、常规方案不可用原因、院内药事／伦理备案审批及患方充分知情同意前置条件；所有题包产出的医嘱、处方、手术或康复计划均界定为**供具备相应执业资质人员审签启用的专业定稿／建议稿**，严禁伪造医师手签、电子签章或谎称已实际执行给药／手术。

## 四、急诊时效、慢病共同决策与伦理去标识边界

- **急危重情景时效与评测交付深度解耦**：在临床救治逻辑上，休克、气道梗阻、过敏性休克、急性卒中／胸痛时间窗、严重高钾心律失常或大出血必须坚持“床旁立即评估生命支持与首剂抢救并行优先”，严禁把等待非紧急报告或文书审批写成抢救前置条件；在评测交付要求上，仍要求作答者完整交付分级急救执行单、精确配制泵速速算工作簿、短程复评换路表及转运交接定稿，两者分属临床时序与案头交付载体，互不冲突。
- **患方意愿与共同决策（SDM）**：仅采用附件明确记载的患方意愿、经济或照护条件，不替患者凭空编造偏好；存在获益与风险取舍不同的多个合法路径时，如实量化呈现各选项利弊、监测负担与可逆性。当患者明确拒绝首选方案（如拒绝输血、拒绝手术、拒绝胰岛素注射）时，须评估其知情决策能力、清晰告知拒绝的具体医学风险，并制定当前条件下最安全可行的替代止损方案与红旗返院标准，严禁写成“拒绝即放弃一切医疗处置”或“强制代患方做主”。
- **隐私去标识化与临床专业校准分离**：题包任何字段不得回显真实患者姓名、身份证号、电话、住址、住院号／病案号、条码／二维码或可反向锁定真实自然人的独特组合信息；同一患者在题面、工作簿与全部文书中的化名代号及生理参数必须前后完全一致。高风险临床结论正式投产前须经具备资质的医疗专业人员按当期规范独立校准；本地作者核对、脚本验算、模型难度实测与医学专家审阅严格分开记录，绝不混同宣称。

## 五、方法层通用参考入口（非个案疾病判据）

以下官方方法学资源仅支持本 Skill 的照护流程、转换交接、手术核查框架与医患共同决策边界设计，绝不替代每道新题针对具体病种与药品开展的权威原文联网检索：

- [WHO: Medication safety in transitions of care](https://www.who.int/publications/i/item/WHO-UHC-SDS-2019.9)：跨场所照护转换中的多源用药差异核查与重整交接原则。
- [WHO-ICRC: Basic Emergency Care](https://www.who.int/publications/i/item/9789241513081)：急症首接 ABCDE 时间敏感风险识别、初始生命支持与安全转运交接框架。
- [WHO: Safe surgery tools and resources](https://www.who.int/teams/integrated-health-services/patient-safety/research/safe-surgery/tool-and-resources)：围术期跨学科团队沟通与关键安全核对节点（不替代具体手术指征与术式决策）。
- [WHO: Rehabilitation](https://www.who.int/news-room/fact-sheets/detail/rehabilitation)：以身体功能、活动参与、环境因素与个体目标为核心的康复评估干预体系。
- [NICE NG197: Shared decision making](https://www.nice.org.uk/guidance/ng197/chapter/recommendations)：围绕循证获益风险、个体目标及包含主动观察／维持选项在内的共同决策与复评沟通规范（中国执业权限仍以国内卫生法律法规为准）。
