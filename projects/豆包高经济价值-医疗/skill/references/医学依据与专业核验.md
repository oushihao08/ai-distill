# 医学依据与专业核验

用于作者求解、编写自足判据和标答校准。这里规定核验方法，不预置通用诊断、治疗阈值或药物剂量；医学依据须针对每道题重新选择。

## 来源、时间与适用性

1. 先明确临床问题、人群、疾病/严重程度、照护场所、干预与备选、关注结局以及决策时点。地域与岗位规范涉及实际权限时一并核对。
2. 优先查与任务相符的卫生主管部门/药品监管机构原文、正式药品说明书、专业学会指南及原始研究。指南没有覆盖时可用系统评价和高质量研究补充；共识、经验和个案证据明确其证据限度。来源权威不能替代适用性判断。
3. 打开原文核对标题、发布者、版本/更新、推荐内容及条件、适用人群和例外；记录稳定链接或可核查出处。药品用题中实际产品、剂型及当地批准说明书；不同国家的批准范围不能直接互换。
4. “当前诊疗”核验现行资料，历史决策核验当时可得依据；当前回顾意见和当时决策评价分开。旧版、勘误、撤回和新版变化会影响结论时查清，不仅凭网页更新时间判断正文版本。
5. 指南存在分歧时比较适用条件、证据质量、收益风险及可及性，允许有依据的替代。院内流程可说明本机构操作条件，但不能自行证明某医学结论正确；不把偏好伪装为唯一标准。
6. 作者完成依据核验后，把决定性规则要旨和适用条件写入 rubric；不能只给网址让评分者猜答案。关键来源无法取得时，不伪造引用或宣称已核验；仍能支持的部分继续完成，依赖部分说明具体限制。

公开检索只用于一般医学依据，不补造患者事实，不向搜索引擎发送可识别患者的信息或完整私有病历。引用来源不默认成为新的题目附件；是否提供全文或必要摘录按任务环境、版权与当前输入边界处理。

## 个案证据与检查解释

- 同时核对患者、样本/检查对象、时间、方法、单位及参考区间。采用比值、趋势、评分或阈值前说明方法和适用人群；不同实验室、设备、采样条件或体位的数据不无条件直接比较。
- 关键数值、单位、小数点、阴性/阳性、左右侧、用药频次和时间以原件复核。原件不清不能用 OCR 确信补齐。只有报告文字时评其报告解释，不声称已阅原始影像、心电图、病理切片或完成查体。
- 区分工作诊断、鉴别诊断、排除程度与确诊依据。病历既往标签是信息，不自动等于本次已证实；不能把“未描述症状”当作否定，也不能以一次阴性检查无条件排除疾病。
- 按本题临床风险与证据选择进一步检查，说明结果如何改变决策；检查清单越长不越正确。对明确具有时效性的处置，不能把非必要检验或文书当作前置条件。
- 量表、风险模型、公式与统计结论须核对版本、变量、适用人群、缺失处理及结果含义。分数不能独立替代临床判断；统计显著、临床重要、相对效应和绝对效应不能混写。

## 用药与数值核算

涉及具体药物决策时，按其实际相关性核对下列输入，不机械要求每题收齐全部字段：适应证、治疗目标、年龄/体重、过敏及反应性质、孕哺状态、器官功能及其变化、合并药物、既往反应、给药途径、实际产品和执行条件。缺少会改变安全剂量或方案选择的信息时，不能给出无条件执行剂量。

| 核验对象 | 必须区分或核对的内容 |
| --- | --- |
| 药物身份 | 通用名、成分、盐型/剂型、规格、释放形式及复方重复；商品名相似不代表相同 |
| 实际用药 | 入院前自用、院内开立、已经执行、临时停用、按需及拟出院；不能把所有清单直接叠加 |
| 剂量口径 | 单次与每日、按体重与按体表面积、mg 与 μg、质量与体积/浓度、负荷与维持、间隔与速率 |
| 器官功能 | 使用何种估算方法、单位及适用条件；不把不同肾功能指标无条件互换，动态变化和特殊治疗需另核依据 |
| 计算关系 | 输入来源、公式适用性、量纲、分项和总量、最大量及合理舍入；计算结果需与可实际分取/输注的制剂相容 |
| 相互作用 | 是否有实际临床意义、什么条件触发、如何监测或调整；不能只列药名或把全部相互作用均称禁忌 |
| 执行安排 | 途径、频次/间隔、疗程或复评点、启停/调整条件、监测和责任交接；按本题用途写到可使用程度 |

使用计算工具时保留关键输入、公式、结果及复核关系；正确代码不能替代正确口径。题目与 rubric 写明所需精度和可接受容差，接近临床决策边界时核验舍入是否改变行动。药物库存或费用属于已知约束时才纳入，不无依据认定可获得或医保覆盖。

涉及超说明书方案时，按适用地区、岗位和专业证据判断其成立条件、必要告知和审用要求；不自动等同错误，也不省略关键限制。评测中的建议稿与真实开方、签发、给药是不同状态。

## 急诊急救和临床时间

急症任务优先评价对时间敏感风险的识别、当前可执行动作、必要并行评估、复评和升级/转运。具体顺序、阈值、药物和操作依据适用人群、场所及最新/历史对应指南核验，不把单一急救算法泛化给全部患者。

- 给出判断所需的观察、时间及资源；信息不足时评价合理的立即评估与行动，不强判唯一病因。
- 专业岗位和公众/照护者角色分别设计。侵入性操作、设备处置和处方权限以场景为准；公众题不能以自行实施专业操作为满分条件。
- 情景内的医疗时限与模型完成题包的墙钟耗时分开。急救处置不能为了“高经济价值”要求等待检索、生成文件或凑操作次数；事后病例复盘、流程设计可以展开较长的专业工作。
- 虚拟题中写出行动不等于真实实施。不得伪造呼叫、转运、会诊、给药或患者反应；后续反应只能来自提供记录或已披露模拟条件。

## 康复、慢病与患者共同决策

按[康复场景](医疗场景与工作流程.md#康复理疗的具体设计)把目标、限制、干预、监测及调整连接起来。具体运动强度、器械参数、负重和进阶取决于本题依据，不以一组通用数值覆盖术后、心肺、神经和肌骨场景。

长期管理需判断目标与患者实际能力是否相容，明确复诊/复评、观察指标、行动触发点和责任人。患者偏好、治疗负担和家庭支持以材料为据；不给未知偏好代填答案。拒绝某方案时应说明后果、可行替代与再评估条件，不能把不服从等同无决策能力。

解释风险和收益时避免保证疗效；建议要具体到本题的选择与行动，不以笼统“请遵医嘱”替代可完成工作。患者版保留必要剂量、单位、时间及危险信号，语言通俗不能损失实质条件。

## 隐私与校准

题目只携带所需的去标识信息，保持一个患者在全文的代号和医学关系一致；不要回显真实身份、联系方式、二维码或不必要的可识别组合。脱敏状态须以实际产物核验，不能从目录名推定；不自动改原件或执行入库。

高风险结论按具体专科与场景安排有资质人员校准，分别检查事实、适用依据、可执行性和可接受替代。记录已校准范围与仍有争议的部分；未开展只写未开展，不假称有专家背书，不因此停止不依赖校准的候选题设计。模型评分通过不证明临床适用，专家审阅也不代替同版模型难度实测。

## 方法来源与进一步核验入口

以下官网页面于 2026-11-09 查阅，仅支持方法设计，不是本项目全部临床方案的依据库，也不代表已审阅所链接的全部手册。具体疾病、药品和操作仍按上述方法核验。

- [WHO：Rehabilitation](https://www.who.int/news-room/fact-sheets/detail/rehabilitation)：康复围绕功能、活动参与、环境及个人目标组织；用于本 Skill 的康复任务范围设计。
- [WHO：Medication safety in transitions of care](https://www.who.int/publications/i/item/WHO-UHC-SDS-2019.9)：照护转换中的用药差异及信息衔接；用于本 Skill 的药物重整与交接设计，不提供具体药物剂量。
- [WHO-ICRC：Basic Emergency Care](https://www.who.int/publications/i/item/9789241513081)：面向首接医护的时间敏感评估、初始处理和交接方法；课程组件有更新，出题时按实际组件版本核验，不只记总书名。

2026-11-10 为分支方法补核以下官方内容；只支持相关流程设计，不证明所有专科场景已经逐病种验证：

- [WHO：Safe surgery tools and resources](https://www.who.int/teams/integrated-health-services/patient-safety/research/safe-surgery/tool-and-resources)：团队沟通及麻醉前、切开前、离开手术室前的关键核对节点；支持区分围术期工作及团队责任，不代替手术指征和术式选择。页面鼓励结合本地情境适配，不能机械复制到所有外科任务。
- [NICE NG197：Shared decision making，建议 1.2.9–1.2.17](https://www.nice.org.uk/guidance/ng197/chapter/recommendations)：选择应结合证据和个人目标，讨论获益、风险、维持/不治疗等适用选项，说明已决定事项及复评安排。用于共同决策分支与患者表达方法，不直接作为中国地区的处方权限或具体治疗标准。
- 同日重核上述 WHO 急救和照护转换用药安全官网入口，分别用于时间敏感工作与用药交接的范围依据；未据入口页面宣称通读全部课程和技术报告。
