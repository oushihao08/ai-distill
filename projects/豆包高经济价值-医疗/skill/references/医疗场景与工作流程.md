# 医疗场景与工作流程

用于从本次材料选择岗位任务。按“场所与阶段 × 专业问题 × 患者特点 × 成果使用人”组合；下表不是穷尽目录、题型配额或固定流程。未列专科沿相同方法扩展，须重新核验其专业依据。

## 场景选择

| 场景 | 有意义的触发材料与判断 | 实际成果及使用关系 |
| --- | --- | --- |
| 全科、基层与初诊门诊 | 主诉、病史、查体、既往资料；紧急性、鉴别方向、检查必要性与基层能力 | 初诊处置意见、分层随访或转诊交接；不能只列可能疾病 |
| 内科专科 | 心血管、呼吸、消化、内分泌、肾脏、神经、血液、风湿等病程与治疗记录；病因、严重程度、并发症及干预冲突 | 会诊/病程处理意见、检查与治疗调整、监测方案；按实际专科选取，不一题全覆盖 |
| 外科与围手术期 | 普外、骨科、神外、胸心外、泌尿等病历、手术/麻醉记录；指征、替代、风险、准备及术后变化 | 围术期评估、术后处理或交接方案；文本分析不假称完成手术或体格操作 |
| 急诊分诊与急救 | 起病时间、生命体征、现场观察、可用资源和已做措施；时效风险与当前优先级 | 立即行动、并行评估、复评和升级/转运安排；详细依据可置后，不等待报告才启动必要处理 |
| 院前与灾害救援 | 现场安全、伤病员信息、救援岗位能力和转运条件；分诊、处置能力与资源分配 | 岗位可执行的处置/转运交接，面向公众与专业人员的任务分开 |
| 重症与住院值班 | 趋势监测、器官功能、治疗反应和支持记录；恶化识别、方案协调和复评 | 当班处理、会诊与交班成果；不从文字报告伪造床旁测量或设备调整已完成 |
| 临床药学与药物治疗 | 实际用药、处方、药品规格、过敏、器官功能与检验；适应证、重复、相互作用、剂量与监测 | 药物重整、处方审核、剂量核算或用药教育；新增/停用/保留及理由要与最终药单一致 |
| 慢病与多病共存 | 连续复诊、自测数据、目标、依从性、合并疾病和生活条件；趋势可信度、目标冲突与方案可持续性 | 个体化长期管理、具体复诊/调整条件与家庭记录工具；不把宣教长文当管理方案 |
| 老年与照护 | 功能、认知、跌倒、营养、用药、照护者能力和患者意愿；综合目标与干预负担 | 综合评估、照护/药物调整及交接；年龄本身不能代替功能和偏好判断 |
| 儿科与新生儿 | 年龄、必要时胎龄/校正年龄、体重、生长与喂养、检查和用药；人群适用性与监护人执行能力 | 诊疗、喂养、剂量或随访成果；不得直接缩小成人剂量或沿用成人阈值 |
| 妇产与生殖 | 孕周/产后阶段、母胎信息、用药与检查；双重风险、时机及可选路径 | 评估、会诊、用药/监测及共同决策材料；不将孕期、哺乳期及备孕期混为一类 |
| 肿瘤与缓和照护 | 病理、分期依据、既往治疗、毒性、功能和意愿；治疗获益、负担和照护目标 | 多学科意见、症状管理、支持照护或阶段调整；不能把病理推测当确证或把缓和照护等同放弃照护 |
| 精神心理与成瘾 | 精神状态、行为风险、病程、躯体/药物因素和支持系统；风险分层、鉴别及处置能力 | 岗位范围内的评估、危机升级、治疗协作与随访；少量描述不强行确诊，不向公众交危险操作 |
| 感染、院感与公共卫生 | 病原结果、标本时点、暴露、症状、抗菌药和院内流程；感染/定植/污染、治疗与传播风险 | 抗感染审核、隔离与报告建议、接触者/流程管理；法定要求核验所在地区现行依据 |
| 康复、运动与理疗 | 功能测评、术式与限制、症状、运动反应、目标及环境；干预适应性、强度、进阶和停训 | 具体康复/理疗计划、训练安排、复评与家庭衔接；见下节，不以器械项目清单替代 |
| 护理与专科护理 | 观察、医嘱、皮肤/伤口、管路、出入量、活动与自理资料；护理优先级、执行和变化识别 | 护理计划、操作前核对、观察记录和升级交接；不把护士角色自动改成独立处方者 |
| 临床营养 | 摄入、营养评估、体格/检验、疾病状态与给养途径；需求、耐受、限制及监测 | 个体化营养方案、核算、实施与复评；不能仅按一个体重公式决定全部方案 |
| 检验、影像、病理与功能检查 | 标本/检查条件、原始数据或正式报告、质量控制及临床问题；结果可靠性和解释边界 | 检查选择/复核、专业意见或危急结果交接；未提供原图不考阅片发现，不能凭转写伪造形态学 |
| 口腔、眼、耳鼻喉与皮肤 | 专科病史、检查或图像、既往处理；局部与全身因素及功能后果 | 专科处置、转诊、围操作/随访建议；保持所需原图和检查可见 |
| 体检、筛查与预防 | 纵向体检、风险因素、检测方法和参考区间；筛查与确诊区别、阳性后处理及随访优先级 | 有依据的异常解释、进一步评估与预防计划；不逐项恐吓、不把所有异常都升级急诊 |
| 出院、转诊与居家照护 | 入院前/院内/拟出院方案、待报结果、家庭条件及接收机构能力 | 一致的出院摘要、有效药单、患者指引、随访与交接；形成信息到下一责任人的传递 |
| 病案质控与医疗运营 | 已授权的记录、定义明确的指标、时间与流程；数据质量、可归因问题及资源约束 | 缺陷核查、流程改进、容量/质量分析及效果评价；不能把缺记录直接认定实际没执行 |
| 临床研究与循证工作 | 研究问题、方案、论文或获准数据；设计偏倚、效应、适用性与不确定性 | 证据评述、方案审阅或分析成果；不将关联写成因果、不虚构伦理批准或数据收集 |

## 康复理疗的具体设计

区分康复医学评估、物理治疗、作业治疗、言语/吞咽训练、运动处方、辅具适配、物理因子治疗和家庭练习；“理疗”不能一概替代这些岗位工作。中医或整合医疗任务仅在材料、岗位和本次范围支持时采用，同样核验方法的证据、适用条件和风险，不把传统使用等同已证实效果。

1. **功能与目标**：由损伤/疾病、身体功能、活动、参与和环境资料明确实际问题；结合患者目标确定可观察成果，不能只以疼痛分数或影像好转代表全部康复效果。
2. **起点与限制**：核对病程、手术与负重限制、当前耐受、重要合并情况和专业检查。红旗信息是否需要先评估或转交，由本题依据决定；资料不足不能擅自填“无禁忌”。
3. **干预选择**：针对功能目标选择措施，比较获益、风险、资源和可执行性。运动方案按需要给出方式、强度依据、频次、持续时间、组次/负荷及监督要求；物理因子治疗按具体设备和方法核验参数、部位、适应证与禁忌，不能沿用一个万能参数表。
4. **进阶与停止**：按本题适用依据给出进阶、维持、降阶、暂停或转诊条件和复评方法。只写“循序渐进、量力而行、疼痛明显停做”不足以支持需量化管理的任务；也不为量化编造统一阈值。
5. **反馈更新**：有实际或获准模拟的训练反应时，解释变化并完成修订；不能因测评分数上升就自动加量，需判断测量可靠性和目标含义。
6. **执行与家庭衔接**：专业治疗计划与患者练习说明按用途分别写清动作、协助、器材/环境、记录及异常处理。仅给文字无法验收真实手法或操作质量时，明确评价的是方案与说明，不声称验证操作能力。

## 成果应接上真实流程

临床工作不默认走同一串行清单。根据本题选择必要环节：接诊/交接 → 风险与状态判断 → 进一步评估或立即处理 → 决策与沟通 → 执行安排 → 监测复评 → 升级、转交或持续照护。急救可并行评估处置，随访可回到前一阶段；排程和审批不能替代时效判断。

成果写清其使用人、当前能做的事、适用条件、待核事项及后续责任。医生、药师、护士、治疗师、检验/影像人员和患者说明各自承担相应工作；不让一个角色假装完成全部岗位的签发或操作。题目可以要求提交待专业审用的处方/医嘱建议，但不得假称已签署、已给药或已经产生疗效。

科普、咨询和患者建议也可纳入，但须有具体材料、真实决策和可验证成果。面向患者使用可理解语言，说明现在做什么、什么情况下改变安排；不能靠术语堆积提高难度，不能以“谨遵医嘱”替代已可回答的内容。
