## 一、任务与执行范围

- 根据本次冻结附件，以明确的医疗卫生专业岗位身份（临床各科医师、驻科药师、专科护士、康复治疗师、临床营养师、检验／影像／病理／输血技师或医师、院感专职人员、病案编码／医疗质控员、临床研究协调／监察人员等），围绕特定照护时点尚未解决的实际问题，设计单场景或关联多场景的专业工作与配套交付物。
- 任务对象可以是单个患者（门诊、体检、急诊、住院、围术期、康复、居家），也可以是科室抽查病案组、院感暴露队列或临床研究受试者样本；多样本任务中各病例只是分析对象，须逐例建立独立对应，严禁把不同患者的年龄、体重、检验或医嘱混拼为一个病例。此类队列／质控任务仅在材料确能支持跨样本口径穿透与整改落地时选用。
- 医疗服务以患者安全、临床获益与执业规范为准绳，不套用法律对抗式的单方利益最大化立场，也不把作答角色写成“精通所有专科且拥有无限处方手术权限的全能专家”。
- 若输入附带 `material-scope.json`，用整包摘要、逐份类型与 `notes` 中的冲突或识别提示定位需回正文核实的线索；摘要缺失、未归类或技术警告不自动成为临床事实或考点。完整精读全部附件正文后，再决定岗位、阶段、场景组合与配套文书；无整理文件时仍按正文完成同等盘点。

## 二、先确认材料，再确定岗位与方向

严格按以下顺序推导任务，绝不从固定诊断名、固定“用药重整三件套”或考点数倒推材料：

- **附件客观正文 → 实际就诊轨迹、医疗事件与主体关系 → 本次担责的具体岗位与机构场所 → 成立的临床／业务阶段与信息盲界 → 具体待决专业冲突 → 指向接收人下一步动作的配套成果。**

| 要素 | 选择与核定要求 |
| --- | --- |
| 材料 | 精读正文，核清主诉、查体、原始检验／检查报告、医嘱与护理执行记录、自备药、手术／会诊／随访或体检流水；文件名仅辅助定位 |
| 作答岗位 | 明确单一主责岗位及所在机构层级（社区／基层卫生院、综合医院门急诊／普通病房／ICU、专科康复机构、体检中心、质控部门等） |
| 服务与接收关系 | 分清谁在何时启动评估、成果交给谁直接用于下一步临床或管理动作（主诊组审签、当班护士执行、跨科会诊、基层接诊、质控整改或患者／家属居家照护） |
| 临床／业务阶段 | 初诊筛查、纵向体检复评、急诊首接、入院收治、查房调整、术前评估、术后管理、会诊裁决、转科／出院转换、康复随访或事后质控复盘 |
| 配套成果 | 必须属于该岗位在当前阶段有权制作或提交审签的真实医疗／管理载体，严禁跨权限签发或生造无用途文件 |

- 同一患者在不同就诊阶段具有不同临床状态（如术前评估对象 → 术后监护患者 → 康复期随访对象）；选定某一决策节点后，其当前生理参数、有效医嘱与待决风险必须与该时点严格对应，不得把不同住院日或不同年份的状态混为同一时点的当前状态。

## 四、一个材料包如何支持多种场景与跨期新方向

区分三种设计情形，彻底破除“拿到病历只能按最后一份出院小结出题”的惯性：

1. **单题选题候选（多切口比较）**：同一份纵向医疗材料往往支持多个不同岗位与时间切口。例如一份含“门诊初诊→入院检查→术前讨论→手术记录→术后发热与药敏→出院小结”的材料包，既可切在**术前节点**做手术指征时机与围术期抗栓停启排程（此时手术及术后记录不进入已知输入），也可切在**术后节点**由住院总或会诊医师做发热鉴别、标本去伪与抗菌抗栓协同修订，也可切在**临床药师／营养师／康复师岗位**做专项量化方案，或切在**质控办视角**做全住院周期病案首页编码与围术期抗菌药规范性核查。作者先在内部比较各候选方向的证据密度、计算深度与判别力，再择优确定本题切口。
2. **单题关联多场景组合**：一次出题可选单场景，也可选服务同一照护链条的多个关联场景（如“急诊首接生命支持与抗凝逆转评估 ＋ 稳定后转入专科病房交接”“术前多药停启排程 ＋ 术后肾功波动与引流变化后的重启修订”）。组合场景须明确区分：
   - **连续推进**：交代前后时点、已知信息增量与状态承接；
   - **条件触发**：如待培养／病理／复查电解质达特定阈值后方可启用的序贯方案；
   - **互斥备选**：如“急诊内镜／手术路径 vs 保守药物路径”或患方不同意有创操作时的次优安全方案，要求比较并分别明确启用边界，严禁要求同时执行互斥医嘱。
   同一份核算表或交接单确能覆盖关联场景时不重复拆成冗余文件，不按场景个数机械翻倍文书。
3. **显式跨期复用新方向**：当系统显式跨期复用同一材料包并指定新 `authoring_direction` 时，新题必须实质改变**责任岗位、决策时点、核心临床冲突或成果下游用途**（例如原期为“出院多药重整与居家指导”，新期改为“术后第 3 天急性肾损伤合并感染的液体营养热氮平衡与抗菌降阶会诊”或“病案质控与围术期预防用药合规复盘”）；仅换标题、换患者称呼或增减一份附表不算新方向。严禁偷读原期题面、标答或评分。

## 五、材料、岗位、场景与成果的六条匹配底线

每道题必须同时满足以下六项硬约束：

1. **临床与业务关系相符**：健康体检报告不得硬改成急诊抢救；稳定期慢病随访不得凭空捏造休克危象；单患者门诊病历不得硬套多病例率值分母统计。
2. **岗位职责与执业权限一致**：主治／值班医师、会诊医师、驻科药师、专科护士、康复治疗师、营养师、检验／病理人员与质控员各守其责。药师、护士、营养师或康复师发现超本岗权限的处方或手术问题时，应出具**供主诊医师审签的调整建议稿、配伍核查单或升级会诊触发单**，绝不伪造已独立签发医师处方、已完成有创操作或已代患方签署知情同意书。
3. **诊疗阶段与条件成立**：所选场景依赖的检查回报、手术实施、会诊发起或出院安排必须源于可见附件或合规明示披露的模拟前提，不为凑某种文书虚构既成医疗事实。
4. **逐节点信息盲界严密**：同一材料包中较晚时点才出现的培养药敏、术后病理、复查影像或最终转归，绝对禁止泄漏给较早决策节点当作已知前提；若设计为事后病案质控／不良事件复盘，必须严格分开评价“当时可得信息下原处置的合规性”与“结合后续全貌的系统改进建议”。
5. **场所资源与接收人能力匹配**：基层社区医院、院前救护车、三甲医院 ICU 与患者居家自管在药品目录、检验可及性、监护设备与操作能力上截然不同；交付给专业医护的文书与交付给高龄患者／家属的通俗指引必须符合各自接收能力，同时保持核心药名、单次量、频次与停药就医红线 100% 一致。
6. **成果实质可完成**：材料支持的部分直接形成完整可用正文与公式底稿；局部缺证处写出明确条件分支与待报前安全过渡方案，严禁交空壳模板或用“待完善检查后再议”逃避当前可完成的临床判断。

## 六、专科分流与康复理疗量化准则

### 为什么不同专科的工作链不可互换

### 康复医学与物理治疗／理疗量化设计规则

严格区分康复医学评定、物理治疗（PT）、作业治疗（OT）、言语吞咽治疗（ST）、运动处方、矫形辅具适配、物理因子治疗与居家训练指导；**严禁用笼统的“理疗”或器械项目名称替代上述分岗位专业判断**：

1. **功能诊断与参与目标对齐**：依据损伤机制、手术方式、ICF 身体结构功能、日常活动参与及居家／工作环境设定可测量的阶段功能目标，不得仅以 VAS 疼痛评分下降或影像描述代替功能结局。
2. **安全起点与外科／内科限制穿透**：逐项核清骨折内固定／韧带重建术后允许的关节活动度（ROM）区间与分阶段负重百分比、心肺运动禁忌、β 受体阻滞剂或起搏器对心率反应的钝化影响、抗凝出血风险、骨质疏松、深静脉血栓及皮肤感觉障碍；材料未载明处严禁擅自填“无禁忌”。
3. **运动与物理因子参数精确量化**：运动处方须按 FITT-VP 明确方式、强度计算口径（如考虑药物修正后的储备心率 HRR 靶区间、RPE、1RM 百分比或允许疼痛耐受阈值）、频次、单次时长、组次间歇、周总容量计算及监护等级；物理因子治疗必须核明具体物理因子类别、设备输出模式、频率／波长／强度档位、作用部位、单次时长疗程，并逐项排查心脏起搏器、局部金属植入物、恶性肿瘤、活动性出血／感染、骨骺端、孕期腹部腰骶及感觉缺失等绝对与相对禁忌证，严禁套用万能参数表。
4. **量化进阶、降阶与即时停训红旗**：给出客观可测的进阶达标线、训练负荷下调条件（如次日关节肿胀／静息痛反弹超阈值）及训练中立即终止并呼叫临床医师的红旗指标（如收缩压异常骤降／飙升、SpO2 跌破安全线、新发胸痛晕厥或神经根症状加重），严禁只写“循序渐进、量力而行、不适即停”。
5. **阶段反应重评与居家衔接**：当材料包含阶段训练反馈时，须区分真实功能提升、代偿动作假象与测量误差，实际重算调整下一阶段负荷表；医护／治疗师执行单与患者居家图文／文字动作说明分别成稿，明确文字评测验收的是方案与指导质量，不假称已目视验证现场手法操作。

## 七、配套交付、实质差异与设计核对顺序

- **配套交付原则**：按本次委托中接收人的独立使用动作确定必要文件，不设固定文书份数下限，也不靠拆碎无内容小文件凑数。同一用途在不同动态节点产生修订时，保留基线可回查性与当前最终有效完整定稿，绝不让接手医护或患者自行拼凑修改片段。
- **形成实质跨题差异**：题目的辨识度必须落在**“临床核心冲突 × 岗位权限 × 决策时点 × 定量／消歧机制 × 接收人实际动作”**上。若输入含 `batch-context.json`（同期白名单设计摘要），须主动错开已高频使用的临床任务结构与交付套路，拒绝仅换患者姓名或病种的同构复刻。
- **作者内部五步核对顺序**（仅供内部把关，不写入题面或新增字段）：
  1. 精读全部附件，核清患者／样本主体、时间轴、事实层级与可见边界（有图核图，无图不盲考图形）；
  2. 查阅[医疗垂类评测（材料-场景-交付物）参考](../assets/医疗垂类评测（材料-场景-交付物）参考.md)相关方向，按[任务盘点](出题设计方法.md#任务盘点与范围确定)查全同一岗位与时点下材料支持的全部可办工作，确定单场景或关联多场景组合；
  3. 对每项选入工作核定材料依据、权威指南／说明书原文、定量计算模型、实体文件载体与核验标准；
  4. 先用集中脚本实算并完成全部 `reference_answer`，再按[评分规范](评分与难度验证.md#考点)编制复合 0/1 `rubric` 与单处案件化整体失效条件，最后拟定 `question`、`answer_approach`、`task_name` 与 `task_type`；
  5. 自检能否清晰回答：材料为何支持该岗位与此时点？删掉任一中间底账是否真会影响下游临床方案？医护版、工作簿与患方版口径是否完全一致？本题与其他医疗题的实质专业区别在哪里？
