# 医疗实务出题

从全部冻结附件中选择尚未解决、直接影响患者安全照护或医疗管理落地的具体岗位任务，依据材料自身形态展开纵向跨源去伪消歧、权威指南与药品说明书原文裁决、贴合专科的个体化多表定量核算、正式医疗文书定稿或确有状态依赖的跨节点修订，同步拉升临床判别难度、真实有效工具步长与实体交付深度；严禁将所有病历窄化为单一“审方算肾功模板”，严禁以百科综述、隐藏关键输入、机械凑表或事后改尺替代真实医疗难度。

## 输入与阅读

- 按用户当前要求、本次任务及实际提供的适用规则确定范围；示例与历史数字不是永久配额。普通出题会话只读取本次 `input/` 下的清单、冻结附件与本 `skill/` 目录，不执行仓库 `git` 检查、不扫描仓库其他源码目录、不在出题会话内另行生成抛弃型 DOCX/XLSX/PDF/PNG 校准实物、不运行 `render_command` 生成可选 `题目.md`，也不单独落盘编写设计核对记录或完成说明文件。
- 设计前必读[场景规范](references/医疗场景与工作流程.md)、[临床决策分支](references/临床决策分支.md)、[出题设计方法](references/出题设计方法.md)、[医学依据与专业核验](references/医学依据与专业核验.md)和[评分与难度验证](references/评分与难度验证.md)，在会话内部完成整包任务盘点。完成临床求解、脚本实算与判据后，必读[交付规范](references/题目格式与交付.md)、[临床语气建议](去%20ai%20化建议.md)、[表述方法](references/表述方法.md)及[书面表达组合库](assets/书面表达组合库.txt)组织五字段成稿，按[字段模板](assets/题目模版.md)逐项对照；按需深挖定位见[资料索引](references/资料索引.md)。
- 每次选题必须查阅[医疗垂类评测（材料-场景-交付物）参考](assets/医疗垂类评测（材料-场景-交付物）参考.md)（35 项岗位与场景参考）；将相关方向的工作与成果逐项同本包材料、岗位权限、机构层级、时点盲界与接收动作核对并纳入内部盘点；适用者完整完成，排除者明确具体依据。参考表不是固定套餐或穷尽目录，表外有材料支撑的必要临床或质控工作一并纳入。
- 完整精读全部冻结附件（长文档分段读完），摘要仅作定位。多患者抽查、流调或研究样本逐例建立独立主体对应，严禁跨患者混拼年龄、体重、检验或医嘱。仅使用本次冻结附件、公开权威医学依据及明确披露且获准的模拟条件；严禁读取历史题包、答案、成绩或个人记忆作为新题输入。
- 若输入附带 `material-scope.json`，结合其定位文档关联、候选方向及 `notes` 中的矛盾线索，回正文逐字核实后自主决定切入岗位、单场景／关联多场景组合与配套交付物；缺失整理文件时仍按正文完成同等盘点。若提供 `batch-context.json`（同期白名单设计摘要），必须在选题与定稿前比对临床目标、岗位角色、定量模型类别与文书组合，避开仅换患者化名或病种的同构复刻。
- 显式跨期复用同一材料包时，依据本次冻结附件与给定 `authoring_direction` 切换至全新的岗位视角、决策阶段、核心临床冲突或下游用途；仅改标题、角色称呼或增减附表不算新方向。严禁偷读原期题面、标答或评分。
- 明确责任岗位、机构资源层级、信息截止时点、执业权限与接收人；围绕患者安全与真实职责边界设计，不塑造成无执业边界的“全能专家”，也不照搬法律对抗式的单方利益立场。

完整交付覆盖每项已选步骤：多源记录对应与采样／执行伪影剔除明细、贴合本专科的定量核算底稿、各阶段可直接使用的医疗／患方正式正文；题面对作答者按接收用途布置实体文件制作、公式重算联动与逐页版式核验义务，作者在 `reference_answer` 完整呈现正式文书全文、工作簿分表结构与活公式写法、汇总勾稽及争议异常项逐笔处理，附件无争议大批量常规监测或发药流水按来源范围、笔数与区间小计归并引用，不在文本标答逐行重抄。

PDF 单文件上限与分册要求严格按[输出形式与 PDF 分册上限](references/题目格式与交付.md#输出形式与-pdf-分册上限)执行：单份不超过 `18,000,000` 字节（`18MB`），超限按连续页均衡完整拆分并覆盖全部分册逐页渲染核验，严禁删页、截断宽表或糊化清晰度。

## 出题标准

<question_standards>

1. 完整精读附件后，核清记录生成者、采样与执行时点、检测方法单位、事实层级与未决临床或管理冲突；依[任务盘点与范围确定](references/出题设计方法.md#任务盘点与范围确定)及[一包多向机制](references/医疗场景与工作流程.md#四一个材料包如何支持多种场景与跨期新方向)查全同一岗位与时点下材料支持的相容独立工作及排除依据，不自动绑死最后一份出院小结，更**严禁作者自设“仅作科普咨询”“只给诊疗大原则”“不做定量核算”“不出具体医嘱／排程／交接单”来缩水材料支持的实质工作**（用户或原件明确限定除外）。新增工作必须贡献独立临床判断与下游使用动作，不靠换标题或拆碎空文件扩量。
2. 从接收人下一步实际动作反推待解专业结果。按[按材料展开实质临床工作](references/出题设计方法.md#按材料展开实质临床工作)展开审用修订原稿、裁决跨科与多目标冲突、穿透多源纵向记录或照护转换交接；当既有方案安全达标或有创／加药风险大于获益时，支持有依据的**主动监测观察、维持原方案或去处方阶梯精简**，防止诱导过度检查与过度治疗。
3. 以代码级高效作答者预演最短正确完整解：若仅靠摘抄既有诊断、套背通用指南原则、代入单个常规公式或单遍正则提取即可完成主体工作，必须重返本包挖掘至少两层互相咬合的底层消歧（采样溶血稀释／非稳态误采／定植菌剔除、跨院单位或盐基元素量折算、医嘱开立与执行错位、中成药／复方隐藏成分、静脉溶媒与非营养热卡隐性负荷等）及跨成果定量依赖；严禁靠隐藏关键输入、禁止批处理或人为等待凑步长。
4. 按[设项与覆盖五步法](references/评分与难度验证.md#设项与覆盖五步法)划分复合 R：每条独立 R 须含跨源数据消歧、伪影／缺口识别、特殊人群与版本规范跃迁、多病竞争约束协同或动态换路重算；常规病史与生命体征摘录一律并入所支撑的核心决策 R（零送分项），具有独立证明逻辑与不同接收用途的多项实质任务分别设 R（严禁粗捆成 ≤3 条大总包 R 碰运气）。**不可分割的同源定量链**（基线去伪消歧＋人群专属公式估算＋隐性负荷累加＋成人极量／安全速率封顶＋制剂可分取规格与滴速／D0 排程／热氮配比／风险积分／FITT-VP 容量／质控分母）决定同一执行方案可用性时，**必须合并为一条复合定量核算 R**，严禁拆成多条分段算术 R 让下游凭上游误差免责白拿算式分；鉴别、会诊、审方、康复与质控类 R 须锚定排他性临床裁决、具体错重／禁忌剔除或待回报双层安全过渡（当下过渡处置＋阳／阴性排他切换），彻底封死“完善检查、请专科会诊、密切观察、个体化调量、待结果再定”万金油套话。
5. 按本包材料客观形态选择任务结构：材料支持分批检验／药敏回报、术前术后转换、阶段训练反应、患方拒绝首选方案或跨机构转诊且存在真实状态依赖时，优先按[连续照护与跨节点修订](references/出题设计方法.md#连续照护与跨节点修订)设计动态任务（单次关键新证据连锁重算、同节点多源冲突输入并行汇入、严格生理／流程先后依赖推进，变化源随专科多元展开，不千篇一律写成“次日肌酐升高调抗生素”）；材料天然聚焦于遗留草稿纠偏、多年体检／多院处方纵向穿透、单点复杂液体营养配比或多例质控稽查时，采用单窗口深度审校定稿。**严禁构造一段话内集中暴露多处低级医疗常识错误的“稻草人草稿／戏剧化投诉信”**。
6. 先用集中计算脚本验算全部公式与临界容差，并联网实际打开权威指南与 NMPA 说明书原文完成全部 `reference_answer`，再编写自足 `rubric`，最后双向反查每项独立工作均已在题面明确布置成果与核验要求。只出现在 rubric 或标答中的未交办义务不得扣分。

### 题面与成果

- 首句直接从本例真实临床或业务触发点切入，严禁默认拿患者姓名／代号或“你是某医院XX科主任医师”作首词，严禁在首段堆砌“角色设定＋基准日＋‘该接诊关系为本题设定’＋四连禁令”公式；模拟时点与假定前提用自然临床措辞明确标示模拟／假定身份，不越权签发处方、不代患方签字等执业边界随具体医嘱建议或患方沟通段落就近交代。引用卷宗统一自然写“附件”“所附病历”或具体医疗文书名称，**严禁在任何字段出现 `附件1`、`附件 1` 或页码**；严禁单拎错误医嘱反问，严禁在题面喂给生理计算公式、量表权重、指南分期阈值或常规停药洗脱天数。
- 严格执行[双向图文可见边界](references/临床决策分支.md#双向界定图文可见输入与输出端工具要求)与急危重症时序原则：有临床原图传入时交叉核对图文；仅有文字报告而无原始影像／波形／切片图传入时严禁盲考图形形态，但**100% 保留输出端多源消歧、权威原文检索、全公式 XLSX 联动、正式 DOCX 与全套分页 PDF 逐页转图校改要求**；急危重症在临床处置序列上坚持床旁生命支持与首剂处置优先，在评测交付层完整交出急救执行单、配制速算表与转运交接定稿。
- 需要审签、配比重算、排程更新、院际交接或患者居家执行的成果，必须按[作答端检索、依据与实体交付核验](references/题目格式与交付.md#作答端检索依据与实体交付核验)点名本例具体文书与工作簿名称，将权威医学原文联网核验与四项硬性文件动作拆散嵌入对应成果段落（严禁照抄内部缩略词串、严禁开头写“请先详细规划”、严禁末尾单挂统包技术尾段、严禁单交《文件交付回执》）：①交付可编辑正式医疗文书（DOCX）及贴合本例材料形态（见[八类医疗定量模型](references/出题设计方法.md#材料到成果的工作链与临床交接)）的全公式驱动多分表工作簿（XLSX），实际执行重算并读回；②完成工作簿动态联动验证（跨节点题承接新增回报触发重算更新并读回；单窗口静态题围绕本例真实估算口径分歧、生理临界波动、手术改期或备选路径设置临床敏感性／情景对比试算栏验证公式自动联动并读回，与正式执行主表区分，禁用“在与病例事实隔离的核验副本中改变一项关键输入”套话）；③将主评估／会诊／审方／质控报告全文、全部正式执行／排程／交接／患者指导文书及经横向或列宽适配的多栏核算宽表悉数导出为分页 PDF（单文件 ≤18MB）；④将导出的全部 PDF 逐页转为页面图像排查宽表横向劈裂、审签／警示框孤行跨页、剂量单位截断及跨文书药名／剂量／频次／红线出入，发现问题回改源 DOCX/XLSX 后重新导出核准。
- 作答运行环境暂缺某项文件或渲染工具时，仅由作者在会话回复收尾简述缺口（严禁写入五字段业务正文），绝不删减题目业务与文件要求。
- `reference_answer` 首屏按四类临床主成果体例分散切入（正式执行／会诊／排程／交接文书前置、无信头直入核心临床裁决、院内审方／MDT／质控签报纪要式、或核心定量重整／液体营养／纵向分层总表先行），**严禁整批套用“［XX评估意见（书）］＋致／接收科室：XX＋评估基准日：XXXX年X月X日”三行公文信头**；医护专业文书、工作簿与患方通俗指引的核心数值与停用红线 100% 一致。

## 评分标准

<scoring_standards>

- 每条 R 评价一个复合专业结果，依据核心结论、决定性依据与成果可用性作 `0` 或 `1` 二元等权判定，百分制按成立项占比换算；`max_score` 仅按当前 schema 填写，不在判据正文写“得1分／得0分”或“全部满足得分”。

<whole_answer_validity required="every_question">
按[评分规范](references/评分与难度验证.md#每题必备的整体失效条件)，从岗位职责与患者身份对应、决定性临床事实与检验真实性、核心定量核算与关键依据可追溯性、当前有效成果跨文书一致性、绝对禁忌／急症致命延误／核心病理生理推导五个方向排查本例风险；将经本例证据充分证实的整体失效行为融入最直接相关的那一条 criterion 中（全题只出现一次，不固定塞在末条末尾，不用“一票否决”固定标题，不额外增加分母）：写明具体最终致命行为、核验依据、对核心医疗用途或患者安全的实质破坏，并以贴合本例临床后果的自然行文写明全题计零分后果（禁止逐字复读同一固定句尾）。普通局部漏项、合理舍入容差、有权威依据的合法替代方案、注明前提的条件分支及已在最终有效稿修正的初稿瑕疵严禁推定触发；XML 仅用于作者指令，绝不进入五字段正文。
</whole_answer_validity>

- 独立评分者不读取本 Skill、作答思路或默认标答。每条 `criterion` 必须自足写清临床结果、附件决定性记录与数值（统一称“附件”或具体文书名，禁写 `附件1` 与页码）、权威指南／NMPA 说明书全称年份与核心要旨、计算口径与合理容差、合法替代方案及排他失败边界；**严禁出现 `本条评价……` 及 `评分端`、`轨迹未传`、`评测条件不满足`、`不作为有效专业难度成绩`、`纳入有效成绩均值` 等内部评测产线术语**。
- 严格执行[共享前提与重复处罚四原则](references/评分与难度验证.md#共享前提与重复处罚四原则)与[内容、文件和执行的归属](references/评分与难度验证.md#内容文件和执行的归属)：同一判断跨文书一致落实合为一条验收，不重复计分；若上游错判导致跨越临床分期或禁忌红线绝不笼统免责；在单条复合载体／交接 R 中点名本例具体文书与工作簿集中核验活公式重算联动及全套分页 PDF 逐页版式与跨件一致性，明确仅列文件名、口头自述、填静态常数或仅交未执行脚本均不成立，不在每条内容 R 重复粘贴共用文件门槛。
- 冻结前完成[八类样本加压检查](references/评分与难度验证.md#冻结前八类样本加压检查表作者内部静态校验严禁发给作答者)，确保完整正确解与简洁合法替代解满分通过，漏关键消歧／禁忌／换算解、万金油套话解与跨文书矛盾解精准失分。

</scoring_standards>

## 交付

提交前对照会话内部任务盘点逐项复核：35 项垂类参考相关方向已查全、无自设缩水、每项工作与各阶段材料三端闭合、权威医学原文已打开核实、集中计算脚本已实算验准、PDF 18MB 分册规则与双向图文边界已遵守、五字段去同构且零生产残留。确认合法后写入 `result.json` 即结束会话。

作者静态自检仅证明题包设计自洽；真实压分与步长耗时表现按[执行复杂度与实测证据](references/评分与难度验证.md#执行复杂度与实测证据)由独立模型作答与冻结盲评验证（内部严控口径 `有效独立评分 ≤ 50 分、可核实执行轮次 ≥ 50 轮、单题有效耗时 > 40 分钟` 与外部平台口径分别记录，严禁写入题包），临床适用性另须具备资质的医疗专家校准；未取得对应实测与校准证据前，严禁宣称“已达标”或“已通过医学验收”。
