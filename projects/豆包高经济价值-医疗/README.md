# 豆包高经济价值-医疗

本目录面向医疗出题人员、专业审阅人员和 ai-distill 维护者，是医疗高经济价值主项目的共享工作区。它与法律项目隔离，共用系统的全局材料库、出题、作答、评分和达标判定流程。医疗 Skill 参考法律 Skill 的材料驱动、真实成果和复合评分方法独立编写，不运行时依赖法律 Skill，也不继承其单方代理立场、材料数量约束或专业成果格式。按 2026-11-10 用户要求，归档与飞书交付链路与法律项目同构，但期次目标按主项目分别冻结；医疗专业验收仍按本项目边界和当期项目方规则执行。

## 医疗出题方法

以真实岗位在特定时点要完成的工作为入口：材料和患者状态 → 专业判断及依据 → 当前可使用成果 → 必要的监测、复评或交接。覆盖门诊、内外科、围术期、急诊/院前急救、重症、药学、慢病、妇儿、老年、康复理疗、护理、营养、检查、出院和相关业务任务；具体题目只取材料支持的范围。

2026-11-10 强化为按条件选路：岗位、场所和信息时点 → 当前主问题与紧迫性 → 证据支持的路径 → 干预/观察/转交选择 → 实际成果 → 必要复评与换路。专科差异在场景文件按触发材料、关键决定和交付说明；内科、外科、急诊、药学及康复不共用固定诊疗清单。增加工作量须产生新的专业判断或实际修订，不以科室数、步骤数或文书数制造难度。

完整增强项、价值、适用时机及静态核查范围见[本次强化说明](执行观察/medical-skill-strengthening-20261110/强化说明.md)。只修改本地 Skill 与维护说明；未进行真实出题、作答或医学专家验收。`server/rule-files.ts` 扫描有效 Skill 全目录，`server/authoring/executor.ts` 将其中资源写入作者输入并提供入口。使用该共享路径的新派发会读取当前文件；期次覆盖路径和已冻结任务不能据此认定已采用。书面组合库经 Skill/交付参考导航读取，不修改后端 schema 或评分程序。

与法律方法的主要差异是患者目标、风险时效、专业权限、临床不确定性和方案可执行性。评分接受有依据的合理替代，按独立专业结果等权 0/1 验收；逐题检查整体失效风险，但只有具体证据能证明核心用途整体失效时才设置归零条件。具体医学判据须进入 rubric，不能让独立评分依赖本 Skill 或隐藏标答。

当期外部规则、岗位分类及达标阈值从本次明确适用的输入读取；法律项目旧期次指标不自动写入医疗运行配置。模型调用、队列派发、患者材料上传和飞书投稿均不是加载此 Skill 的副作用。

## 数据与专业边界

- 题目不回显姓名、身份证号、电话、病案号、二维码或可反向识别个人的组合信息。
- 医疗任务必须有明确的专业角色、业务目的、基准日和可核验交付物；不把一般健康建议包装为诊疗结论。
- 诊断、鉴别诊断、用药、剂量、禁忌、转诊和紧急处置等高风险结论，必须由有资质的医疗专家按当期适用依据校准；附件不足时必须保留缺口，不猜测补齐。
- 作答、评分和投稿是不同状态。模型得分、执行步数或耗时达标，不代表医学内容已经专家验收。
