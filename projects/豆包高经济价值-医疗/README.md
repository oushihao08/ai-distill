# 豆包高经济价值-医疗

本目录面向医疗专业人员和 ai-distill 维护者，是医疗高经济价主项目的共享工作区。它与法律项目隔离，共用系统的全局材料库、出题、作答、评分和达标判定流程，不继承法律项目的 Skill、材料数量约束或交付脚本。

## 当前入口

| 路径 | 用途 | 维护边界 |
| --- | --- | --- |
| `skill/SKILL.md` | 医疗高经济价出题入口 | 只约束新出题任务，不改写冻结题包 |
| `skill/references/医疗任务设计与安全边界.md` | 材料准入、专业任务与安全评分边界 | 出题前必读；不代替当期平台规则和医疗专家审定 |
| `第一期/questions/题目1…题目6/` | 用户提供的六个候选材料包的本地来源分组 | 包含健康与身份信息，由`.gitignore`排除；不代表已入全局材料库或已脱敏 |

当前不创建`materials/`业务输入目录：项目规则材料与患者业务材料必须分开。患者病历、检验单、处方、影像及体检报告只在`questions/`本地候选来源中分组，不进入 Git。它们应在获得处理授权、明确正式投稿的 AI 使用规则并完成去标识化后，通过全局材料库原子入库，再由具体期次显式加载。

## 数据与专业边界

- 题目不回显姓名、身份证号、电话、病案号、二维码或可反向识别个人的组合信息。
- 医疗任务必须有明确的专业角色、业务目的、基准日和可核验交付物；不把一般健康建议包装为诊疗结论。
- 诊断、鉴别诊断、用药、剂量、禁忌、转诊和紧急处置等高风险结论，必须由有资质的医疗专家按当期适用依据校准；附件不足时必须保留缺口，不猜测补齐。
- 作答、评分和投稿是不同状态。模型得分、执行步数或耗时达标，不代表医学内容已经专家验收。

## 当前就绪状态

仓库已具备项目工作区和出题 Skill。正式业务运行仍取决于下列外部或运行态条件：

1. 项目方确认当期规则是否允许 AI 辅助出题、脱敏和生成考点。
2. 患者材料的处理授权和去标识化验收已完成。
3. 当期的医疗专家、适用指南版本、评分口径、答题模型和达标阈值已明确。

未满足时可做内部候选题设计，但不得表述为已可正式投稿或已通过医学验收。
