## 医疗出题方法

以真实岗位在特定时点要完成的工作为入口：材料和患者状态 → 专业判断及依据 → 当前可使用成果 → 必要的监测、复评或交接。覆盖门诊、内外科、围术期、急诊/院前急救、重症、药学、慢病、妇儿、老年、康复理疗、护理、营养、检查、出院和相关业务任务；具体题目只取材料支持的范围。

与法律方法的主要差异是患者目标、风险时效、专业权限、临床不确定性和方案可执行性。评分接受有依据的合理替代，按独立专业结果等权 0/1 验收；逐题检查整体失效风险，但只有具体证据能证明核心用途整体失效时才设置归零条件。具体医学判据须进入 rubric，不能让独立评分依赖本 Skill 或隐藏标答。

当期外部规则、岗位分类及达标阈值从本次明确适用的输入读取；法律项目旧期次指标不自动写入医疗运行配置。模型调用、队列派发、患者材料上传和飞书投稿均不是加载此 Skill 的副作用。

## 数据与专业边界

- 题目不回显姓名、身份证号、电话、病案号、二维码或可反向识别个人的组合信息。
- 医疗任务必须有明确的专业角色、业务目的、基准日和可核验交付物；不把一般健康建议包装为诊疗结论。
- 诊断、鉴别诊断、用药、剂量、禁忌、转诊和紧急处置等高风险结论，必须由有资质的医疗专家按当期适用依据校准；附件不足时必须保留缺口，不猜测补齐。
- 作答、评分和投稿是不同状态。模型得分、执行步数或耗时达标，不代表医学内容已经专家验收。
