# 豆包高经济价值-医疗

本目录面向医疗出题人员、专业审阅人员和 ai-distill 维护者，是医疗高经济价值主项目的共享工作区。它与法律项目隔离，共用系统的全局材料库、出题、作答、评分和达标判定流程。医疗 Skill 完整对齐并内化 `豆包高经济价值` 法律 Skill 经实测验证的一包多向挖掘、底层证据穿透、不可分割耦合评分防放水、长步长多表公式联动与逐页渲染校改、以及五字段去同构体系，同时立足真实医疗岗位职责、患者生命时效底线、八类跨专科定量建模与医患沟通规范原生构建，不运行时依赖法律 Skill，也不套用单方对抗立场或诉讼文书壳子。按 2026-11-10 用户要求，归档与飞书交付链路与法律项目同构，期次目标按主项目分别冻结；医疗专业验收按本项目边界和当期项目方规则执行。

## 医疗出题方法演进

以具体岗位在特定时点必须解决的真实临床或管理冲突为起点：客观记录去伪消歧 → 多部权威原文版本核实 → 八类专科定量与多表活公式建模 → 竞争目标协同与合理观察／干预裁决 → 多接收人实体文书与全套分页 PDF 逐页渲染校改闭环。

- **2026-11-14 深度对齐与临床去偏重构（版本 `2026.11.14.1`）**：
  1. **还原全口径真实医疗场景与一包多向机制**：重构 `医疗场景与工作流程.md` 并将垂类参考矩阵扩充至 **35 项**，补齐纵向健康体检与早筛分层、精神心理与器质性谵妄鉴别、临床输血相容性与不良反应、检验／影像／病理质量复核与危急沟通、中西医结合隐藏成分与有毒饮片核查，恢复“合理观察／维持原方案／去处方精简（防诱导过度医疗）”原则，确立“一包多切口／关联多场景组合／跨期异向”与六条匹配底线，彻底破除把所有医疗材料硬套成“药师审方算肾功”的窄化偏置；补齐有图核图、无图不盲考图形但保留输出端全套文件义务的双向边界；
  2. **做实增加豆包有效时长与步数的原生定量链**：在 `出题设计方法.md` 建立 **8 类医疗原生底层穿透与多表全公式 XLSX 模型**（覆盖纵向体检趋势积分、复方与 TDM 药代封顶、24h 显隐性液体酸碱与营养热氮、围术期 D0 多药停启排程、肿瘤 BSA/AUC 与累计毒性、康复药物修正 FITT-VP 容量、妇儿校正年龄生长 Z-score／小时胆红素、院感时空流调与 DRG／研究分母穿透），拓展跨节点动态照护的多元真实变化源，并在 `SKILL.md` 与 `题目格式与交付.md` 补齐遗漏的 **PDF 单文件 ≤18,000,000 字节（18MB）连续页拆分与全分册逐页转图目检返修规则**；
  3. **封死豆包骗分逃逸口，对齐复合 0/1 严密判据**：全面补强 `评分与难度验证.md`，补齐设项五步法与二分独立性试判、同源耦合定量链合并、待回报双层安全过渡防套话锚点、共享前提与上游误差传递四原则（明确跨越临床分期或禁忌红线时禁止笼统免责）、跨节点连续照护专节验收、非药学＋药学双示例、八类对抗样本加压检查表、逐 R 评分输出规范，以及内部严控三指标（`≤50分 + ≥50轮 + >40分钟`）与外部平台口径分离记录规则；
  4. **模块去重解耦与五字段真多样性**：新增医疗原生 `去 ai 化建议.md` 与 `references/资料索引.md`，收敛去重 `表述方法.md`，扩充 `书面表达组合库.txt` 跨专科搭配组件，消除跨文件重复粘贴并打断“内部四步流程照搬成同序四段题面／标答”的批量同构。

## 数据与专业边界

- 题目任何字段不回显真实患者姓名、身份证号、电话、病案号、二维码或可反向识别个人的组合信息。
- 医疗任务必须具备明确的专业岗位、机构场所、基准时点、执业权限边界和可核验实体交付物；不把泛泛健康宣教包装为临床决策结论。
- 诊断、鉴别诊断、用药、剂量、手术指征、禁忌、转诊和急症处置等高风险结论，正式投产前须经有资质的医疗专家按当期适用规范校准；附件不足时如实保留条件分支，不猜测补齐。
