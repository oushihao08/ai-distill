# Work法律全场景项目情况与相似度分析

整理日期：2026-10-13

## 项目情况

Work 法律全场景是法律专业工作任务评测项目，目标覆盖诉讼、非诉、企业法务合规、法院、检察及法规政策研究六类角色、51 个三级场景，采用 L2–L5 长程等级并排除 L1。题包需有真实脱敏源文件、专家标准答案及真实检索轨迹、Rubric、metadata，并转换为 Harbor 运行格式。难度依赖三个被测模型的平均分、Oracle 参考答案质量及人工质检。

本地当前仅建立了规则资料根、规则记事本和重点速查。未收到新案件源文件、认领场景或专家答案，尚未建立题目/期次目录、skill 或 Harbor 题包，也没有运行模型。项目规则页引用的场景分类资料因跨组织权限没有读取，故本报告只比较已读到的项目边界与本地现有资料。

## 相似风险判断

**领域层面相似度高，具体题目是否重复需逐题检查。** 两个项目都评价真实法律工作，都依赖案件/交易材料、专业判断、计算、谈判或执行方案以及可用的法律交付物。当前可读的第五期成果与 Work 项目总体场景之间，尤其在公司法务、债务处理、诉讼/执行和解、款项核算及交易处置方面存在直接的题材邻接。

这种领域邻接本身不能证明题目重复；但 Work 规则明确禁止迁移任何过往已提交数据。因此，新项目必须另用新来源、新事实组合、新业务决策和新答案/检索轨迹。对已提交题目不得只换当事人、金额、行业、格式、文书名称或 Rubric 表述后再交。可保留的只是抽象层面的工作方法，不能把既有题目中的具体任务、案件事实、附件、提示词、标准答案、计算或评分项搬入新包。

本次没有给相似度百分数，因为没有项目方查重算法，也无法访问全量已提交题库。Work 项目最终重复认定由项目方决定；本报告只能识别本地已知的风险邻域，不能替代平台查重或保证结算资格。
