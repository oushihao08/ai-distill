# Work 出题评分设计验收标准

## 适用边界

本标准依据用户本轮确认，仅验收实际生成Rubric的三项设计：考点独立、计分不重复、维度归类正确。依据为当前`skill/出题与评分规则.md`第四节；是本地修订与四题测试口径，不是平台正式验收或模型作答得分。

材料真实与否、专家手续、日期和付款事实的既有争议、等级认证、上传包装不参与本次评分设计审查；争议可以另记，不据此扩大本次修订。难度要求及已设角色、场景、方向、模型、推理强度、时限、阈值保持。不得通过删核心考点、降低法律工作量或改评分宽严换取合规。

## 三项判定

### 出题问题、模型表现与技术故障的区分

**已经提供必要材料，题面任务明确且Rubric有材料或合法规范依据时，模型未读出、漏答、答错或未完成要求，属于本次模型表现，不能仅凭作答失败反推题目、材料或Skill不合格。** 模型失分可以体现真实难度，不据此降低题目要求或补写答案提示。

| 场景 | 归属与处理 | 必须核对的证据 |
| --- | --- | --- |
| 材料实际已提供，模型遗漏或误读其中信息、推理错误、计算错误、未覆盖任务要求 | 模型表现问题；按本题有效Rubric评价，不计为出题设计缺陷 | 作答当次实际输入中的材料及位置、题面要求、对应Rubric、答案原文或缺失内容 |
| 材料在来源目录或数据库中存在，但未实际发送给作答模型、被截断或绑定了错误版本 | 输入传递／执行问题；不能归责模型未读取，也不能直接判材料源有问题 | 本次作答冻结输入、实际请求、附件完整性和版本绑定；仅看本地材料存在不足以证明模型收到 |
| 模型已返回完整答案，但某项结果不正确或未完成 | 有效作答中的失分；不等于模型调用失败，不反推出题失败 | 完整答案、实际执行方式及逐项判据；正确性仍以材料和适用规则为依据 |
| 超时、接口报错、鉴权失败、旧worker拒绝新快照、版本校验失败、未取得完整答案 | 技术故障；记录失败原因，不虚构有效零分，不用它证明题目难度或模型得分达标 | attempt状态、错误原因、调用及结果记录 |
| 正确完成任务所必需的信息确实未提供，且不能通过题面允许的条件性分析、缺口识别或补证方案完成 | 才可能构成题目输入缺陷；须指出具体缺失及其如何使任务无法完成 | 必要结果、缺失信息、全部获准材料及合法替代是否成立；不能仅因模型说“材料不足”就认定 |
| Rubric要求无材料／规范依据的唯一结论，或拒绝有依据的等效合法答案 | 评分设计问题；不能将评分标准错误包装成模型能力不足 | 原判据、材料或规范依据、被排除的合法答案及具体冲突 |

审查必须区分“没有回答”“回答错误”“调用未成功”。不把每次模型失分变成出题返修，也不因材料真实或完整就预设Rubric必然正确。对题目设计的否定须有独立证据；模型得分和达标仍依有效的真实评分结果判断。本节不改变现有模型、权重或阈值。

| 编号 | 合格条件 | 认定问题所需证据 | 不构成问题的情况 |
| --- | --- | --- | --- |
| A 独立性 | 一条评价一个独立业务结果 | 给出同一合法回答能答对其中一项、答错另一项的具体组合，并说明两项各有独立业务意义 | 同一计算的基数/公式/结果，或同一法定动作成立所必需的要素，可共同判断；不能因条目长、含多个法条或有且/或就认定捆绑 |
| B 去重 | 同一业务要点只承担一次主计分 | 列出相关ID及共同评分对象，说明同一回答为何重复加分或漏正分后再反扣 | 事实识别、法律适用、行动安排可独立评价不同结果；共同引用同一证据不等于重复。独立否决不计分，不因与安全负项共同触发就判重复 |
| C 归类 | 按statement真正判断的结果归一个主维度，内容质量归一个主Q | 引用实际判据，指出其评价的对象与当前维度为何不符，并给出正确归属 | 不能仅凭案件涉及法律就归Q3；有辅助知识不等于多归主维度；不同合法分类存在合理解释时标待核，不能凭个人偏好认定违规 |

### 归类速查

- 维度1：交付齐备、明示硬约束、角色立场、基准时间的遵守；专业事实和法律结论归维度2。
- Q1：事实、证据及证明范围；Q2：风险识别、等级与依据；Q3：法源真实性、引用内容及时间效力；Q4：事实对应法律要件、定性和抗辩；Q5：金额、期间、比例、门槛核算；Q6：结论、执行主体、时限、材料与替代路径；Q7：内部矛盾，默认负向。
- 维度3：体例和可读性；维度4：独立的推理/规划过程；维度5：具体安全违规；维度6：接手协作；维度7：具体模板偷懒行为。不能将核心业务结论换名称后在这些维度再奖励一次。

## 检查与统计

### 判定边界：防止过严审查

- 独立性须同时说明可一对一错及各自独立的业务意义。条目较长、含多个法条、证据或条件，不足以认定捆绑。同一法定动作的必要要素、同一次计算的基数/公式/结果可整体判断；统一检查法源引用字段完整性，不直接等于捆绑多个法律结论。
- 重复计分须指出具体重叠部分及触发方式。共享材料、同一主题或存在正负项对应不自动构成重复。正项遗漏不触发实际错误负项；如二者仍评价同一核心结果，须划清边界，不能仅凭负向措辞认定已经独立。
- 同组重复可能涉及多个条目，须同时列出关联ID和一组根因；不得将两条关联记录当成两组独立重复问题。修订时保留一个主计分位置，不要求两条一起删除。
- 归类按实际命中条件判断。维度4可评价工作顺序、跨文件核验和版本核验的方法；Q5评价计算结果；Q7评价内部矛盾。不能把跨文件核验全部强制归Q5或Q7。维度7可评价用空话、复制或模板替代分析的具体行为，不能一律改归Q6。
- 混合条目只对有证据的问题部分提出调整，不能将整条内容都宣布无效；有合理分类解释但证据不足时记待核，不当作已证实违规。
- 场景方向中的常见成果是候选范围；除题面、本次设置或适用规则明确必交外，不能因未交齐参考组合判失败。难度和实质业务工作保留，不通过删除考点提高比例。

简短对照示例：

| 类型 | 成立的问题 | 不构成该问题 |
| --- | --- | --- |
| 独立性 | 一条同时要求欠款核算正确和上诉可行性判断正确；两项影响不同决策 | 同一次欠款计算要求基数、公式、结果均正确 |
| 去重 | Q5与维度4均以同一算式正确为得分条件 | Q1判断凭证证明范围，Q6安排取得缺失凭证的行动 |
| 归类 | 仅评价具体补证行动，却登记为风险识别Q2 | 维度7评价以“待核实”等空话代替分析；维度4评价跨文件核验方法 |

### 结论等级与证据边界

| 结论 | 所需依据 | 不得混用 |
| --- | --- | --- |
| 项目明文违规 | 可定位的适用原文、具体要求及违反内容 | Skill新增写法或本地偏好不能充当官方规定；原文未核实不称项目违规 |
| 评分设计问题 | 原始判据、明确的独立结果/重复触发/分类错位证据 | 局部问题不等于整题不合格；同组关联条目不重复统计根因 |
| 优化建议 | 有可说明的改进收益，但未证明违反要求 | 不计为不合格 |
| 待核 | 关键依据或对评分对象的区分尚不足 | 不计为已确认错误，也不通过排除待核项制造新的合格率 |

1. 固定题目及attempt，依据原始题包核对，不用后加示例追溯判定旧题违反官方规定。
2. 对每个疑点记录判据原句、具体证据、结论等级和适用边界。A/B/C是诊断分类，不是平台否决门槛。
3. 正项遗漏与负项实际错误分别代入回答检查；仅“不得正分且扣分”不足以证明重复。需证明两条确实评价相同对象且无独立错误条件。
4. “甲正确乙错误”只是识别线索，还要证明两项具有独立业务意义；不能由多个法条或检查对象直接推导必须拆条。
5. 原先的“全通过条数/总数≥80%”仅为历史本地测试口径，暂停作为当前放行依据；不称项目官方合格率。当前报告确认问题、撤回判断、待核项及其依据，不输出未经完整复判的新比例。
6. 真实出题成功、评分设计审查、模型作答分数、项目正式验收分别报告。不因局部设计问题宣称整题或四题全部不达标，不自动启动重出。

## 修改原则

拆分独立结果后重新按实务后果定权重，不机械为每个子项继承+10；合并重复项时保留实际覆盖内容；重新核对必设维度、至少三个Q、主F锚点及其正分占比、两条+10、主观比例和否决规则。难度来自真实业务判断，不来自捆绑、重复扣分或错误归类。
