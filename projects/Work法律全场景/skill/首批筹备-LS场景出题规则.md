# 首批筹备材料包的出题规则

## 适用范围与判定顺序

本规则适用于「Work法律全场景 - 首批筹备」中标题带 `L2`、`L3`、`L4`、`L5` 的材料包及其创建的题目。出题时使用下表全部内容；这是本批次确认的对应关系，不是 Work 项目通用分类。

1. **等级标签**：从材料包标题识别本批次指定的等级，例如 `首批筹备-L2-劳务合同` 中的 `L2`。
   - 创建题目时选择该项目的同名等级标签；若项目中尚无此标签，先在项目内创建，再选择。
   - 题目名称中的等级文字不能代替实际标签。
2. **场景与题目身份**：按下表确定该题唯一的三级细分场景。
   - 场景填写完整编号和名称，不把案由「劳务合同」当成三级场景，也不把等级 `L2` 当成场景编号 `LS02`。
   - 本批一包一个题目身份；新建、返修或发现历史重复时，按[材料包与题目的固定关系](出题与评分规则.md#材料包与题目的固定关系)处理。
3. **能力与出题方向**：阅读本题冻结来源材料（脱敏正文或已提取原文），从对应行的「考察 AI 重要能力」中选择有材料依据、符合委托工作的能力，写成具体出题方向。
   - 方向要说明让作答者完成什么专业判断或工作，不能只复制场景名称或整行能力清单；方向须与本包唯一题目的工作重点一致。
4. **交付物**：据此确定题面要求的交付物。优先从对应行「常见交付物」中选择与方向匹配、材料足以支撑的成果，并在题面写清内容与用途。
   - 常见交付物是候选范围，不表示每题必须全部提交；不得列出题面未要求、材料无法支持或与方向无关的成果。
   - 场景行提供的是出题依据，不能把交付物列误当成考察能力列。
5. **角色与视角**：角色／视角不由材料包标题或这张表预填。
   - 出题 Agent 根据实际材料、委托关系和该场景的职业权限自行决定；如创建题目的表单把角色设为可选，可留空交给 Agent 决定。
6. **一致性与缺口**：核对一致性：`材料包等级 → 题目等级标签 → LS 场景 → 出题方向 → 题面任务 → 交付物 → Rubric/标答`。
   - 如材料不足以支撑指定方向或交付物，调整该行内的方向与成果；仍无法形成真实任务时，记录缺口，不编造材料或为了匹配标题强行出题。

方向说明写真实办理目标，不复制旧题答案或评分反馈。具体难度设计与最少题面统一按[通用规则第一节](出题与评分规则.md#一任务描述)执行；本表只分配场景和能力候选，不认定材料包越大就越难。

## 示例：首批筹备-L2-劳务合同

| 项目 | 本题填写口径 |
| --- | --- |
| 材料包 | `Work法律全场景 - 首批筹备-L2-劳务合同` |
| 项目题目标签 | `L2`。若尚未创建，先在本项目创建 `L2` 标签，再给题目选择。 |
| 三级细分场景 | `LS02 证据整理、阅卷分析与质证意见`。`劳务合同` 是本题案件／合同类型。 |
| 角色／视角 | 不预填；出题 Agent 读取材料后自行决定。 |
| 出题方向 | 在读取该材料包后，从 LS02 的证据编目、证据“三性”分析、矛盾识别、质证要点等能力中选取材料确实支持的工作，写明本题具体争点和委托目标。 |
| 交付物 | 与选定方向对应，例如材料支持双方证据核对和质证时，要求证据目录、阅卷笔录、质证意见；是否需要问题清单或证据补强建议，由材料缺口与委托任务决定。 |

上述方向与交付物是**填写方法示例**，不是对「劳务合同」材料内容的已核实结论。实际出题前须检查冻结来源材料；不能仅凭标题断定存在双方证据、矛盾点或可起草的质证意见。

## 与项目通用规范的关系

本表只规定首批筹备的场景、方向及交付物；通用内容与字段要求见[出题与评分规则](出题与评分规则.md)。`L2–L5`是Work任务长程等级，不能只凭标题认定；按[等级依据与逐份清点](出题与评分规则.md#等级依据与逐份清点)核对真实材料规模、实际业务工时及必要工作，不编造材料或工作量。本表不表示已完成逐包材料审查、出题或外部认领。
