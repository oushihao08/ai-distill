# 首批筹备材料包的出题规则

## 适用范围与判定顺序

本规则适用于「Work法律全场景 - 首批筹备」中标题带 `L2`、`L3`、`L4`、`L5` 的材料包及其创建的题目。按本题对应行核对登记主场景、能力与成果候选，不把全表作为每题必做清单；这是本批次确认的登记对应关系，不是 Work 项目通用分类，也不是关联业务场景的封闭目录。

1. **等级标签**：从材料包标题识别本批次指定的等级，例如 `首批筹备-L2-劳务合同` 中的 `L2`。
   - 创建题目时选择该项目的同名等级标签；若项目中尚无此标签，先在项目内创建，再选择。
   - 题目名称中的等级文字不能代替实际标签。
2. **场景与题目身份**：按下表确定该题登记的三级主场景；登记分类不等于单题只能做一种业务工作。按[材料方向场景与交付设计](材料方向场景与交付设计.md)选择材料支持的单场景或多个关联场景，组合仍为同一题目。正式认领明确限定工作范围时保持一致，不虚填场景或认领结果。
   - 场景填写完整编号和名称，不把案由「劳务合同」当成三级场景，也不把等级 `L2` 当成场景编号 `LS02`。
   - 本批一包一个题目身份；新建、返修或发现历史重复时，按[材料包与题目的固定关系](出题与评分规则.md#材料包与题目的固定关系)处理。
3. **能力与出题方向**：阅读本题冻结来源材料（脱敏正文或已提取原文），登记主场景的工作从对应行「考察 AI 重要能力」中选择；有材料依据的关联工作按场景设计规范确定，不限于本行。方向必须符合委托与正式认领范围。
   - 方向要说明让作答者完成什么专业判断或工作，不能只复制场景名称或整行能力清单；方向须与本包唯一题目的工作重点一致。
4. **交付物**：据此确定题面要求的交付物。登记主场景优先参考对应行「常见交付物」，关联场景按其实际工作选择配套成果；整体任务至少三份实质文书，逐份写清内容与用途，不把本行当成唯一成果范围。
   - 常见交付物是候选范围，不表示每题必须全部提交；不得列出题面未要求、材料无法支持或与方向无关的成果。
   - 场景行提供的是出题依据，不能把交付物列误当成考察能力列。
5. **角色与视角**：作答者为律师／法务；其所代表的一方和具体业务／诉讼身份不由材料包标题或这张表预填。
   - 出题 Agent 根据实际材料、委托关系和职业权限确定单方代理立场；表单可留空由 Agent 设计，不表示可以同时代表多方或改成其他职业作答。
6. **一致性与缺口**：核对一致性：`材料包等级 → 题目等级标签 → 登记主场景及关联业务场景 → 出题方向 → 题面任务 → 交付物 → Rubric/标答`。
   - 如材料不足以支撑某项方向或成果，按场景设计规范比较其他有依据的工作，不限定只能在本行内调整；不得虚填登记主场景或超出正式认领范围。仍无法成立或登记要求与材料无法匹配时，记录具体缺口，不编造材料或为了匹配标题强行出题。

方向说明写真实办理目标，不复制旧题答案或评分反馈。具体难度设计与最少题面统一按[通用规则第一节](出题与评分规则.md#一任务描述)执行；本表只分配场景和能力候选，不认定材料包越大就越难。

## 示例：首批筹备-L2-劳务合同

| 项目 | 本题填写口径 |
| --- | --- |
| 材料包 | `Work法律全场景 - 首批筹备-L2-劳务合同` |
| 项目题目标签 | `L2`。若尚未创建，先在本项目创建 `L2` 标签，再给题目选择。 |
| 三级细分场景 | `LS02 证据整理、阅卷分析与质证意见`。`劳务合同` 是本题案件／合同类型。 |
| 角色／视角 | 不预填；出题 Agent 读取材料后自行决定。 |
| 出题方向 | 在读取该材料包后，从 LS02 的证据编目、证据“三性”分析、矛盾识别、质证要点等能力中选取材料确实支持的工作，写明本题具体争点和委托目标。 |
| 交付物 | 与选定方向对应，例如材料支持双方证据核对和质证时，要求证据目录、阅卷笔录、质证意见；是否需要问题清单或证据补强建议，由材料缺口与委托任务决定。 |

上述方向与交付物是**填写方法示例**，不是对「劳务合同」材料内容的已核实结论。实际出题前须检查冻结来源材料；不能仅凭标题断定存在双方证据、矛盾点或可起草的质证意见。

## 与项目通用规范的关系

本表规定首批筹备登记主场景、能力及成果候选，实际单场景或关联组合按[场景设计规范](材料方向场景与交付设计.md)执行；通用内容与字段要求见[出题与评分规则](出题与评分规则.md)。`L2–L5`是Work任务长程等级，不能只凭标题认定；按[等级依据与逐份清点](出题与评分规则.md#等级依据与逐份清点)核对真实材料规模、实际业务工时及必要工作，不编造材料或工作量。本表不表示已完成逐包材料审查、出题或外部认领。
