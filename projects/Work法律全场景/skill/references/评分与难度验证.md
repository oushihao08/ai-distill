# 出题考点与标准答案

本文件沿用原 skill 的独立考点、求解与自检方法，计分和验收替换为 Work 规则。开始编制前完整读取[出题规范](出题规范.md)第 6–11 节及[交付规范](交付规范.md)；本页不能替代完整字段表。

## 考点

不固定条数。原始计分仅 +3／+7／+10／−3／−7／−10，priority 逐项对应；Veto 的 score=null，独立统计可用性。维度 1、2、5 必设，另选四选二；Q 至少三个并含 F 类型两个锚点，锚点正向分占比 ≥30%，至少两条 +10，Subjective 条数 ≤10%。

F1 锚点 Q3／Q4；F2 为 Q2／Q3；F3 为 Q1／Q4；F4 为 Q4／Q6；F5 为 Q1／Q5。默认 binary；likert 仅用于有意义的程度差异，points=5，各档独立可核验。正向来自专家终稿；负向写本题具体错事，不把正项缺失再次扣分。

从专家终稿拆出正向结果后，回查题面、真实材料、适用法源及职业语境：终稿若遗漏本题确需完成的工作，先补正并由专家核定，不能把遗漏固化为 Rubric，也不能凭经验添加题面和材料不支持的要求。

- 按本题真实工作覆盖必要的证据取舍、规则适用及具体交付结果；独立争点、核算、方案比较、条件求解和反驳只在材料与委托需要时设项，不为凑考点或难度补设。
- 每条先确定独立的专业结果，再写清得分所必需的判断依据、条件，以及相应错误或遗漏。按该条实际内容注明决定性材料及定位、法律适用条件与核实来源、计算口径与关键结果、可接受分支；不要求每条具备全部类型。
- 成稿后并排核对各条的专业结果和必要条件：共用条件若分别服务于不同的办理动作，可核查各动作是否正确落实；若只是同一事实或结论换名称、换位置出现，不重复得分或处罚。作者核验所用的页码、条号和说明，不自动成为作答者逐项复述的义务。
- 一条考点若捆绑互不依赖的专业结果，应分别设项或聚焦本条要评的结果；共同构成同一结果的必要条件仍须保留。不把全部核算、全部提案或整个变化情景压成一条。
- 基础事实与摘抄项保持适当覆盖，将主要分值用于有挑战的专业结果。
- 成果份数不直接对应考点数。优先核查跨材料取舍、连续事件后的独立结果、方案成立条件及可执行文本；已在基础底账计分的同一结论，不因它又出现在签批意见或条款中重复给分。
- 接受实质正确的替代表达和合法路径；不同于标准答案原句不是错误。
- 考点依据题面要求、事实及适用规则，不能靠标答额外增加未布置的任务。
- 依主要作答者的职责、可见材料和行动权限设通过条件；检验其应完成的专业判断及实际后果，不以另一角色才能取得的证据或行使的职权判错。
- 对必须说明依据的争点，得分检查结论与决定性依据的对应关系；照抄原则、偶然猜中结论或用相反规则支撑结论，不能替代完成该项判断。法源类 Q3 项按 Work 明确要求嵌入全称、条号、条文内容或可核验摘要及本案对应关系；案例给案号与要旨。题面未明示的特定引用排版不额外强制；接受实质正确的替代法源与专业表述。
- 关系型考点写明具体结论、决定性证据关系、可接受的替代解释及对应错误，合并在现有通过标准和零分条件中。接受实质等价的证据组合；不按引用数量、载体数量或是否照抄标答计分，不用“分析充分”代替判分条件。
- 同时覆盖该成立或可办理与该排除或阻断的具体事项。已能确定却只写“可能、建议核实”不满足确定结论；确实缺失条件时，准确给出分支和行动边界属于正确作答，不以一律肯定或一律否定为标准。
- 连续情景分别检查新事件的性质、规则及办理结果。上游同一算术错误机械传到后续金额，不另拆多个扣分项；后续还有独立规则判断时，写清其自身的通过条件。数值标准注明必要的精度与舍入口径。
- 事实、适用口径和精度明确时才设唯一数字或日期；合法分支分别写明条件和结果。用错法律时点且影响本项要求的依据或结论时判错，不因无关条号或措辞差异扣分。

## 判分依据完整性

判分依据自包含。Harbor judge 的评分对象仅为候选 output，input 用于真实性核验，golden 副本仅作校准；参考答案不能替候选得分，不逐字匹配。ai-distill 独立评分默认不提供标准答案；仅显式 `model_report_v1` 题目可按任务冻结的 calibration 政策提供标答作校准参考，不能将其作为唯一答案键，也不提供作答思路。将影响得分的结论、决定性依据、适用条件及合理替代路径写入对应 rubric 条目；不得仅写“符合标答”“依据正确”或引用未提供的思路、标答章节。涉及作者检索核实的法律，写明用于本项判断的规则要旨、适用时点和可追溯出处，不能只给评分环境无法打开的链接。

rubric 保留判分必需的信息，不复制整份标答或附件。区分作者用于确认标准的依据与作答者必须交付的内容：法源项保留 Work 所需具体规则及引用信息；不因题面未写某隐含专业要求而删除它，也不把作者全部核验笔记、唯一论证顺序或特定措辞升级为候选义务。对结论相同但依据不同的合法路径，明确可接受范围。

## 关系型考点示例

以下抽象示例只说明判据关系，不继承为新题事实、固定任务或可提交材料：银行生成的入账记录证明仅有一笔金额 M 的实际到账；回单原页与复印页具有同一交易标识，聊天截图转发同一回单。M 只代表本示例金额。

- 考点：同一到账事件在不同载体中的识别。
- 通过标准：确认上述记录指向同一笔实际到账，计入 M 一次；说明交易标识及入账记录如何对应，复制页和转发截图没有新增到账事件。未引用交易标识但通过足以排除另一笔交易的其他记录组合正确对应，也可通过；不要求使用标答原句。
- 零分条件：按载体或页数重复累计；只因金额相同便断言同一交易而无足够对应依据；推造被遮蔽的金额或交易标识。

来源独立性与交易去重分别判断：两个独立来源也可证明同一笔交易，不能累计为两笔。银行回单不能仅因付款人提交而认定为付款人生成；回单证明发起、受理或完成何种状态，须读实际内容。此示例不要求每个考点都核对多份材料。

## 作答思路

写出材料之间的关系、争议形成原因、证据取舍、规则适用及计算逻辑。说明表面理解和深入核验后的差异，回应有依据的竞争解释，交代可接受分支。

涉及印证时说明记录的生成者、共同来源、证明范围及不能推出的内容；区分提交者与生成者，不把同源转述当作独立支持。

作答思路解释如何解决题目；其篇幅或复杂程度本身不增加作答要求。

## 标准答案

完整完成题面全部工作，呈现本题需要的分析、逐项结果及具体交付内容；涉及计算、方案、后续变化或条款请求时，给出相应明细、条件和可用正文，不只给原则、摘要及文书名称。

分清真实案件事实与有依据的测算假设、裁判范围与履行余额、真实现状与条件测算。数值核对分项、期间和合计；脱敏值用原有形式或符号表达。支持不同结果时列明各自条件。

题面、考点、作答思路和标答对主体、金额、期间、状态和依据保持一致。

标答由可见事实、有来源的业务条件及经核实的适用法律支持，保留可追溯法律来源。将内部测算与依法可请求的金额区分；不得以作者检索到的单一网页观点排除合理答案。

## 加压检查

逐条遮去作答思路和标准答案，只用评分实际收到的题面、rubric、附件与待评答案核对：能否判断结果、必要依据及替代路径是否满足？若仍须回看标答才知道如何判分，将缺失的判分依据补入该条，不增加题面未布置的任务。

用可信的简化回答逐项核对考点：只摘抄事实、只讲原则、全批、全拒、全部待核、只给结论、只列文书名称，或把初始方案原样用于变化情景，分别还能得到哪些分？如果未处理核心争点也能拿到主要分值，就重构任务及独立考点的覆盖，不能只把零分措辞写狠。

核对同一正确陈述是否被多次奖励、一个错误是否被重复处罚，以及自洽但走合法替代路径的答案是否会被误扣。目标是检出实际漏判、错算和错误办理，不因答案不像标答或篇幅较短而失分。

结合已提供的完整作答和逐项评分，找出模型已掌握的部分及可能遗漏的真实专业工作。只有当前委托、材料和作答者职责确实支持时，才扩展争点或成果，并同步修订题面、专家答案与 Rubric；高分本身不是新增任务或扣分项的依据，不临时改变等价解标准或把正确回答判错。

利用实际作答评估难度时，核对可获得的完整答案、供应商终止原因及输出上限。已确认输出被技术截断时，不把该部分缺失当成专业难度有效的证据；仅末尾缺失或回答简短不能证明截断。缺少运行证据时，截断原因标为未确认；完整答案中的实质漏答仍按既定 rubric 判断。这是作者解释难度证据的边界，不改变现有评分，也不自动免扣分。

若实际配置确认无法容纳完整交付，记录输入输出约束及影响，另行处理执行能力；不凭标答字数预测 token 或直接删减专业要求。此检查不授权调用新模型、重跑评分或改动系统限制。

目标是形成真实、可用且具有规定区分度的法律任务；模型难度由有效作答与评分检验，不能用作者设想、额外工作或加重扣分代替已发生的结果。

## Work 计分与验收核对

按出题规范逐项填写 id、statement、criterion_type、criterion_necessity、dimension、evaluated_files、knowledge_points、atomic_capabilities、priority、score、type、points、trigger_count。分析元数据不计分，不能替代自包含判据或实际待查文件路径。

- Q7 默认只负向；事实错误与跨文件矛盾区分；上游同一错误不反复扣分。维度 5 对本题具体违法、编造法律、事实证据与检索来源分别设明确负项和累计规则。
- R0-V01 独立于数值计分；幻觉各类“累计超过 3 处”不改成“达到 3 处”或一次触发。否决数量、Harbor 输出接口等冲突按完整规范保留，不自行赋权重。
- 原始净分只用正向满分作分母；Harbor 主分按交付规范裁剪归一化，负向用正 weight＋negate，不能双重翻转。无限累计负分与单项封顶转换不等价，不隐瞒。
- 专家 golden 满足所有正项且无负项；专家真实检索记录覆盖全部引用，模型工具记录不冒充人工办理记录。
- 内容准确性 ≥99%；Oracle 主分 >0.90 且 verifier_error=0，规定三模型在真实 Harbor 框架下均分 <0.55，并完成人工验收。不存在“每个模型必须低于 55%”要求；API／工具失败和缺失分数不补 0。
- 本地文本评分与平台文件评分有不同能力与公式，不能以本地通过或低分替代正式验收。原文未决事项只影响关联部分，记录实际缺口，不自行删除要求。
