# 案例模板集

本文件沿用豆包 skill 的构造机制，只参考判断关系。示例不是 Work 选题许可或来源材料；按 Work 两类防重复要求核对。所有事件、授权、报价和文书须从当前真实来源取得，不生成模拟文件或补造业务事实。

以下机制以公司法务场景示范高难度任务构造。用于其他角色时，按该角色的职责、可见材料、权限和交付用途重新设计；保留具体争议、核算、比较、变化及文书工作，不继承示例中的主体立场或成果组合。机制不限定任务范围或成果数量。

## 1. 多案卷整理与专业办理决定

业务用途：公司法务将一批裁判、争议及履行材料整理为支持{应诉/和解/债权处置/内部审批}的底账与意见。

材料组合：多份原始裁判文书、请求与答辩、合同、付款和履行凭证、相关规则。各案完整内容可读；案号、并案关系和主体交叉保留原状。

内部设计：一份文书未必等于一个案件；主张不等于确认事实；同一人的不同款项可能有不同标准；合同名称不直接决定法律关系；举证分配须按适用规则；计算输入散在文书中；裁判支持不等于实际受偿；引用规则按相关时点核对。选择本次材料中实际存在的机制。

可展开的工作：确认案件与对象范围 → 采信事实及规则 → 逐案核算与办理判断 → 汇总专业决定。案数与金额回对明细，不能以逐份摘要代替。

考点候选：合并后的案件数量、某项事实性质、某笔给付口径、举证分配、适用规则、支持与履行状态各自单列。具体值和零分条件必须先由当前原件独立求解。

## 2. 截止时点、多版本与连锁核算

业务用途：业务底表决定{供应/采购/履约}，法务核验其规则、合同权限与可执行安排，形成{批准条件及履约方案}。

材料组合：原始期间数据、多个版本底表、审批记录、变更通知、优先规则、批准前提清单。所有计算输入和期间关系完整。

内部设计：审阅时点影响适用范围；最新文件未必有效；待批或批准晚于审阅时点不自动纳入；前期余额影响后期；处理按有效优先规则，不按行顺序或比例默认分配；已提供检查全过不代表全部批准前提齐备。

构造重点：保留完整核算，新增挑战优先来自条件差异。例如真实审批同日只覆盖对象甲，对象乙仍待批，要求分别确定可履约范围及后续条件，并落实到交接文本；不在题面提前宣布批准结论。不靠增加期间、底表版本或重复代入次数加难；原件无相应差异时，不使用该机制加压，不补造模拟记录。

可展开的工作：定版本与时点 → 定批准范围 → 逐对象逐期间核算 → 规则约束下选方案 → 变化后重算 → 审批与交接对数。

考点候选：有效版本、某对象截止时点状态、某期间基数、调整后结果、方案入选对象、缺失前提对批准的影响，分别核对。

## 3. 多版本整改完整性与放行决定

业务用途：复核{不同主体/时期/版本}的整改是否完成，决定{上线/交割/启用/解除限制}及剩余条件。

材料组合：两个或多个实际快照、既往整改记录、适用规则、实施状态与验证记录、完整对象清单。工程示例原本使用源码和修复差异；法务改编可以使用制度、合同版本、通知及历史办理记录。

内部设计：最新规则修正不等于历史问题消除；一条线完成不等于另一条线同步完成；历史动作执行过不等于会再次生效；表面相同对象可能机制不同；看似异常的安排可能实际无影响。原工程例区分新建污染、更新后失效、历史数据修复与已执行补丁，学习其状态和覆盖结构，不照搬修复代码。

可展开的工作：全量对象覆盖 → 逐版本定状态与机制 → 核对历史整改范围 → 确定剩余动作 → 核验实际完成证据 → 分别决定放行。

考点候选：某对象所在版本、实际整改覆盖、未来与历史分别处理、无需整改的对象、剩余条件、跨产物一致性。按本题独立、可核验的判断确定条数，避免重复；不复制原示例27条或特殊扣分建议。

## 4. 正式规则、临时豁免与撤销的证据裁决

业务用途：确定{某笔交易/某对象}在截止时点适用哪套规则，并决定办理措施。

材料组合：已生效制度、新但未生效版本、授权豁免、撤销通知、原始业务记录和汇总表。各文件权限、对象、期间可判断。

内部设计：最醒目或最新的汇总可能用旧快照；较早正式文件仍有效；豁免只作用于指定对象且可能撤销。先判权限与效力，再定适用范围。

考点候选：某对象有效口径、豁免是否适用、撤销后的措施、汇总错口径导致的结果。不同措辞若实质一致可通过。

边界：不固定“正式一定优先于所有其他材料”；结论取决于实际权限、法律效力及适用时间。

## 5. 显眼指标与真正决策瓶颈

业务用途：选择能满足当前关键要求的{供应商/交易路径/办理方案}。

材料组合：评分或报价表、实际履约能力、合同条件、项目变更、当前期限及权限记录。改变关键要求的记录具有效力依据。

内部设计：材料大量描述质量、报价或综合分，但当前瓶颈由有效变更和实际能力共同决定。模型须恢复当前约束，再找证据，不能选总分最高就结束。

考点候选：当前有效要求、某候选实际满足与否、最终方案、必要条件与下一步。不要在题面直接说明“真正瓶颈是某项”。

边界：瓶颈不能藏成缺失输入；若多个方案均满足要求，允许依据充分的选择，不指定唯一标答。

## 6. 同一对象命中多项规则与例外

业务用途：对完整范围内对象给出{支付/履约/申报/整改}措施。

材料组合：对象明细、多项规则、覆盖条款、例外及生效条件。对象有真实差异，避免复制记录凑量。

内部设计：对象同时命中条件时规则适用会改变；两项交叉、三项交叉及例外只有存在依据时才设置。不能全局按固定排序套用每个对象。

考点候选：选有代表性的规则组合分别核对具体措施；普通对象保留合理覆盖，不能只评最复杂对象。

扩展：比较规则的适用条件及例外，要求回应不同立场的反驳，并写出具体处理方案。

## 7. 局部未知持续到交付与执行

业务用途：在部分输入尚未具备时完成可办理部分，并安排受阻部分的补齐及恢复。

材料组合：已确定事项、真正缺失的一项必要依据、权限与恢复条件、其他不依赖该缺口的对象记录。

内部设计：整题可完成，只有某步骤目前不能继续。上下游都保持该状态，不能在总表补造数值，也不能全案暂停。

考点候选：某项当前状态、具体受阻动作、其他可办理部分、责任与恢复条件、意见和底账同一命题的一致性。

边界：局部未知本身不要求唯一数值；考正确管理。不能因标答给了一条办理路径就排斥其他合法路径。

## 8. 债权、履行、期间与执行安排联动

业务用途：决定{债权处置/付款/执行准备}的范围及条件，形成意见、核算和办理交接。

材料组合：裁判或合同、送达及生效依据、授权记录、已履行凭证、费用与计息依据、主体和线索记录。需精确核算时提供完整日期、金额和口径；题设使用有来源的测算时点、履行情景或变化条件，不补出脱敏值。

内部设计：生效依据影响履行期，履行期影响后续期间和计息；偿还先定抵充，再判断余额与计息基数；义务人、通道方、代收人分别判断；不同程序期限对应不同动作；卷内状态不能写成已办结。允许有正常而看似异常的条款，避免全案否决。

构造重点：例如真实材料分别仅含收款权限、另含减免处分权限时，要求按各自对象与范围判断清偿、处分及可签文本，不将两类授权统一处理。后续授权变化仅作用于指定处分时，修订受影响条款，既往收款与其他债权仍分别核对；具体效力按本题适用法律核实。正常付款和计息仍完整计算，不靠增加付款次数或利息分段作为主要挑战。

可展开的工作：主体与权利范围 → 效力及时间 → 履行抵充与分段余额 → 办理路径 → 付款或申请条件 → 风险补齐责任。预计受偿与法律上可主张范围分别表达。

考点候选：某主体角色、某有效期间、某笔抵充结果、特定阶段基数、独立费用范围、某项当前状态、局部受阻动作及补齐责任。分别核对独立结果，不重复扣同一采信判断。

边界：签收写法不同未必矛盾；还款未必减本金；期限届满不自动等于权利消灭或不能提出申请；既有案件状态及异议路径须按当前证据和适用规则判断。不要把这些个案问题预先写成确定标答。
