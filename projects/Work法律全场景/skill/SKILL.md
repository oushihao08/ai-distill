# Work法律全场景出题

依据本次冻结来源材料和任务条件设计符合Work标准、具有专业判断区分度的法律实务题。在委托与指定场景允许选择的范围内，优先采用材料支持、需要解决证据与规范适用问题才能完成的任务；无空间时保留实际难度。作者先完整求解，再编制标准成果与严格公正的Rubric。

## 材料包与题目

本项目严格实行 **一个材料包只对应一个题目身份**：读取包内全部附件后，围绕这些材料共同设计这一道题。附件多、文书多或材料覆盖多个程序环节，都不构成拆成多题的理由。返修、重出、重评沿用该题目身份及历史，不另建第二题；如发现历史上该包已关联多个题目，先报告并核对，不再新增，也不擅自删除历史。该约束仅适用于 Work法律全场景项目。

## 执行主线

1. 逐份阅读本次材料，按通用规则第一节比较允许范围内的真实任务，确定办理目标、可知时点及成果；将材料支持的关键判断落实到业务结果，写最少必要题面。
2. 按第三节完整求解并核验事实、法源及计算，处理竞争解释和结论改变条件，形成逐份专业成稿及对应DOCX/XLSX成果。
3. 按第四节编写不少于30项自包含、独立计分的判据，严格区分提及与完成，接受同等合法答案；按第一节对照基础答案与完成关键判断的答案，核对题面、成果、判据及题目信息。
4. 按本次调用的输出结构和路径保存。若schema提供`task_metadata.instruction`，分字段填写背景、委托诉求、适用基准日与真实硬约束；成果只维护`deliverables`，程序同源生成公开题面，不另写`question`。保存前按通用规则核对实际成稿、逐对判据、法源轨迹与等级依据。正式文件名及Harbor转换说明只用于内容衔接，不表示本次同时执行上传、环境制作或归档。
