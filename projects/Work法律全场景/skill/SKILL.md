# Work法律全场景出题

依据本次冻结来源材料和任务条件设计符合Work标准、具有专业判断区分度的法律实务题。在委托与指定场景允许选择的范围内，优先采用材料支持、需要解决证据与规范适用问题才能完成的任务；无空间时保留实际难度。作者先完整求解，再编制标准成果与严格公正的Rubric。

每次确定方向、场景和成果前，完整读取并执行[材料方向场景与交付设计](材料方向场景与交付设计.md)。该文件是本 Skill 的场景设计规范：律师／法务只代表一方，按材料选择单场景或多个关联场景，每题至少三份实质配套文书，并核对程序、时点与代理立场。正式登记分类与实际业务工作分开；多场景仍组成同一题目，不改变下述一包一题约束。评分、等级和文件交付按 Work 通用规则执行。

方向、场景及配套成果的选择以该规范为准，批次行、通用参考组合和填写示例不构成单场景或成果范围限制；正式认领范围仍须据实遵守。不能借多场景虚构材料、换成其他合同关系，或同时替不同方交付成果。

## 材料包与题目

本项目严格实行 **一个材料包只对应一个题目身份**。按[材料包与题目的固定关系](出题与评分规则.md#材料包与题目的固定关系)核对共同来源、已有题目、返修续作及历史重复关系。该约束仅适用于 Work法律全场景项目。

## 执行主线

以下顺序用于作者设计与保存；具体内容规则以所引章节为准。

1. **确定任务**：逐份阅读本次材料，按通用规则[第一节](出题与评分规则.md#一任务描述)比较允许范围内的真实任务，确定办理目标、可知时点及成果；将材料支持的关键判断落实到业务结果，写最少必要题面。
   - 按[证据关联与方案核验](出题与评分规则.md#证据关联与方案核验)展开本案必要判断，按[候选的依据支持与交叉核验](出题与评分规则.md#候选的依据支持与交叉核验)落实检索和成果要求；不把作者的求解路线写进题面。等级必要步骤与模型实测轮数分开记录。
2. **完成标准成果**：按[第三节](出题与评分规则.md#三标准交付物)完整求解并核验事实、法源及计算，处理竞争解释和结论改变条件，形成逐份专业成稿及对应DOCX/XLSX成果。
3. **编写判据**：按[第四节](出题与评分规则.md#四评分方案)编写不少于30项自包含、独立计分的判据，严格区分提及与完成，接受同等合法答案；按[第一节](出题与评分规则.md#保存前核对)对照基础答案与完成关键判断的答案，核对题面、成果、判据及题目信息。
4. **保存与复核**：按本次调用的输出结构和路径保存。
   - 若schema提供`task_metadata.instruction`，按[结构化输出](出题与评分规则.md#结构化输出)填写；成果只维护`deliverables`，不另写`question`。
   - 保存前按通用规则核对实际成稿、逐对判据、法源轨迹与等级依据。
   - 正式文件名及Harbor转换说明只用于内容衔接，不表示本次同时执行上传、环境制作或归档。
