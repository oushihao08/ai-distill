- `materials/` 目前只保存本项目规则笔记。尚无案件源文件、输入附件或参考答案；收到新且可使用的原始资料后再按来源和唯一性要求归档。

- 尚未创建期次、题目目录或 `project.json`；认领批次、场景及来源信息确认后再建立。
