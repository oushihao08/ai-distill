# Work法律全场景

AI 开始处理本项目任务前先读 [AGENTS.md](AGENTS.md)，了解当前代码契约、各步骤输入边界以及执行成功与内容／外部验收的区别。本文档中的项目数量和历史状态不代替当前 API 状态。

本目录是 Work 法律全场景项目的主项目资料根。已建立本地 `首批筹备/` 材料分组，收录 18 个现有材料目录，并通过本机工作台 API 重建项目（项目 ID：`db617d63-cdc5-4c0a-a791-ec530e2fe625`），登记为 18 个材料包工作流；正式期数和外部认领仍以项目方与后续题目流程为准。内部模拟专家成果须标注 AI 身份，不冒充真人；外部真人专家要求单独核验。目录同步不代表附件已入库、脱敏或题包已完成。

本项目固定采用 **一个材料包只对应一个题目**：包内全部附件共同支撑该题，不按附件或文书数量拆题；重出、返修和重评沿用同一题目身份，不另建第二题。历史上若有重复关联，先核对并报告，不擅自删除历史。该规则只约束 Work法律全场景，不改变系统支持其他项目采用不同数量关系的能力。具体执行要求见 [AGENTS.md](AGENTS.md) 与 [出题 Skill](skill/SKILL.md)。
