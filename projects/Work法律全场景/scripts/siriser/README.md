# Siriser 内容稿生成

本目录只管理 Work 项目内容稿五件套相关指令。归档执行器由 `server/publishing/work-simulation.ts` 调用；固定提示词、项目交付规范和模拟专家模板作为本次输入只读提供给 Agent。

| 文件 | 用途 | 维护边界 |
| --- | --- | --- |
| `模拟专家生成提示词.md` | 依据题面、Rubric 和脱敏材料生成 AI 模拟成果，并要求真实网页检索 | 不虚构真人身份、检索行为或验收结果；修改后检查服务端输入文件清单与 `材料/交付规范.md` |
| `generate-five-piece.ts` | 从冻结题目和逐份成果组装五件套；题目信息保留场景、角色、能力、专业知识、等级及人时 | 新Work内容直接读取作者冻结记录，不把它描述为归档新执行的检索 |
| `generate-five-piece.test.ts` | 验证新元数据完整投影和检索来源描述 | 单元测试不验证真实法律、文件排版或平台提交 |

归档生成的 Word、Excel、脱敏输入和 `golden_output/` 写在题目成果目录下的版本化内容包，不写回本目录。`golden_output/` 包含可读的 AI 模拟主成果、Harbor 清单中的每一份实际交付文件、真实检索轨迹和模拟生成记录；Harbor 交付文件从同次生成的六件套 golden 原件复制，保持内容及文件格式一致。Harbor 六件套另由 `../harbor/` 管理。
