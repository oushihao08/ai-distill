# Siriser 内容稿生成

本目录只管理 Work 项目内容稿五件套相关指令。归档执行器由 `server/publishing/work-simulation.ts` 调用；固定提示词、项目交付规范和模拟专家模板作为本次输入只读提供给 Agent。

| 文件 | 用途 | 维护边界 |
| --- | --- | --- |
| `模拟专家生成提示词.md` | 依据题面、Rubric 和脱敏材料生成 AI 模拟成果，并要求真实网页检索 | 不虚构真人身份、检索行为或验收结果；修改后检查服务端输入文件清单与 `材料/交付规范.md` |
| `generate-five-piece.ts` | 从冻结题目和逐份成果组装五件套；题目信息保留场景、角色、能力、专业知识、等级及人时 | 新Work内容直接读取作者冻结记录，不把它描述为归档新执行的检索 |
| `generate-five-piece.test.ts` | 验证新元数据完整投影和检索来源描述 | 单元测试不验证真实法律、文件排版或平台提交 |

归档生成的 Word、Excel、脱敏输入和 `golden_output/` 写在题目成果目录下的版本化内容包，不写回本目录。业务正本使用 `主成果.docx` 文件名，正文采用正常业务文书体例，不包含 AI 或模拟过程自述；AI 来源、模型和生成状态保存在独立的 `模拟生成记录.md` 及平台要求的来源字段中，不冒充真人专家成果。`golden_output/` 同时包含 Harbor 清单中的每一份实际交付文件和真实检索轨迹；Harbor 交付文件从同次生成的六件套 golden 原件复制，保持内容及文件格式一致。Harbor 六件套另由 `../harbor/` 管理。

## 平台确认稿（2026-10-16）

新Work契约由`generateSiriserConfirmation`独立输出三JSON＋input_files＋golden_output的五件套及同名ZIP。Rubric平铺保留全部原始字段，包括Veto及累计规则；标准成果按作者声明格式生成，轨迹写`法规案例检索轨迹.xlsx`。不复制Harbor目录、不重写题面业务内容、不重新调用模型。旧`generateSiriserFivePiece`仍保留DOCX／XLSX初稿，支持直接生成成果，任务说明不混入Rubric。

`document-boundaries.json`登记特定冻结脱敏文本SHA与人工整理的文书起止页；仅SHA匹配才分册，未知文本保持原附件。跨页连续文书保留完整，重复判决副本放同一分册，分册文件名带原附件／页码定位。生成器验证全部原页覆盖一次并保留字符范围，私有状态保存正文哈希与重建映射。该文件不含材料正文，不能用拆页、复制或新材料填充清单；当前192分册是整理数量，不是业务L5认证。

`Siriser五件套.json`位于成果目录外层，保存版本、ZIP及文件摘要和原文重建范围，不打入公开ZIP；`submission_ready=false`仅表示尚未外部验收。平台导入／导出实证见项目当前任务执行日志。目录命名中的署名默认采用用户已确认的杨政，日期采用上海当日；需要其他署名可通过生成函数options明确指定，不伪造名额认领码。

## input_files DOCX（2026-10-16修正）

确认稿和兼容初稿均输出真正的DOCX，不再写TXT。发布模块传递经当前脱敏索引摘要、正文投影校验的脱敏结构；按冻结原文页段分册，保留标题、列表、表格与单元格合并、脚注及分页，保留原附件/页定位。分册覆盖校验不变。无正文块且没有未解决识别问题的空页不生成定位标题或空白页；PDF 提取阶段对 OCR 空页或有识别问题的页，使用配置的提取器复识别一次，只替换这些页；复识别后仍为空但无其他问题时跳过，其他问题未解决则停止导出。历史无结构附件采用Markdown兼容渲染，私有状态的structure_mode如实区分两者，不声称重建原始布局；导出阶段不重新调用MinerU、不读取未脱敏原件。内容摘要包含渲染版本与结构，旧TXT包不作为新DOCX包复用。已提交的历史ZIP不自动替换。

本地API尚未重载时，独立delivery脚本可通过127.0.0.1:3700的现有只读workflow/artifact接口补齐同attempt脱敏索引；校验工作流、正文SHA、结构SHA和正文投影后使用，不直连数据库、不获取原件、不改变归档资格。读取失败或结构部分缺失即停止归档；新API已传结构时不再查询。

结构化确认稿的页段定位按结构投影时的实际字符偏移计算，不扫描正文中的同形“附件/原页”标记；防止合并卷内的引用文字被误当作外层页码。冻结正文与结构完整投影校验仍保留，不读取原件、不降级TXT、不改变分册覆盖规则。

标准成果声明为TSV时按冻结正文原字节输出UTF-8表格，保留制表符，不转换列值或追加内容；此支持仅用于golden_output，不改变input_files统一DOCX的要求。
