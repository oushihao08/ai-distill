# 出题项目目录与文件说明

每一期一个独立文件夹，统一位于 `/Users/jack/Documents/codes/lvgou/ai-distill/projects/`。项目规则、本地skill、案件附件和成果分别保存；九份规则资料不是九条题目工作流。

```text
projects/
├── README.md                         # 本文：各期通用的目录约定
└── 豆包高经济价值-第五期/             # 第一个项目；其他期次建立同级目录
    ├── README.md                     # 本期材料说明、标准摘要和未决问题
    ├── project.json                  # 项目登记清单、文件指纹和来源
    ├── materials/                    # 大纲、评分规则、流程说明、会议纪要
    ├── skill/
    │   ├── SKILL.md                  # 本期出题/审查/返修/评分的入口
    │   ├── references/               # skill方法及评分、交付规则
    │   └── assets/                   # 原有Word模板等资源
    ├── questions/                    # 项目的案件材料根目录
    │   ├── 题目 1/                   # 一条工作流：项目ID＋题目目录标识
    │   │   ├── 附件-1.pdf
    │   │   └── 附件-2.pdf
    │   └── 题目 2/
    │       └── 卷宗.pdf
    ├── outputs/                      # 规划：每题的脱敏文本、题目、答案、评分及导出
    └── snapshots/                    # 已接入：冻结后的完整资料/skill版本
```

树中的题目1/2是结构示例，本期没有凭空建立题目或案件附件。`questions/`中只放输入材料；成果放在其外，避免同步材料时把产出的PDF重新当成题目输入。

## 本地文件与数据库的职责

| 内容 | 本地保存 | 数据库保存 |
| --- | --- | --- |
| 项目规则资料 | `materials/`原文 | 资料清单、相对路径、来源、SHA-256、规则版本 |
| 项目skill | `skill/`完整目录，含references/assets | 本地路径、关联项目、版本、全目录文件指纹；不复制SKILL.md正文入表 |
| 案件附件 | `questions/题目 n/`来源文件，受管理副本单独存储 | 工作流、材料索引、指纹、输入版本及状态 |
| 产物与模型答案 | 产物文件；目标位置为本期`outputs/` | 文件索引、使用的题目/规则/skill版本、答案及评分记录 |
| 执行过程 | 必要的执行日志/文件 | 排队、执行、返回结果、错误、尝试、返修历史及时间 |
| 模型设置与密钥 | 密钥只在受保护的凭证配置 | 模型设置及密钥引用；不在project.json、skill或文档写密钥 |

数据库仍是工作台状态的唯一依据。`project.json`是项目登记及来源清单，不承担运行调度，不和数据库同时维护两份任务状态。JSON中的评分标准摘要是草稿配置，发布前须核对相应原文。

## 后续按最短路径实施

1. **项目资料与skill登记已接入**：页面展示`materials/`清单与完整本地skill；增改删后更新草稿清单及指纹，旧冻结版本保留。正文不入数据库，使用现有rule_versions保存索引。旧指纹不能覆盖新文件。文件修改先落盘再更新草稿；若数据库中断，文件保留，页面刷新并重新登记即可核对实际状态，不声称文件系统和数据库是一个原子事务。
2. **内部快照已接入，执行绑定待接入**：冻结一版完整资料＋skill到`snapshots/`，检查入口和相对引用，读取前校验全部文件指纹。冻结不替代用途及规则冲突审查，正式资格仍未验证。后续每个任务必须绑定版本，不直接读取变化中的skill冒充原版本。
3. **衔接后续执行器**：按项目解析输入和产物路径，实际写入`outputs/`；接入本期规则加载、出题/质检、模型作答、独立评分、返修与成果导出。做题模型只读取题面和实际附件，评分者读取同版本rubric及匿名答案。保留每轮证据，成绩和正式提交资格分别记录。

新增期次时建立同级目录，放入该期规则及独立skill，再在工作台创建项目，材料根目录填写该期`questions/`，本地skill填写该期`skill/`。不得直接继承第五期的50分门槛、8题上限、人工要求或交付格式；新一期以其实际规则为准。
