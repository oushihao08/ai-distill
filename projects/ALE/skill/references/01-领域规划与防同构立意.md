# 领域规划、净量核算与防同构立意

**用途：**指导作者在任务立意阶段对齐 ALE 的 `domain / sub_domain` 配额体系、独立原创净量计量规则、“同核异形”异构任务演化方法及数据集私有 `canary` 保护。

---

## 一、ALE `domain / sub_domain` 配额与均匀分布规则

按去重且验收合格的**独立任务净量**计量，单个 `domain` 配额目标如下：

| `domain` 标识 | 合格独立任务净量需求 | 推荐覆盖的核心 `sub_domain`（域内均匀分布，随批次附统计表） |
| --- | ---: | --- |
| `computing_math` | **200 条** | 系统与分布式排障、编译器与静态分析、密码与安全审计、运筹优化与组合算法、数值计算与形式化验证 |
| `life_science` | **200 条** | 多组学与单细胞测序管线、蛋白质结构与分子对接、代谢通路与系统生物学、进化遗传与群体统计、实验协议排错与定量分析 |
| `health_medicine` | **200 条** | 临床多模态病历与指南循证决策、药物相互作用与剂量肾肝功折算、医学影像/生理信号定量质控、真实世界研究（RWE）生存分析、医保DRG/临床路径合规审查 |
| `business_finance` | **200 条** | 多表财务尽调与合并抵销重述、衍生品定价与风控压力测试、税务稽查与跨境转让定价、供应链排产与库存资金优化、商业并购交割结算与商事合同核算 |
| `engineering` | **200 条** | CAD 机械零件/装配体公差与拓扑重构、EDA 电路/PCB 时序与功耗分析、结构/流体/热仿真（CAE）网格与边界核验、化工过程物料能量衡算、建筑/土木工程造价与规范校核 |
| `visual_media` | **200 条** | Blender 三维建模/骨骼绑定/程序化材质与重渲染、多轨音视频非线性剪辑与响度/色彩达标合成、SVG/矢量UI工程与响应式交互实现、技术制图与数据可视化工程修复 |
| `physical_science` | **100 条** | 天体物理与光谱巡天反演、地球物理/气象海洋网格同化、量子化学与晶体材料第一性原理数据分析、高能/光学实验标定与系统误差分离 |
| 其他 `domain`（如 `law_compliance`、`public_policy`、`operations` 等） | **每个最多 50 条** | 如 `law_compliance`：复杂民商事诉讼与执行穿透、公司治理与并购交易文件修订、行政/反垄断/数据跨境合规审查、知识产权侵权比对与赔偿测算 |

### 批次标签与均衡要求

- 每题在 `task_card.json` 与 `batch_manifest.json` 中必须完整标注：`domain`、`sub_domain`、`task_family`（任务族）、软件与工具、操作系统（Linux / Windows / macOS）、输入与输出文件格式、自然语言/编程语言及计算资源档位（CPU / GPU / RAM / 磁盘 / 超时）。
- 同一 `domain` 内各 `sub_domain` 题目数量应保持均匀，禁止将 80% 题目集中于单一容易批产的子方向；同一道题无论挂载多少标签，**不得跨 domain 或跨批次重复计入独立净量**。

## 二、独立任务净量与防同构核减红线

ALE 严格区分四个独立统计口径：**独立任务数、独立材料包数、环境数、共享世界数**。

| 情形 | ALE 计量裁决 | 作者立意执行准则 |
| --- | --- | --- |
| **合法复用底层软件环境或大型共享世界**（如同一套 ERP 数据库底座、同一套 Blender 渲染镜像、同一套开源代码仓初始快照） | **不扣减独立题数**（共享材料和环境在 `batch/shared/` 只存一份，以版本、路径和 SHA-256 引用） | 鼓励复用重型基础镜像与高真实感共享世界，但每道题必须定义独立的业务目标、不同的核心故障/冲突链、不同的操作工具路径与独立验收标准 |
| **同构换皮题**（仅替换公司/人名、调整输入数值比例、更换随机种子或平移日期，而求解脚本/公式/推理拓扑完全同构） | **归零，不重复计入合格净量** | 立意前执行**“脚本迁移测试”**：把同任务族上一题的 `solve.sh` 只改文件名和常数参数搬过来，若能拿到 `> 0.30` 分，判定为同构题，必须重设立意 |
| **公开原题、直接改写或历史已交付题目复投** | **不计新增原创净量**（必须如实披露上游来源与本次实质增量；隐瞒不报触发防 hack 违规） | 优先采用脱敏真实实务材料、自建原始工程或深度重构的多源复合场景；若基于公开基准或既有案卷升级（如从纯文本问答升级为原生多文件实操＋可复现环境），必须在 `source_provenance` 明示上游及新增环境/材料/判据增量 |

## 三、“同核异形”跨任务立意方法（从同一专业底座衍生真异构任务）

当同一批次使用相近领域的真实材料或共享世界时，通过改变**决策站位、任务阶段、约束耦合方式与原生产物形态**生成真正独立的任务（严禁只换数字）：

| 维度切换 | 立意演化方式 | 跨领域实例对比 |
| --- | --- | --- |
| **1. 顺向构建 vs 逆向排障审计** | 一题要求从原始观测与约束构建工程产物；另一题提供前手留下的含隐蔽缺陷工程，要求定位根因、修复原生文件并量化下游偏差 | `engineering`：根据载荷设计支架参数化 STEP 模型 vs 接手现场断裂返修件的 STEP 装配体，排查干涉与壁厚违规并重构公差 |
| **2. 执行生产 vs 对抗审查/异议核驳** | 切换委托方职责：从“产出申报/执行方案”切换为“核驳外部第三方报告中的方法学谬误与数据操纵” | `business_finance` / `law_compliance`：编制并购交割价格调整 `.xlsx` 工作簿 vs 代表卖方逐项核驳买方审计报告中的过渡期坏账计提与赔偿篮子重复扣减 |
| **3. 静态离线核定 vs 动态服务/状态恢复** | 从静态文件分析切换为真实运行态服务调试、数据库状态修复与端到端交互验证 | `computing_math`：静态日志根因定位与补丁 vs 启动失步的微服务集群、修复幂等锁与脏账状态并通过并发回放验证 |
| **4. 单模态数值计算 vs 跨模态工程协同** | 要求将底层计算结论精确映射回可视化/三维/排版原生工程属性 | `visual_media` / `physical_science`：从声学/光学物理参数表驱动 Blender 节点材质与关键帧曲线并重渲染校验 |

## 四、数据私有性与专属 `canary` 埋设规范

1. **严防污染与外泄**：所有自建题目、真实脱敏业务输入、参考解与评分器必须保持私有，严禁上传公开 GitHub 仓库、公开 Gist、在线 Pastebin 或公共评测榜单。
2. **逐题绑定 `canary`**：
   - 每道题必须在 `task_card.json`（及内部元数据）生成并记录数据集专属唯一标识符，格式示例：`ALE-CANARY-<DOMAIN>-<TASK_ID>-<16位随机十六进制>`。
   - **放置位置**：写入 `task_card.json`、`tests/rubric.json`、`solution/solve.sh` 头部注释（非执行区）；若在 `instruction.md` 尾部或输入元数据中放置防抓取 canary 标记，须确保不影响专业语义理解，且 `tests/grade.py` 不因产物是否原样复制 canary 而误判分数。
   - **防 hack 核查**：在 `review/<run_id>.json` 中检索 Agent 的网页搜索词、外部请求与推理轨迹，确认未通过搜索 canary 或题目特征串从外部仓库/历史会话获取参考答案。
