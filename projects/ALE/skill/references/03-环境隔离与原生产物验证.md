# 环境、网络隔离与原生产物实质检查

**用途：**指导作者按《ALE 数据交付技术规范》第 3 节构建可独立复现的容器/VM 环境、实施构建到判分五阶段真值隔离，并针对五大类专业产物编写原生产物实质检查逻辑。

---

## 一、可独立构建与复现的环境契约

每道题的环境必须能在买方干净机器上独立构建、启动、健康检查、执行参考解、收集产物、判分并通过 `reset.sh` 干净复位，**零依赖供方私有 harness，题目间与各次 `run` 间绝不串状态**。

| 环境要素 | Linux 容器题要求 | Windows / GUI 桌面工程题要求 |
| --- | --- | --- |
| **镜像与快照** | 提供完整 `Dockerfile`、固定基础镜像 `sha256` digest 及镜像归档/可拉取源 | 提供可复现 VM 镜像/快照、精确软件版本号、合法安装/使用授权说明及启动脚本 |
| **依赖锁定** | 提供 `requirements.lock` / `Cargo.lock` / `package-lock.json` / 系统包精确版本；**严禁**在运行或判分时临时 `pip install` 拉取浮动版本 | 预装全部所需商业/开源桌面软件（如 FreeCAD/OpenCASCADE、Blender、LibreOffice/Excel、浏览器驱动）及插件 |
| **资源与权限声明** | 在 `task_card.json` 与 `env.json` 明确声明 CPU 核数、GPU 型号/显存（如需）、RAM 上限、磁盘空间、单次运行超时（timeout）及容器运行用户权限 | 同左，并声明显示分辨率/虚拟帧缓冲（Xvfb/RDP）或无头批处理入口 |
| **复位机制 (`reset.sh`)** | 一键清理临时进程、重置数据库/文件系统/服务状态至初始干净快照，确保 8 次标定每次从完全一致的初始状态起步 | 快照回滚或幂等复位脚本，清理注册表/缓存/临时工程锁文件 |
| **禁止环境误判** | **绝不能**仅因宿主机 Python 版本不同或宿主侧静态 `import` 未解析就判题失败；一切执行与判分必须在声明的环境内完成核实 | 无 GUI 或权限受限的评测节点，必须在 `tests/` 提供可执行的无头等效检查器（如 Python OpenCASCADE / `bpy` / `openpyxl`），**绝不因此删掉原生产物要求** |

## 二、离线默认与网络访问控制（`allow_internet`）

1. **默认离线可复现**：`task_card.json` 默认设 `"allow_internet": false`，容器执行期断网运行，所需文档、手册、标准规范或数据包如属任务合理工具书，可按真实工作形态预置在环境文档区（不预置答案或解题提示）。
2. **确需联网任务的显式声明**：仅当真实专业工作必须访问外部检索或业务 API 时，设 `"allow_internet": true`，并在 `task_card.json` 与 `env.json` 逐项列明：
   - 允许访问的域名/服务白名单与网络范围；
   - 授权使用的工具名称；
   - 凭据运行时安全注入方式（**严禁**将真实密钥硬编码进镜像、`Dockerfile` 或任务文件）；
   - 时间敏感数据的合法离线快照或版本锚点（保证事后复评可复现）。
3. **判分阶段网络铁律**：
   - **确定性判分（`grade.py`）必须 100% 本地离线运行**；
   - 确需模型评审（LLM Judge）的连续专业评分项，仅允许访问预先约定的 Judge API，全部评审依赖、Prompt 模板与模型资产必须预置，**严禁在评分时临时下载依赖或静默更换评审方法**。

## 三、五阶段可见性物理隔离与故障显式分类

必须在 `env.json` / `task_card.json` 明确声明并通过挂载隔离强制执行以下五阶段边界：

| 阶段 | 允许可见/读写范围 | 绝对禁止暴露或混入的内容 |
| --- | --- | --- |
| **1. 构建（Build）** | 系统依赖、业务软件、授权工具、初始工作区与 `environment/input/` | **严禁** `COPY`/`ADD` 任何 `tests/`、`solution/`、`rubric.json`、`grade.py`、`reference/` 或 git 历史到镜像层（防 `docker history` 或层扫描泄露） |
| **2. 挂载（Mount）** | 只读或工作副本形式的 `input/`、受控工具套接字 | **严禁**挂载宿主机评分目录、其他 `run_id` 产物目录或含真值的共享卷 |
| **3. 执行（Execute）** | Agent 仅能通过声明的授权工具读写工作区与目标业务状态 | 禁止绕过授权工具直接改后端私有状态库；**Agent 自写的运行日志、`DONE.txt` 或“已完成”声称绝不作为完成证据** |
| **4. 收集（Collect）** | 停止 Agent 进程后，按 `task_card.json` 声明的精确产物路径与系统状态快照提取产物，计算 SHA-256 | Agent 正常结束但漏交约定路径产物 → 记为**模型未完成（0分/失败）**，不替模型从临时目录猜找文件 |
| **5. 判分（Grade）** | 在隔离的评测容器/进程中挂载收集到的只读 `artifacts/` 与私有 `tests/`（`grade.py`, `rubric.json`, `reference/`）执行判分 | 缺依赖、目标服务未拉起（基建侧）或 Judge 网络故障 → **必须显式报 `ERROR` 退出**，**严禁 catch 后伪装成正常的模型 `0` 分**！ |

## 四、原生产物实质检查规范（严禁用截图/导出件替代）

凡题面要求专业工程、表格、应用或科学数据产物的，`grade.py` 必须用对应原生解析引擎执行实质检查（以下五类为官方基准，其他专业软件按同等深度扩展）：

| 产物类型 | `grade.py` 必须执行的实质检查项 | 严禁放水的伪检查 |
| --- | --- | --- |
| **CAD / 三维设计**<br>（`.step`, `.iges`, `.fcstd`, `.dxf`, `.sldprt` 等） | 调用 OpenCASCADE (`OCP`/`pythonocc`) / FreeCAD 无头重开原生工程或实体；逐项核验**长度/角度单位制、流形拓扑闭合性（无自交/破面）、包围盒与关键特征尺寸（孔径/距/倒角/壁厚）、装配配合约束及特征树可编辑性** | 仅检查 `.stl` 三角网格文件非空或仅看渲染预览 `.png` |
| **Blender / 音视频**<br>（`.blend`, `.hip`, `.nk`, `.otio`, 多轨音频/视频工程） | 调用 `blender -b -P` / `ffprobe` 重开原生工程；核查**骨骼绑定权重/约束、着色器节点图连接与贴图属性、时间线轨道/关键帧/转场、采样率/帧率/色彩空间与响度（LUFS）**，并实际执行无头**重新渲染或导出**比对像素/频谱误差 | 仅检查预先导出的 `.mp4`/`.png` 分辨率或时长 |
| **XLSX / Office**<br>（`.xlsx`, `.docx`, `.pptx`） | 执行**三层防伪核验**：① 公式图核查（解析公式 AST，确认引用真实上游明细单元格，**拦截 `=90000+0` 或 `=IF(1=1,90000,...)` 假公式投机**）；② 公式 AST 独立重算零 `#REF!/#DIV/0!/#VALUE!/#NAME?`（无 LibreOffice 时 `openpyxl` 生成的 `cached is None` 100% 合法，仅当模型写入非空 `<v>` 缓存却与重算值矛盾时判错，**严禁使用 `data_only=True` 单读缓存误杀未注缓存模型**）；③ **输入微扰动 $\Delta$ 重算校验**（在临时副本微调一处上游输入，重算验证目标汇总格按理论 $\Delta$ 精确联动），并检查跨件勾稽与可读排版 | 仅用 `pandas.read_excel()` / `openpyxl(..., data_only=True)` 读静态缓存，或仅用 `startswith('=')` 粗查公式前缀 |
| **Web / 应用操作**<br>（全栈服务、前端交互、数据库/ERP 状态） | 在隔离端口**启动真实后端服务与页面**，使用 Playwright / 真实 HTTP 客户端执行用户级关键交互序列（增删改查、权限拦截、并发提交、异常回滚），核对**后端数据库/持久化存储的真实终态、DOM/API 契约及约定视口（Viewport）布局无遮挡溢出** | 仅用正则 `grep` 前端源码字符串，或轻信前端页面写死的假状态而不查持久化层 |
| **科学计算 / 代码数据**<br>（`.py`, `.cpp`, `.parquet`, `.h5`, `.nc`, `.vcf`, 模型权重） | **从原始输入独立复算或注入未见过的同分布校验集**：核查物理/统计假设、训练/验证样本划分零泄漏、物理单位与量纲守恒、数值收敛残差与误差容差、时间/内存运行约束，以及**全量输出对象**（不抽查前几行） | 仅比对标准输出打印的最后一行汇总数，或仅跑代码自带的自测而不跑私有独立测试 |

- **复合办公与法律/商业尽调任务补充**：当交付组合为多份 `.docx` 正式文书 ＋ `.xlsx` 活公式测算工作簿时，除执行上述 XLSX 活公式重算核验外，还须解析 `.docx` 结构化段落/表格，交叉核验对外正式文书引用的核心金额、日期、主体与 `.xlsx` 重算结果完全一致。
