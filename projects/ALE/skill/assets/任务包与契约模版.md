# ALE 任务包与结构化契约模版

**用途：**提供《ALE 数据交付技术规范》第 6、7 节全套核心 JSON/Markdown/Python 文件的标准结构模版，以及在 `ai-distill` 工作台出题时的 `ale_package` 内嵌桥接契约。花括号与示例值仅说明类型与结构，**严禁将示例数据带入真实题包**。
