| **2. 编译器/DSL 解析与静态分析** | 含边界 Bug 的自定义 DSL 编译器源码、AST 规范文档、线上误编译样例集 | 定位运算符优先级/作用域逃逸与类型推导缺陷 → 修改语法分析与 IR 生成 Pass → 保证已有回归集零退化 | 可编译源码工程；在私有隐藏复杂嵌套程序集上编译并运行比对输出与内存泄漏 |
| **3. 密码协议与二进制安全审计** | 固件/服务端源码、流量抓包 `.pcap`、残缺密钥协商日志 | 识别随机数重用/填充预言机或验签绕过漏洞 → 编写离线流量解密还原受损业务负载 → 提交安全修复补丁 | 解密还原的结构化载荷文件 ＋ 修复后服务端源码；验证私有攻击向量被拦截且正常握手吞吐达标 |
| **4. 运筹优化与带约束调度（MIP/CP）** | 多工厂产能表、带维护窗口的设备日历、阶梯电价与违约罚金合同、残缺旧排程脚本 | 清洗冲突班次与跨日时区 → 建立混合整数规划/约束规划模型处理非线性能耗跳变 → 输出全局可行最优排程 | 求解源码 ＋ 排程结果 `.parquet`/`.xlsx`；独立校验全部硬约束 100% 满足且目标成本达全局最优容差内 |
