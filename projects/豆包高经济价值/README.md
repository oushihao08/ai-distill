# 豆包高经济价值

此目录是“豆包高经济价值”主项目根。`materials/` 保存跨期共用的规则资料；`skill/` 保存跨期共用的出题 skill，入口为 `skill/SKILL.md`，完整引用与模板位于 `skill/references/` 和 `skill/assets/`。

## 出题规则导航

| 入口 | 作用与读取时机 |
| --- | --- |
| [出题 Skill](skill/SKILL.md) | 作者总入口及专项规则导航 |
| [材料方向场景与交付设计](skill/references/材料方向场景与交付设计.md) | 每次设计前完整读取并执行；规定材料匹配、律师／法务单方服务、五类场景、关联组合、配套文书与批次差异；不依赖桌面原始文件 |

场景规范已接入作者入口及题目模板；旧题与历史快照不改写。新任务读取当前共享 Skill，文档接入不等于已完成真实出题或项目方验收。

[难度提取表](%20难度.md)（文件名带一个前导空格，按用户指定路径保留）整理当前 `skill/` 的真正难度机制、原文提示词、设计案例与 Work 迁移边界；它是分析参考，不是运行 Skill，也不作为题目附件。

`scripts/delivery.ts` 是各期共用的归档入口。项目专用的 OCR 调查脚本按用途放在 `scripts/ocr/`，skill 候选冒烟脚本放在 `scripts/skill/`；索引及运行影响见 [`scripts/README.md`](scripts/README.md)。

## 目录约定

```text
豆包高经济价值/
├── materials/          # 主项目各期共用的规则资料
├── skill/              # 主项目各期共用的出题 skill
├── scripts/            # 项目脚本；由 scripts/README.md 索引
│   ├── delivery.ts     # 各期共用的归档入口
│   ├── ocr/            # 本项目 OCR 调查脚本
│   └── skill/          # 本项目 skill 验证脚本
├── 第五期/             # 第五期独立工作内容
│   ├── questions/      # 本期题目来源，工作流 material_root 指向此处
│   ├── reports/        # 本期规则更新分析
│   ├── updates/         # 本期待核来源
│   ├── outputs/        # 本期本地成果
│   ├── snapshots/      # 本期历史快照与归档副本
│   └── project.json    # 本期来源清单及登记信息
├── 返修文档/           # 跨期逐题返修原因、操作记录及返修地图
└── <其他期数>/         # 各期自己的题目、更新记录和成果
```

规则资料和 skill 是主项目级共享输入。编辑或替换 `materials/` 中的文件会影响该主项目后续各期的新任务；已创建任务仍按各自冻结的文件清单校验。`questions/` 只放案件来源文件，由期次工作流单独扫描；`reports/`、`updates/`、`outputs/` 和 `snapshots/` 不作为案件附件输入。

## 第五期当前目录

第五期的题目来源、成果、更新记录、历史快照和 `project.json` 均位于 `第五期/`。共享规则资料已放在本目录的 `materials/`，共享 skill 已放在 `skill/`。第五期 `project.json` 中的 `materials_dir` 与 `skill_dir` 相对指向 `../materials` 和 `../skill`。

本期未核事项、来源说明和具体文件清单见[第五期说明](第五期/README.md)。工作流状态、已入库附件和运行结果以数据库当前记录为准；本地文件清单不代表入库状态。

## 返修跟踪

跨期题目返修原因、每题最多两次的返修记录及当前状态统一登记在[返修文档](返修文档/README.md)；总览见[反修改题目地图](返修文档/反修改题目地图.md)。该目录是本地维护记录，不作为题目输入、项目规则或公开交付物；数据库中的工作流与评分状态仍以本机 HTTP API 当前记录为准。

本轮得分路径、评分争议、共享Skill修改及设计字段补齐记录见[第六期难度复判与修改计划](返修文档/第六期难度复判与修改计划.md)。角色与场景是建题／重出设计输入；作者在正文推导身份不会自动回填这两个字段。通过设置API修改它们会使步骤4–8当前结果失效，历史尝试保留；共享Skill修改只供新派发读取，不需要重启服务。
