1. **建题与派发顺序**：先完成建题，再严格按 **P0（12 名有名称人员）→ P1（无名称）** 顺序派发 `author_question` 出题。
2. **状态定义**：
   - `📝 已建题待出题`：已在 `豆包高经济价值-返修 - 第六期` 创建题目并冻结脱敏材料，等待执行 `author_question`。
   - `✅ 已出题成功`：`author_question` 步骤状态为 `succeeded`。
   - `⚠️ 未建题（缺材料包）`：原题材料包尚未加载至 `豆包高经济价值-返修 - 第六期`，无法建题。
