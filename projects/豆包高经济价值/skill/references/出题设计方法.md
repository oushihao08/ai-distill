# 对抗审查与加压设计

## 找茬的对象

检查每份材料能证明什么，以及它与其他材料是否一致。按本题实际涉及的主张方、相对方、审查者和承办人立场发问；这些是作者检查争议的视角，题目的主要作答者仍须单独确定：

主要作答者为律师／法务，只代表一方；下列机制按[场景设计规范](材料方向场景与交付设计.md)选取，不要求每题安排核算、方案比较或连续变化，不减少所选场景应完成的专业工作。

- 事实：谁的陈述，证明什么，是否遗漏对象、期间、款项或后续事件？
- 证据：原始记录与汇总是否一致，文书之间如何关联，矛盾能否裁决，举证责任落在哪里？
- 规则：法律性质是否被名称误导，适用版本及期间是什么，多项规则、例外及程序条件怎样共同作用？
- 金额：基数、期间、抵充、费用、利率及合计怎样确定，前后事件如何改变余额？
- 程序与权限：权利成立与本次能采取的动作有何区别，谁有权作出承诺、处分权利或提交请求？
- 方案：对方最有力的反驳是什么，方案何时可行，怎样修改条件才能成立，变化后如何调整？
- 文书：具体主体、范围、条件、顺序和后果是否完整，承诺、审批意见、请求与底账能否相互核对？

逐项深挖，不以“最终建议没变”为由删除证据分析、备选路径、独立核算、反驳或文书工作。

## 加压机制

| 机制 | 怎样展开任务 |
| --- | --- |
| 多案与多对象 | 按业务问题确定需分别处理的对象及层级，核对多份记录是否指向同一事项、同一事项是否包含独立权利义务或结果。分别形成处理结论、依据及必要核算，说明合并、区分和排除的理由；不止于分类，不以文件数代替业务对象数，不为加量机械拆分 |
| 竞争证据 | 将醒目汇总与分散原始记录交叉核对；追查记录由谁制作、依据什么原始记录、证明谁的什么事项、涉及什么权限和期间，判断支持、限制和冲突，不能按文件份数、最新日期或名称选依据 |
| 同数不同口径 | 区分请求与裁判、合同与实付、含税与未税、原币与折算、不同期间 |
| 规则交叉 | 按具体条款、法律关系与适用时点处理规则及例外；安排表面相似但法律结果不同的对象，不按合同名称套结论 |
| 时间与状态 | 区分发生、作出、形成、送达、生效、履行等时点；根据当时适用规则推算确需推算的期间，并处理顺延、中断及其作用范围 |
| 多事件核算 | 先确定给付性质、有效约定和法定抵充口径，再更新余额、基数及期间；用于加难的新增事件须带来新的适用判断，不以付款次数或分段数量代替挑战；正常履行事件仍完整核算 |
| 方案比较 | 分别求解各方案的法律条件、经济结果、风险及实施安排 |
| 临界条件 | 求出最低付款、担保、时点或其他条件，表达可接受区间及依据 |
| 变化后处理 | 改变决定适用条件的一项事件，使原结论需要收窄、放开或改换路径；重做受影响成果，保留未受影响部分 |
| 对抗论证 | 构造有依据的相反主张，要求回应其最有力理由而非笼统否定 |
| 实际文本 | 写出本方律师／法务有权制作或提出的条款、请求、代理意见、通知或交接正文，并与相关分析和核算核对 |
| 局部未知 | 对同一业务范围分别落实可执行、附条件及受阻事项；既不能补造缺口，也不能让全案停办获得全部分数 |
| 归纳与迁移 | 多对象的共同点与差异影响本方判断、审查标准或后续办理时，要求比较共同条件、实质差异及有依据的例外，形成有适用边界的结论，并落实到本方可使用的审查动作、文本或办理安排；用于当前事项时判断条件是否满足。材料不足以支持普遍结论时保留局限，不预设必须存在统一规律或反例 |

按本案需要选用上表方法，可以组合。对象、争点和成果数量由实际委托决定，不照搬案例数量。

## 核对有依据的竞争解释

### 记录关系与证明范围

- 按记录的制作和转引过程核对：谁生成、基于哪个事件或上游记录、证明哪个主体与期间。区分独立观察、同源转述和复制件；提交人、文件名或载体不同不自动构成独立证据。
- 材料一致时仍检查是否共同依赖同一未经证实的前提。

- 对每个拟考的材料关系，核对它怎样支持、限制或推翻具体结论，并落实到证明范围、权利、金额或办理动作；若只需列出来源而不影响必要判断或交付，不单列难点或考点。总体建议不变时，仍保留确实限定核查、反驳或执行范围的关系。
- 单项证据已经足够时不人为配第二份，不规定每题证据份数；保留原始结构及上下文，不预先整理为正确事实表。

材料未记载不自动证明事项未发生。完整性已知的记录可以支持排除推断，但应说明覆盖范围及剩余可能性；不把无法消除的分歧强行写成唯一结论。

### 竞争解释与裁决依据

寻找容易引发错误理解的线索：醒目的汇总、较晚形成的文书、相似主体、常见合同名称、含混付款性质、看似正常的提案或貌似冲突的日期。

- 分别推演其表面理解、相反解释及法律后果。保留原始材料中的诱因，让作答者自行查找裁决依据、回应竞争解释并形成成果；不要在题面提前拆穿。
- 也可以在明确模拟的业务提案中呈现待审主张，让作答者判断。

- 裁决依据按证据性质、权限、适用对象、时间和法律规则核对。真实存在多种成立解释时，标答写明分支及成立条件；不将作者偏好冒充唯一答案。

- 对每个拟用难点先辨明：诱人的表面解释、作答者可见的裁决依据、应得结果及容易出现的具体错误。把双方最有力的理由都推演到结果；如两种解释均成立，就考条件分支，不强行指定一条。
- 此为作者构造依据，不把难点清单或错误标签贴进题面。

### 误判假设的边界

“模型会顺从、忽略中段或套模板”只是待实测的误判假设。不能因职位高、句子长或第几次计算就预断模型必错；选取真实改变定性、金额或动作的线索，保留其自然位置和充分上下文。

## 规则与载体落地

### 法律核验与工具能力

- 研究新旧法、行业规则及例外时，核对官方原文、施行时间、适用对象、过渡规定及有依据的相反解释。核验结果用于出题、考点和标答，保留可追溯来源；题面不附作者检索笔记、规则讲解、搜索链接或答案依据清单。
- 原始资料中的法律内容和业务条款保持完整。

- 复杂、少见规则可以考；标答须由可见事实、明确模拟条件及经核实的适用法律支持，存在实质争议时保留成立条件。是否要求作答者另行联网取得资料，按本次实际工具能力确定；作者能检索不等于作答者能取得未提供的特定资料。

### 可见输入与载体完整性

- 按本次实际输入形式使用修订、批注、表格差异或撤销记录，关键内容须保留来源、顺序及对应关系；仅传文本时不能考未传入的图像信息。作者新增的模拟记录写入题面，不能只保存在本地文件中。
- 保留真实明细和汇总的冲突，不拆坏表格、不删除关键字段、不人为制造提取遗漏。

### 时点与计算条件

- 区分事件发生、证据形成、取得和业务决策时点。明确任务是当时决策还是事后回溯，不用后取得的信息证明当时已经知悉；按相关行为时点确定适用法律。

- 保留决定结果的计算端点、精度和有效约定。内部测算假设与依法可主张金额分别表述；模拟政策或计算约定不当然改变法定责任或对外权利，不用“模拟设定”掩盖法律冲突。

- 本题所选场景确需处理多次付款、且材料允许相应构造时，至少安排一笔抵充顺序或计息基数未约定或仅部分约定的付款，由作答者结合可见事实与适用法律求解；保留原材料已有的有效约定、日历、端点及舍入条件，不为加难删改。其他场景不为套用该机制新增付款或改造业务关系。

- 本场景时点已可取得的有权文书所确定的生效日或状态须纳入判断，不能为了拉长日期链弃用它；后形成或后取得的文书不作为较早场景的已知依据。确需计算时，由作者用工具复核起止日是否计入、顺延规则、利率分段、精度与舍入方式；题目交代已有有效约定及必要的模拟条件、日历、计算端点和精度；待考的法定抵充顺序、计息基数和规则适用由作答者判断，不补写成约定。
- 法律上存在合理分支的保留分支。

## 充分展开工作

### 从复核记录到办理选择

先核对本题要求的是历史事实复原、当前办理还是方案决策。若材料中的主文摘抄、常见法律原则及“调卷后再定”已经足以完成主要工作，就检查还有哪些有实际用途的选择尚未展开：不同履行或处分方式的权利后果、受偿与成本的区别、对方可接受条件、保留与放弃的范围、权限变化后的可签文本等。按材料与职责选择适用者，不为集齐机制拼接无关工作，也不强求每题转成交易题。

对用于加压的业务提案分别求解：现有条件下能做什么、缺哪项决定性条件、改变该条件后结果怎样变化。条件已足够时必须形成具体结果；条件确实未知时，给出参数、可接受范围或互斥分支，并落实已可办理部分，不能靠泛泛“建议核实”完成整题。临界值和方案比较只有影响真实选择时才设置。

需要模拟补充时，提供可判断的记录而不是宣布法律效果。例如给出不同主体的收款、转付、授权或提议及发生顺序，让作答者判断是否构成清偿、处分或新的办理条件；不要直接写成“此笔无效”“不得抵扣”再把复述作为难点。原卷已由有权文书确认的事实和状态仍须保留；模拟条件不能推翻既判内容或补写脱敏值。

### 核心工作与模拟分支

先选出材料与所选场景委托中真正需要解决的专业问题，并明确各自成果：取舍什么证据、确定什么权利或责任、选择什么程序、形成什么可执行安排。不能因原卷复杂就假定题目复杂。以所选场景的办理时点确定已知事实和待求事项：该时点已生效裁判确定的争议，不强迫作答者推翻；卷内后续裁判不使此前有材料依据的接案、应诉或庭审场景失去选题资格，也不把其结果提前交给较早场景使用。

充分展开材料支持且所选场景委托需要的独立专业工作，核对各项依据、待求判断和具体用途。范围内各对象须有可核验的处理结果，必要时呈现分项依据、计算及差异，并落实为本方可使用的判断、文本或办理安排。用途可以是历史复核、风险排除、独立争点处理或办理决策，不要求每项都改变最终方案。共用依据可合并说明，独立争点仍须处理；允许并列任务，不强求串成一条链，也不规定每题必须有财产处置、和解或担保。

新增模拟前检查它会保留、改变还是消除哪些待考条件：

- 用公开的原始记录或业务提案补足可求解事实，让作答者确定效力和后果；不以作者汇总直接宣布待考的同源关系、清偿效力或办理路径。
- 如果真实委托确需采用已确认底账、已核实条件或独立敏感性测算，保留并明确其用途。它们是输入，不证明原卷争议已经解决；另有争议必须在其自身的专业成果中得到处理，不能用测算正确替代处理正确。
- 如果模拟把核心争议全部设为已解决，重新选择本题真正待求的专业问题，或改变模拟设计。不要保留一串失去实际用途的原卷考点，再增加现金差额和条款复述凑难度。
- 条件变化的难度取决于是否需要新的判断：数值或日期跨越阈值，也可能改变约束、可行方案或办理结果；需据此重新求解。仅重复同一机制的代入计算，不能自动算作新难点。

需要增强工作之间的关联时，以真实业务约束或充分公开的模拟事实为依据，不修改既判事实、不创造隐含条件，也不设置“一处错、后续全零”的连带规则。

### 让必要判断真正相互作用

按本案材料选择适用方式，不要求每题集齐，也不强迫原本独立的工作串联：

- **证据关联**：明确待判断的是哪一主体、事件、期间或权利。检查作答者是否需要先用一组记录确定对应关系，再结合另一组记录判断证明范围或法律后果。若任一摘要已经给出完整结论，多份附件本身不构成关联难点。保留足够的身份、时间、交易或版本线索，不能靠猜测把记录连起来。
- **共同约束**：方案涉及同一资金、标的、期限、审批权限或履行前提时，检查各项安排能否同时成立。不能把同一资源重复用于互斥安排，也不能逐项通过就断言整体可办。提供必要的资源边界与条件，由作答者选择顺序、范围和替代安排；没有真实约束时不硬造资源争夺。
- **方案取舍**：备选路径须在权利后果、成本、时机、风险或实施条件上有实质差别。根据委托明确必须满足的条件及选择目标；没有统一优先顺序时，接受有依据的权衡和条件化建议，不暗设作者偏好的唯一最优方案。仅换金额或名称的选项不自动增加判断深度。
- **变化后重选**：采用新事件时，检查它是否改变可行范围、前提、顺序或路径选择；让作答者说明原安排哪些仍成立、哪些失效，并落实到受影响成果。允许重新核算，但不能只用旧方案换数字就声称增加了新的专业判断。

在作者内部用“可见依据—待求判断—受影响结果”核对选定难点，可沿用思路与标答，不新增表格或作答字段。题面要求作答者给出处理结论、说明决定性依据并形成办理成果，不提前提供这些答案；不要求展示内部思维、写更长推理过程或按作者顺序执行。

按以下原则内部审核，不将其变成统一题面章节或每题必选机制：

- 材料关系决定难点：从现有记录的差异、缺口及证明范围确定需要解决的问题；保留足以判断的原始线索，让作答者自行发现关系并选择依据。材料缺口确实无法消除时，接受有依据的条件结论，不把猜测设为唯一答案。
- 判断影响实际处理：检查证据取舍或规则选择会改变哪个金额、办理范围、方案条件或文书内容。存在影响时让成果落实该结果；有业务价值的独立核查、反驳和风险排除仍保留，不为串联而虚构依赖。
- 成果能够实际使用：按本次委托检查接收人取得成果后能否完成相应决定或办理。仅列风险或通用建议不足以替代本应完成的处理；权限或材料确有限制时，交付明确的条件、边界和可执行的后续安排。

明细覆盖由业务完整性决定，后续变化由新的办理需要决定，不把扩量或新增事件设为固定补丁。题面按本案触发事项、委托关系和成果用途自然组织，只交代必要输入、工作范围与交付要求，不照抄上述审核口令或列出作者发现的争点。调整表达时逐项保留专业工作、条件和完整成果，不以减少要求换取自然语气。跨题比较实质任务与组织方式，不因使用标题、表格或正式文书体例就认定模板化。

对拟考的关联再做一次检查：暂不使用某组决定性记录，结论是否仍能从其他合法依据得出？若能，承认替代依据，不强制引用该组记录；若不能，说明缺少它会使哪个判断无法确定。此检查只在作者内部进行，正式输入仍完整保留，不通过删件、拆坏表格或移走关键条件加难。

### 题面提示与输入充分性

- 对主要考点逐一核对三处：题面是否直接给出该结论；作答者需要跨哪些记录或规则才能得到它；错误处理会改变什么实际结果。题面已经确认的日期、款项性质、对应关系或计算方法，可作为后续工作的输入，不再冒充待推断的同一难点。
- 纯复制、按指定公式代入仍可合理覆盖基础工作，但不能支撑主要挑战。

- 题面可指定要交付的成果、覆盖范围及说明依据，不逐条提示哪份材料有错、哪些付款无效或哪条规则应当优先。作者研究所得的法律讲解不默认写入题面；业务必要约定、端点和可求解条件不能删去。
- 撤去提示后重新求解；若裁决依据随之缺失，就补足事实输入或保留合法分支，不以信息残缺加难。

先研究材料和法律，再构造题目；不要先套“意见＋底账＋清单”后挑几项容易摘抄的事实填空。明确布置逐项回应、全面覆盖、反驳及实际文书；涉及数值、期间或多种路径时，加入具体计算与方案求解，避免“分析材料、提出建议”成为全部任务。

### 成果与待审提案

- 把工作量放在真实交接上：先确定本题的决策、复核、执行、对外沟通及条件变化分别由谁处理、需要什么内容，再安排对应成果。签批结论、分项底账、执行指令、可签署文本或修订结果只是可选形式；各项实质配套成果均须有实际用途，数量随独立工作确定，不把同一意见换标题重复提交。候选形式不能替代场景所需的正式文书正文。
- 各成果按自己的对象范围使用已核实的事实、余额和条件；一处变化应落实到所有受影响的成果。

- 有待审提案时，说明提出者希望获得的实际利益：它可以省时、提前结案或降低表面付款额，却遗漏决定结果的条件。要求本方律师／法务在职责内判断能接受、修正或阻断什么，并形成相应文本；围绕本场景实际涉及的请求、证据或方法提出有材料依据的不同解释，并要求说明采纳理由和处理结果。
- 不要直接问“哪项错误”或列出全部陷阱。

### 连续变化、授权与修订

- 连续变化只在本案确有需要重新判断的专业工作时采用，不作为材料不足或加深难度的默认补丁。设计前反查：新增事件形成什么独立专业判断，为什么当前委托需要分两次办理；如果只是再次核算、重写原意见或补足成果数量，取消该新增事件，回到原材料深挖争点。单一时点的任务同样可以满足完整度和难度，不因缺少第二阶段判为不足。采用时可改变适用条件、授权范围、责任结构或程序路径。作者反向核对：只替换这一条件时，哪些结论应变化、哪些应保持？例如明确披露的模拟授权仅新增某项减免处分权限，要求判断本次可签文本及其范围，并继续按原履行记录核对余额；不能把新增权限扩展到其他标的或当作新的收款事实。
- 示例只提供构造方式，具体效力按本题事实与法律重新核实；仅换数字不冒充新的法律难点。

- 授权类任务落实到可签文本：要求在具体授权范围内确定对象、金额、到账条件、权利释放时点及违约后果。题面已明确宣布某项处分不在授权范围时，单纯复述“无权减免或代收”不单独设考点；将专业工作展开为可接受条款、必要修订或取得授权后的办理安排。
- 仍需判断授权含义、效力或适用范围的独立争点可以设项。

- 题面明确布置修订本角色受影响的文书、结论或办理安排，并交代未受影响部分。接受完整修订稿或明确的替换位置、范围与正文；初稿、历史账和对比说明可以保留旧值，当前有效成果不得互相矛盾。
- 不要求重复提交未变化内容，也不把同一判断在多个成果中的落实当作多个独立难点。

### 补充输入与核验

- 可补充明确披露的模拟报价、预算、测算时点、履行事件、备选条款及变化情景，以展开核算和方案求解。原卷事实与模拟条件分别表述；脱敏数值可用符号、关系式和区间处理。

- 保留文书原始结构、相互引用、不同口径及背景信息，避免将输入先整理成正确答案表。使用工具研究、核算和复核，不预设处理速度或固定步骤。

## 成稿

### 快捷路径检查

完整阅读附件后，按委托范围确定须分别处理、共同处理、排除或暂不能确定的对象，核对有无漏项或重复。影响结果的材料缺口须说明其覆盖范围及后果，不能把提取或传输故障当成专业难点。再确定哪些记录须关联、哪些结果须计算或比较、哪些成果须相互核验；保留来源、版本和对应线索，不提前把待判断关系整理成答案。不要求每份附件单独形成成果，也不要求每题集齐清洗、计算和自查等工序。

对照委托范围检查：总体意见、代表性样本或通用清单是否替代了本应完成的逐项工作；仅通读摘要、复述原则或把同一判断扩写为多份文书，是否已能完成主要交付。若能绕过必要工作，回到材料支持的逐对象处理、跨记录关联、独立核算、方案求解或变化后的核验，补足遗漏的独立结果；不要求集齐机制或串成单一链条。多个成果共用结论是正常的，但重复呈现本身不增加执行复杂度。

将工作要求写具体：核对哪些记录及差异，依据哪些材料作出判断，计算哪些金额或期限，以及各份成果中哪些结论必须一致。只选本题适用的工作，不要求每题都有计算或条件变化。允许作答者自行选择工具和处理顺序，不规定步数或耗时，不用重复操作、无关材料或扩写凑工作量。实测按[执行复杂度与实测证据](评分与难度验证.md#执行复杂度与实测证据)记录。

### 内容与表达核对

本文件的研究、求解与核对顺序是作者内部流程，不是题面或答案的固定章节顺序。成稿按[表述组合](../assets/题目模版.md#独立使用与组合规则)选择组织；组合可以影响规则允许范围内的新题设计，但不能覆盖材料依据或专业要求。

把工作要求写入题面，把求解结果完整写入标准答案，从不同专业结果提炼考点。作答思路说明依据取舍、规则适用及主要争议，不把任务简化成事实复述。

核对材料、判断和成果是否对应：哪些可见材料或明确模拟条件形成当前业务约束，作答者须据此作出哪些独立判断，成果交给谁后能执行什么。如果抽掉与本案有关的材料、约束和角色立场，题目仍可用同一套泛泛意见完成，就重新设计这些内容的作用；不靠增加身份称谓、无关附件、文书名称或收益说法证明价值和难度。保留业务中实际需要但不改变最终建议的核查、反驳、核算和交接工作。

从考点和标答逐项找出应由作答者求出的结论，再检查题面及新增模拟记录是否直接断言交易对应关系、效力、规则选择或推算结果。把作者提前给出的判断改为足以裁决的事实记录；原件已确定的事实、有效约定及唯一求解所需条件完整保留。修改后仅凭作答者可见材料重新求解，仍有合理分歧时保留成立分支，不用缺失信息制造难度。工作与成果的布置按[题目格式与交付](题目格式与交付.md)核对。

按[题目格式与交付](题目格式与交付.md)完成题目包。案例的结构可迁移，案例结论按当前材料重新求解。
