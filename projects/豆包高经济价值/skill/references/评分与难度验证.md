# 复合 R、评分与难度验证

用于编制 rubric、思路、标答及审查已有反馈。标准先于答案冻结；难度不足通过改题解决，正确完成任务始终应得满分。

## 考点

每项只评价一个复合专业结果，内部多个判断共同决定其成立与可用性，可前后依赖或共同约束。依据核心结论、决定性依据与成果落实判断成立或不成立；次要错漏未改变结果和实际用途时仍可成立。完整要求用于引导充分处理，不把列举的每个说明都变成独立失败开关。不把简单核查堆成得分点，不把无关问题或整案成果捆成一条。

各条等权，结构化旧契约保留max_score=1；未触发整体失效时，题目百分制得分=成立条数÷总条数×100。判据正文不写“得1/得0”或重复计分尾句。条数由完整、去重的专业结果决定，无固定下限或配额。

每条R定稿前检查其结果边界：若一部分正确仍可独立交给接收人使用，另一部分错误只影响另一个独立用途，应分别评价；共同决定同一具体办理决定的证据、条件及正文保留复合评价。不能用“同案”“同一份意见”或统一总标题把独立工作塞入一条。判据保留决定性依据、成立条件、可接受替代及具体失败影响；重复背景与通用说明删去，必要业务条件不减。完整性须落实到每项业务材料及阶段成果，不能把空文件、摘要或未来制作承诺判为已完成。

#### 按本题推导触发条件

承接设计方法中已核清的核心成果成立基础与失效范围，以下方向仅用于查漏，不是固定五条否决项，也不要求每题集齐。依据本题委托方、权限、核心决策和成果用途，将附件及题面支持的风险写成具体对象、行为及后果；不得为套入某类风险增加无关任务或在评分阶段另造失败条件。

| 审查方向 | 形成触发条件的实质错误 | 必须保留的边界 |
| --- | --- | --- |
| 服务立场与权限 | 最终成果服务了错误主体，或超越授权处分本方核心权利，实质背离本次委托 | 如实揭示本方弱点、承认已被充分证明的不利事实、提出合法止损方案，不等于立场错误 |
| 事实基础与采信 | 把无材料支持的关键事实、事件不存在或对方未经证实的单方说法当作已确定事实，据此作出损害本方核心权利的承认、扣减、放弃或办理安排 | 附件未记载不等于事实不存在；有材料和适用证明规则支持的推论及针对未决争议的条件备选分析，不按虚构处理。对方陈述须结合其性质、其他证据和证明规则评价，不能一概采信或排除 |
| 核心数据与事实可追溯 | 决定主要金额或办理路径的数据无法由所交付输入、口径及计算关系复算，或决定性事实无法对应允许附件中的原始记录，导致核心成果无法核验使用 | 核对整份答案及可取得文件；允许等价定位和计算方式，不要求特定页码、软件或重复引文。法律依据来源与案情来源分开；产物未提供不得直接推定作答者伪造 |
| 有效成果一致性 | 同一对象、时点和条件下，最终有效成果对核心主体、权利范围、金额、状态或办理动作给出不能并存的结论，使接收人无法确定应采用的处理 | 比较当前有效版本；清楚标识的历史稿、不同假设、条件备选及已纠正旧值不构成矛盾，局部笔误按实际影响处理 |
| 决定性法律推导 | 错用决定性规则，遗漏或颠倒必要构成要件、适用条件或例外，导致核心权利、责任或程序选择明显不能成立 | 判据写出本题适用规则要旨、事实对应及错误后果；有依据的解释分歧、合法替代和不影响结论的条号笔误不直接触发 |

每个选定情形须在 rubric 内形成完整判断链：具体错误行为 → 核对的答案／文件内容与附件或规则依据 → 对核心委托的实质破坏 → 全题归零后果（按本案自然表述，不复读统一尾句）。多个情形写清各自是否可独立触发；不得用“出现上述问题”等泛称代替触发边界，也不得要求五类同时发生才触发。足以破坏核心委托的单一严重错误可以触发；仅影响可分离的局部结果时，按对应考点处理。数量由本题风险决定，不设固定条数、固定组合或统一标题。

出题前逐一对照“该严重错误仍留在最终成果的答案”和“仅有相邻轻微错漏、合法替代或明确条件说明的答案”：前者应触发，后者不应误触发；完整正确解应全部避开。说不清具体证据和整体影响的条件，收回普通考点或重新设计，不以“严重”“不专业”等形容词扩大判零范围。评分须指出命中的预设条件、答案证据、相反依据及整体影响；不能从低分或工具次数反推触发。

### 从评价维度形成复合考点

先检查整题需要评价什么，再划分计分结果。以下是覆盖检查，不是固定三条考点、题面目录或每题必做的三类任务：

| 评价维度 | 核对的问题 | 纳入考点的条件 |
| --- | --- | --- |
| 数据与依据是否可信 | 对象是否完整、身份是否对应、记录是否重复、主张与认定是否分清、决定性来源能否回查 | 支撑本案结果；只有可独立使用且包含实质判断的数据成果才单独设项 |
| 专业处理是否成立 | 定性、规则及例外、证据取舍、期间金额与部分状态是否共同支持处理结果 | 按独立专业用途分项，保留同一结果必需的复合判断 |
| 成果能否用于后续工作 | 结论是否进入请求、方案或工具，使用边界及跨成果关系是否正确 | 检验新的应用判断或实际使用能力，不重复奖励或处罚前面的同一结论 |

把每项必要工作对应到“题面交办或业务必要性→决定性依据→专业结果→验收证据→失败影响”。先保证覆盖，再按下节划分 R。禁止先套参考案例的编号、法律主题或文件组合，再把本案细节塞入；多样性同样作用于考点的组织与表述。

### 设项与覆盖

1. 从完整标答识别题面已布置或完成委托必然需要的专业结果，逐一对应成果用途。考点条数完全由本案去重后的独立专业结果决定，不凑固定条数、不拆碎，也不把证明逻辑独立的事项硬捆成极少粗颗粒大条。
2. 分组同时看用途与判断联系。同案、同文书或同交付包不是合并理由；子条件可分别检查、可一对一错，也不是拆分理由。共同决定同一成果能否使用的条件保留在一条：同源债权、价款或费用的本金、一般利息、迟延履行加倍部分、诉讼／执行费勾稽及法定清偿抵充顺序（如法释〔2014〕8号第三、四条）共同决定同一核定表或同一请求范围时，必须合并为一条复合资金核定 R，严禁拆成3—5条常规分段算式 R 让下游凭“上游误差传递”白拿算式分；存在证明逻辑各自独立、服务不同下游文书或办理用途的多项实质审查、救济、质证、刑事控告或交易事项时应分别设 R，既不把多组无关明细硬捆进超长单条，也不把多项独立实质任务过度压成 ≤4 条总包 R（避免单条偶发通过即大幅拉高总分占比）。同一判断跨意见、底账、文书落实，不重复计分。
   冻结前试把一条内的结果分别判对、判错：若两部分各能独立使用，且无共同条件决定同一成果的可用性，应分别设项；若一方错误就使同一成果失效，保留复合判断。
3. 冻结前逐条件说明遗漏或错误会造成的具体后果：结论、范围、金额、程序、文本实质错误，或完成委托必需的依据无法核验。说不清的条件移出判分要求。区分决定结果的必要条件、可替代的证明方式和仅用于解释的背景；不把三者全部写成必须逐项复述的清单。直接影响本轮权利、抵扣或程序的历史事实仍须核验；接受表达凝练但内容充分的等价论证，不强求复述作者的历史叙述、顺序或全部记录。
4. **零送分条与高判别力边界**：每条独立 R 须同时绑定题面未提示的深层材料依据消歧或异常明细核准、适用规则裁决及在对应独立正式成果中的实际落实，并结合该项具体业务失效原因写出明确的成立与不成立二元边界（随具体失效后果自然组织措辞，防止部分给分，也不重复固定尾句）。**题面交办与判据验收必须严格双向对齐**：判据只验收题面已明确交办的任务及该成果在法律与实务上成立、可用所必需的实质条件，不设题面未要求的内部表数或拆分件数配额；只要数据范围完整闭合、决定性异常与冲突无遗漏、公式逻辑可复算且跨成果自洽，不同的内部表结构组织、不影响结论与核验效力的无争议记录归并方式，以及符合本方代理立场且有明确法律与材料依据的口径选择均予认可（仅在材料事实与适用法律唯一锁定结果时验收单一数值）。**以下情形不单独占条（一律并入其所服务的核心争议 R）**：①泛化“未核事项暂列待核＋拟核验函”；②明示无争议款项的简单加减；③拒绝明显违法主张的表态；④无争议沿革或直球法条摘录；⑤正式文书的体例合规、法规出处引注与通用办理交接；⑥自身不含独立材料消歧或规则裁决、仅承接上游结论或常规模板结构的衍生文本；⑦超过 1 条的综合载体／公式／版式验证项。无争议前置工作并入其直接支撑的争议决策 R；若整题主要由常规套用构成，回到任务设计深化，不靠重新捆绑压分。
5. 反查完整覆盖、计分去重与各条的判断边界。拆合按业务独立性与实质判断密度决定，不为凑固定条数或目标分数拆分、硬捆分组。

材料盘点、底账、复算、归纳、规则核验及成果一致性只在影响本题可用专业结果时纳入对应考点。多份材料、多步工作或多种载体不自动各占一条；同一口径跨成果不重复计分。跨成果不一致按具体影响判定，整体失效只适用本题预先明确的触发条件。多案归纳核对分析单位、样本范围、条件及反例；单案不强制套用统计标准。不得移植示例题的条数、阈值或具体失效情形。

### 一条 R 必须写清什么

采用[实质工作选择](出题设计方法.md#按材料展开实质工作)时，从已完成的具体成果反推判据：哪些内容须保留或调整、对实际意见应作何处理、对象结论如何满足共同约束、取舍如何落实为可用正文。只取本题适用内容，写明决定性依据、允许分支及错漏造成的使用影响；不把四类工作各设一分，也不以“完成审查／回应／修订”代替结果标准。原稿可依法采用、有依据地接受对方意见或存在不同合法安排时，不因未改稿、未反对或偏离作者偏好失分。上述具体判据须进入评分者可见的 criterion，不能让评分者自行读取本表或推测作者意图。

| 内容 | 写法 |
| --- | --- |
| 结果及任务依据 | 直接点明所验收的具体业务结论或成果能力及其在本次委托中的用途（严禁以“本条评价……”之类元话术起笔） |
| 必要判断及联系 | 哪些判断共同决定结果；允许的替代路径分别需要哪些条件 |
| 判定依据 | 所附分件脱敏卷宗中的决定性原始文书／记录及具体内容（直接点明具体原始文书名称及案号／日期／出具主体或统称“所附卷宗”，严禁写“附件1”“附件 1”“合并卷宗”、`材料-xxxx.docx` 哈希名或页码）；必要规则的要旨、时点和出处；涉及计算时给口径、精度和关键结果 |
| 成立条件 | 核心结论、决定性依据及成果可用性成立；条件分支与已知事实相容，非实质错漏不否定本项 |
| 不成立情形 | **明确二元失效边界**：结合本项具体业务失效原因明确写出成立与不成立边界（锚定决定结果成立的材料冲突、规则适用或核算条件，随业务后果自然表述；不省略否定边界，不重复固定尾句，也不把题面未要求的内部制表配额或非实质呈现差异设为失败开关） |
| 接受范围 | 实质等价证据、合法分支、不同措辞或组织方式；不得只认作者原句 |
| 依赖边界 | 存在共享前提时，指出本条新增的独立判断及与其他条的计分分界 |
| 验收证据 | 本条查答案正文或所交业务文件中的哪些实质内容；文件与操作条件按下节归属，不能每条重复附加 |

不要求每条都出现法律条号、算式或多个附件。定位信息供评分者核验，不自动成为答案必须逐字复述的义务；答案须提供题面要求且足以核查的决定性依据，不要求内部思维过程。

### 判分强度

- 只提术语、通用原则、风险方向，未完成本案的必要判断与成果，不通过。
- 按复合结果判断对错，不能仅因提及部分术语而判成立，也不能因不影响结果的次要错漏而判不成立；理由须指向具体业务影响。
- 不用附件或标答中的正确内容替答案补齐遗漏。可在整份答案中找到明确对应的内容时不强求重复书写，也不将引用定位差异当成实质遗漏。
- 结论碰巧正确但决定性依据错误，或分析正确而当前有效请求／条款无条件扩大、相互矛盾，本条不通过。明确注明的历史稿、条件备选和修订前后差异不误判为矛盾。
- 已能确定的结果不能以“建议核实”替代；确实缺失条件时，正确的分支、边界及可办部分是完整答案，不因没有猜中未知事实扣分。
- 表达凝练须仍完整交付已要求的逐对象结果、决定性依据、必要计算、各阶段正文及实际文件；只给正确结论或摘要、让接收人补做核对或起草，不属于内容充分。选择不同合法路径、采用足够的等价证据，均按同一标准通过。未要求且不影响成果的条号、顺序、措辞、引用数量不设暗门槛。

### 共享前提与重复处罚

作答前划清计分归属，不能等看到答案后决定宽严：

- 同一判断在底账、意见、文书中落实，合为一个 R 的完整通过条件；不得重复计分。
- R₂确有独立的新判断且使用 R₁的结果时，在 R₂内写明它验收什么独立于上游的新增边缘凭证、规则选择、程序条件或文书正文要求。纯粹照搬上游错误数值、对象或状态不再单列扣分；但若下游未完成自身独立的新规则判断、未落实在对应文书具体请求中、或直接因依赖上游偷懒而跳过了本条的独立消歧／程序核对义务，仍按本条自身缺失判 0。上游误差传递仅适用于确有独立证明逻辑与下游用途的后续专业任务，严禁将同一债权的本息加倍部分与抵充顺序拆成多条算术 R 后用上游误差免责让下游白拿分。
- 若接受沿用上游值，必须事先写明条件式判据及适用范围，并记录“上游误差传递”，不声称整份成果数值正确。该错误若会改变本条规则选择、阈值或路径，不能笼统免除，应把不可分割的判断合为同一 R，或明确本条新增的独立核验义务。
- 不能既要求下游绝对正确的同一金额，又承诺不重复扣该上游错误。跨条重复的标准须在冻结前修正；独立新错误仍各按其条判0。

### 内容、文件和执行的归属

- 题面依本案委托角色与后续动作自然交代所需的可编辑文稿、动态公式底表或定版版式文件（严禁写入“逐页转为页面图像”“18MB/18,000,000字节”等内部评测术语）；凡需在 rubric 验收的文件载体、公式联动、版式或出处要求，均须与题面交办的业务目标一致。编制 rubric 时分别确定专业结论与实际使用能力的归属，不把文件生成要求复制到所有条目。
- 评价专业结论时，核对答案或可取得成果中的决定性依据、计算、正文和条件；缺少某种载体不自动抹去已可验证的其他专业结果。文书体例、法源引注与启用交接并入其承载的争议 R；题面已交办的分件可编辑交付、公式动态联动与版式跨件一致，既可并入核心结果 R 验收，也可在多文件强耦合时单设至多 1 条综合交付验证 R（不拆出多条形式保底项，也不设题面未要求的表数或件数配额）。已交办的载体与跨件能力按实证标准验收：①应独立使用的正式文件分别成件生成（擅自合并塞进单份合册或缺件不通过）；②要求动态公式联动的底表由活公式驱动重算，无静态硬编码覆盖派生结果，默认待核空值状态下无公式报错；③要求定版 PDF 的文件版面完整可读，无宽表截断、文字重叠或签章孤页；④各成果间的核心核定口径一致且符合材料与适用法律（存在有法律与材料依据的不同代理立场口径时，底表算清关系且正式成果主口径自洽即通过；核心基数或法定期间算错并跨件铺开的“错得一致”不通过）；仅列文件名、口头自述已完成或未执行脚本不通过。
- 共用生成、导出或读回义务只归入与其用途直接对应的结果。若构成独立的交接或复用成果，须结合本案对象对应、数据联动、全套定版版式或使用边界等实质判断设项；不设只验扩展名、下载链接或调用次数的简单分，也不强制每题脱离业务用途硬凑文件分。
- 题面要求成果使用与办理交接时，按本案实际动作核验文书、条件、主体、手续材料、期限及结果衔接中影响可用性的必要判断；各维度只取本案适用者，不以栏目齐全或通用流程叙述得分。与已有专业结果共用的判断纳入原条，确有独立用途和新增实质判断才另设复合条目；不得给每条重复附加完整流程门槛。判据须明确具体错漏如何导致无法办理、误用成果或遗漏必要后续动作，接受不同载体与等价合法安排。
- 相同文件缺失不得成为多个内容考点的同义失败理由。确有不同使用能力均无法实现时，逐项写清独立损失；缺少全部正文、数值或依据，仍按各条实际缺失处理。文件存在却内容错、链接错、公式断裂或当前成果互相矛盾，按实际影响归属，不因文件能打开而通过。
- 严重事实虚构、主体错配或规则错误先映射到受影响的复合结果；仅在本题预先写明的整体失效条件被证据确认时归零整题，否则按共享前提规则处理。

### 跨阶段原卷核改与联动试算的验收

本题涉及原卷内跨程序阶段文书穿透、在卷遗留文稿纠偏或真实争议情景联动时，按设计方法选定的真实卷宗业务链验收，严禁虚构卷外事件或把“保留双版本”“分两轮窗口”单独设为考点。

- 题面围绕所附真实分件卷宗交办跨阶段核查、纠偏与配套文书定稿；标答按独立命名的各份成果完整求出核定基数、争议分支结果及最终可用文本。rubric写清所附原始文书记录、证明范围、适用规则、关键结果或条件关系、受影响文书正文及使用状态，评分者无需读取Skill或猜测作者意图即可判定。
- 依独立用途及新增判断划分复合结果，不将全部跨阶段核改塞入共用文件分，也不按单份卷宗文书、日期或输出文件机械各拆一分。新设独立结果须有独立的证据评价、规则应用、请求或安排决定；沿用同一结论且无新判断的跨件同步并入对应条。分母随实际独立结果确定，不固定沿用旧题条数。
- 划清上游错误与下游独立判断错误：仅传递同一错误基数不重复处罚；误判另一份在卷凭证、错用后阶段程序规则、漏剔重复记载或修订未落实到正式文书正文，按事先写明的独立判断验收。共享前提的条件式判据按上节执行，不能用下游条目重复扣掉整个上游算术错误。
- 读取各独立命名成果文件及实际重算证据，检查记录能否追溯到在卷原始输入、公式派生结果与正式文书文本。对题面要求支持争议款项／时点备选试算的工作簿，预填静态常数、汇总范围漏行或必须手改结果格才变化，均不能冒充已实现的公式联动能力。验收的是业务依赖与公式逻辑，不规定特定软件或内部表结构。
- 合法替代、在卷历史文稿与本次正式定稿的区分、针对真实未决争议的条件备选方案不误判为冲突。当前有效正式成果混同在卷瑕疵旧稿、把未经证实的单方主张当既成事实或跨文件请求与核定结论矛盾，按实际影响归属；整体失效仍只执行该题预先明确的规则。

## 判分依据完整性

独立评分使用同版题面、rubric、题目冻结来源附件、匿名完整答案及评分提示词，不读取项目 Skill 或思路；标答默认不提供，显式校准政策另按冻结契约执行。rubric 必须自足，不写“符合标答”“见作者分析”或只给无法打开的链接。

规则判据包含足够的要旨、适用条件和出处，支持评分者核验，不复制整份标答。仅凭引文不能证明实际联网；轨迹不可得不推断未检索。内容正确性与工具执行事实分别核验。

题面要求实际文件或工具成果时，作者在相应 criterion 中只写正面的产物内容、公式联动与版式标准，以及“仅列文件名、口头自述、静态常数或未执行脚本不成立”的业务判分边界；**下表仅供本机评分执行器与评测复盘区分运行异常状态，严禁作者把表中的“评分端”“轨迹未传”“评测条件不满足”“不作为有效专业难度成绩”“纳入有效成绩均值”等内部流水线术语写进任何 rubric 条目**：

| 评测运行异常状态（仅评分执行器与复盘使用，禁入 rubric 正文） | 运行与复盘处理 |
| --- | --- |
| 必需能力可用，完整答案明确未做或现有证据证明未完成 | 按冻结判据判对应结果不成立；文件名、自述或未执行脚本不证明完成 |
| 产物或轨迹在评测传输环节缺失，无法确认完成情况 | 评分执行器报告具体证据缺口，保留可确认的内容判断；不推断未做或冒记通过 |
| 经运行配置或错误记录确认必需工具不可用、输入缺件或传输失败 | 评测复盘记为运行异常，不据本次低分充当专业难度证据 |
| 模型只声称没有工具，但实际能力和失败记录未核实 | 复盘核实运行配置，不单凭模型自述免除遗漏 |

证据不足不改为部分分、不删条目改分母；按本次报告契约保留争议和可确认结论，未解决前不宣称已取得有效总分。旧题已有的文字呈现约定按冻结契约处理，新要求不追溯加到旧题。Skill 不替代程序的状态处理或产物传递。

逐 R 评分须列：ID、0或1／1、答案原文位置或短引、各必要条件的满足情况、决定性未满足条件及依据。判0时说明该缺失按冻结判据如何影响本条结果或必要论证；不临时决定条件是否必要，不新增或豁免条件。未找到证据先查整份答案及明确引用，仍缺失则写“未找到”；不可编造引文。理由和分数一致，条目无遗漏或重复，最后核对通过数、条数及百分比。

rubric 与材料冲突、必要依据不足或合法路径被排除时，保留具体争议，不补造条件、不临时改分母、不以低分作为有效难度证据；按评分契约报告可确认结论与限制。

## 标准答案

按题面指定的各成果独立正式文件名逐件完成全部工作：确定核定结果、真实证据缺口下的条件分支、必要计算及可直接提交或签署的正式法律文书正文。分清在卷已证实事实、单方主张与待核缺口，分清不同程序阶段状态、测算总额与法定可请求范围，核对跨文件数据与条款的一致性。对合理替代路径说明条件；不把作者偏好的单一路径作为答案键。严禁将标准答案写成脱离独立文书命名的“出题人自撰审签结论正文”或围绕评分点的综述评注。

涉及跨阶段原卷穿透或前手文稿纠偏的题目，须按各独立命名成果完整写出纠偏后的正式可用文书、工作簿核定结构与争议情景试算结果，说明在卷后阶段凭证怎样推翻、修正或印证前阶段记录，不能以修改提纲或“据卷宗更新”替代；获准开展独立实物校准时，另行验证跨表公式联动及各独立命名文件能够直接使用。

沿设计阶段确定的核心成果成立基础，核对标答中的依据、推导与最终安排确实相互支持；用同一依据检验普通考点及整体失效条件，合理替代仍应通过。若标答与判据冲突，修正实际错误的一方，不为保住否决条款排除合法答案。上述核对留在作者自查，标答正文只呈现对应独立文件名的正式法律实务成果。

`reference_answer` 文本标答须严格以题面指定的各成果独立正式文件名分件标示并完整写出每份正式可用法律文书全文（含法定文书首部、当事人／致送机关、请求或结论、事实与理由、尾部及附项）、工作簿分表结构与字段口径、关键活公式写法、分项汇总与勾稽核对结果，以及存在冲突、重复、异常、待核缺口或口径调整的逐笔处理明细，不把“工作簿应包含”“生成后检查”等未来指令当已完成成果；所附卷宗中已明确记载且无争议的大批量同质原始流水或台账记录，在文本标答中按具体原始文书来源、筛选口径、笔数与分项小计归并引用，不逐行重抄原始长表（题面对作答者实际工作簿的全量明细处理要求不受影响）。普通出题由作者用计算脚本实算核验全部数值与公式闭环并直接输出 `result.json`，不在出题会话内制作配套 DOCX、XLSX、PDF 文件或调用办公软件转换、渲染读图；仅当专门获准制作独立实物校准样本时，才生成真实文件核验文件判据。未经授权不另发真实模型评测。

## 加压检查

冻结前逐 R 做内部检查，不另调用模型，也不把检查表发给作答者：

| 检查对象 | 应有结果；否则怎样改 |
| --- | --- |
| 完整正确标答内容 | 内容判据全部通过；失败则修正题面、标答或判据冲突。仅有文本不证明文件及执行条件通过 |
| 最简合法替代 | 同样通过；不能因表达凝练或不按作者顺序失分 |
| 只漏一个必要判断、其他均正确的近似答案 | 对应 R 不通过；若仍可正确完成成果，该条件并非必要，不能硬设失败 |
| 只复述题面或套常见原则的答案 | 未解决的复合结果不能通过；若已完成主要工作，应深化题目 |
| 局部判断正确但最终安排冲突的答案 | 明确矛盾及对应结果的影响；仅符合预先写明的整体失效条件时整题归零 |
| 捷径答卷（只读主文＋3次摘要搜索＋套现行通用法条＋泛用“待核实+附条件”＋单文件合册） | 接近 0 分（至少 85% 以上 R 不通过）；若能拿分超过 1 条，须立即排查送分 R |
| 中等勤勉表层答卷（已完成分件导出、常规重算与 10–15 次常规检索，但顺着主文／诉状表层口径推进，漏掉题面未提示的底层凭证硬冲突与隐蔽顺延） | **通过率严格低于 30%（单题硬上限严格低于 40 分）**；若因题面剧透分支、R 漏写明确二元失效边界或拆设无独立判断的文书体例／交接／衍生保底项导致预估得分 ≥ 30 分，必须在冻结前删去题面剧透提示、补齐二元失效边界并合并保底项 |
| 只有同一上游错误的答案 | 按预先划分的归属计分，不因重复出现造成多项同义失败 |
| 专业内容正确，仅缺共用文件或读回证据 | 按内容、文件与执行的预定归属处理，不把同一缺口扩成多项同义失败；证据未知与明确漏做分开 |
| 仅遗漏背景叙述或改用足够的等价证据 | 结果及必要论证仍成立时通过；否则判据把非必要表达当成了条件 |

隐含问题逐项反查可见依据和业务必要性；隐藏义务、原文没提供的事实及无关细节不能作为加难手段。评分者看不到思路和标答时仍能逐条判定，否则补齐 rubric 的必要判据。

获准实测时，先用同版完整正确解与真实产物做评分校准，再用合法替代及有明确单项缺口的对照答案核对通过边界。满分样本被误拒、等价解被误扣或同源错误被重复处罚，先定位判据、产物传递或评分误读；不据此继续加难。作者静态推演、产物检查和独立评分分别记录，未执行的环节保留为未验证。

## 扩展任务后的增量核对

先核对工作是否增加，再解释成绩和耗时。与获准旧版比较时，沿用相同计数口径：任务按独立业务用途计，复合考点按专业结果计，文件份数和工具调用不充当任务数。

- 作者内部对应旧有／新增任务、材料依据、实质处理、实际成果、考点覆盖及成果依赖。旧有难点、必要条件和成果不能被新增工作替换或稀释；新考点仍执行复合0/1验收。仅换表达时各条判定必须不变；增加独立考点后分母会变化，总分不能直接当作原题难度升降的证明。

## 执行复杂度与实测证据

本节只约束获准评测和结果解释，不授权调用模型或更改业务状态。

当前用户要求的内部验收目标为：**每道单题独立盲评有效得分均严格低于 40 分（`< 40` 分）、批次平均分低于 30 分（`< 30` 分）、可核实的有效作答步长严格高于 60 步（`> 60` 步），单题实际运行时长不设硬性下限但越高越好（通过全卷逐行台账、零提示边缘凭证遍历、跨时际深检与异构实质长文书实作自然推升至 35–45+ 分钟，三项分别记录；另同步对照外部平台公开合格线`≤50分，且≥50步或>40分钟`，两套口径不能混同）**。轮次不等于文中步骤、脚本内部循环或工具调用数量；无对应轨迹记未验证。排队、无意义等待、技术故障和重复返工不能冒充必要工作量；**严禁把目标分数、步数要求或评测指标泄入题面、rubric 或标答**。

未达到时先定位原因：材料或产物缺失先修输入与交付；错误或表层答案仍得 ≥30–40 分时重点检查三处病灶——①题面是否喂饭式剧透了待求法律路径、修法顺延节点或前手草稿错漏类型；②各条 R 是否漏写了锚定深层依据的明确二元失效边界；③是否把文书体例、法源引注、通用交接或无独立判断的衍生文本拆成了保底送分项；完整正确答案得高分则深化材料支持的边缘消歧与多约束实质任务；执行步长 ≤60 步或单题耗时偏短则检查是否以多份同质短申请充当主要交付而缺少有效明细核准与实质长文书、或题面提前点破方向省去了排雷迭代。禁止改变合法答案标准压分、设题面未交办的暗桩、强制低效调用或编造新事实。修改题面、材料或判据后，在新会话重新作答和评分，旧结果不代表新题达标。目标分数、模型身份和既往成绩不进入作答或评分输入。

1. **先冻结**：确定题面、附件、rubric、标答和评测配置；开发样本与独立验收样本分开，样本范围、重复次数、聚合方式和异常处理在看答案前确定。
2. **独立作答**：新会话只接收题面和允许附件，保持指定模型、推理配置、工具、输入输出限制一致；保存完整答案、成果及终止状态。请求模型与可核实返回模型分开记录。
3. **独立评分**：按冻结 rubric 逐条判定，保留原始理由与证据；核对0/1、条目完整性、合计和矛盾。结构有效不证明评分准确，实质争议须单独处理并留痕。
4. **解释结果**：分别识别记录漏读／对应错误、规则误判、条件分支遗漏、共同约束冲突、成果未落实、纯算术错误及评分争议。正确核心工作与旁支遗漏分开报告，不能用总分代替分析。
5. **比较与修订**：不同材料、不同 rubric 或旧加权／部分分结果不能直接解释为新方法的因果效果，旧分不换算为新0/1。修改后对新版本重新作答评分，不继承旧结果。
6. **验收与留痕**：先算每次作答的通过率，再按预定方式聚合；条数不同不能直接汇总所有 R 让条数多的题主导平均分。保存所有预定样本与重复结果，不挑最低分。查看过并据以调参的验收样本转作开发材料，下次改用未见样本。

输入缺件、传输失败、技术截断或调用故障保留为异常，不填0拉低均值；只报有效样本均值时同时报预定总数、有效数、异常原因及未完成的验收范围。回答篇幅较少或完整答案漏做不自动等于技术截断。必要材料、完整输出或评分争议未核实，不宣称难度达标。

实测还须保留题包与配置版本、答案和逐项判据、运行起止及可得轨迹。排队、工具次数、执行轮数、推理token和耗时分别记录，不互相换算；外部平台验收另按当次规则，不能由本地自查代替。未实测就报告未实测，不预测或保证分数。
