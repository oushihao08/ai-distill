# 复合 R、评分与难度验证

用于编制 rubric、思路、标答及审查已有反馈。标准先于答案冻结；难度不足通过改题解决，正确完成任务始终应得满分。

## 考点

每项只评价一个复合专业结果，内部多个判断共同决定其成立与可用性，可前后依赖或共同约束。依据核心结论、决定性依据与成果落实判断成立或不成立；次要错漏未改变结果和实际用途时仍可成立。完整要求用于引导充分处理，不把列举的每个说明都变成独立失败开关。不把简单核查堆成得分点，不把无关问题或整案成果捆成一条。

各条等权，结构化旧契约保留max_score=1；未触发整体失效时，题目百分制得分=成立条数÷总条数×100。判据正文不写“得1/得0”或重复计分尾句。条数由完整、去重的专业结果决定，无固定下限或配额。

#### 按本题推导触发条件

承接设计方法中已核清的核心成果成立基础与失效范围，以下方向仅用于查漏，不是固定五条否决项，也不要求每题集齐。依据本题委托方、权限、核心决策和成果用途，将附件及题面支持的风险写成具体对象、行为及后果；不得为套入某类风险增加无关任务或在评分阶段另造失败条件。

| 审查方向 | 形成触发条件的实质错误 | 必须保留的边界 |
| --- | --- | --- |
| 服务立场与权限 | 最终成果服务了错误主体，或超越授权处分本方核心权利，实质背离本次委托 | 如实揭示本方弱点、承认已被充分证明的不利事实、提出合法止损方案，不等于立场错误 |
| 事实基础与采信 | 把无材料支持的关键事实、事件不存在或对方未经证实的单方说法当作已确定事实，据此作出损害本方核心权利的承认、扣减、放弃或办理安排 | 附件未记载不等于事实不存在；有材料和适用证明规则支持的推论、明确披露的模拟条件及未冒充事实的条件分析，不按虚构处理。对方陈述须结合其性质、其他证据和证明规则评价，不能一概采信或排除 |
| 核心数据与事实可追溯 | 决定主要金额或办理路径的数据无法由所交付输入、口径及计算关系复算，或决定性事实无法对应允许附件中的原始记录，导致核心成果无法核验使用 | 核对整份答案及可取得文件；允许等价定位和计算方式，不要求特定页码、软件或重复引文。法律依据来源与案情来源分开；评分端缺件不得推定作答者无依据 |
| 有效成果一致性 | 同一对象、时点和条件下，最终有效成果对核心主体、权利范围、金额、状态或办理动作给出不能并存的结论，使接收人无法确定应采用的处理 | 比较当前有效版本；清楚标识的历史稿、不同假设、条件备选及已纠正旧值不构成矛盾，局部笔误按实际影响处理 |
| 决定性法律推导 | 错用决定性规则，遗漏或颠倒必要构成要件、适用条件或例外，导致核心权利、责任或程序选择明显不能成立 | 判据写出本题适用规则要旨、事实对应及错误后果；有依据的解释分歧、合法替代和不影响结论的条号笔误不直接触发 |

每个选定情形须在 rubric 内形成完整判断链：具体错误行为 → 核对的答案／文件内容与附件或规则依据 → 对核心委托的实质破坏 → 整题最终得分归零。多个情形写清各自是否可独立触发；不得用“出现上述问题”等泛称代替触发边界，也不得要求五类同时发生才触发。足以破坏核心委托的单一严重错误可以触发；仅影响可分离的局部结果时，按对应考点处理。数量由本题风险决定，不设固定条数、固定组合或统一标题。

出题前逐一对照“该严重错误仍留在最终成果的答案”和“仅有相邻轻微错漏、合法替代或明确条件说明的答案”：前者应触发，后者不应误触发；完整正确解应全部避开。说不清具体证据和整体影响的条件，收回普通考点或重新设计，不以“严重”“不专业”等形容词扩大判零范围。评分须指出命中的预设条件、答案证据、相反依据及整体影响；不能从低分或工具次数反推触发。

### 从评价维度形成复合考点

先检查整题需要评价什么，再划分计分结果。以下是覆盖检查，不是固定三条考点、题面目录或每题必做的三类任务：

| 评价维度 | 核对的问题 | 纳入考点的条件 |
| --- | --- | --- |
| 数据与依据是否可信 | 对象是否完整、身份是否对应、记录是否重复、主张与认定是否分清、决定性来源能否回查 | 支撑本案结果；只有可独立使用且包含实质判断的数据成果才单独设项 |
| 专业处理是否成立 | 定性、规则及例外、证据取舍、期间金额与部分状态是否共同支持处理结果 | 按独立专业用途分项，保留同一结果必需的复合判断 |
| 成果能否用于后续工作 | 结论是否进入请求、方案或工具，使用边界及跨成果关系是否正确 | 检验新的应用判断或实际使用能力，不重复奖励或处罚前面的同一结论 |

把每项必要工作对应到“题面交办或业务必要性→决定性依据→专业结果→验收证据→失败影响”。先保证覆盖，再按下节划分 R。禁止先套参考案例的编号、法律主题或文件组合，再把本案细节塞入；多样性同样作用于考点的组织与表述。

### 设项与覆盖

1. 从完整标答识别题面已布置或完成委托必然需要的专业结果，逐一对应成果用途。
2. 分组同时看用途与判断联系。同案、同文书或同交付包不是合并理由；子条件可分别检查、可一对一错，也不是拆分理由。共同决定同一成果能否使用的条件保留在一条；另有独立用途且包含新的实质判断的结果分别设 R。同一判断跨意见、底账、文书落实，不重复计分。
   冻结前试把一条内的结果分别判对、判错：若两部分各能独立使用，且无共同条件决定同一成果的可用性，应分别设项；若一方错误就使同一成果失效，保留复合判断。
3. 冻结前逐条件说明遗漏或错误会造成的具体后果：结论、范围、金额、程序、文本实质错误，或完成委托必需的依据无法核验。说不清的条件移出判分要求。区分决定结果的必要条件、可替代的证明方式和仅用于解释的背景；不把三者全部写成必须逐项复述的清单。直接影响本轮权利、抵扣或程序的历史事实仍须核验；接受表达凝练但内容充分的等价论证，不强求复述作者的历史叙述、顺序或全部记录。
4. 基础日期、主体、数字和格式纳入其直接支撑的结果，不因容易而删除必要工作，也不另设只查通用授权、提示语或栏目是否齐全的简单项。拆分后每条仍须有本案实质判断；若通用模板即可完成，回到任务设计，不靠重新捆绑压分。
5. 反查完整覆盖、计分去重与各条的判断边界。拆合会改变分母及业务结果的相对份额，不为达到目标条数或分数调整分组。

材料盘点、底账、复算、归纳、规则核验及成果一致性只在影响本题可用专业结果时纳入对应考点。多份材料、多步工作或多种载体不自动各占一条；同一口径跨成果不重复计分。跨成果不一致按具体影响判定，整体失效只适用本题预先明确的触发条件。多案归纳核对分析单位、样本范围、条件及反例；单案不强制套用统计标准。不得移植示例题的条数、阈值或具体失效情形。

### 一条 R 必须写清什么

采用[实质工作选择](出题设计方法.md#按材料展开实质工作)时，从已完成的具体成果反推判据：哪些内容须保留或调整、对实际意见应作何处理、对象结论如何满足共同约束、取舍如何落实为可用正文。只取本题适用内容，写明决定性依据、允许分支及错漏造成的使用影响；不把四类工作各设一分，也不以“完成审查／回应／修订”代替结果标准。原稿可依法采用、有依据地接受对方意见或存在不同合法安排时，不因未改稿、未反对或偏离作者偏好失分。上述具体判据须进入评分者可见的 criterion，不能让评分者自行读取本表或推测作者意图。

| 内容 | 写法 |
| --- | --- |
| 结果及任务依据 | 本条评价哪个具体成果，为什么属于本次委托 |
| 必要判断及联系 | 哪些判断共同决定结果；允许的替代路径分别需要哪些条件 |
| 判定依据 | 附件1中的决定性记录及具体内容，不写页码；必要规则的要旨、时点和出处；涉及计算时给口径、精度和关键结果 |
| 成立条件 | 核心结论、决定性依据及成果可用性成立；条件分支与已知事实相容，非实质错漏不否定本项 |
| 不成立情形 | 哪个决定性判断错误、缺失或与最终成果矛盾，以及它如何使本条结果或必要依据不成立；不只写“分析不足” |
| 接受范围 | 实质等价证据、合法分支、不同措辞或组织方式；不得只认作者原句 |
| 依赖边界 | 存在共享前提时，指出本条新增的独立判断及与其他条的计分分界 |
| 验收证据 | 本条查答案正文、文件中的哪些内容或哪项执行记录；文件与操作条件按下节归属，不能每条重复附加 |

不要求每条都出现法律条号、算式或多个附件。定位信息供评分者核验，不自动成为答案必须逐字复述的义务；答案须提供题面要求且足以核查的决定性依据，不要求内部思维过程。

### 判分强度

- 只提术语、通用原则、风险方向，未完成本案的必要判断与成果，不通过。
- 按复合结果判断对错，不能仅因提及部分术语而判成立，也不能因不影响结果的次要错漏而判不成立；理由须指向具体业务影响。
- 不用附件或标答中的正确内容替答案补齐遗漏。可在整份答案中找到明确对应的内容时不强求重复书写，也不将引用定位差异当成实质遗漏。
- 结论碰巧正确但决定性依据错误，或分析正确而当前有效请求／条款无条件扩大、相互矛盾，本条不通过。明确注明的历史稿、条件备选和修订前后差异不误判为矛盾。
- 已能确定的结果不能以“建议核实”替代；确实缺失条件时，正确的分支、边界及可办部分是完整答案，不因没有猜中未知事实扣分。
- 表达凝练但内容充分、选择不同合法路径、采用足够的等价证据，均按同一标准通过。未要求且不影响成果的条号、顺序、措辞、引用数量不设暗门槛。

### 共享前提与重复处罚

作答前划清计分归属，不能等看到答案后决定宽严：

- 同一判断在底账、意见、文书中落实，合为一个 R 的完整通过条件；不得重复计分。
- R₂确有独立的新判断且使用 R₁的结果时，在 R₂内写明它评价什么。纯粹照搬上游错误数值、对象或状态不再单列扣分；只检查新规则的选择、条件应用及相应成果是否正确。
- 若接受沿用上游值，必须事先写明条件式判据及适用范围，并记录“上游误差传递”，不声称整份成果数值正确。该错误若会改变本条规则选择、阈值或路径，不能笼统免除，应把不可分割的判断合为同一 R，或明确本条新增的独立核验义务。
- 不能既要求下游绝对正确的同一金额，又承诺不重复扣该上游错误。跨条重复的标准须在冻结前修正；独立新错误仍各按其条判0。

### 内容、文件和执行的归属

- 题面保留有业务用途的实际文件、检索、计算和读回要求。编制 rubric 时，分别确定哪些结果是专业结论，哪些是可更新、可编辑、可提交等实际使用能力；不把“必须生成 DOCX/XLSX 并读回”复制到所有条目。
- 评价专业结论时，核对答案或可取得成果中的决定性依据、计算、正文和条件；缺少某种载体不自动抹去已可验证的其他专业结果。评价可更新工作簿等成果时，实际文件、输入与公式关系、适用范围及修改后结果共同决定其可用性，文字算式不能冒充已交付的工作簿。
- 共用生成、导出或读回义务只归入与其用途直接对应的结果。若构成独立的交接或复用成果，须结合本案对象对应、数据联动、版本或使用边界等实质判断设项；不设只验扩展名、下载链接或调用次数的简单分，也不强制每题另设“文件分”。
- 题面要求成果使用与办理交接时，按本案实际动作核验文书、条件、主体、手续材料、期限及结果衔接中影响可用性的必要判断；各维度只取本案适用者，不以栏目齐全或通用流程叙述得分。与已有专业结果共用的判断纳入原条，确有独立用途和新增实质判断才另设复合条目；不得给每条重复附加完整流程门槛。判据须明确具体错漏如何导致无法办理、误用成果或遗漏必要后续动作，接受不同载体与等价合法安排。
- 相同文件缺失不得成为多个内容考点的同义失败理由。确有不同使用能力均无法实现时，逐项写清独立损失；缺少全部正文、数值或依据，仍按各条实际缺失处理。文件存在却内容错、链接错、公式断裂或当前成果互相矛盾，按实际影响归属，不因文件能打开而通过。
- 严重事实虚构、主体错配或规则错误先映射到受影响的复合结果；仅在本题预先写明的整体失效条件被证据确认时归零整题，否则按共享前提规则处理。

### 连续续办的结果验收

按设计方法选定的业务链验收，不把“有演练版”“新增文件”或“完成两轮”单独设为考点。

- 题面交办每个业务节点的处理和实际更新；标答求出基线、各节点结果及最终有效成果。rubric写清给定事件、证明范围、适用规则、关键结果或条件关系、受影响正文及使用状态，评分者无需读取Skill或猜测作者意图即可判定。
- 依独立用途及新增判断划分复合结果，不将全部续办塞入共用文件分，也不按事件、日期或文件各拆一分。新设独立结果须有新的证据评价、规则应用、请求或安排决定；沿用原结果且没有新判断的更新并入对应条。原任务与新增任务均完整覆盖，分母随实际独立结果确定，不固定沿用试验旧题条数。
- 划清上游错误与续办新错误：仅传递同一错误基数不重复处罚；误判新增凭证、错误处理新事件、漏掉必要分段、失效条件仍被沿用或更新未落实到有效正文，按事先写明的新增判断验收。共享前提的条件式判据按上节执行，不能用续办条重复扣掉整个原案错误。
- 读取各阶段文件及实际更新证据，检查记录能否追溯到当前输入、派生结果与有效文本。对题面要求持续更新的工作文件，预填阶段总数、汇总范围漏接新事件或必须手改答案格才更新，均不能冒充已实现的更新能力。验收的是业务依赖，不规定软件、内部表结构或文件数量。
- 合法替代、原案与模拟的隔离、历史版本及不同条件下的结果不误判为冲突。当前版本无法辨认、模拟被当成原案事实或当前有效请求与处理结论矛盾，按实际影响归属；整体失效仍只执行该题预先明确的规则，不因增加演练自动扩大否决。

## 判分依据完整性

独立评分使用同版题面、rubric、题目冻结来源附件、匿名完整答案及评分提示词，不读取项目 Skill 或思路；标答默认不提供，显式校准政策另按冻结契约执行。rubric 必须自足，不写“符合标答”“见作者分析”或只给无法打开的链接。

规则判据包含足够的要旨、适用条件和出处，支持评分者核验，不复制整份标答。仅凭引文不能证明实际联网；轨迹不可得不推断未检索。内容正确性与工具执行事实分别核验。

题面要求实际文件或工具成果时，按上述归属在相应 criterion 写清内容、使用能力、执行证据及失败边界。规则不能只留在 Skill；独立评分者须能仅凭其实际收到的题面、rubric、答案与证据判定。区分以下情况，不以调用数量计分：

| 已知情况 | 处理 |
| --- | --- |
| 必需能力可用，完整答案明确未做或现有证据证明未完成 | 按冻结判据判对应结果；文件名、自述或未执行脚本不证明完成 |
| 产物或轨迹未传给评分端，无法确认完成情况 | 报告具体证据缺口，保留可确认的内容判断；不能推断未做或记为通过 |
| 经运行配置或错误记录确认必需工具不可用、输入缺件或传输失败 | 记录评测条件不满足；不据本次低分证明专业难度或纳入有效成绩均值 |
| 模型只声称没有工具，但实际能力和失败记录未核实 | 记录待核，不能仅凭自述免除遗漏，也不能据此断言环境正常 |

证据不足不改为部分分、不删条目改分母；按本次报告契约保留争议和可确认结论，未解决前不宣称已取得有效总分。旧题已有的文字呈现约定按冻结契约处理，新要求不追溯加到旧题。Skill 不替代程序的状态处理或产物传递。

逐 R 评分须列：ID、0或1／1、答案原文位置或短引、各必要条件的满足情况、决定性未满足条件及依据。判0时说明该缺失按冻结判据如何影响本条结果或必要论证；不临时决定条件是否必要，不新增或豁免条件。未找到证据先查整份答案及明确引用，仍缺失则写“未找到”；不可编造引文。理由和分数一致，条目无遗漏或重复，最后核对通过数、条数及百分比。

rubric 与材料冲突、必要依据不足或合法路径被排除时，保留具体争议，不补造条件、不临时改分母、不以低分作为有效难度证据；按评分契约报告可确认结论与限制。

## 关系型考点示例

以下只演示复合结构，不是新题事实、法律结论或必选题型。

明确模拟业务约定：同一项损失的实际补偿只抵扣一次，受理申请不等于付款，尚未实际取得的补偿不提前放弃请求。附件含受理单、部分到账记录及转发该记录的截图；委托要求核定剩余请求并修订结算条款。

**同一补偿事项的剩余请求及结算处理。** 共同核对受理与到账状态、补偿对象与范围、重复记录、剩余请求及条款中的抵扣条件和权利保留。把受理当到账或把同笔款项重复抵扣，导致剩余请求或条款错误时，本项不成立；结果及决定性依据充分、仅省略重复叙述时可以成立。允许其他足够证据，不要求复述作者顺序。实际出题须填入材料定位、数额或公式和条款范围，不照搬抽象标准。

这个 R 检验的是同一结果如何由多项判断共同决定。日期、去重、差额和条款不是拆开的简单分，也不与无关的授权或其他案件结果拼接。

## 作答思路

解释本案决定性材料关系、取舍、规则适用、计算及合法分支。呈现可核查的论证，不以章节数量、篇幅或作者内部处理顺序增加作答要求。

## 标准答案

完成题面全部工作：确定结果、条件分支、必要计算及可用正文。分清案件事实与模拟条件、不同阶段状态、测算与可请求范围，核对各成果的一致性。对合理替代路径说明条件；不把作者偏好的单一路径作为答案键。

连续续办题须实际求出各阶段结果，说明新增信息怎样改变或保留原处理，并完成相应正文与工作数据。文本标答提供可复核的阶段计算、状态关系及完整修订内容，不能以“据反馈更新”替代；实际文件校准还须验证后项使用前项结果及当前有效版本能够使用。原案结论与演练结论分清，后到信息不倒灌到初始判断。

沿设计阶段确定的核心成果成立基础，核对标答中的依据、推导与最终安排确实相互支持；用同一依据检验普通考点及整体失效条件，合理替代仍应通过。若标答与判据冲突，修正实际错误的一方，不为保住否决条款排除合法答案。上述核对留在作者自查，标答正文只呈现专业处理。

文本字段提供完整内容及必要公式，不把“工作簿应包含”“生成后检查”等未来指令当已完成成果。文本自查只能证明内容相容；要证明该题在实际文件要求下可满分，校准样本须包含同版完整内容、实际文件及题面要求的检查证据，并由评分端实际取得。若本次作者返回契约只保存文本，不擅自添加 schema 字段或假造文件链接；在完成说明报告文件校准缺口，不能声称文件验收已通过。未经授权不另发真实模型评测。

## 加压检查

冻结前逐 R 做内部检查，不另调用模型，也不把检查表发给作答者：

| 检查对象 | 应有结果；否则怎样改 |
| --- | --- |
| 完整正确标答内容 | 内容判据全部通过；失败则修正题面、标答或判据冲突。仅有文本不证明文件及执行条件通过 |
| 最简合法替代 | 同样通过；不能因表达凝练或不按作者顺序失分 |
| 只漏一个必要判断、其他均正确的近似答案 | 对应 R 不通过；若仍可正确完成成果，该条件并非必要，不能硬设失败 |
| 只复述题面或套常见原则的答案 | 未解决的复合结果不能通过；若已完成主要工作，应深化题目 |
| 局部判断正确但最终安排冲突的答案 | 明确矛盾及对应结果的影响；仅符合预先写明的整体失效条件时整题归零 |
| 只有同一上游错误的答案 | 按预先划分的归属计分，不因重复出现造成多项同义失败 |
| 专业内容正确，仅缺共用文件或读回证据 | 按内容、文件与执行的预定归属处理，不把同一缺口扩成多项同义失败；证据未知与明确漏做分开 |
| 仅遗漏背景叙述或改用足够的等价证据 | 结果及必要论证仍成立时通过；否则判据把非必要表达当成了条件 |

隐含问题逐项反查可见依据和业务必要性；隐藏义务、原文没提供的事实及无关细节不能作为加难手段。评分者看不到思路和标答时仍能逐条判定，否则补齐 rubric 的必要判据。

获准实测时，先用同版完整正确解与真实产物做评分校准，再用合法替代及有明确单项缺口的对照答案核对通过边界。满分样本被误拒、等价解被误扣或同源错误被重复处罚，先定位判据、产物传递或评分误读；不据此继续加难。作者静态推演、产物检查和独立评分分别记录，未执行的环节保留为未验证。

## 扩展任务后的增量核对

先核对工作是否增加，再解释成绩和耗时。与获准旧版比较时，沿用相同计数口径：任务按独立业务用途计，复合考点按专业结果计，文件份数和工具调用不充当任务数。

- 作者内部对应旧有／新增任务、材料依据、实质处理、实际成果、考点覆盖及成果依赖。旧有难点、必要条件和成果不能被新增工作替换或稀释；新考点仍执行复合0/1验收。仅换表达时各条判定必须不变；增加独立考点后分母会变化，总分不能直接当作原题难度升降的证明。
- 核对完成：新增任务有完整标答及可验收结果；新增 rubric 含独立的新判断，不把基础步骤拆成简单分。未增加说明材料或委托边界，不以多标题、多段落、多文件冒充增量。
- 实测分别记录实际完成的任务／成果、复合考点及通过情况、成功／失败工具操作、有轨迹支持的执行轮次、单题执行耗时和批次墙钟耗时。轮次须说明按什么执行事件计；没有轨迹记未知。独立工作并行完成不折算为串行时长，作者写出的步骤不等于真实轮次。
- 连续续办实测单列基线办理、反馈及后续事件处理、成果核验、制作故障返工；统计截止交付，不含事后询问统计的调用。业务阶段、含工具执行轮次、调用次数和墙钟耗时分别记，按工作目的而非工具名称推断业务占比。旧判据只比较对应原任务，新增结果单列后再按新版冻结rubric报告总分；新增排版或返工耗时不冒充专业判断增量。
- 用同等运行条件比较；模型、工具、预算或材料不同须列明。没有实测只报告设计增量，不能保证指定调用次数、40分钟或目标成绩。证据缺口与异常按下节处理。

内部设计核对不新增题包字段或作答者报告；获准实测记录放执行报告，不放题面、作答思路或标准答案。

## 执行复杂度与实测证据

本节只约束获准评测和结果解释，不授权调用模型或更改业务状态。目标分数、模型身份和既往成绩不进入作答或评分输入。

1. **先冻结**：确定题面、附件、rubric、标答和评测配置；开发样本与独立验收样本分开，样本范围、重复次数、聚合方式和异常处理在看答案前确定。
2. **独立作答**：新会话只接收题面和允许附件，保持指定模型、推理配置、工具、输入输出限制一致；保存完整答案、成果及终止状态。请求模型与可核实返回模型分开记录。
3. **独立评分**：按冻结 rubric 逐条判定，保留原始理由与证据；核对0/1、条目完整性、合计和矛盾。结构有效不证明评分准确，实质争议须单独处理并留痕。
4. **解释结果**：分别识别记录漏读／对应错误、规则误判、条件分支遗漏、共同约束冲突、成果未落实、纯算术错误及评分争议。正确核心工作与旁支遗漏分开报告，不能用总分代替分析。
5. **比较与修订**：不同材料、不同 rubric 或旧加权／部分分结果不能直接解释为新方法的因果效果，旧分不换算为新0/1。修改后对新版本重新作答评分，不继承旧结果。
6. **验收与留痕**：先算每次作答的通过率，再按预定方式聚合；条数不同不能直接汇总所有 R 让条数多的题主导平均分。保存所有预定样本与重复结果，不挑最低分。查看过并据以调参的验收样本转作开发材料，下次改用未见样本。

输入缺件、传输失败、技术截断或调用故障保留为异常，不填0拉低均值；只报有效样本均值时同时报预定总数、有效数、异常原因及未完成的验收范围。回答篇幅较少或完整答案漏做不自动等于技术截断。必要材料、完整输出或评分争议未核实，不宣称难度达标。

实测还须保留题包与配置版本、答案和逐项判据、运行起止及可得轨迹。排队、工具次数、执行轮数、推理token和耗时分别记录，不互相换算；外部平台验收另按当次规则，不能由本地自查代替。未实测就报告未实测，不预测或保证分数。
