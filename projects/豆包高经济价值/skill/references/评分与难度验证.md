# 出题考点与标准答案

本文件用于编制题目包中的考点、作答思路和标准答案。

高难度与公平评分同时成立：题目保留有依据的深度、工作范围和完整成果要求；评分如实衡量完成程度。修改评分规则须在不知道模型身份、已有分数和目标分数时仍有充分理由，不为压分调整考点，也不为公平而降低题目难度。模型正确完成全部要求，应获得满分。

## 考点

默认 15–20 条，每条 0/1 分、等权。按不同专业结果设项；这个数量不限制题面的工作规模与复杂度。

### 设项与覆盖

- 覆盖本题所选场景实际要求的证据取舍、规则适用、独立争点、核算、方案比较、条件求解、反驳及具体文书结果；不为集齐这些类型而新增场景无关任务，已布置且必要的工作完整设项。
- 一条 0/1 考点若捆绑互不依赖的专业结果，应分别设项或聚焦本条要评的结果；共同构成同一结果的必要条件仍须保留。不把全部核算、全部提案或整个变化情景压成一条。
- 依据任务的实际专业要求覆盖基础工作与复杂判断，不按预期得分高低选择考点。独立且必要的核算、判断和文本工作均正常计分。
- 考点依据题面要求、事实及适用规则，不能靠标答额外增加未布置的任务。
- 本题涉及对象划分或归纳迁移时，按错误归并、遗漏独立对象、混用口径或超出证据范围推广所影响的专业结果设项，写明正确范围及允许的替代处理；不按台账行数、编号样式或表格份数拆分考点。

### 通过条件与合理分支

- 每条先确定独立的专业结果，再写清得分所必需的判断依据、条件，以及相应错误或遗漏。按该条实际内容注明决定性材料及定位、法律适用条件与核实来源、计算口径与关键结果、可接受分支；不要求每条具备全部类型。
- 依主要作答者的职责、可见材料和行动权限设通过条件；检验其应完成的专业判断及实际后果，不以另一角色才能取得的证据或行使的职权判错。
- 对必须说明依据的争点，得分检查结论与决定性依据的对应关系；照抄原则、偶然猜中结论或用相反规则支撑结论，不能替代完成该项判断。精确条号只有在任务明确要求且适用版本可核对时才纳入，不因无关紧要的引法形式差异否定正确处理。
- 关系型考点写明具体结论、决定性证据关系、可接受的替代解释及对应错误，合并在现有通过标准和零分条件中。接受实质等价的证据组合；不按引用数量、载体数量或是否照抄标答计分，不用“分析充分”代替判分条件。
- 同时覆盖该成立或可办理与该排除或阻断的具体事项。已能确定却只写“可能、建议核实”不满足确定结论；确实缺失条件时，准确给出分支和行动边界属于正确作答，不以一律肯定或一律否定为标准。
- 事实、适用口径和精度明确时才设唯一数字或日期；合法分支分别写明条件和结果。用错法律时点且影响本项要求的依据或结论时判错，不因无关条号或措辞差异扣分。

### 去重与合法替代

- 成稿后并排核对各条的专业结果和必要条件：共用条件若分别服务于不同的办理动作，可核查各动作是否正确落实；若只是同一事实或结论换名称、换位置出现，不重复得分或处罚。作者核验所用的页码、条号和说明，不自动成为作答者逐项复述的义务。
- 成果份数不直接对应考点数。优先核查跨材料取舍、连续事件后的独立结果、方案成立条件及可执行文本；已在基础底账计分的同一结论，不因它又出现在签批意见或条款中重复给分。
- 接受实质正确的替代表达和合法路径；不同于标准答案原句不是错误。
- 连续情景分别检查新事件的性质、规则及办理结果。同一对象对应或算术错误机械传到后续金额、表格或文书，不另拆多个扣分项；后续还有独立规则判断时，写清其自身的通过条件。数值标准注明必要的精度与舍入口径。

## 判分依据完整性

题面已布置检索、证据支持或交叉核验时，将其落实在对应专业结果的通过条件中：依据真实可追溯、版本与对象适用、能够支持所作结论，决定性冲突或相反解释得到处理，重要计算及办理条件核对正确。标答同步给出实际来源、对应关系和必要核验结果，不只写“应检索”或“已验证”。不以搜索次数、链接数量、固定检索措辞或“交叉验证完成”的自述计分；同一依据缺陷不在多个同义条目重复处罚。独立且必要的检索成果按实际任务设项，不机械新增统一考点。

仅凭最终答案不能确认实际联网行为；引文正确不等于工具轨迹已核实，未看到轨迹也不等于没有检索。内容评分依据可见答案与既定标准，执行行为由获准取得的实际轨迹另行核验；不得从缺少轨迹推断专业判断错误。评分所需规则要旨、适用条件和出处仍须写进 rubric，不假定评分端能够联网打开链接。只接受作者预选网页或原句的标准无效，实质等价且适用的权威依据正常接受。

独立评分只读取题面、rubric、脱敏附件、匿名答案和评分提示词，不读取作答思路或标准答案。将影响得分的结论、决定性依据、适用条件及合理替代路径写入对应 rubric 条目；不得仅写“符合标答”“依据正确”或引用未提供的思路、标答章节。涉及作者检索核实的法律，写明用于本项判断的规则要旨、适用时点和可追溯出处，不能只给评分环境无法打开的链接。

rubric 保留判分必需的信息，不复制整份标答或附件。区分作者用于确认标准的依据与作答者必须交付的内容：题面未要求逐字引文、精确条号或特定论证顺序时，不把这些核验信息变成额外得分条件。对结论相同但依据不同的合法路径，明确可接受范围。

## 关系型考点示例

仅示范判分写法，不继承为新题事实或固定任务：模拟材料中，银行生成的入账记录证明仅有一笔金额 M 的实际到账；回单原页与复印页具有同一交易标识，聊天截图转发同一回单。M 只代表本示例金额。

- 考点：同一到账事件在不同载体中的识别。
- 通过标准：确认上述记录指向同一笔实际到账，计入 M 一次；说明交易标识及入账记录如何对应，复制页和转发截图没有新增到账事件。未引用交易标识但通过足以排除另一笔交易的其他记录组合正确对应，也可通过；不要求使用标答原句。
- 零分条件：按载体或页数重复累计；只因金额相同便断言同一交易而无足够对应依据；推造被遮蔽的金额或交易标识。

来源独立性与交易去重分别判断：两个独立来源也可证明同一笔交易，不能累计为两笔。银行回单不能仅因付款人提交而认定为付款人生成；回单证明发起、受理或完成何种状态，须读实际内容。此示例不要求每个考点都核对多份材料。

## 作答思路

说明本题实际涉及的材料关系、争议原因、证据取舍、规则适用及计算逻辑；有表面理解与深入核验的差异时解释，有竞争解释或可接受分支时交代，不为套结构制造差异。以上是内容核对范围，不是固定叙述顺序；组织方式按[四字段表述方法](../assets/题目模版.md#独立使用与组合规则)选择。

涉及印证时说明记录的生成者、共同来源、证明范围及不能推出的内容；区分提交者与生成者，不把同源转述当作独立支持。

作答思路解释如何解决题目；其篇幅或复杂程度本身不增加作答要求。

## 标准答案

完整完成题面全部工作，包含分析、逐项结果和配套文书正文，编排顺序按所选表述方法与文书实际用途确定；本题涉及计算、方案及条件、后续变化时完整求解，不只给原则、摘要及文书名称。不把这些可选工作类型变成所有场景的固定组合。

分清案件事实与模拟假设、裁判范围与履行余额、真实现状与条件测算。数值核对分项、期间和合计；脱敏值用原有形式或符号表达。支持不同结果时列明各自条件。

题面、考点、作答思路和标答在同一场景、时点和口径下，对主体、金额、期间、状态和依据保持一致；不同阶段的身份、余额或结论变化须有明确依据，不将合理变化误判为前后矛盾，也不混用不同时点的信息。

标答由可见事实、明确模拟条件及经核实的适用法律支持，保留可追溯法律来源。将内部测算与依法可请求的金额区分；不得以作者检索到的单一网页观点排除合理答案。

## 加压检查

逐条遮去作答思路和标准答案，只用评分实际收到的题面、rubric、附件与待评答案核对：能否判断结果、必要依据及替代路径是否满足？若仍须回看标答才知道如何判分，将缺失的判分依据补入该条，不增加题面未布置的任务。

### 得分路径检查

每次成稿执行以下检查；历史反馈与运行记录按后续小节的适用条件使用。

按当前题型构造能够完成常规工作、但存在明确专业缺漏的回答，检查它完成了哪些要求、遗漏了哪些判断，以及题目是否真正要求解决这些问题；不固定为算账、执行或和解场景。按题目适用情况检查全批、全拒、全部待核或不更新方案等路径。该检查由作者依据题包推演，不要求额外调用模型，也不把推演结果冒充实测。

复用题面、考点、作答思路和标答核对待求结果、决定性输入及共用结论；仅对复杂或有争议处按需补记，不要求逐考点另写记录。按下列方式检查，不把自查记录或难度目标放入题面或评分输入：

| 得分来源 | 成稿时怎样处理 |
| --- | --- |
| 题面已宣布的关系、效力或结果 | 保留必要事实；不把复述当作待推断难点。需要考关系时提供足够记录，由作答者判断 |
| 参数明确后的独立核算、合理基础判断 | 正常计分；不能因模型做对就删除条件或否认能力，也不默认其足以提供高难度 |
| 同一余额、授权或结论在报价、意见、条款中再次出现 | 合并重复评价；若另设项，指出新增的独立判断及实际后果，不能仅换成果名称 |
| 核心证据、法律条件或程序取舍 | 写清可见依据与具体专业结果；不能只列难词或让通用“待核、依法办理”满足 |
| 新事件后的结果 | 区分新的性质／范围／路径判断与单纯重算；对共同上游算术错误不重复处罚 |

按上表完成一次核对：题面布置的独立成果有对应判据；遗漏补足，重复合并，含糊要求写清。不同办理动作共用事实但各有必要判断时分别计分；同一正确陈述不重复奖励，同一错误不重复处罚，合法替代路径正常接受。

同时检查仅复述题面能完成哪些工作。必要事实、有效约定、合理基础判断及独立核算照常保留和计分；主要挑战若可被复述绕过，深化材料支持的证据取舍、规则竞争、独立争议或办理条件，再按新任务编制考点。不得回收正确分、删除易得分项、重排分值、捆绑无关结果、增加事后门槛或否决项来压分；也不缩小工作范围、删除独立考点或降低完整交付要求。不设易得分项比例，不以缺件、机械串联数字、错误传播或答案篇幅制造难度。

### 有历史反馈时：区分能力缺漏与评分争议

先按既定 rubric 如实评分，再单独解释题目难度。逐项区分：未找到决定性记录、记录对应错误、规则或证明范围误判、各局部正确但整体安排冲突、条件变化后沿用失效方案，以及独立成果漏做。引用答案和具体依据定位，不从答案篇幅、工具次数或耗时推断模型内部思考。

核心判断已完成而失分主要来自旁支遗漏时，分别报告已解决的主要工作与遗漏的独立要求；遗漏仍按既定标准计分，但不能据总分推断核心推理困难。方案比较按题面目标、共同约束和实际后果判分，不按列举选项数量或是否选择作者偏好的方案判分。多个成果出现同一错误时，继续按去重规则区分共同根因与独立错误。

修订后获准比较效果时，尽量保持作答模型、推理配置、工具、输入载体和输出限制一致，记录新旧题真正改变的待求判断，并对新版本独立求解、编制对应 rubric。比较具体工作是否完成及错误类型，不把不同题目、不同评分标准下的分数差直接解释为思考量增加；只做作者检查而未重跑时，标明效果待验证。

使用历史反馈时，同时看模型实际得分点、具体失分点及判分争议。核心工作已正确但因未抄精确条号、未列不影响结果的细节或同一错误的传播被扣分，不能据此证明题目难；理由与rubric相矛盾、总分与逐项合计不一致或标答基数未经核实，单独列为待核事项，不按低分反向固化出题方法。评估题目难度时，不因出现部分分就取整、重判或修改评分配置。方法改进只迁移已证实的能力边界，不把旧答案、成绩和个案争议注入新题。

单次答对只能说明该模型在该样本上完成了工作；多题反复答对可作为优先加深设计的线索，不据此声称统计上的高得分概率。模型已正确完成核算、同时满足收付款限制、用足且未超出授权范围，并写出合格文本时，增加同类算式或条款数量不能证明难度提高；优先引入有事实依据的独立规则竞争、证据取舍或办理条件变化。保留已验证有效的工作，不把所有高分归咎于泄题。

结合已提供的完整作答和逐项评分，找出模型已掌握的部分与仍可深入的争点，扩展专业工作和独立结果。正确完成的部分照常给分；需要设计新题时，选择材料中尚未考查的问题，不临时改变等价解标准或把正确回答判错。

### 有实测记录时：核对截断与执行能力

利用实际作答评估难度时，核对可获得的完整答案、供应商终止原因及输出上限。已确认输出被技术截断时，不把该部分缺失当成专业难度有效的证据；仅末尾缺失或回答简短不能证明截断。缺少运行证据时，截断原因标为未确认；完整答案中的实质漏答仍按既定 rubric 判断。这是作者解释难度证据的边界，不改变现有评分，也不自动免扣分。

若实际配置确认无法容纳完整交付，记录输入输出约束及影响，另行处理执行能力；不凭标答字数预测 token 或直接删减专业要求。此检查不授权调用新模型、重跑评分或改动系统限制。

出题要让作答者依据材料解决具体问题。是否解决、错在哪里，须由完整答案和逐项评分说明，不能凭作者预想判断。

## 执行复杂度与实测证据

适用于解释已有实测或执行获准自测；不要求作者每次出题额外调用模型。仅设计题目时，完成设计检查并标明执行指标未实测。

### 设计要求与实测用途

本 Skill 不设模型目标得分或得分率。出题不规定执行步数、工具调用次数或最低运行时间，也不要求作者预测这些数值。设计时明确作答者需要处理的记录、需要解决的问题和应交付的结果；实测时检查这些工作是否完成、结论是否正确。低分本身不能证明题目需要大量工作。

实测记录实际使用的模型和推理配置，不将Lite、Pro等名称自行等同，不根据一个模型的结果推算另一个模型得分。按事先确定的 rubric 如实评分，不根据实际分数改动本次评分标准。外部提交规则另行核验，本节的设计检查不代表平台已验收。

### 作答端材料核对

作者核对题面和考点依赖的关键记录是否在本次可见附件中，并保留可定位位置。实测执行者核对实际上传或传入的版本、文件清单及关键正文，特别检查导出、合并、提取后是否遗漏表格、诉状、图像或引用内容。作者看过原件不等于作答端收到完整内容；无法检查上传件时标未核实。

区分题目有意保留且可合理处理的业务信息缺口，与传输、提取或导出造成的意外缺件。后者影响必要输入时，记录本次结果及缺口，不能据其低分证明专业难度；不能直接归因于模型漏读。修复输入后的结果属于新版本，不沿用旧分数作为新版本证据。

### 获准自测时的执行顺序

1. 完整求解题目并固定题面、附件、rubric及标答版本；先确定评分标准，再取得模型回答。
2. 确认指定作答模型、推理配置、工具与输入输出能力符合本次评测条件。新建独立会话，只提供正式题面和允许附件，不提供rubric、标答、作答思路、难度目标或旧答案。
3. 保存完整回答、执行轨迹、起止时间及异常情况；按下节核验输入完整性、轮次、耗时与完成状态。
4. 依既定rubric独立逐项评分，核对得分依据和合计。评分输入不暴露作答模型身份、目标分数或运行指标；不能为了达标回改本次判分尺度。
5. 同时检查得分、执行指标和失分原因，区分专业误判、任务漏做、输入缺件、技术截断及评分争议，再决定保留或修订。
6. 修订题目后，重新求解并同步核对题面、rubric与标答；在获准范围内以新会话复测最终版本。未获准复测时标待验证，不沿用旧版本达标结论。

### 根据结果修订设计

| 观察 | 修订方向 |
| --- | --- |
| 模型正确完成主要工作 | 如实记录已完成的判断；继续出新题时检查材料是否还有未考查且有实际用途的争议。题面已给出待求结论时修正提示，不删除必要输入、不收回正确分 |
| 只读摘要、套用通用说法就能完成主要交付 | 检查题面是否遗漏了材料中需要逐项处理的问题；补清需要核对的记录、需要解释的矛盾、需要计算的金额或需要落实的办理条件。只添加业务必要且材料支持的工作 |
| 执行量大但得分仍高 | 保留必要工作，检查核心难点是否真正影响必须交付的结果；机械重复处理不能替代专业挑战 |
| 低分源于输入或运行故障 | 先解决材料或执行问题，再验证专业难度；不把故障固化成出题方法 |
| 评分争议或合法替代路径被误扣 | 依据题面和规则核对判分，保留纠正记录；难度不足通过修改题目解决，不通过排除正确答案解决 |

各项修订继续遵守材料匹配、单方服务、场景及表达多样性规则；不固定成同一文书组合、连续变化或核算题型。运行记录用于解释本题结果，不自动成为新题的事实输入。

### 实测记录与判断

沿用现有运行记录，保存或引用以下证据，不新增作答者交付要求：

- 题面、附件和rubric版本；请求模型、可核实的实际模型标识、推理强度、工具环境及限制，未知项明确标注。
- 完整答案、逐项得分及依据、总分与满分，按总分÷满分计算得分率；核对逐项合计，不用笼统印象分替代。
- 运行起止、平台显示耗时、完成或中断状态、执行轨迹及可取得的统计。区分模型运行时间与上传、排队、人工等待、故障重试等耗时；计时边界不明确时保留原值和不确定性，不自行据此认定通过。
- 执行轮数按项目明确口径统计。页面卡片可能汇总多个操作，工具调用数也未必等于Agent轮次；口径或完整轨迹缺失时只报告可观察记录，不将其当官方轮数。答案章节、文字规划段落、token数与不可见内部推理均不能自行换算成执行轮数。

先核对输入是否完整，再报告逐项得分、哪些工作已完成、哪些工作遗漏以及具体错误。没有实测就标未实测；运行中断就标未完成。步数与耗时仅作为运行观察，不设硬性达标数量，不因运行短就判定题目简单，也不因运行长就判定题目合格。外部验收需要额外证据而当前缺失时，如实说明缺口。

保留同版已有各次实测及差异，不只挑最低分或最长耗时。题目修改后重新验证受影响结果，不用收紧评分、强制拆步、重复操作或拖延制造达标。记录留在内部运行证据中，不注入后续新题或公开题包。
