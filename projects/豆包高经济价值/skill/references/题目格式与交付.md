# 题目格式与交付

## 题面

### 角色与职责

- 区分主要作答者的职业岗位、诉讼或业务身份、服务对象与材料中的其他人物；当事人、被告人等诉讼身份不能直接填作职业。若由当事人本人作答，明确其可取得的材料、能亲自采取的动作及成果用途，并核对本期必填行业和职业是否能据实归类；不能归类时不编造字段。
- 若由律师等专业人员代办，明确委托人与承办人的不同权限。法官、鉴定评估人员、公司法务等也只承担其职责内的判断和交付，不代行其他角色职权。
- 多方立场须实际改变证据取舍、规则适用、行动边界或成果，不能只换称谓。

### 工作范围与强度

用成果使用者布置高强度专业工作的口吻写题。写清主要作答者、背景、对象、条件和成果要求，充分展开工作：

- 分别回应待评主张、方案及反驳理由，定位决定性材料，说明依据之间如何支持、限制或冲突，并给出具体处理结论。
- 全面处理案件、主体、款项、期间和条款，表达合并、区分、排除及适用情况。
- 涉及数值或期间时，给出分项计算、基数、公式、结果或条件表达式，并核对汇总关系。
- 角色须在多个处理路径间选择时，比较方案及其成立条件；后续事件改变判断时，重新形成相关成果。
- 写出本角色有权制作或提出的条款、请求、裁判、鉴定意见、通知或交接正文，保持主体、范围、条件和后果一致。

### 工作要求与答案提示的边界

- 题目可以要求多项独立工作和多个成果，不限于单一决定或单一路径。题面可以限定核对领域、指定成果及要求说明依据；不要预先宣布材料存在某类错误、指定错误数量、采信方向或解决顺序。
- 一个工作要求对应考点本身是正常设计，只有它透露待求结论或裁决线索时才构成提示。保留自行发现证据问题、选择规则和裁决争议的工作，不将详细任务缩减为泛泛意见。

| 工作布置 | 泄露判断线索 |
| --- | --- |
| 核对现有付款记录，确定已清偿范围，并在余额表及付款条款中落实 | 回单存在重复，必须去重；对账单余额错误，请以银行流水为准 |

### 事实输入与待求判断

- 区分原材料明确事实、必要业务条件和本题要求求出的结果。保留前两类；待考的交易对应、授权效力、适用规则、推算日期及余额由作答者判断，不由作者提前确认。
- 原文书明确记载的生效日、履行内容和有效约定不得为加难删改；必要日历条件、计算端点和精度仍须提供，不能一律删除星期、日期或口径。作者新增的模拟记录应提供可判断的主体、范围、时点及关联信息，不直接宣布其法律效果。

- 保留估值时点、有效计算约定、业务政策及模拟条件。事件时间、信息取得范围、计算端点及舍入按任务需要交代，不固定为每题栏位。
- 内部测算确实采用不同口径时明示用途，分别处理对外权利；不能以模拟约定当然替代法定口径。法律存在合理争议时列可成立分支，作者尚未核实不等于法律有分支。
- 题面不附作者检索所得的法律讲解、搜索链接或答案依据清单。

### 成果用途与变化处理

- 题面按实际工作写明成果的使用人、接收人、专属约束、后续决策或执行动作，以及做错会影响什么；具体内容依本题材料和委托事项确定，不固定为签批或交易场景。各份成果承担不同用途，可以在一份纯文本答案中分别呈现。
- 要求给出可直接使用的口径、条件和文本，不以“另行制作”“待核后决定”代替已可完成的部分。可复用的文书格式或核查清单仅在本题确有复用需要时交付，并写清适用边界；有数据时核算经济结果，不为证明价值补造金额。
- 不要逐一提示附件中的矛盾、错误数字和正确法律口径。

- 安排逐对象的处理结论与理由，让作答者自行区分成立、附条件成立、应排除或受阻的范围；涉及办理动作时进一步落实可执行边界，不预告哪些对象属于哪类。变化情景说明发生的事实和时点，要求修订受影响的成果及其依据、交代未受影响部分，不直接宣布原方案失效。
- 完整修订稿或明确替换范围及正文均可；历史值可用于初稿及对比，核对的是当前有效文本之间的一致性。

## 七项内容

- 成稿时对照标答核查必要专业成果是否已由题面布置，或为完成任务必然要求。缺失时补清交付对象与内容，不把多余展示细节升级为要求。
- 例如确需收益率时明确要求计算收益率，但不提前给出待考的公式、规则选择或应得结果；材料已有的有效约定、必要计算条件及测算定义仍须保留，不借此补写待考结论。不把标答求解步骤逐条改写为题面。任务可以充分具体，答案与裁决路线仍由作答者形成。

### 七项字段

| 内容 | 要求 |
| --- | --- |
| 表头 header | 题目 ID、一级行业、二级行业、任务形式、可见附件名称、按主要负责最终交付者填写的 L1 职业簇与 L2 职业 |
| 任务名称 task_name | 一句交办话，依次写明办理方向、具体主体与款项或争议及所处环节、标答实际完成的具体成果；不用泛称替代这些信息，不提前写出待求结论。下例只示范表达结构，不固定事实或成果。 |
| 任务类型 task_type | 用“法律关系或款项性质＋关键程序状态＋主导处理事项”写专业类别，例：“买卖合同货款执行回款核算与清偿安排”；只示范结构，按本题材料替换。不并列宽泛标签，不写人名或交付物；无依据的状态不补造，相同专业工作允许同类。 |
| 题面 question | 完整角色、背景、条件、对象范围和具体工作要求 |
| 考点 rubric | 不同专业结果及其通过标准、对应错误或遗漏 |
| 作答思路 answer_approach | 依据取舍、规则适用、求解关系、争议及替代路径 |
| 标准答案 reference_answer | 完整回答本题全部要求，包括适用的核算、比较、变化处理及实际文本 |

### 命名与分类检查

任务名称示例：“清算被执行人周明远货款的执行余额，拟好保单回款和尾款结清方案。”其中“清算”是方向，“周明远货款的执行余额”是具体对象和场景，“保单回款和尾款结清方案”是交付成果。新题须替换为本题有依据的主体、业务、阶段和成果，不照搬例句。

交付前对照最终题面和标答，检查名称是否像一句可直接交办的工作、成果表述是否准确、类型是否为简短业务类别；不符合时在本次出题内改写名称或类型，不改变题目工作。

### 输出形式

按当前任务指定的结构返回上述内容。内容为纯文本；表格、条款、请求和文书也在正文完整呈现，不要求生成 DOCX、XLSX 等文件。

## 表达与引用

- 行业、职业、角色和任务背景相互一致。行业按任务发生组织的主营业务填写，职业按主要负责最终交付的人及当前职业分类要求填写，不把诉讼身份当职业，也不因题目涉及法律就一律归法律服务。
- 公司法务任务仍以公司业务为背景；《公司法务出题准则》仅适用于此类任务。模拟主体、业务条件和履行情景明确标示为题设，不冒充已发生的真实交易或实际使用证据。

- 附件使用作答者可见名称或序号引用，序号对应实际正文。附件名仅用于准确引用文件，不能替代正文阅读或决定任务名称、任务类型。
- 引用案号、日期、主体和金额时核对材料原文，脱敏保持原样。

- 题面不列出正确采信方向、陷阱位置、rubric 或解题步骤。标准答案用正式业务文书表达，完整呈现具体成果，不用“另拟申请”“制作明细”或文件名替代正文。

- **内部信息**：各项内容不出现数据库编号、本机路径、程序字段、模型成绩、AI 自述或出题流程。
- **出处与原附件**：作者核验、考点必要依据和标答保留法律出处及争议说明；原附件的法条、条款和来源信息不因删除检索讲解而删改。
- **题面事实边界**：题面保留完整事实边界、模拟假设和适用时点，不自动附作者的来源清单。
