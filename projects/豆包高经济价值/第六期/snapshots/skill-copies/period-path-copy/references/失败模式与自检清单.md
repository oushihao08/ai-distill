# 出题找茬清单

## 会降低强度的设计

- 只要求摘要、原则、意见、底账或补件清单，未展开具体工作。
- 题面提前确认待考的交易对应、效力、规则或推算结果，替作答者指出错误文书、陷阱位置，或附作者检索讲解而透露解题路线；原件确定事实和必要条件不属于这类提示。
- 为了可快速完成，删掉独立争点、反驳、核算、方案比较或具体文书。
- 要求所有工作影响同一个决定，因最终建议不变而删除专业分析。
- 全部工作必须串成同一链条，排除有挑战的并列任务。
- 将实际文书改成报文件名，将变化处理改成“重新评估”。
- 将未知现状当成取消条件测算、方案求解及可确定工作的理由。
- 考点反复奖励同一简单陈述，复杂结果却挤在一条中。
- 把案例骨架、考点数量或固定成果组合当作任务上限。
- 多份成果只是同一段意见的改写，或变化情景仅把原金额替换成新数字；模型不重新裁决争议也能交付。
- 待审提案的错误及正确替代方案在题面已经明说，作答者只需逐句复述。
- 所有事项都只能否决或待核，笼统保守意见可以绕过主体、权限和例外判断。
- 新旧规则只考记住条号，不要求判断适用对象、期间及其具体后果；只靠增加付款、期间和重复代入次数加难，未增加适用判断。

## 会使标准出错的设计

- 附件序号、案件、主体或文书关系错配。
- 主张与判决、裁判金额与履行余额、形成日期与送达日期混同。
- 模拟条件冒充卷宗事实；推算脱敏身份或隐藏金额。
- 未核对材料就断言某项事实不存在；没有依据却指定唯一结论。
- 按文件份数或提交者判断来源独立性，将同源转述、复制页或同一交易记录当成独立印证或多笔交易。
- 多份材料相同就认定事实成立，未检查共同来源；未见记录就认定事项未发生，未核对记录覆盖范围。
- 法律版本、适用期间、基数、分段、抵充或合计错误。
- 将内部测算假设当作法定责任，以模拟约定无条件改变对外权利；将后取得的信息当成早期决策时已经知悉。
- 题面、考点、作答思路和标答互相矛盾。
- 将合理替代路径判错，或把标答里的额外要求当成扣分条件；必要专业成果未在题面布置，却依赖隐含要求制造失分。
- 要求全文不得出现旧金额、旧日期，误伤初稿及历史对比；应核对当前有效文本是否矛盾，并允许完整新版或明确替换说明。
- 同一判断重复计分，同一错误重复处罚。
- 题面或成果带数据库编号、本机路径或出题过程。
- 将隐藏批注、未传入的新增文件或作答环境无法取得的特定外部资料设为判分前提。
- 关系型考点只有“分析充分、相互印证”等主观措辞；存在合理口径分支却只接受一个数值或日期。
- 为了制造冲突删掉字段、破坏表格，或不顾已有生效证明强行重推期间；计算端点与舍入未定义却只接受一个数值。
- 将最新文件、合同名称或职位高低直接当作效力依据；把真实可裁决的不同解释强行压成唯一结论。
- 禁止一切法律分析，导致结果缺乏必要依据；将正确但不同于标答的条款表述判错。

保留加压工作，修正事实和标准错误；不通过删减任务来掩盖设计问题。
