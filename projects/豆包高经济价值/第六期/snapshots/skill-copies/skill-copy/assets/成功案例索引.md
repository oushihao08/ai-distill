# 出题案例索引

本库收录不同题型的设计参考。文件名保留兼容既有引用；“收录”不表示已证明成功。每行对应独立精华卡，选择依据是适用机制和证据边界，不是最低分排名；案例1不是默认模板。

先根据当前附件和业务判断选择最匹配的一张卡；只有需要另一种尚未覆盖的机制时再补读。无匹配项时自行设计，不遍历全部案例。使用方式见[模板参考与迁移](../references/模板参考与迁移.md)。
