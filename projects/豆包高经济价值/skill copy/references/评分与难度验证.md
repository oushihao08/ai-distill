# 复合 R、评分与难度验证

供出题作者在作答前确定考点、标答和判分依据。逐项用完整正确解和有具体错漏的答卷试判。若两者得分相同，先查卷内是否有遗漏的办理事项，或判据是否漏验了影响使用的错误。完整正确解应得满分。

---

## 考点

- **按独立可用的复合专业结果设项**：每条 R 验收一项足以改变实际办理的结果，写明哪些独立事实、适用规则或权限判断共同支持它，接手人拿它能办什么。漏做决定性工作有具体后果。次要错漏未改变结论与可用性时仍可成立。
- **等权二元计分**：各条等权，字段填 `max_score=1`；未触发整题归零时，`百分制得分 = 成立条数 ÷ 总条数 × 100`。`criterion` 正文不写“得1/得0”或重复固定计分尾句；总条数由本案去重后的独立专业结果自然决定，不设机械条数配额。
- **拆合试判原则**：冻结前取本案一份本可使用的成品，只改错其中一个事实判断、规则适用或办理动作，其余保持正确。收件人因此必须撤下哪项请求、改签哪一笔或暂缓哪次放行？共同决定这一结果的要件留在同一 R。若原请求仍可照办，错误只影响另一项已交办的独立决定，归入该决定所属 R；只影响表述或核对便利的，留在说明中。两件事即使写在同一份意见里，也按各自的办理后果判断。

#### 判断错误影响整题还是单项的示例

| 审查方向 | 足以触发整题归零的实质错误 | 必须保留的不误伤边界 |
| --- | --- | --- |
| **服务立场与授权边界** | 最终正式文书服务了错误主体，或超越代理权限擅自放弃本方核心债权/抗辩权、代委托人作出不利处分承诺 | 内部意见书中客观揭示本方败诉风险、承认已被生效证据证实的不利事实并提出止损预案，不属于立场错误 |
| **核心事实基础与采信** | 将卷内不存在的虚构事实或对方毫无佐证的单方主张直接当作确定事实采信，据以缩减本方核心权利或扩大本方责任 | 卷宗未记载不等于未发生；针对客观证据缺口设置明确条件分支不按虚构处理 |
| **核心数据与原始记录可追溯性** | 决定主要请求或抗辩上限的核心金额无法由所交底稿输入与公式关系复算，或决定性事实完全脱离所附卷宗原始记录 | 允许等价定位与合理舍入表达，不强制特定页码或特定表格拆法 |
| **最终有效成果跨件自洽性** | 同一基准日与适用前提下，最终对外正式文书、内部意见与核算主表对核心主体、请求金额、责任上限或办理动作给出互斥结论，使接手人无法使用 | 明确标注的在卷旧稿对照值、不同争议假设试算列及附启用条件的备选稿，不构成矛盾 |
| **决定性法律要件** | 错用适用时点、构成要件或除斥期间，导致委托人拟签的核心请求依法不能成立或权利已无法行使 | 对存在权威解释分歧的事项，有依据的处理方案可以成立。个别条号笔误未影响结论时不触发 |

### 从评价维度形成复合考点

从委托逐项回查：此项工作凭什么成立，须作哪些取舍，怎样检查接收人拿到的成品？涉及金额、期间或新旧法才核相应计算与时际规则；多项事实即使相符，也须各自证明所需的要件。

### 设项与覆盖

1. **同源资金链合并，独立实质任务分设**
   - 本金、已付或已执行金额、分段利息、费用和抵充顺序共同决定同一请求余额时，合在一条考点内核验。从同一基数推得的各段算式不另计分。
   - 两项工作各有证明依据和接收用途，办对其中一项仍不能完成另一项时，分别设项。例如，核准本金不能回答由谁负担该债务。
2. **哪些工作可独立计分**
   - 每条 R 均要写出卷内具体依据、专业判断、在成果中可验证的结果，以及一处足以使本项无法使用的具体错误。独立用途可分别计分，也可落实在同一份文件的不同条款。连续办理看是否依据真实反馈改变了该改的内容；并行工作分别验收，允许有依据的办理顺序、取证和交付组织。
   - 下列内容在其支撑的业务结果中核验：
     ① 泛化的“未核事项暂列待核＋拟核验函”；
     ② 题面或主文已明示无争议数字的简单加减；
     ③ 拒绝明显常识性违法主张的表态；
     ④ 无争议历史沿革摘录或现行通用法条直抄；
     ⑤ 正式文书的常规体例、法规出处链接与通用交接套话；
     ⑥ 自身不含独立材料消歧或新规则裁决、仅承接上游结论的衍生短申请或说明；
     ⑦ 已在同一综合项核验过的文件、公式和版式要求。综合项至多一条。
   - 题面已交办走向研判时，将它并入所服务的决策考点。同一争点的预测、理由和随后的办案选择不重复计分。作者须把本案实际的决定性记录与反证、适用的证明规则、当前可支持的判断范围，以及另一采信结果会改变的具体办理内容写进该条 `criterion`。可算的写明对照值或边界；无法定值的写清哪些结论仍成立、何种缺口才会改变哪一项文书或行动。评分者据题面、附件、判据与交付成果即可核对。
   - 只押中结论、两边罗列却不权衡、泛称待核却回避已能判断的部分，或意见改变而请求、数字或签发条件仍沿用已排除的前提，均不能完成该项决策。有根据的不同倾向须面对同一决定性反证、符合可核定的事实与规则，并把影响落实到本方成果。固定百分比、列举分支数量及后来实际裁判均不作答案键。

3. **比较有据可选的办理方案**
   - 把证据充分性并入它影响的案件结果。固定在卷事实，对照“按客户要求全办”“笼统要求补材料”和按有据范围实际办理的答法。判据写明哪一项可办或受阻、根据何在、这会改变哪笔请求或哪处可用正文。补证仅在真能改变决定时核验，接受能证明同一事实的其他合法来源。请求已具备条件时，无端要求等待同样可能造成错办。
   - 比较方案时固定证据、授权和客户目标。若一项合法方案能避免另一方案确定会造成的少收、多付或失权，判据写出差额或受影响的权利及其依据。以客户会不会承受该项可避免的损失区分两份答案；能保住同一权利的合法做法均可成立。
   - 金额、受偿时间或失权风险互有取舍，而客户偏好尚不明时，核准各选择的具体得失、当前必须保全的权利和须经客户决定的事项。不能用“各有利弊”替代可完成的比较，也不能替客户虚设偏好。
4. **核对每个考点对应的委托事项**
   - 提出另一种成品试办：收件人依法须提交特定文书的，替代品须具备该文种的实质要件；客户只需在现有订单上批准或更正的，直接改妥并可留存的订单同样可用。依据在卷需要及题面验收，不把场景库列举的诉状、报告或工作簿变成隐含必交件。
   - 判据只验收题面已明确交办的任务及该成果在法律与实务上成立可用所必需的实质条件，不设题面未要求的内部 Sheet 数量或无争议空记录展开配额；不影响结论与复算核验效力的不同表结构组织或无争议同质流水归并方式均予认可。
   - 需要承办人选择路径、编配证据或适用公开办案依据时，先在标答做出经核实的交付，再在对应考点写明该收件用途的实质要件。按实际发送清单检查正文和所有随件，须用副本限制披露的核到所交副本的具体内容，依法须完整提供的材料及其提交方式仍须保留。核实正文所引材料是否真在交付件、替代路径的依据能否支持其请求、所引案例的事实差异会否推翻类比。只核验题面有业务理由交办的部分，接受达到同一用途的合法组织和可复核的等价来源。
   - 独立评分者只拿题面、材料、判据和交付件。给他一份法律结论正确却会使普通经办人办错的答卷：例如拟付款对象正确，却没划出可释放与须留存的批次。对应判据要写明在卷依据、接收人实际应当怎样处理和具体失误影响哪部分；合法等效的划分与指令可通过。判据把证明范围落到相应对象：若仅有一笔整改后的审批样本，须能区分确认该笔与确认全部业务均已按新制度运行。若删掉通用文书名就分不出相邻两项在验收什么，重划二者各自的案件判断。

### 一条 R 必须写清什么

评分者独立判卷时不读取项目 Skill、不读取 `answer_approach`，默认也不提供标答；每条 `criterion` 必须完全自足。下表用于检查信息是否充分，不规定落笔顺序。先各用一句话写出本案不同的裁决，例如哪笔钱仍可催收、哪项签字只同意查账、哪一旧请求应在收到凭据后撤换。再补足独立评分所需的文书与判断依据。对已经确定的界线，可直接写清准许范围及越界后果；对有争议的界线，写清什么反证或等效安排足以改变判断。用一份只错在此处的答卷试判，能定位错在哪里即可。通读全组，把可原样搬到相邻项的收尾删去；若删后无法判错，补回这项特有的事实、权利或使用后果。整题归零仍按本题唯一的触发条件明写。

| 必备要素 | 具体写法要求 |
| --- | --- |
| **所验收结果与对应文件** | 先写可核查的专业判断。需定位时在判断旁指出对应成果（严禁写“本条评价……”元话术） |
| **决定性原始文书与规则依据** | 精确点明所附分件卷宗的具体原始文书名称及案号／日期／出具主体（严禁写“附件1”“附件 1”“合并卷宗”、`材料-xxxx.docx` 哈希名或页码），写清适用规则要旨；涉及时间效力或计算时给出版本、口径和结果（兼容合理舍入尾差） |
| **成立条件与合法分支** | 写出本案可支持的结论、决定性依据及该结论在成果中的位置。缺证时说明何种凭据会改变结论，以及取得前可办到哪里 |
| **决定性错误的实际后果** | 指出本案哪项错误会使成果不能使用。例如重复扣除已付款导致少主张的，写明是哪笔款、影响哪项请求 |
| **共享前提分界** | 下游 R 引用上游核定结果时，明确本条验收什么独立于上游的新增证据消歧、程序规则或专门条款判断 |

### 共享前提与上游误差传递边界

- 同一判断跨底账、审查意见与对外文书同步体现，属于同一复合 R 的内部一致性要求，不拆成多条重复计分。
- 仅当下游 R₂ 确有独立的新证据核查、新程序规则或新条款重构任务且引用上游 R₁ 数值时，事先写明条件式判据：纯粹沿用 R₁ 数值偏差已完成 R₂ 全部独立判断与正式文书落实的不重复扣分；但若因未做本条独立核查、错选本条适用规则、未落实到正式文书具体条款或将同源本息抵充人为拆碎，仍按本条不成立判 0。

### 内容、文件和执行的归属

- 把题面交办的文稿（`.docx`）、工作簿（`.xlsx`）及版式定稿（`.pdf`）放在其服务的业务考点内验收。多件文件须共同使用、确需单设综合项时，至多 1 条。按实际交付要求检查以下内容。
  1. **分件实体生成**：各独立用途正式文件均已分别生成实际文件；仅在聊天回复中贴出正文、只列文件名或将多份独立文书合并塞入单一合册文档的不通过。
  2. **活公式动态重算与空值安全**：`.xlsx` 底表的各期天数、分段本息、抵充余额、分项小计及争议口径对比栏均由活公式驱动计算，严禁填入静态常数覆盖派生结果，且默认待核留空单元格状态下零公式报错（无 `#VALUE!`、`#REF!`、`#NAME?`）。
  3. **定稿核对**：打开 PDF，检查宽表、正文和签章位置是否完整可读。以原始凭据和适用规则核准主体、基准日、金额及请求条件，再核对同一前提下各文件的记载。多份文件引用同一错误金额时，该金额仍判错。

### 跨阶段原卷核改与联动试算的验收

以下验法须有对应工作才使用。证据目录可能需要按现卷实配，确认旧稿提及的材料究竟能否随送；仅就一个争点给意见，可直接查决定性记录能否支持该结论。其他事项依各自的使用方式验证。

- 卷内已有前后阶段记录时，验收后件究竟确认、补足还是改变前案处理，核对当前稿中该保留和该修订的部分，以及实际需要的随件。未来结果未出现时，只验收本次可制作的文件、启用依据与接办动作；不要求虚构初办版或补件。
- 方案同时受几项卷内条件约束时，在所属复合考点试判一个近似答案：它分别说对了每项权利和限制，照它签署或履行时却有一项承诺无法兑现。把决定成败的那处冲突及其对应的可行结果写进本项；其他足以办成同一委托的条款或安排同样成立。只在某次变更确实改变后项时核验重办结果，不因未复述前一版本或未采用标答段落而失分。
- 对接手人还要更新的工作簿，从核实后实际会补录的原始明细或办理参数开始，沿公式核到最终供签发或处置使用的值。作者在文本标答中给出可复算的对照及其业务含义，评分在原有业务考点内核验同一依赖。经办人收到的是一张新凭证，就从新增明细试到供签的数值；更正旧记录才改原行。直接改汇总数或只看中间小计，不能证明日常录入能更新请求。待核数与已证实的零须能区分；若受上限等条件约束，最终值确应保持不变，须能从更新后的明细及约束复算得出。涉及已定稿的文书时，核清再签前该改哪项或为何仍可沿用，无需让 Word 或 PDF 自动取数。

## 关系型考点示例

以下仅演示多项判断如何围绕同一可用结果闭合，不作题型模板：

> 所附卷宗含补偿协议（约定同一损失实际到账补偿仅抵扣一次，受理通知不作扣减）、社保受理回执、银行部分入账回单及微信转发该同笔入账的截图。委托要求核定截至基准日尚可主张的差额并定稿结算补充协议。
> 可签的结算条款须保留尚未到账部分的权利。协议约定以实际入账抵扣，社保受理回执只能证明已受理；银行入账与微信转发件指向同笔清偿。核算簿应能从原始行只扣一次并复算出付款条款中的差额。若把受理额先扣掉、以转发件重扣、把派生额填死，或在协议中放弃未到账的差额，即使另一件上的数字碰巧正确，该结果仍无法用于签约。

## 作答思路与标准答案

- **作答思路（`answer_approach`）**：说明已完成的关键判断及其依据、必要取舍和对行动的影响。并办事项各自论证，续办事项解释何种真实记录支持沿用或修订。法源分期、利益测算和反证回应依本案实际展开，不写操作清单。
- **标准答案（`reference_answer`）**：逐件提供接收人可以直接采用的全文、实际数据和必要随件。须对外签发的用正式体例，供内部拍板的直接写决定和授权范围。按[交付规范](题目格式与交付.md#七项内容)核对可复算底稿及逐项办理明细。让经办人遮住作答思路复走当日委托；如果必须请律师另挑一份证据、算一笔关键款或起草替换文字，将缺口补在相应成品中。作者交文本标答；实体办公文件由作答端制作。

## 加压检查

冻结前，在作者会话内用以下答卷试判相关考点，核对哪些条目应成立、哪些应失分。无需调用外部模型，试判记录不写入题包。

| 对照答卷 | 核查办法 |
| --- | --- |
| **1. 完整正确解与简洁的等价合法解** | 两者均应满足全部考点且不触发整题归零。若两者只因措辞、段落或等效表结构不同而得分不同，删除该呈现限制 |
| **2. 纯聊天文本／合册／静态常数答卷**（未生成独立 `.docx`/`.xlsx`/`.pdf` 或表内填死静态常数） | 对应文件与公式联动要求明确判不成立；排查题面是否残留“在回复中列出全文即可”豁免句 |
| **3. 成果看似齐全，实际漏办了一件事** | 从标答取掉一项拟交办工作的结果，其余正确内容保留。用收件人有权取得的东西试办：他还能否正确完成当下的事，包括有依据地决定暂缓？若缺了它就会办错、失去机会或必须重做专业判断，检查题面是否交代了这个需要、标答是否已解决、所属复合考点能否识别遗漏。另一种做法依法达到相同效果时照常给分；重复成果并回原事项。这个试判只供作者使用 |
| **4. 文件齐全，但请求沿用失效旧稿或采用有明确损失的口径** | 据卷核准请求及可选方案，检验判据能否识别因此少收、多付或失权的具体结果。若错误方案仍能通过，补明依据和失效后果；若题面已透露待求路径，改写泄露答案的位置。其余独立事项照常判定 |
| **5. 上游基数有误，下游独立判断正确** | 按预先写明的共享前提判分。同一错误只在其所属考点扣分；下游另有独立要件的，按答卷是否实际满足该要件判定 |

---

若本题有走向研判，在同一决策考点对照两份近似答卷：一份猜对倾向且文件齐全，却漏掉决定性反证或仍照抄旧请求；另一份充分解释该反证，并在可辩护的采信前提下给出对应的可用成果。前者应在该项失分，后者按其依据和成果判定。若两者只能靠措辞区分，回到设计方法重做该处案件依赖。不得靠增加整题归零情形制造差距。

## 首答实做覆盖

这是检验出题效果的私下口径。仅在已经取得同版真实首答和随附成果时使用；独立评分继续按冻结的复合 R 判定。备忘录留在出题侧，覆盖率、目标时长和轮次不写入题面、考点或标答。

- **先定比较对象。** 从本次成题时私有备忘录的最终采纳项取分母，每项对应一个可独立使用的业务结果。必要前提、重复引述、同稿多种格式、工具动作不另计。查同版题面、材料、首次交付的正文及附件；后续追问补做另记。首答收集不全时注明无法核实的项，暂缓给整题比例。首答已收齐而其中承诺的成果缺件，则按收件人实际拿到的内容判断。旧题没有预定事项时只作回看诊断。
- **逐项找实作证据。** 在答卷中定位本案原件、判断或处理及其实际产出的结果，记为“做到结果”；有实质处理却停在中途记“部分”；只列文件名、复述要求或许诺稍后做记“未做”。实作充分、但结论算错或选错的，记“做到结果，结论有误”，由原考点判断正确性。合法等效做法按同一用途核查；只获授权备办或客观上只能查到当前阶段的，以该阶段本可完成的工作为准。
- **逐题判读。** 首答实做覆盖率取“做到结果”的项数除以全部采纳项，列出分子、分母及部分项。目标至少 80%，且委托人首要事项须实际做到结果。这个比例衡量独立事项的实做面；正确性、交付耗时和 Agent loop 各按本身的证据记录。简答若满足了题面却漏掉设计意图，保留该项并记“交办不清”，修订后用新首答验证。若已清楚交办而作答者漏做，检查能否让接手用途更明确；若已经实做却出错，保留原判断难度。不得在看过答卷后改变分母或给公开题面补上正确解。

## 对照相近任务

有其他题目的完整正文供比较时，遮去名称和数值，试用其中一题的判断、正文及随件去办另一题。写得都像诉状并不说明雷同；核到某个请求、证据范围或客户动作，才能区分二者。若替换后仍可交差，重查本卷是否还有更合适的办理任务。业务已经不同但题面、考点、标答总照一份文件目录展开的，分别按客户怎么交办、错在哪一步、收件人怎样使用重写。只有业务摘要时，仅比较其中可见的办理方向。
