# 题目包字段

按本次返回 schema 填写七项内容；下列花括号、Markdown标题和列表只用于说明字段，不原样进入业务文字。题面＝question，标准答案＝reference_answer。字段契约不固定业务文体或作答工具，业务文字采用[书面表达组合库](书面表达组合库.txt)中的办公写法。

## 表头

题目 ID：{本次 ID，仅用于题包关联，不写入业务正文}
一级／二级行业：{任务发生组织的主营行业及细分行业，按当前分类}
任务形式：{本次契约允许且有真实业务依赖的形式，不机械拆轮}
输入附件：{作答者实际可见的名称或序号}
L1 职业簇／L2 职业：{负责交付的律师／法务岗位，不填当事人的诉讼身份}

## 任务名称

{具体事项及核心办理工作；按最终题面命名，不照抄路径，不提前给待求结论，不堆全部文书名称。}

## 任务类型

{按最终业务用途选本期适用的主要类型，不按附件名分类。}

先按设计方法完成任务盘点、全部求解及复合判据，再为任务名称、prompt、rubric、作答思路、标准答案-文本分别组合表达。下列字段说明不是题面或答案的固定目录，不把内部盘点、写法名称或自查清单作为新增返回字段；不得为采用某种组合反向调整题目内容、方向和难度。

## prompt

{按[场景规范](../references/材料方向场景与交付设计.md)、[设计方法](../references/出题设计方法.md)及[交付规范](../references/题目格式与交付.md)写真实委托：服务一方、办理时点与信息、权限、对象范围、成果用途及必要依据要求。按用途布置实际检索、计算及文件制作、导出和检查工作，可要求 PDF、DOCX、表格等成果，不统一限制为纯文本。对需要深入处理的部分，明确要求完整梳理、全面核对、逐项列明、细致区分或展开论证，并写清需要呈现的依据、结论、计算、条件、例外、成果落实和核查结果。模拟条件明示；不提前给冲突位置、判断结论、分支清单或解法。}

{题面不得使用“简短回复”“简要说明”“无需详细”“不必展开”“只需概述”“不要过多说明”等压缩实质作答的措辞。文件题要求业务成果完整交付；如需回复说明，应按本题实际用途交代各文件、关键口径、实际核查结果、发现的问题及未完成限制，并明确该说明不能替代文件正文或缩减成果。交付说明的内容和位置由对应成果的用途决定。}

## 考点 rubric

{整体失效规则依评分规范筛选本题适用风险，落到具体对象、错误行为、核验依据和核心委托后果；多个情形写清独立触发关系及不触发边界。五个风险方向仅供作者审查，不作为固定条款复制到题包。}

{按[评分规范](../references/评分与难度验证.md#考点)划分复合专业结果，完整覆盖且不重复。逐项依据核心结论、决定性依据和成果可用性判断成立或不成立，非实质错漏不否定本项。等权换算百分制，不设固定条数。每题必须写入一处案件化整体失效条件及整题归零后果；按评分规范放入现有字段，不另占得分项或分母。}

{评分者不读取 Skill、作答思路或默认标答；每条 criterion 须包含自足的完整判据。正文写具体成立要求及决定性失败影响，不重复“全部满足得分”之类尾句；整体失效条件写清具体行为、证据及全题后果，不固定标题或措辞，不增加schema未声明的字段。参考[复合示例](../references/评分与难度验证.md#关系型考点示例)，不继承示例事实。}

## 作答思路

{用日常专业书面说明完整展开本案决定性记录如何支持、限制或推翻主张，逐项说明规则与条件如何决定处理，细致区分对象、时点、证据效力和适用分支，并解释必要计算及竞争解释的取舍。写已完成的专业论证，不复述通用工作流程，不交Markdown正文、代码或生成脚本。}

## 标准答案-文本

{按日常办公材料或对应正式文书体例全面完成委托，逐项给出必要论证、核算、分支、办理动作和可直接使用的正文。结论、条件与实际条款前后一致；细致区分不同时点、原卷事实、模拟条件及剩余未知，并完整说明其对成果使用的影响。业务正文不带Markdown标记或编程内容，不能只列文件名、“另拟文书”或以代码代替文件交付。}

{文件题的文本标答须写全内容及必要公式；实际文件和检查记录另按本次契约交付与校准。未实际生成或评分端未取得时，在完成说明报告校准缺口，不把未来操作指令、未执行脚本或虚构链接当执行证据，不新增 schema 字段。}

## 独立使用与组合规则

业务设计完成后必读[表述方法](../references/表述方法.md#独立使用与组合规则)和[书面表达组合库](书面表达组合库.txt)。任务名称、prompt、rubric、作答思路、标准答案-文本分别依据本题的触发事实、信息关系、接收人和成果用途选择并组合表达组件。以改写前内容核对全部业务工作、难点与0/1判分关系不变；选型编号和内部组合过程不进入题包。

## 已有题目的保义改写

仅授权润色时按[保义改写规则](../references/表述方法.md#已有题目的保义改写)，不借改写改变题面工作、rubric 或标答结论。
