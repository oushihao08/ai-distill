# 法律垂类评测：材料、场景与交付物参考

## 来源与使用方式

第 1–37 项依据律师提供的《副本法律垂类评测（材料-场景-交付物）对应表20261111.docx》，沿用其场景编号与专业核查思路。原表的文书举例可在仓库提交 `276b18b` 的同名文件中查到。第 38–62 项为后续按领域补充的方向。两张表的末列均说明材料与办理状态怎样影响实际交付。

**使用原则（按需定点读取，不作固定模板或机械套餐）：**
- 先确定本方今天要办成的事、谁接手、已有哪一版能用，再查相近行的专业问题。客户只等返稿，就在原稿副本中改全受影响的正文和引用，交回可用版本。另有签署人、接收机关、披露范围或持续复算用途时，按该人能独立办理的动作另备所需成果。其他办事方式更贴合本卷时直接采用。
- **相容实质工作应选尽选，但严禁塞入低依赖常规内容**：相关行中由本包底层证据支撑、具有独立业务用途的工作均应纳入盘点；**严禁为扩充篇幅塞入脱离本案具体冲突的常规公司章程通则、通用合规手册或同质短申请**。
- 客户已经收到指定格式的补正或已决定送交某份文书，就按真实要求交办。办理去向和文种尚待律师判断时，题面只交代客户要解决的事情、收件用途及需守住的权利，让律师据材料选定路径并备好相应文件。
- 原表与扩展表中的条号、期限、数额标准及程序结论仅作检索线索，出题时必须按[作者依据核验要求](../references/出题设计方法.md#规则与载体落地)打开行为时与现行权威原文核实。身份与时点边界遵守[场景规范](../references/材料方向场景与交付设计.md)。

## 律师原表：第 1–37 项方向参考

| 税务稽查通知/税务事项通知书+进销项发票台账+采购合同+物流及资金流水 | 60. 涉税“四流不一致”善意取得专票申辩、补税滞纳金封顶与偷税阻断 | ①逐笔比对合同流、发票流、货物流（过磅入库单）与资金流（含挂靠代付、三方抵账），区分真实交易下的善意取得虚开增值税专用发票与恶意让他人为自己虚开；②依据国税发〔2000〕187 号、国家税务总局公告 2012 年第 33 号及行政强制法第 45 条，核算进项税额转出补税额、不加收滞纳金或滞纳金不超税款本金边界；③阻断偷税行政罚款及刑法 205 条移送风险，把握先缴清税款滞纳金或提供担保的复议前置门槛。 | 尚处于稽查核实时，将凭证逐笔对应到待解释交易；已经有处理决定时，依决定内容和客户所求判断是否须另备救济或履行材料。 |
| 首封与轮候查封裁定+抵押/建工/税款凭证+拍卖成交裁定+执行分配方案 | 61. 多债权参与分配顺位重排、首封移送与执行分配方案异议之诉 | ①核查被执行人是否具备参与分配主体条件（公民或其他组织 vs 企业法人破产转衔接），严控收到分配方案后 15 日书面异议期与收到反对意见通知后 15 日分配方案异议之诉起诉期；②穿透执行费用、建设工程价款优先权、设立先后登记抵押权、欠缴税款、职工工资及普通债权（含首封奖励比例）的法定受偿顺位与各债权计息止算口径；③重算本方应分得款项差额并锁定异议之诉被告范围。 | 正式分配方案尚在征询与已经送达且出现反对意见，分别核对当下谁能处理哪一项差额；算出的同一金额应写进当前可使用的文本。 |
| 公证债权文书及执行证书+实际放款还款流水+仲裁裁决书/条款+执行通知 | 62. 赋予强制执行效力公证债权文书不予执行与商事仲裁撤裁／不予执行 | ①公证执行线：穿透借据票面与实际出借本金、预扣砍头息、复利违约金超法定上限及公证处未向债务人核实履行争议即签发执行证书的程序严重违法，核验不予执行申请期限及裁定不予执行后另行起诉衔接；②商事仲裁线：核对仲裁协议效力、超裁、隐瞒足以影响公正裁决证据或违反法定程序事由，比选向中院申请撤销仲裁裁决（6 个月内）与执行阶段抗辩的管辖及审理边界。 | 先认清正在执行的是公证债权文书还是仲裁裁决。审查文本服务于当前收到的执行行为和客户可主张的具体事由，另一类执行依据不凭空并入。 |

## 补充设计参考：怎样从材料中展开高负荷实质工作

先看客户今天要推进什么，再从下表找与卷内记录吻合的工作。若材料止于一次询问、一次会面前或一次返稿，就做到该节点能交给接手人使用的程度。各行可以单独成立，取得新材料或另有授权后才可推进的事，写明届时依据什么办理。

| 材料中出现的具体情况 | 哪项判断会影响行动 | 实际接手人如何使用结果 |
| --- | --- | --- |
| 主裁判、主合同或汇总表与底层附件记载不一致 | 逐笔核对原始凭证与转述记录，辨明重复入账、当日退回、面积/单价颠倒、条文漏引或前案已结清扣减，回应最强竞争解释 | 金额须逐笔勾稽时在活公式底表完成核销，并改准请求。差异仅影响一项条款或证明范围时，直接改定收件人使用的文字并配上对应凭据 |
| 历审、送达与执行多阶段文书并存 | 核清哪些节点真正改变现行权利和期间，例如电子签收何时完成、查控发生在结案前还是结案后 | 只有一个决定性日期时，直接在现有办理稿中写清起算依据并改准请求。几项期限仍须由他人持续跟进时，另交能接续使用的记录，保留仍然有效的裁判结论 |
| 多套救济或交易方案存在利害不对称 | 算清各路径的法定要件、除斥期间、税费诉讼成本及对本方的反噬风险（如重算倒增债务、未减资径诉被驳回） | 可确定哪项会白白丧失权利时，交可保住该权利的当前稿。不同路径在回款速度、风险或成本之间确有取舍时，把具体差别交有权人决定，分别备妥有现实用途的文字 |
| 公司档案、章程、决议与出资转股记录交织 | 结合行为时的规则核清责任与表决权限。留意本次受托的是公司还是股东个人、是否真有待议的章程条款 | 个人收到索款时，针对其责任范围交可用的回复；公司有具体会议议程时才改相应议案。多笔缴付需陆续核销的，将其原始凭据与可更新的余额交经办人 |
| 争议尚待查明，卷内另有须及时行使的权利 | 分别核实两件事的对象、期限、起算依据及当前可办部分。在等待一方答复期间完成另一方到期前所需的行动 | 负责守期的人拿到可送签的文本和已有证明；负责核查的人拿到针对特定持有人的取证请求，明确两项结果何时需一同复核 |
| 一份报告涉及多项争点，原始记录各由不同人掌握 | 把能用现有材料质证的报告条目逐项办完，对关键缺证区分可由本方调取和须依法申请调取的范围 | 提交对象收到有依据的具体异议及可随附的凭据；只有确需向不同对象取证时另备相应文书，同时保留可独立主张的部分 |
| 在卷已有补正通知、实际收讫或验收反馈 | 从前次递件或履行版本逐项对照：原请求哪部分仍有效，反馈解决了什么，还缺哪项证明或履行 | 接手人拿到本次可用的补正正文、更新后的请求或履行安排及对应随件；尚未获得的回执保留待核，不虚写完成 |
| 交易拟交割，有签署权限、交付清单和未满足的先决条件 | 核实各方可签范围，分别处理可移交的部分与须暂缓部分；确需豁免或重新授权的交给有权人决定 | 按卷内条件拟好能用的交割指令、交接清单或授权文本，让签字人能明确放行范围及须留存的凭据，不推定对方已经同意 |
| 双方已有还价或协议返稿，付款、担保或权利释放的条件未谈拢 | 对照前稿和本方授权，指出对方改动会让谁先履行、谁承担落空风险。将能交换的条件写进回稿，超出授权的选择交委托人决定。卷内另有期限的，核定最迟行动日 | 谈判代表拿到可发的具体反提议，内部底价和须请示的让步留在己方。下一轮尚无回复时保留未决条款和到期动作。已有对方回函时才据实际文字更新约定 |
| 已有相对方的报告、主张或送审材料，同卷有逐项核对所需原文 | 承办人须把争执落实到能用的那一件事。例如庭前逐项选定认可与反驳范围、对有争议的记载准备可当场出示的证据；工程结算中按签认变更与验收范围审定哪些行可付、哪些应退回 | 庭上用的证据副本应能从异议找到所附完整记载；付款审批人收到可放行部分和有依据的异议明细。同一底数不能代替两种决定 |
| 客户面临取舍，规范文本没有解决影响行动的具体争点，且存在可核实的公开办理依据 | 依[规则与载体落地](../references/出题设计方法.md#规则与载体落地)对读公开原文与本卷。比如比较两案中责任主体是否处于同一程序位置，或核对公开受理条件是否涵盖本次申请 | 只在比较足以改变请求、签约条件或补证安排时，把结论落实到已有成果。题面交代客户要解决的争点与用途，不另发统一的类案检索作业 |
| 首次来询，发件人替公司和高管个人同时求助，或委托文件与实际指示人不一致 | 用来函、授权和卷内当事人关系确定拟服务对象。出现利益冲突线索时，在本所可核范围内说明还须查谁、由谁决定能否接办。期限逼近时，先让来询人知道何事仍须自己安排 | 来询人收到可转达的回复，能据此找有权人、及时另聘或补交授权；承办合伙人掌握核查所需身份与关系。接案未定时，其他主体的保密材料与具体抗辩意见留在适当的接收范围内 |
| 刑事案件已有阶段性文书，委托关系指向犯罪嫌疑人或被告人，卷内陈述与客观记录存在具体出入 | 先核对当前阶段、律师身份及能取得的材料。例如会见前将待本人核实的行为时间与在卷记录并列，拟开放式提问；已经阅卷且有异议依据时，追到原笔录、提取记录或相应原始凭据，确定异议会改变哪项指控或处理意见 | 会见律师可按争点发问并区分本人陈述与待核线索；具备向办案机关提意见条件时，写出有卷内出处的具体请求和理由。尚未会见时保留答复位置，不能代当事人作陈述 |
| 庭前、听证前或调查访谈前，已有相互抵触的陈述、签收材料或照片 | 围绕会影响请求或处理决定的差异，确定向谁发问、凭哪份原件追问。若已有真实笔录，将其中的承认、否认、未答分别与客观材料核对，决定哪些争点尚须举证 | 出席人能从一句事实问题直接找到待出示的材料及追问方向。已举行且卷内有记录，才据原话整理可请对方确认的更正或补充意见，不能预写证言、对方认可或现场结果 |
| 业务部门今天要发报价、签订单或给客户回复，往来稿与已签框架在服务范围、验收或退款口径上有出入 | 在拟发送的原文旁比对有效约定，圈出会新增义务的具体措辞，改到业务人员能直接使用。若客户要求超出既有授权，给负责人讲清接受该条件的代价与可回复的替代说法 | 销售收到能给客户看的修订稿；需要决定是否承担例外时，审批人另看到有分歧的原句、备选条款及其对履约的影响。双方认可情况以现有签批或回函为准 |
| 客户要判断一项审批能否挡住违规操作，或决定已整改的业务能否恢复办理 | 先用权限表和审批规则检查流程设计，例如经办人还能否批准自己的订单。只有制度或整改稿时，改清有缺陷的步骤，给验收人列出核实实际执行所需的记录。有整改后样本时，把该笔订单的经办人、审批权限和实际操作记录对到一起 | 复核人可据样本说明本次审批有效、仍被绕过，或因缺失记录须补证，并据此给出该笔业务的办理指示。仅凭一笔通过不能宣布全部整改完成；卷内没有运行样本时，交可执行的验收办法，保留运行效果待验 |

接手未办完的事务时，可对照下面的实例定位还要亲自处理的原件。只取本案有根据且客户当下需要的工作。

| 具体来由 | 还须律师实际办理的事 | 接收人如何使用 |
| --- | --- | --- |
| 债权人已有一处受控财产，正考虑追加一项有成本的追索 | 还原原案控制的权利和实际到款，核第二项能新增的可分配价值、优先负担和启动成本。缺少价格时，找出决定继续投入前最值得核清的事实 | 负责人据此批准当前查证、推进处置或暂缓新增支出；原案经办人取得已有依据可办的请求。签发数、投入预算和估值各有出处 |
| 分批供货发生质量扣款，既有验收和退换单，又有对方要求一次结清的返稿 | 从争议批次追到退货是否实收、替换品是否另验、扣款是否已在对账中体现；审查结清文字会不会放掉未决质量责任 | 可结批次核准付款，未决批次的条件改进对外回稿。财务执行的金额与双方准备确认的权利范围能够同时成立 |
| 接到补正通知，并留有前次实际递件副本、收件清单和新增凭据 | 逐项对出哪版交过、哪些内容须替换、新凭据能解决哪项退件理由，以及补正是否改变原请求范围 | 经办人能带着这次确须递交的替换内容、说明和随件接着办，手中分得清哪份前稿仍有效、哪部分尚不能报送 |

### 延长有效工作链与去同构底线

1. **按工作关系查漏**：从现有结果追后续办理，从等待事项查并行工作，从接收人动作查正文及随件。确有共同的资金、标的、授权或期限，再验组合是否能同时实施。具体按[办理关系](../references/出题设计方法.md#材料到成果的工作链)与[接手使用](../references/出题设计方法.md#成果使用与办理交接)落实。
2. **考点与表达随业务分化**：同一复合专业结果（如逐份质证映射支撑答辩反驳总额、全量流水去重与清偿抵充支撑执行标的）合并为高判别力复合 R，具体按[评分规范](../references/评分与难度验证.md#设项与覆盖)划分；定题时按[书面表达组合库](书面表达组合库.txt)第七节比较材料支持的办理形态；成稿时按前六节选各字段写法，严禁把本表栏目编号或内部设计黑话照搬进题面。
