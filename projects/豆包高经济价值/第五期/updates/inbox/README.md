# 群消息待核收件区

这里保存从项目群、通知群或工作群收集的待核消息原文／导出快照，供后续查找是否有规则变化。它不是正式规则目录，消息中出现的要求、建议或转述都不自动成为出题依据。

每条消息尽量单独保存为 Markdown；群聊导出可按日期分批保存。记录以下来源信息：

- 平台、群名称和原消息链接或消息编号；
- 发布者/发布角色及原始发布时间；
- 本地抓取时间、检索的起止时间和是否拿到完整上下文；
- 原文正文；涉及图片、文件或引用时一并保存可核验来源。

建议文件名：`YYYY-MM-DD_HHMM_群名_消息编号.md`。不改写原文；需要脱敏时另外保存脱敏副本并明确标记。目录内文件被本目录的 `.gitignore` 排除，避免群聊原文及个人信息意外提交；请使用受控备份保存原件。

分析后在 `reports/updates/` 建立报告，列出原文链接、与当前冻结版本的差异、可信度和未决项。负责人确认后，才将必要且适用的规则修改到 `materials/` 或 `skill/`，并通过工作台冻结新版本。不要直接编辑已冻结的 `snapshots/`。

从旧 `materials/` 移入的 `难度提升会议纪要.md` 和 `优秀案例讲解会-程前AA录播纪要.md`，只确认了原归档位置和会议内容类别；原群链接、群名及准确日期未登记，不根据内容猜填。引用它们时需注明来源元数据缺失。旧冻结快照中的同名副本是历史版本，不在这里修改。
