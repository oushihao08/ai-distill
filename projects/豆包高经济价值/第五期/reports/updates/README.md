# 更新分析报告

一轮核查一份报告，建议命名为 `YYYY-MM-DD_来源_更新核查.md`。报告是更新发现与判断记录，不是正式规则或题目成果。用[模板](模板.md)记录：

- 核查时间、来源平台/群、检索范围及是否完整；
- 对照的当前冻结版本及其规则版本号；
- 新消息的原始链接/编号、发布者角色、发布时间和抓取时间；
- 逐项差异、影响范围、证据和状态：`已确认`、`建议采纳`、`待核实`、`与现行规则冲突`或`未发现变化`；
- 负责人决定及后续修改到哪些 `materials/` 或 `skill/` 文件。

“未发现变化”只能表示在报告写明且已完整读取的范围内未找到变化；无法进入群、缺少上下文或导出不完整时，结论必须标为未完成核查。群内转述不能单独证明外部平台现行规则；优先回到官方文档、原公告或有权发布者确认。报告只保留必要摘要和来源定位，不复制无关聊天或个人信息。

出题和独立审查可以把**已采纳并进入当前冻结版本**的变化作为规则输入。未核实消息只作待核提示，不能转成硬约束、案件事实或评分点。现有执行器尚未把这些报告自动注入题目上下文；报告位置本身不代表模型已经读取。
