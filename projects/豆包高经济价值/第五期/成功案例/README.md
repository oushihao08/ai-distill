# 出题案例模板库

本库供出题 Agent 参考历史案例的构造方法，目录名保留历史命名，不表示已验证成功。先按材料特征和业务判断选择案例，再读精华卡；完整题目、附件和复盘仅供按需追溯，避免每次加载全部历史资料。题目3、4、6的记录核查见[提炼报告](../reports/updates/2026-10-11_题目3_4_6案例提炼与评分边界.md)；它们未保留为 skill 模板。

## Agent读取规则

1. 结合当前用户目标及新附件判断适用性；按决策关系匹配，不只按“借款”“法务”等词匹配。
2. 命中后读取对应案例卡，将适用机制映射到新材料；不强行使用全部机制，不继承本案事实、数值、条数或结论。
3. 需要核对某个具体实现时，按案例卡末尾索引读取相关原文；不要默认打开所有附件、完整标答和复盘。
4. 新题的事实、规则、计算和考点重新求解。案例卡不能替代新附件阅读，历史评分不能作为新题的预定成绩。

## 后续案例如何入库

每个案例使用独立目录，以`README.md`作为精华卡，保留：适用条件、核心决策关系、附件作用、机制与具体证据、迁移步骤、易错边界、实际反馈及原文入口。完整资料留在同目录，库索引只增加一行，不复制整份案例卡。

案例卡面向出题者，不发送给作答或独立评分 Agent。本目录是案例资料库，不是题目附件输入目录。工作台使用 [skill 内的模板入口](../../skill/references/模板参考与迁移.md)及自足精华卡，完整归档不进入其 skill 扫描范围。新增案例供工作台参考时，同步提炼到 skill/assets 并在[案例库索引](../../skill/assets/成功案例索引.md)增加一项，无需逐案修改主提示词；修订时核对两处精华，避免结论漂移。
