# 公司法务出题准则

适用：公司内部法务题。身份是法务，不是律所律师；一级行业跟公司主营业务走，不写成法律服务。下文用寅鼎判决债权受让题的出题和人工盲评做例子，例子不是新的门槛。

评分仍只按官方规则：15–20 条，一条一事，0 或 1、等权。先写通过时产物里必须出现的结论，再写何种写法得 0。不设权重、倒扣、一票否决。官方分以机标为准。没跑过的题只标未验证。

## 1. 先定一个拍板

一道题只服务一个决定。写清谁在什么截止前用结果做什么：签、不签、付、不付、发、不发、改、申报、应诉、交割，或拦住一笔会亏的交易。说不清谁用、拿去做什么，就停。

寅鼎题的拍板是：模拟汽车流通公司的业务负责人，在 2026年3月31日前，要不要按他的方案付款受让（2018）渝0104民初37号债权并立即申请执行。法务出意见，不代替他签字。

拍板要能被卷宗否掉一部分、留下一部分。业务方案本身就是错误请求：七折、把范*和凯博列进去、把没进主文的项目算进价款。模型若顺着业务方案写，核心决定就错；若一律写成全部不能受让、债权绝对消灭，另一边也会错。

不要出的题：通用法律问答、法条解释、单份材料摘要、律所接客户的交付、几件互不相关的小事拼在一起、只换公司名的换壳题、必须登录真实系统才能做的题。

## 2. 材料按来源拆开，不先做成答案表

模型只看 prompt 和附件。思路、标答、考点不进模型输入。

附件保留原始结构。同一事实在起诉状、协议、回单、庭审、判决、公告、送达回证里各写一遍，允许互相打架，但必须有一份能裁决。没有裁决依据的矛盾不能拿来压分。

寅鼎卷里实际能用的层次：

- 裁判层：判决主文、本院认为、宣判笔录、判决公告。这层决定给付和生效。
- 当事人层：框架协议、欠款附加条款、起诉状、证据清单、庭审发言。这层有请求和算法，多数没有进入主文。
- 程序层：受理通知、缴费说明、简易程序通知、普通程序通知、两份传票、两次开庭公告、电话笔录、送达回证。这层决定案件还在不在审、何时生效。
- 凭证层：银行回单、诉讼费收据、刷卡凭证、营业执照、身份查询、授权委托书。这层核对主体、日期和费用，不能替换主文金额。

脱敏金额不考点具体元。改查主体、口径、程序、是否进入主文。星号保持原样，禁止用部分回单加总后还原本金。

合成主体必须标明模拟，不得冒充卷宗里的真实当事人。外部项目另有真实材料要求时，模拟主体不因此取得提交资格。附件不得用模型改写、补页或生成。

## 3. 难点必须同时有依据、必经处理和可核对后果

自留一张清单，不写进题面，也不写进思路和标答。每一行只记：卷宗位置、正确结论、模型常错法、错了会改哪一个后续决定、对应哪一条考点。

能绕过的点不要当成难点。模型只写“建议否决、及时效风险、主体待核”，仍然交得出一份像样意见时，这个点没有接到交付物上。要让错误结论改变付款、被执行人或对价口径，底账才能对出来。

寅鼎题里模型实际拿到的分，和实际绕过的点，就是后面写考点的依据。

模型做对、考点也查到了的：

- 执行依据是（2018）渝0104民初37号，没有另立金融纠纷。
- 总结论是不同意付款、不提交执行申请，没有写出七折价款。
- 范*因超出日常生活、非夫妻共同债务被驳回。
- 凯博不是当事人，链动只是收款户名。
- 寅鼎和王**都在主文第一、二项。
- 单笔 10% 违约金和保全费没有计入。
- 卷外有没有执行立案，列为待核实，补齐前不付款。

模型绕过、考点因此得 0 的：

- 不写 2018年5月11日已宣判审结，只用“2018年5月作出”。
- 不写 2018年5月14日公告、满 60 日视为送达、上诉期至公告期满后 15 日。
- 不处理宣判笔录“上诉以书面材料为准”，也就不写卷内无上诉状、无二审裁判。
- 不处理 2016年6月24日与 2017年6月24日回单的冲突。
- 不处理合议庭署名不一致，也不写简易转普通、2月12日传票不否定判决。
- 申请执行期间写成“若已过”，放进待核实，不按公告路径认定二年期间在卷内已经届满。
- 不写 2024年2月24日回证签收人喻**已于 2018年2月8日撤回授权，也不写 2024年12月4日判决回证不中断时效。
- 不写主文之后的加倍迟延履行利息，与月利率 2% 分开。

模型写错但考点没扣住的：

- 底账写判决“认定一人公司财产混同”。判决没有这样认定，王**是主文列明的付款义务人。原考点的零分条件只写“必须先证明第六十三条才负责”或“据此去掉公司”，错写混同仍然得 1。
- 回购 10% 的依据错安到《欠款附加条款》上，但因为该项仍列为不能，单笔违约金那条仍得 1。
- 诉讼费列为可以计入受让对价。给付范围那条若只把零分条件写成“回算保底利润”，这项错法扣不住。

这三处就是返修考点的直接理由。不是为了压分收紧措辞，是产物里已经出现的错法，原零分条件没有覆盖。

## 4. 题面只布置工作，不点破坑

题面写成给同事的签批任务：角色、截止日、业务方案、三份交付物、金额不还原、未完成状态不得写成已完成。

不要写：哪一页是重复、哪个日期写错、谁的授权已撤回、公告怎么起算、哪一项会被驳回、必须跑多少轮、准备压到多少分。题面一点破，对应考点作废。

业务方案可以写进题面。它是待裁决的请求，不是解题步骤。寅鼎题把七折、四个被执行人、保底利润和保全费写进方案，模型必须逐项回应；没有告诉它哪一项会被主文挡住。

交付物要互相锁住。签批意见、底账、待核实清单对同一对象的结论必须一致。底账要求卷宗里出现过的公司、自然人和收款账户都留行，没有义务的也留。待核实只收挡住付款或执行、而且卷宗不能闭环的事项。已经能否定的，不得放进待核实。

这一条是为了对付“全部待核”。寅鼎答卷把执行时效、确切金额、转让通知、履行能力都放进待核实，看起来完整，实际上把卷内已经能算完的二年期间也放走了。

## 5. 让错误请求和正确放行同时存在

不要设计成全案否决也能拿满分。卷宗里有依据的事项必须放行，没有依据的必须拦住。

寅鼎题里必须拦住的：范*、凯博、链动、保底利润、回购违约金、单笔 10%、保全费、立即执行、七折价款。

必须保留的：寅鼎和王**是主文义务人；主文本金、截止日利息、月利率 2% 按原写法转记；诉讼费只是负担裁决，不并入价款；加倍迟延履行利息单独记载，不折进一次性对价。

局部未定只留真没有材料的点。卷外是否另有执行立案或时效中断，可以待核实。待核实要写明卷内已经能确定什么、不能写成什么、谁补、补齐前哪一步不能做。不得把待核实写成已经执行到位，也不得写成债权绝对消灭。

## 6. 考点按答卷会出现的句子来写

一条只查一件事。通过标准写成产物里必须出现的结论，不用“考虑了”“区分了”“识别了”。零分条件写成这道题已经见到或很可能出现的句子，不只写最极端的一种。

每条都按这个顺序自检：

1. 不写这一句，核心决定还能不能交卷。能交卷，这条还没接到交付物上。
2. 只写半句、写成“若已过再核实”，算不算通过。算通过，零分条件要把这种写法列进去。
3. 写错依据但结论方向对，能否得 1。若这处依据本身就是坑，零分条件要覆盖错依据。
4. 上游错了会不会用同一句话再扣下游。会，就拆开查不同结果，标答里说明连带。

寅鼎题应改成的写法：

- 王**那条：通过标准仍是两人都按主文第一、二项列为义务人。零分增加“写成判决已认定财产混同或已适用公司法第六十三条”。只写主文列明、没有写混同的，不因此得 0。
- 回购违约金单独一条：不计入对价，依据是框架协议第三条，不是《欠款附加条款》。把依据安错文书的得 0。单笔 10% 仍另查。
- 诉讼费单独一条：负担主体按判决尾部，不并入受让价款。列为可以计入对价的得 0。保全费继续单独查。
- 时效那条：通过标准写明按 2018年5月14日公告推算，履行期为生效后十日，二年申请执行期间在签批日已经届满。零分增加“写成若已过、可能过期、建议核实时效后再定，而没有先给出卷内届满结论”。卷外中断仍是另一条，避免同一句话扣两次。
- 2024 年回证那条：必须写两份回证的日期和喻**撤权日期。只写“2024年送达不是执行文书”得 0。

格式、结构、常识合计不能接近一半。文件交齐、有标题、金额带星号，这种条目最多放一两件，而且要绑在会改决定的内容上。

条数保持 15–20。少了，一条权重大；送分项多了，否决结论本身就会把分数抬过 50。寅鼎这版 18 条里，结论、范*、凯博、链动、主文利息、保全费都比较好拿。真正拉开分数的是公告期间、撤权回证、合议庭、日期冲突、253 条和“若已过”这种半句。返修时补的是零分条件，不是再加一批好拿的格式分。

## 7. 思路和标答按承办人写

这两部分给人看，不进模型。用连贯的话写材料怎么分层、哪一句为准、写错会变成什么决定。不用表格，不按考点序号往下填，不写“本条得 0”“模型只能看到 prompt”“内部难点清单”。

标答要能独立核对。主文金额沿用星号。期间按公告原文推算：2018年5月14日刊登，满 60 日为 2018年7月13日，上诉期至 2018年7月28日，无上诉则其后生效，再加十日履行。不要把推算写成卷宗里印好的日期。

标答附件只放交付物要求的底账，字段和题面一致。不把考点表再贴进去。

## 8. 自测和返修

先让模型只拿 prompt 和附件作答。再把产物和考点交给另一个模型逐条留原文，不给标答，不把目标分数告诉它。做题模型自己报分不用。

记录题目版本、考点版本、模型、作答原文、逐条证据、步数或时长。缺一项就标未验证。人工分不是官方成绩。

只有产物证明某条没有测到目标能力时才改题或改考点。可以改的情况：

- 模型错了，零分条件没覆盖它的句子。
- 模型不写某句也能完成付款决定。
- 材料不够，无法唯一裁决。
- 待核实被用来装下已经能确定的事项。

不能改的情况：为了压分把一种标答措辞设成唯一解；同一错误用两条重复扣；题面补一句提示；规定必须跑满多少轮。

版本改完重新盲测，旧轮次保留，不横比。

## 9. 交稿格式

成稿只一个 markdown，顺序固定：表头、任务名称、任务类型、prompt、考点rubric、作答思路、标准答案-文本。表头写题目 ID、一级行业、二级行业、单轮、附件绝对路径、L1 法律与合规、L2 法务。

任务类型默认整段照抄“法务、合规与交易支持”。不写飞书账号、领取状态、质检、自测分数。不代填、不代交。

本期若已锁定一级行业，新题必须沿用。在手超过 2 道不再新领。新题进度填已完成；打回改完填返修完成，不填已完成。
