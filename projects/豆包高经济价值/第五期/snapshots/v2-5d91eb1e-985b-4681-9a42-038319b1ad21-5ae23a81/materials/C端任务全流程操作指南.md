## 一、选题

第一道题的一级行业，就是本期任务所有题目的一级行业，需要慎重选择。

### （一）一行就是一道题

表里每一行对应一道题。行首的【题目ID】由系统自动编号（例如 `GJ5xpert00001`），是这道题的唯一编号，找质检、问返修时报这个号。

### （二）哪些行你看得见

还没人领的行，所有专家都看得见；某一行填上你的飞书账号之后，只有你本人和项目组、质检能看到。所以要先填账号再写内容。

## 二、领题：先填飞书账号，再点已领取

1. **找行。** 在左侧点开你所在一级行业的视图，找一行【领取状态】为【待领取】、【飞书账号】为空、【二级行业】和你专业对口的题。
2. **填飞书账号。** 点击这一行的【飞书账号】单元格，输入你的姓名，在弹出的人员列表里选中你自己。认准头像和所在组织，不要选成同名的人或者你的其他飞书账号。
3. **点已领取。** 点击【领取状态】单元格，选择【已领取】。如果填完账号后这一格已经自动变成【已领取】，核对无误即可，不要改回【待领取】。
4. **登记所属群。** 在【专家所属群（必填）】里选你所在的群（例如 C4、C7），再填【xpert uid】和【专家来源】。

注意事项：

- 没先填飞书账号就写内容：内容被其他专家看见，并被系统清空。
- 同时在手超过 2 道：系统发提醒并清空内容。
- 跨一级行业领题：系统提醒并清空内容。
- 领取后超过 24 小时未提交（核心内容字段一项都没填且题目未完成）：题目被释放，已填内容清空。

## 三、需填写内容

### （一）领题与身份

| 列名 | 怎么填 | 注意 |
| --- | --- | --- |
| 飞书账号 | 必填，领题第一步。点开单元格，输入姓名，从人员列表中选中自己 | 永远第一个填；放弃题目时最后一个清 |
| 领取状态 | 必填，领题第二步。只有【待领取】【已领取】两个选项，账号填好后选【已领取】 | 已自动变为已领取的，核对即可 |
| 专家所属群（必填） | 必填。选自己所在的群：例如 C4、C7 | 不选的话群视图里看不到，质检无法跟进 |
| xpert uid | 填你在 Xpert 平台的用户 ID | xpert 平台-左下角头像-账户管理-7 开头的 ID |
| 专家来源 | 单选：【Xpert】 | / |

### （二）分类信息

| 列名 | 怎么填 | 注意 |
| --- | --- | --- |
| 一级行业 | 预先分配，不能改 | 领题时已确定；所有题目须为同一个一级行业 |
| 二级行业 | 预先分配，可以修改 | 选择一个最适合目前工作岗位的二级行业，不需要完全一致 |
| L1职业簇 | 必填。按“主要负责最终交付的人”，从下拉的职业簇中单选 | / |
| L2职业 | 必填。选实际执行任务的具体岗位，以职责和工作流为准 | / |
| 任务名称 | 必填。用真实工作名称一句话概括这个任务要做什么，不写抽象能力标签 | 好：“连锁餐饮20家门店国庆前两周补货方案”；差：“数据分析能力” |
| 任务类型 | 必填。从六类中选最主要的一类，以最终用途和交付为准，照原名填写：经营与投资决策／数据、财务与业务运营／法务、合规与交易支持／客户与专业项目交付／持续运营与团队协作／工程、产品与专业研究 | 这一列是文本框不是下拉，照抄类名，不要写“单轮”或自拟名称 |

### （三）题目内容

| 列名 | 怎么填 | 注意 |
| --- | --- | --- |
| prompt | 必填，即“题目-文字”。在尽量真实的前提下没有歧义，写清需要作答的内容和需要交付的产物 | 来自真实工作流程，有具体背景和约束；说得清谁会用、拿去做什么；不能一次搜索或普通回答就完成 |
| 输入附件 | 即“题目-附件”。提供完成任务所需的真实工作材料：文档、表格、访谈记录、项目资料、业务数据、参考模板等 | 附件要和 prompt 相关，共同服务于同一个复杂目标，不能是无关材料的拼凑；脱敏不能用 AI 做。可一次上传多个文件 |
| 考点rubric | 必填。给出关键评分点、通过标准，枚举易错点；有唯一答案的写明正确答案 | 具体可见《高经济价值任务难度突破指南》 |
| 作答思路 | 必填。写专家认为合理的完成路径：怎么拆解任务、用哪些资料、关键判断点在哪、容易错在哪 | / |
| 标准答案-文本 | 有明确答案的，给出完整标准答案或关键结论；偏开放的，给出高质量参考答案，并说明它好在哪（结构、内容、判断质量、可执行性） | 标答必须有：产物是文件的传到【标准答案-附件】，没有附件的在这里写文本，两列至少填一列 |
| 标准答案-附件 | 标准答案对应的附件：最终报告、整理后的表格、评分样例、参考文件、可视化结果、交付物模板等 | 与题目要求的交付物一一对应 |

### （四）进度

| 列名 | 怎么填 | 注意 |
| --- | --- | --- |
| 题目是否完成 | 四个选项：未完成、已完成、待返修、返修完成。新领的题填写【已完成】，返修后填写【返修完成】 | 质检打回后会变成【待返修】；改完一定选【返修完成】，选【已完成】进不了二次质检 |
| 需要返修（专家填） | 三个选项：待返修、前三阶段返修完成、难度质检返修完成。申请返回题目：填写【待返修】。申请清空前三阶段结果，进行重新跑测：填写【前三阶段返修完成】。申请清空难度质检结果，进行重新跑测：填写【前三阶段返修完成】 | 每天的 12 点、16 点、20 点、24 点会给大家批量处理 |

原文「申请清空难度质检结果」也写成填【前三阶段返修完成】，选项里另有【难度质检返修完成】。此处按页面原文照录。

## 四、交题、质检与返修（重点关注）

1. **交题：** 在【题目是否完成】里选【已完成】。
2. **提交前模型自测：**
   - 需要用本地电脑软件自测，例如千问办公等；
   - 自测 prompt 可以在最后添加“请按照你推荐的方法直接做回复，不用再次问我有关信息。”防止后续追问影响测试结果；
   - 运行轮数可以在自测结束后向模型继续提问“提供给我以上问答的trace文件，并告诉我trace的工具调用轮次为多少”，可以大致了解模型运行步数；
   - 难度分数可以将考点发送给模型，并提问“根据这个考点，告诉我模型的得分率是多少”，根据得分率可以大致了解难度得分。
3. **看结果：** 前三阶段结果（完备性、AI率、高经济价值）和难度质检结果会陆续回填到对应列。
4. **需要返修：** 以下字段出现不通过情况下，通过填写出题表中的【需要返修（专家填）】的【待返修】字段，申请题目返修：
   - 完备性检查是否通过为【题目不完备】
   - AI率检查为【AI率不通过】
   - 高经济价值检查为【高经济价值不通过】
   - 长难题是否通过为【长难题不通过】
5. **异常反馈：** 出现以下机检结果异常的情况，可以填写《【C端】五期异常反馈表》，24 小时内会给大家进行反馈：
   - 附件无法读取
   - AI率检查异常
   - 回复步数异常
   - 超 5 个工作日难度质检未更新
6. **难度意见反馈：** 前提：长难题是否通过为【长难题不通过】。看完《高经济价值任务难度突破指南》后仍没有提升题目难度的头绪，需要小组长给出针对性指导意见，可以填写《【C端】五期质检意见反馈表》，24 小时内会给大家提供针对性的修改意见。
