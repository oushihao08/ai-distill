# 返修文档

本目录按题目保存评分未达标原因、对应修改方向及最多两轮的返修尝试记录。当前总览见[反修改题目地图](反修改题目地图.md)；每道题使用一个独立 Markdown 文件。

[第六期难度复判与修改计划](第六期难度复判与修改计划.md)记录本次历史题包与实际得分路径、评分待核事项、共享Skill加压方法及角色／场景修补边界。它是方法和执行记录，不替代逐题返修轮次或当前API状态。

## 记录约定

- 返修原因以本地工作流的独立评分结果和达标判定为准；评分无效或有争议时先标为待核，不计入返修次数。
- `已完成次数/2`只统计已完成“修改题目—重新作答—重新评分”的完整返修轮次。正在执行、失败或仅完成其中一步的轮次分别登记，不冒记为完成。
- 修改方向引用评分考点并要求作者核对已冻结材料，不补造事实、不把旧答案或旧评分作为新任务的业务材料。题目修改后须重新作答和评分。
- 文档只记录必要的考点摘要、工作流 ID、步骤状态及操作结果，不复制案件材料全文、完整答案、凭证或私有主体映射。
- 地图每次随返修步骤更新，保留历史状态，便于中断后续作。
