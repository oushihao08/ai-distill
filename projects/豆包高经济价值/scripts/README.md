# 豆包高经济价值项目脚本

此目录集中管理主项目各期共用的脚本。

| 文件 | 用途 | 调用方式 |
| --- | --- | --- |
| `delivery.ts` | 归档时写入交付缺口说明，不写题面、思路或标答 | 由服务端归档流程调用 |
| `delivery.test.ts` | 验证归档入口的已有行为 | 运行授权遵循仓库 `AGENTS.md` |
| `ocr/` | 本项目 OCR 识别试跑、抽查、缓存对比及真实题目流程核对 | 逐个阅读脚本顶部的影响说明；部分会调用模型、读取真实卷宗或改变工作流 |
| `skill/` | 本项目 skill 候选生成冒烟 | 会调用真实 Codex；只写候选和证据，不自动采用 |

服务端由 `server/publishing/project-delivery.ts` 解析 `delivery.ts`。项目专用脚本统一放在主项目的 `scripts/`，再按用途归入 `ocr/`、`skill/` 等目录；不放进某一期的 `questions/`、`materials/` 或 `skill/`，避免扫描成附件或规则输入。OCR 子目录中的脚本含固定历史题目、样本和任务标识，只用于对应调查，不是通用命令。
