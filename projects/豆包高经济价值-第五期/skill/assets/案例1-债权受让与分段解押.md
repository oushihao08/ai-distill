# 案例1 债权受让与分段解押

用途：供出题 Agent 按需参考的成功案例精华。案例库编号为题目1，原题编号为题目5。以下事实仅解释历史设计，不是新题事实或通用法律结论；使用本卡不需要加载历史题目和附件。

## 何时参考

当前材料包含同一业务的不同阶段、不同主体或不同效力文件，需要决定具体办理动作；付款、通知、审批或新证据会改变部分权利、金额或可执行范围时，参考本案。仅需事实摘抄、没有业务决策且不能补充明确模拟条件时，不强套此结构。

**核心关系：让作答者先确定证据和事件能产生什么效果，再把效果落实到金额、方案门槛及可执行文本；后续变化只更新受影响部分，其余结果保持一致。**

## 附件与题面怎样配合

| 输入 | 本案内容 | 出题作用及边界 |
| --- | --- | --- |
| 附件1 | 起诉、借条与回单、优先受偿申请、抵押证明、笔录、调解及送达 | 区分请求与司法确认、债权与担保、形成与生效；不能补造遮蔽金额或异常日期 |
| 附件2 | 保全立案及裁定、登记查询、结案及送达 | 交叉核对财产与程序；“有抵押”不证明抵押权人，“立案／划拨字样”不证明已有回款 |
| 模拟题设 | 公司受让、期初账、通知与付款、两种处置政策、新登记及报价 | 使历史材料产生当前决策和可核算变化；明确新增，不冒充原卷事实 |
| 历史题的可见规则 | 原题曾提供关键适用规则及来源 | 这是历史呈现方式，不作为新题默认要求；作者检索用于核验，新题按当前规范保留事实与必要条件，不附作者的规则讲解或答案依据清单 |

两份附件共同提供原债权、担保和保全历史，不是两个互不相关案件。原卷核验及程序文书强依赖附件；通知后付款、投资成本及报价计算主要依赖模拟题设。删除附件会失去证据判断，删除模拟题设会失去连续核算和交易决策，不能宣称所有考点都来自原卷。

## 值得迁移的机制

| 材料或任务条件 | 本案具体实现 | 迁移时保留的判断 |
| --- | --- | --- |
| 文件证明范围不同 | 三项优先申请、两证抵押证明、三项“有抵押”；24****与26****；调解未明确全部优先 | 对主张、证明、确认结果逐层判断，不能从名称相似或文件较新直接跨越到权利成立 |
| 日期与记录有异常 | 笔录签字生效与送达日期；执保结案、到位0及后续送达 | 根据有效机制及具体记录判断状态；核实局部异常，不把全案停办作为答案 |
| 同类行为因时点或权限产生不同效果 | 通知前付款有效；通知后付原债权人无代收权；后续实际转付才接受 | 先判断有效行为和发生时点，再更新账或办理决定；不是每次“付款”都直接减本金 |
| 一笔资金涉及不同主体 | 原债权人留存款同时减少债务和转让价款，却不是公司现金回款 | 分别维护债务、成本和现金口径，防止重复抵充、重复收益；金额相同不代表性质相同 |
| 连续事件改变核算基础 | 先费用、利息，再本金；两次有效清偿后分段计息 | 明确基数、端点、舍入及适用规则，用前次结果计算后次；作者先工具复核 |
| 两个方案服务不同目标 | 部分解押看剩余担保覆盖；全部退出看实际成本与现金回报 | 给出各方案自己的批准标准，要求求解最低条件；不要全用账面债权或一个总指标 |
| 需要判断而非一律保守 | 部分解押原报价不足，折价退出仍可达标；普通核账可先做 | 保留可批准、附条件和应阻断的真实差异；法律及经济条件分别成立后才能执行 |
| 新证据既补齐又改变风险 | A、B归属查明，B在先抵押降低净值，C属于他人 | 同时处理“什么已可确认”和“什么变得不利”；只更新受影响结果，不倒改历史履行 |
| 新提议改变法律结构 | 现金报价降低附一般保证；免除余债与保证存续发生关联 | 判断替代物能否满足原标准、是否仍有被担保主债务；不能将保证面值视为已到账现金 |
| 结论要进入实际交接 | 签批、底账、谈判、通知、法院申请、交割与修订 | 同一金额、状态、主体贯穿成果；明确权限、条件、顺序、失败后果，不以文书名称代替正文 |

本案用两个门槛区分决策：部分解押要求“保留担保净值≥1.10×剩余债权”；全部退出要求“公司累计现金回款≥1.10×实际总成本”。比例和金额仅是本案参数。可迁移的是**不同目的使用不同判断标准，并求出可批准的临界条件**。

## 如何用于新题

1. 完整读新附件，找出足以改变权利、金额或动作的竞争解释，并定位作答者可见的裁决依据。确有多解则保留条件分支。
2. 选择材料能支撑的公司业务决定，明确谁使用成果、要执行什么；不要先固定“意见＋底账”再凑事实。
3. 必要时明示模拟交易、预算、付款、时点或新证据，补足可求解条件；原始未知仍保留，不用模拟值恢复原件。
4. 让关键事件影响下游结果，同时保留独立争点。既考该阻断什么，也考满足什么条件就能办理；不强迫所有任务串成一条链。
5. 先独立求解每个方案、临界条件和变化后的结果，再完成实际文书。检查同一结果在不同成果中的一致性。
6. 按独立专业结果写考点，要求结论与决定性依据对应，接受合法等价路径；基础摘抄不能覆盖主要分值，同一上游算错不机械重复处罚。
7. 用“只摘抄、只讲原则、全拒、全待核、只报文件名、变化后照抄原方案”的简化答案检查能否绕过核心工作。核对通过标准是否超出题面任务。

迁移示例：工程款争议可用验收、付款申请和实际付款记录，考支付条件与扣款后的真实余额；供应商和解可用原合同、变更审批和履行记录，考折价结清与保留索赔的不同门槛。两者均不需要复制抵押、三笔付款或本案文书数量。

## 不能丢的边界

- 新材料重新定法律版本、效力、期间及证据优先关系；不将本案正确结论当通用法律答案。
- 保留材料原意、脱敏形式及可见矛盾，不人为删字段、破坏表格或藏关键证据；题面说明工作，不替作答者宣布哪个附件错了。
- 经济测算通过不替代权利核验、特别授权、交割资金及文件控制；普通准备工作不必随处分条件缺失全部暂停。
- 本案存在2023年模拟决策引用2024年卷内记录的时间边界。新题要明确回溯评价或限定当时可见信息，不继承未来信息进入早期判断的问题。
- 金额、比例、案件类型、成果份数、考点数和模型配置按新任务确定；不把“五份成果、20项考点、3/20、low档位”变成固定配方。
