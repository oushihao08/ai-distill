# 本期成果输出

这里保存用户手动生成、供工作流外使用的项目成果。当前提供单题脱敏材料 DOCX：常规流程完成并发布后，在题目详情页点击“生成脱敏 DOCX”，文件写入 `outputs/<题目目录标识>/脱敏材料.docx`。

DOCX 只由数据库中当前有效的脱敏合并文本生成，保留附件分界和原附件页码；不读取原始 OCR 文本，不改写 `questions/` 中的源 PDF，也不自动上传到第三方网站。该导出不创建工作流步骤或尝试，不改变发布、返修或其他流程状态。

本目录及其中生成的文件不作为提示词、规则、题目附件或后续入库输入。`outputs/` 下生成文件默认被 Git 忽略；DOCX 的关联尝试、脱敏指纹和下载权限由数据库 artifact 记录及服务端当前版本检查维护。需要重新生成时可再次点击导出按钮，当前题目只保留一份当前 DOCX。
