## 目录文件清单与保护边界

此项目的 `project.json` 是严格 JSON 格式，登记目录路径、来源文件指纹、评测草稿和本地决定；JSON 不支持注释，字段用途由本段和上方材料表说明。`materials/` 包含本 README「材料说明」表中的七份项目规则／整理文件。`skill/` 包含 `SKILL.md`、`assets/案例模板集.md`、`assets/题目模版.md`、`assets/案例1-债权受让与分段解押.md`、`assets/成功案例索引.md`，以及 `references/出题设计方法.md`、`失败模式与自检清单.md`、`评分与难度验证.md`、`资料索引.md`、`题目格式与交付.md`、`模板参考与迁移.md`。

`updates/inbox/`存放需要核对的群消息原文、会议纪要或导出快照；现有两份第五期会议记录已移入此处。每条记录尽量保留来源群、消息链接/编号、发送者或发布角色、发布时间、抓取时间及上下文；缺失项标为未知。此目录默认不纳入 Git，也不进入新任务输入。`reports/updates/`按日期保存更新分析；报告链接原始消息并说明与当前资料的差异。待核实或冲突内容不得直接并入项目资料或题目事实。现阶段没有登记具体群入口或自动巡查配置，因此这些目录只建立归档和报告约定，不代表已接通群消息抓取。
