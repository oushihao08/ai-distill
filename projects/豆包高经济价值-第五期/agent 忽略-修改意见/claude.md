## 新版会更难吗

**方向是更难，但幅度有限，而且难度主要来自"不给提示"，不是"删规则"。**

- **删规则影响不大。** 题目4 失分的几条（重复回单去重、王**三条责任路径、上诉期推算过程、内部追偿、读题比较）都是跨材料对齐或读题问题。期间顺延、夫妻债务解释这类规则，强模型本来就会，答案里 R5、R7 也拿了分。
- **真正加压的是这三处：**
  - 不再逐一提示异常类别。旧题面写了"名称、付款、人员、程序和日期差异"，等于给了 R3 一份目录。
  - 按生成链判断来源独立性。
  - 关系型考点要求写明决定性证据关系和可接受的替代口径。
- **新版更能防止"假难度"。** 题目4 的加倍部分就有口径张力：题面规则写的是"除一般债务利息外的金钱债务"，模拟条件又限定为尚欠本金，标答只好另注固定利息带来约 24.31 元的差异。新版"模拟约定不当然改变法定口径"的要求，会逼作者在出题阶段处理这个冲突。

## 距离 85+ 的缺口

1. **"写什么、不写什么"没有集中。** 散在出题设计方法、题目格式、SKILL.md 三处，且重复多次。建议合成一张清单。
   - 必写：决策时点、适用法律时点、模拟条件、计算端点与舍入、成果与接收人。
   - 不写：法条讲解、来源、异常类别、解题路线。
2. **删规则的责任没闭环。** 现在只说"按实际工具能力确定"。应要求作者检验：作答者仅凭当时公认的法律，能否推出标答。少见规则尤其需要。
3. **没有强制试答。** 难度验证依赖已提供的作答，首次出题时没有。建议要求用无提示作答者试答一次，逐条判断偏差是模型错还是标答漏。
4. **案例支撑单薄。** 只有一个债权受让案例，模板集里的第 3、5 类带工程和采购色彩，离判决救济、期限类题较远。题目4 的失分分布（R2、R4、R6、R8、R9、R10、R17、R20）正好可以收成第二个案例。
5. **缺少对算术点占比的约束。** "难倒 AI"是唯一目标，又强调"数量不限制展开"，容易堆任务量。建议规定：口径已全部给定的算术，只拆成少数几条，把分值留给证据关系和条件判断。

**总的来说，新版方向对、防错更强，但"更难"目前只是设计推断，需要一次无提示试答来证实。**
