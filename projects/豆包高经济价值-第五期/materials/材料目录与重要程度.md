# 豆包高经材料目录与重要程度

以后出题先看 `出题问题.md`，再看 `题目规范.md` 和 `官方评分标准.md`。本题成稿在 `豆包高经出题/出题 1/题目.md`。下面是仓库里其余文件的存档说明。带「图片提取」的是截图 OCR，和飞书冲突时不用。

重要程度：必读 > 高 > 中 > 低。低的只作存档，不拿来定规则。

## 必读（官方正文）

| 文件 | 干什么 | 为何必读 |
| --- | --- | --- |
| `高经济价值五期任务说明文档.md` | 本期目标、字段、行业/职业/任务类型、合格线、禁止项 | 出什么题、填什么字段、行业怎么锁，都在这里 |
| `C端任务全流程操作指南.md` | 领题、填表、交题、质检、返修 | 飞书表怎么操作；先填账号再写内容 |
| `高经济价值任务难度突破指南.md` | 分数、轮数、时长怎么做上去，难点怎么埋 | 题够不够难，按这份改材料和考点 |
| `从零开始行业专家的Prompt与Rubrics写作实战指南.md` | Prompt 的 R-T-C-O-F，考点怎么写 | 题面写什么、考点怎么拆 |
| `官方评分标准.md` | 从飞书正文抽出的五期判分口径 | 考点怎么打 0 和 1，只认这份，不另起一套 |
| `题目规范.md` | 作答思路和标准答案怎么写才像承办人，以及评分引用哪一份 | 禁止表格腔和考点口吻抄进标答 |

## 高（操作纪律和讲解）

| 文件 | 干什么 | 为何重要 |
| --- | --- | --- |
| `群聊通知-高经五期出题启动.md` | 收题截止、最多 8 题、自测模型；AI使用按本地负责人覆盖决定 | 和说明文档一致的执行口径，含 10 月 8 日截止 |
| `难度提升会议纪要.md` | 难度来自真实任务；模型只看 prompt 和附件；四个设计点 | 补突破指南：证据冲突、藏判断标准、规则叠加、局部无解 |
| `优秀案例讲解会-程前AA录播纪要.md` | 15 份判决书、天然气清洗两道题怎么埋点；答疑 | 法律类怎么埋难点，以这份为准，不要用图片提取里的「十五秒提炼」 |
| `公司法务出题心智.md` | 只做公司法务出题的固定边界和停止条件 | 身份、行业锁、职业、禁止项；选题仍靠真实拍板，心智本身不是案例库 |

## 低（勿当规则）

| 文件 | 干什么 | 为何低 |
| --- | --- | --- |
| `图片提取-C端任务全流程操作指南.md` | C 端指南截图 OCR | 残页，用词有误；用飞书那份 |
| `图片提取-高经济价值五期任务说明文档.md` | 五期说明截图 OCR | 任务类型、行业、每周五提交和飞书正文不是一套 |
| `图片提取-Prompt与Rubrics写作实战指南.md` | Prompt 指南截图 OCR | 框架认成 R-T-C-O-E，和飞书正文不符 |
| `图片提取-高经济价值任务难度突破指南.md` | 难度指南截图 OCR | 分数写成 Scaling Law，不可用 |
| `图片提取-一道好题是怎么构成的.md` | 「十五秒提炼」「四套供气批不批」OCR | 和录播里的 15 份判决书、天然气案例不是同一套 |
| `图片提取-优秀例题demo1.md` | EIP 数据同步方案 OCR | 另一道示例，不是法律案例 |
| `个人经验-用GPT代写并三家模型压分.md` | 某人用 GPT 代写、AI 脱敏、三家模型压到 45 分 | 个人经验只作对照，评分与交付仍以本期正式标准为准 |

## 日常怎么用

1. 填表、领题、交题：C 端指南 + 群通知。
2. 题写什么：五期任务说明 + 公司法务出题心智。
3. 题够不够难：难度突破指南 + 两场会议纪要。
4. 附件：本地工作流允许按项目负责人的覆盖记录使用 AI 出题、脱敏和制作附件；遵守材料追溯和质量检查要求。外部提交资格另按平台现行规则确认。
5. 冲突时：飞书四份正文 > 会议和群通知 > 心智 > 其余。
