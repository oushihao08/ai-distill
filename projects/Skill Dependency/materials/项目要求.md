# Skill Dependency 项目要求（2026-10-12版归档摘录）

适用范围：本项目出题与本地交付。来源为[钉钉文档完整归档](../../../执行观察/alidocs-project-archive-20261108/archive/全过程索引.md)；本文件只提炼能够从归档核实的规则，不取代原页面及后续项目方更新。

- 一题包含 Instruction、Input Files、Rubric、Golden Answer、1—3份作答 Skill 文件和 Metadata。真实业务任务应由输入材料触发 Skill 独有规则；Instruction 明确要求使用 Skill，但不得泄露决定性规则。Rubric 检查规则执行对实际成果的影响。
- 项目覆盖多个领域和复杂度；同一知识点或工作流不得重复堆题。单题文件数与步骤数是复杂度参考，不代替材料必要性或产物质量。
- 平台验收的带／不带 Skill 分差门槛为至少20%，并有 S1/S2/S3 等级；无 Skill 三模型均分低于0.6且至少一个非零，Golden Answer 得分不低于0.85。这些是后续实测要求，不是作者可凭文字声明的成绩。
- 本地直交包只证明六类内容可生成和取回。镜像、模型调用、平台审核与结算分别凭对应回执核实。归档中的示例模型名称和价格说明不自动成为当前期次配置。

当前第一期采用法律材料试制一题。其他领域的材料与 Skill 规则应按实际来源扩展，不把这次案件事实写成全项目默认题型。
