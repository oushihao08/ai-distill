# Skill Dependency 出题

本文件供作者使用。题包中的 `skill_files` 是另行编写、交给作答者的 Skill。每题必须让其中的特有规则实际改变判断、参数、顺序、停止条件或成果；使用过 Skill、增加文件数和写长题面都不证明依赖或难度。

## 输入与顺序

只读本次冻结附件、材料整理结果和 `input/delivery.json`；完整阅读附件，摘要仅用于定位。先按[场景与材料](references/材料方向场景与交付设计.md)和[设计方法](references/出题设计方法.md)盘点工作，求解并按[评分与依赖验证](references/评分与难度验证.md)检查，再用[表述方法](references/表述方法.md)成稿。字段和文件按[本项目模板](assets/题目模版.md)反查，JSON以运行时 schema 为准。[资料索引](references/资料索引.md)仅按需导航。不得读取历史题目、答案、成绩或个人记忆作为新题输入。

## 设计任务与逐题 Skill

1. 从当前材料确定谁为谁完成什么工作、成果给谁使用，以及真实缺口和可办边界。按用途确定文件与读回方式。材料不足以支持专业任务时重选方向，不删决定性事实制造难度。领域由材料决定，不默认法律、执行、计算或固定成果套餐。
2. 先求最简正确解及有依据的竞争解释。从接收人要使用的专业结果反推共同必要的来源判断、规则适用、条件选择和成果落实；同一结果由多项判断共同决定时保留其复合关系，不把日期、数字或格式各拆成简单考点。识别共同约束、部分状态、未知条件和必要的前后承接；仅在输入支持时加入连续办理或标明的模拟事件。难度来自专业选择及成果使用，不来自重复步骤、隐蔽信息或苛刻扣分。
3. 编写1—3份独立可用的作答 Skill。每份写清适用范围、输入、触发规则、优先级、步骤、例外、等待或停止状态、输出、完成检查与来源版本。特殊规则须有依据；获准模拟规则明示模拟身份，不伪称机构政策。停止哪项动作和仍可完成什么工作须分清。多 Skill 各有必要作用，不机械拆分。
4. 在作者私有记录逐条建立“Skill规则位置→附件触发位置→无规则时的具体错误→规则改变的成果→Rubric项”。无 Skill 检查保持其余输入不变；关键规则改写检查只改一条规则并求出变化与不变结果。若无 Skill 仍能完成，或规则改写不改变实质成果，重设计任务或 Skill。题面、附件和模板不能泄漏决定性规则；真实源文件若已公开规则，就调整所测依赖。

## 题面、答案与评分

Instruction 写真实场景、角色、材料、Skill使用要求、实际成果和单列的硬约束，不提前揭示正确路径。Golden Answer 完成题面全部工作；要求文件时提供完整 `golden_files`，名称、内容、公式及跨文件口径一致。输入只有文字投影时不考不可见图像、批注或原始公式；不能把投影称作原件。实际打开、重算、渲染按真实工具结果记录，不能执行就标缺口。

本项目 Rubric 按独立、明确、可验证的专业结果判断 Skill 特殊规则在成果中的作用；一项结果可以包含共同决定其可用性的多个必要判断，不能把无关结果捆在一起。接受合法等价方法及有依据的条件分支；共同上游错误不重复处罚。按[评分规范](references/评分与难度验证.md)填写平台权重、档位和领域内容占比。豆包的等权百分制、整题归零和法律固定题型不适用于本项目。

## JSON与交付

按运行时 `input/delivery.json` 的 schema 保存 `output/result.json`，不添加未声明字段。`question`、`reference_answer`、`rubric` 保留公共契约；`skill_files`、`golden_files`、`metadata`、`task_requirements` 和 `delivery_contract`、`platform_metadata`、`platform_rubric` 按[模板](assets/题目模版.md)填写。公共 `rubric` 的 id/criterion 与平台项的 id/description 一致，`max_score`只服务本地兼容；正式权重保存在 `platform_rubric`。`answer_requirements` 仅反映本地被测器能力，真实任务能力写 `task_requirements`。

`delivery_contract`逐项声明实际输入、Skill、成果，记录无 Skill 和规则改写检查及核验结果。未执行的核验写 `not_performed`；交付入口会拒绝不完整的 v2 题包。XLSX公式写成 `{formula,cached_value}`，不能用以等号开头的字符串冒充可计算单元格；公式写入不等于实际重算。不得编造平台编号、专家背书、模型分数或验收回执。

交卷前用模板反查六类成果、实际文件、依赖触发、评分引用和版本。作者推演不等于带／不带 Skill 模型实测；平台的20%增益、无 Skill 均分、Golden Answer得分及S等级只能由真实回执判断。未取得批次记录时不声称知识点去重完成。
