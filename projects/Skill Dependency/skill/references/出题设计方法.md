# 任务设计与专业难度

## 任务盘点与范围确定

阅读全部冻结附件后，在作者私有工作记录列“可办工作、触发材料、接收人、成果用途、纳入或排除理由”。先求最简正确答案；若主要靠摘抄、常识或已给公式完成，寻找真正会改变成果的专门规则。不能隐藏必要输入、排斥合法捷径或凭作者预测的模型错误制造难度。

## 专业工作链

对每个独立成果建立“可见记录→待判断关系→适用条件→处理选择→成果正文”。检查主体、时点、来源、版本、部分状态和不确定条件。根据材料处理有依据的竞争解释；无法唯一确定时写可执行条件分支，不猜作者意图。各成果的数字、状态和结论相互一致。

先按接收人的实际用途确定要成立的专业结果，再反推哪些判断共同决定该结果可否使用。对每个必要判断写清可见触发、处理选择及遗漏后对结论、范围、条件或正文的具体影响；基础摘录、日期、计算和格式随其支撑的结果验收，不凭可单独检查就各立一题或一条分。两个结果若有不同的使用人或后续动作，且各含新的实质判断，则分别交办和验收；仅因同案或同文件也不强行合并。前项结果改变后项输入、规则选择或成果内容时，明确两项如何承接；无实际依赖的工作可并行。

当成果会持续使用且材料支持反馈或变化时，给出明确来源、时点和内容的后续事件，要求在已有结果上实际修订。只改一个数字、重复导出文件或列未来建议不算完整续办。静态任务不为增加步骤虚构新事件。模拟输入明示身份，不改写冻结原件。

## Skill设计与反事实

把作答 Skill 写成可迁移的条件规则：输入、触发、动作、优先级、例外、停止与恢复。规则必须有真实或获准模拟的依据，不能是本题答案的改写。对每份 Skill 做两项作者检查：

1. 去掉 Skill，保持题面、附件和工具不变，指出可取得与不可取得的结果及具体错误。专业常识足以推出全部结果时依赖不成立。
2. 只改一条关键规则，固定其余事实，求出具体变动与不变的结果。只改变措辞或内部步骤、不影响成果时重设计。

记录规则位置、输入触发位置、错误路径、成果变化及Rubric项。题面不泄露决定性规则；答案和评分文件不进入作答输入。作者检查不是模型对照实测。

冻结前以完整正确解、合法等价解、只漏一个必要判断的近似解和只套通用模板的解反查：完整解与等价解应满足对应结果；近似解若仍可形成可用成果，所漏判断不是必要条件；通用模板若已完成主要成果，应重选或深化材料支持的工作。不得删除可见必要输入、排斥正确捷径或靠加重扣分制造难度。

## 有效工具与文件

检索用于查权威规则，计算用于求解变量，文件工具用于制作可使用成果，读回用于证实内容或数据。工具选择由任务需要决定，不设调用配额。文件题保持输入、公式、生成文件和最终结论一致；工具缺失时如实报告执行缺口，不捏造回执。
