# 题包表述方法

先完成材料盘点、规则设计、求解和判据，再组织文字。任务名称概括实际业务，不泄露结论；Instruction交代对象、动作、成果及硬约束；Skill写执行规则；Golden Answer写完整可用结果；Rubric写独立可复核的判据。内部反事实记录放`delivery_contract`，不作为题面解题提示。

按接收人的实际用途选择自然办公文体。专业判断可分段说明，但不要套固定行业术语或豆包法律文书措辞。文件名和业务对象前后一致；语句简短不意味着缩减任务、结论或核验义务。复核改写前后的事实、条件、成果与评分含义，防止表达润色改变正确答案。

已保存题目若仅获授权润色，保留其委托范围、材料身份、Skill关键规则、答案及Rubric判定；实质变化按新出题或返修处理。
