# 本项目作者资料索引

本目录只服务当前题目。作者先按 `SKILL.md` 阅读冻结附件，再按下列职责取用方法；这些文件不是作答者 Skill，也不作为材料事实。

| 文件 | 用途 |
| --- | --- |
| `材料方向场景与交付设计.md` | 从材料和成果接收动作确定真实任务及范围 |
| `出题设计方法.md` | 盘点、求解、依赖规则与必要专业难度 |
| `评分与难度验证.md` | 本项目原子 Rubric、规则依赖和实测边界 |
| `题目格式与交付.md` | 六类交付及文件核对 |
| `表述方法.md` | 将已确定的内容写成自然业务文字 |
| `../assets/题目模版.md` | 逐题字段与一致性反查，不预填答案 |
| `../assets/书面表达组合库.txt` | 可选写法，不决定题型或评分 |

原始要求见项目 `materials/项目要求.md` 和归档。运行时 JSON schema 是实际字段契约；外部平台格式与本地映射要分别核验。
