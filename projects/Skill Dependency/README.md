# Skill Dependency

适用于本主项目的维护者和出题作者。第一期使用全局材料库的冻结材料快照；`materials/` 保存项目方规则来源，`skill/` 是作者出题规则，`scripts/` 放本项目的交付转换。作答模型使用的 Skill 是逐题产物，不等于这里的作者 Skill。

本项目以真实业务任务为基础，每题交付 Instruction、Input Files、Rubric、Golden Answer、Skill 文件及 Metadata。材料整理只提供候选范围；作者须依据本题全部冻结附件决定任务，说明 Skill 特有规则如何改变可观察的专业结果。题目不得把决定性 Skill 规则泄入 Instruction。原始项目要求见[本地归档](../../执行观察/alidocs-project-archive-20261108/archive/全过程索引.md)。

本期目标为材料整理、出题和本地交付。带／不带 Skill 的模型跑分、平台提交和人工验收是后续独立状态；本地交付包不能冒称已通过这些门槛。项目运行状态以本机 API 回读为准，不从目录存在推断数据库期次已建立。

| 路径 | 职责 |
| --- | --- |
| `materials/项目要求.md` | 从完整归档提炼的当前项目规则及验收边界；原始归档保存在 `执行观察/alidocs-project-archive-20261108/archive/` |
| `skill/SKILL.md` | 供作者 Agent 读取的项目出题入口；按需引用 `references/` 的材料、设计、评分、交付和表述规则 |
| `skill/assets/题目模版.md` | 逐题字段与六类内容反查模板；不能预填业务答案 |
| `skill/assets/书面表达组合库.txt` | 业务表达参考，不决定题型或评分 |
| `scripts/README.md` | 出题后本地直交入口及文件核对边界 |

维护边界：项目规则和作者 Skill 只影响之后新派发的出题任务；已保存题目仍使用其冻结输入。不得把其他项目的固定题量、rubric 或平台字段复制到本项目。

当前原始归档包含页面、图片及附件。模型版本、结算单价及镜像细节可能随平台变更；归档日期的要求不能冒称平台当前验收。案件材料经全局材料库加载，不复制进本目录。

## 作者规则适配（2026-11-08）

作者 Skill 已吸收豆包的材料盘点、专业判断、成果用途、连续处理及完整求解方法，并按本项目增加逐题 Skill 编写、无 Skill 检查、关键规则改写、防泄漏与按独立专业结果划分的复合判断。规则在本项目维护，不运行时引用豆包目录；新任务读取当前 Skill，旧题不自动变化。

本轮验收为规则静态核对：输入、六类成果、两项依赖检查、正式评分规则与本地 schema 边界均已写入作者入口。未派发新题或实测模型增益。后续v2改动已增加平台字段映射、交付检查及显式XLSX公式写入，见[scripts说明](scripts/README.md#v2交付检查)。公式写入不等于实际重算；平台上传兼容与新题业务验收仍待验证。

## 复制 Skill 的项目化改造（2026-11-08）

本次复制的豆包参考文件已逐份改为 Skill Dependency 作者规则，保留材料盘点、最简求解、必要专业判断、成果反查和自然书面表达的方法。逐题 Skill 规则触发、无 Skill 与规则改写检查、六类交付、原子 Rubric、正式权重和平台字段分别写入作者入口与模板。`skill c/` 是用户留存的副本，不是当前期次配置的作者 Skill 路径，本轮未修改。

静态检查覆盖全部当前 Skill 文件与引用；本轮未派发新题、重启服务或验证平台验收。旧题按原冻结输入保留。
